# プロシージャル模様_H

雲・縞・セル・六方格子・反応拡散の 5 つの基本形から、
つまみの組み合わせで大理石・等高線・網点・煙・霜・光の筋などの模様を作るカスタムオブジェクトです。
画像素材を用意せずに、資料の背景・文字の中身・合成で重ねる質感素材を作れます。

模様は **基本形 → 歪み → 整形（階調）→ 出力レベル** の順に作られます。
基本形を選び、残りのつまみで形を変えていく作りです。
よく使う組み合わせは 22 個のプリセットとして同梱しています。

- `Script/プロシージャル模様_H.obj2`（v1.10）

## インストール

1. 次の 3 つを配置する。

   | ファイル | 置き場所 |
   |---|---|
   | `プロシージャル模様_H.obj2` | `Script\` |
   | `EffectUtils_ColorGrade.lua` | `Script\`。無いと動きません |
   | `EffectUtils_ColorSpace.lua` | `Script\`。色空間を sRGB 以外にするときに必要です |

2. プリセットが必要であれば `Preset\プロシージャル模様_H.*.preset` も配置する。
3. AviUtl2を起動する。
4. オブジェクトの追加の **カスタムオブジェクト** から **HexScript → プロシージャル模様_H** を選ぶ。

## 使い方

1. プロシージャル模様_Hを置く。初期値では、1920 × 1080 の淡い灰色の雲模様が出る。画面サイズには自動で合わせないので、幅・高さで決める。
2. **基本形** で模様の種類を選び、**大きさ** で模様の粗さを決める。
3. 形を崩すなら **歪み量**、明暗の付け方を変えるなら **階調** を使う。
4. 最後に **振幅** と **基準** で明るさの幅を、**暗色** と **明色** で色を決める。

初期値の **振幅 10** は、明るさを狭い幅に抑えた「背景向けの淡い模様」です。
はっきりした模様が欲しいときは、振幅を 100、基準を 50 にします。

出力は常に不透明です。
ほかの絵に重ねるときは、標準描画の **合成モード** で重ねます。

### プリセットを使う

オブジェクト設定のアイコンメニューからプリセットを選ぶと、全部の項目がそのプリセットの値になります。**幅・高さも 1920 × 1080 に戻ります。**
オーバーレイ用のプリセットの名称に付いている合成モードは、プリセットでは設定されません。
標準描画の合成モードを自分で合わせてください。

### 用途 1: 資料の背景

振幅を 4 ~ 12 程度に小さくして、文字の後ろに置いても邪魔にならない淡い模様にします。
プリセットの「資料の背景」がこの使い方です。

### 用途 2: 文字やロゴの中身（クリッピング素材）

1. 文字やロゴを上のレイヤーに、プロシージャル模様_Hをそのすぐ下のレイヤーに置く。
2. プロシージャル模様_Hの「上のオブジェクトでクリッピング」を有効にする。
3. **大きさ** で、模様の粒が文字の線の太さの 1/3 ~ 1/8 くらいになるように合わせる。
4. 色は **暗色** / **明色** で付けるか、後から色調補正などで載せ替える。

プリセットの「クリッピング」がこの使い方です。

### 用途 3: 合成で重ねる質感素材（オーバーレイ）

振幅 100・基準 50 にして明暗をはっきり出し、**階調** の「累乗」や「閾値」で中間の明るさを減らしてから、合成モードで重ねます。
中間の明るさが多いと、どの合成モードでも「全体が霞んだだけ」に見えます。

- スクリーン・加算で重ねるなら、黒地に明るい線や点
- 乗算で重ねるなら、白地に暗い線。**暗色と明色を入れ替える**

プリセットの「オーバーレイ」がこの使い方です。

## パラメータ

**基本形や階調によって、関係のない項目は隠れます。**
「常に」とある項目は、使わない基本形でも表示されたままです。

### 出力サイズ

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 幅 | 16 ~ 4000 px | 1920 | 作る画像の幅 |
| 高さ | 16 ~ 4000 px | 1080 | 作る画像の高さ |

### 基本形

| 項目 | 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 基本形 | 雲 / 縞 / セル / 六方格子 / 反応拡散 | 雲 | 模様の元になる形 |

- **雲**: ふわっとした濃淡のノイズ
- **縞**: 平行な縞。向き 0 で縦縞、90 で横縞
- **セル**: 点をばらまいて、いちばん近い点ごとに区切った領域
- **六方格子**: 蜂の巣状に並んだ点
- **反応拡散**: 2 つの物質が反応しながら広がる計算を繰り返して作る、斑点や迷路のような模様

### 形

| 項目 | 範囲 | 初期値 | 表示 | 説明 |
|---|---|---|---|---|
| 大きさ | 1 ~ 400 | 100 | 常に | 模様の大きさ。100 で、画像の短辺におおよそ模様 4 つ分。大きいほど粗い |
| 縦横比 | 10 ~ 1000 | 100 | 常に | 100 で縦横同じ。上げると模様が縦に引き伸ばされ、下げると横に伸びる。伸びる方向は **向き** で回る |
| 向き | -180 ~ 180 度 | 0 | 常に | 模様の向き |
| シード | 0 ~ 9999 | 0 | 常に | 模様の出方を変える種 |

### 粒度

雲と、歪み・縞の不均等の揺らぎに使います。**歪みを掛けていないセル・六方格子・縞・反応拡散には効きません。**

| 項目 | 範囲 | 初期値 | 表示 | 説明 |
|---|---|---|---|---|
| 重ね回数 | 1 ~ 6 | 3 | 常に | 細かい揺らぎを何段重ねるか。多いほど細部が増える |
| 減衰率 | 0.20 ~ 0.80 | 0.40 | 常に | 細かい段をどれだけ強く重ねるか。大きいほどざらつく |
| 周波数倍率 | 1.50 ~ 3.00 | 2.00 | 常に | 1 段ごとにどれだけ細かくするか |

### 歪み

すべての基本形に掛かります。

| 項目 | 範囲 | 初期値 | 表示 | 説明 |
|---|---|---|---|---|
| 歪み量 | 0 ~ 300 | 0 | 常に | 模様を揺らがせてゆがめる量。0 なら歪ませない |
| 歪みの大きさ | 10 ~ 800 | 200 | 常に | ゆがみの波の大きさ。大きいほど長い波でゆるくうねり（風紋）、小さいほど細かく乱れる（大理石）。歪み量が 0 のときは効かない |
| 歪みの反復 | 1 ~ 8 | 1 | 常に | 歪みを何回に分けて掛けるか。1 なら大理石、3 ~ 8 で筋が伸びて渦を巻くマーブル模様になる。回数を増やしても全体の歪み量は変わらない。歪み量が 0 のときは効かない |

### 縞

| 項目 | 範囲 | 初期値 | 表示 | 説明 |
|---|---|---|---|---|
| 不均等 | 0 ~ 200 | 0 | 基本形が縞のとき | 縞をまっすぐに保ったまま、1 本ずつの太さをばらつかせる（地層） |

### セル

| 項目 | 範囲 / 選択肢 | 初期値 | 表示 | 説明 |
|---|---|---|---|---|
| セル出力 | 距離 / 境界 / セル番号 | 境界 | 基本形がセルのとき | 距離: 点の近くが暗く、離れるほど明るい丸い塊。境界: 区画の境目が暗い線になる。セル番号: 区画ごとに違う明るさで平らに塗り分ける |
| ばらけ | 0 ~ 100 % | 80 | 基本形がセルのとき | 点の散らばり方。0 なら正方形の格子に整列する |

### 六方格子

| 項目 | 範囲 / 選択肢 | 初期値 | 表示 | 説明 |
|---|---|---|---|---|
| 格子出力 | 点 / セル距離 / セル番号 | 点 | 基本形が六方格子のとき | 点: 丸い点（水玉）。セル距離: 点の中心が明るく、点の縁で暗くなる勾配（鱗・タイルの陰影）。セル番号: 区画ごとに違う明るさで平らに塗り分ける |
| 点の大きさ | 0 ~ 100 % | 40 | 基本形が六方格子のとき | 隣の点との間隔に対する点の直径。セル番号のときは効かない |
| 大きさのばらつき | 0 ~ 50 | 0 | 基本形が六方格子のとき | 点ごとに、大きさを ± この % の範囲で変える |

### 反応拡散

| 項目 | 範囲 | 初期値 | 表示 | 説明 |
|---|---|---|---|---|
| 供給率 | 0.010 ~ 0.090 | 0.055 | 基本形が反応拡散のとき | 模様の種類を決める値の 1 つ。除去率との組み合わせで、斑点・迷路などの出方が変わる |
| 除去率 | 0.040 ~ 0.075 | 0.062 | 基本形が反応拡散のとき | 同上 |
| ステップ数 | 100 ~ 2000 | 800 | 基本形が反応拡散のとき | 計算を繰り返す回数。多いほど模様が育つ |

初期値の供給率・除去率で 1200 ステップ回すと、迷路状の模様になります。

### 整形

| 項目 | 範囲 / 選択肢 | 初期値 | 表示 | 説明 |
|---|---|---|---|---|
| 階調 | 連続 / 段 / 線 / 累乗 / 閾値 | 連続 | 常に | 明暗の付け方。下の説明 |
| 段数 | 1 ~ 32 | 8 | 階調が段・線のとき | 段: 明るさを何段に分けるか（1 は 2 と同じ 2 値）。線: 何段の境目に線を引くか |
| 線幅 | 0.5 ~ 20.0 | 2.0 | 階調が線のとき | 線の太さ（おおよそ px） |
| 指数 | 0.1 ~ 32.0 | 4.0 | 階調が累乗のとき | 大きいほど暗い部分が広がり、明るい部分だけが残る。1 より小さいと逆に明るくなる |
| しきい値 | 0 ~ 100 % | 80 | 階調が閾値のとき | これより明るい部分だけを明るく、ほかを暗くする境目 |
| 柔らかさ | 0 ~ 50 % | 5 | 階調が閾値のとき | しきい値の境目のぼかし幅。0 に近いほどくっきり 2 値になる |
| コントラスト | -100 ~ 100 | 0 | 常に | 明暗の差。階調より先に掛かる |
| 反転 | ON / OFF | OFF | 常に | 明暗を反転する。コントラストの後、階調より先に掛かる |

- **連続**: そのまま
- **段**: 段数ぶんの明るさに分ける。段数 1 は段数 2 と同じ 2 値になる
- **線**: 段の境目にだけ線を引く。明るさが平らな部分には線が出ない
- **累乗**: 暗い部分を潰して明るい部分だけを残す。スクリーン・加算で重ねる素材向け
- **閾値**: しきい値より明るい部分だけを残す

コントラストはプラスで強まり、100 で明暗の差が 4 倍になります。
マイナスで弱まり、**-100 で平らな灰色**になります。明暗は反転しません。
明暗を反転したいときは **反転** を使ってください。

### 出力レベル

| 項目 | 範囲 | 初期値 | 表示 | 説明 |
|---|---|---|---|---|
| 振幅 | 0 ~ 100 % | 10 | 常に | 暗色から明色までのうち、模様が使う明るさの幅。10 なら基準を中心に幅 10% に収まる。100 で暗色から明色まで使い切る |
| 基準 | 0 ~ 100 % | 50 | 常に | 模様の明るさの中心。0 で暗色寄り、100 で明色寄り |
| 暗色 | - | 000000 | 常に | 模様のいちばん暗い部分の色 |
| 明色 | - | ffffff | 常に | 模様のいちばん明るい部分の色 |
| 色空間 | sRGB / リニア / Oklab / HSV / HSL / Lab / LCh / Oklch / HWB | sRGB | 常に | 暗色と明色の間の色を混ぜる色空間 |
| 色相経路 | 短経路 / 長経路 | 短経路 | 色空間が HSV / HSL / LCh / Oklch / HWB のとき | 色相を回す向き |

**色空間**は v1.10 で足しました。初期値の sRGB は v1.02 までと同じ色です。

| 色空間 | 向いている使い方 |
|---|---|
| sRGB | 今までと同じ混ぜ方 |
| リニア | 光の混ざり方に近い。明るい側が広がる |
| Oklab / Lab | 見た目の明るさが均等に変わる。補色の 2 色の中間がくすみにくい |
| HSV / HSL / HWB / LCh / Oklch | 色相を回して虹色にしたいとき。赤 → 青 を 短経路 にするとマゼンタを、長経路 にすると黄・緑・シアンを通る。Oklch・LCh は色相が回っても明るさがそろう |

黒と白の間でも中間の明るさが変わります。縞を 黒 → 白 で描くと、Oklab の方が全体に暗く見えます。
赤 → 青 を HSV の長経路にすると、模様の中ほどに緑が出ます。

## 注意

- **出力は常に不透明**で、透明な部分は作れません。ほかの絵に重ねるときは合成モードを使います
- **模様そのものは時間で動きません。** 動かすなら、シードや歪み量などの項目のトラックを動かします
- 端と端をつないで並べても継ぎ目が出ない模様にはなっていません。1 枚の背景として使う前提です
- **反応拡散の模様は、大きさ 100 のとき画像の短辺 1 つ分ごとに同じ模様が繰り返します。**
  つなぎ目は出ませんが、横長の画像では同じ形が並ぶのが見えることがあります
- 反応拡散は毎フレーム計算し直します。1200 ステップのものを 2 つ並べたフレームで 25.5 ms でした
- 雲・重ね回数 6・歪み 80・累乗の 1920 × 1080 で、1 フレーム 15.8 ms でした
- v1.10 で設定項目を足しました。ファイルを入れ替えたときは、AviUtl2の再起動が必要です
- 色空間を sRGB 以外にしたとき、`EffectUtils_ColorSpace.lua` が `Script` フォルダの直下に無いとスクリプトのエラーになります
