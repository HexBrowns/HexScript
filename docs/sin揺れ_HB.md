# sin揺れ_HB

オブジェクトを細い帯に切り分け、帯ごとに少しずつずらした正弦波（sin）で左右（または上下）に揺らすアニメーション効果です。
旗や水面、陽炎のように、波が流れながら揺れる見た目になります。揺れは周期的で、乱数は使いません。

- `Script/sin揺れ_HB.anm2`（v1.10）

## インストール

1. `Script\sin揺れ_HB.anm2` を配置する
2. AviUtl2 を再起動する
3. オブジェクトに「sin揺れ_HB」を追加する（HexScript の中）

## 使い方

1. 揺らしたいオブジェクト（画像・テキスト・図形など）に「sin揺れ_HB」を追加する
2. **振幅** で揺れの大きさ（px）、**速度** で 1 秒あたりに揺れる回数を決める
3. **高さ** で、オブジェクトの端から端までに入る波の数を決める（100 で 1 波）
4. **細かさ** を小さくすると帯が細くなり、なめらかに曲がって見える
5. 根元を固定したいときは **揺れ抑制** を ON のまま、**抑制位置** で動かない位置を決める。全体を同じ大きさで揺らすなら OFF にする

### 例: 全体をゆったり波打たせる

実制作で使った設定です（画像に AutoClipping_S → リサイズσ の後に掛けた）。

| 項目 | 値 |
|---|---|
| 細かさ | 1 |
| 振幅 | 40 |
| 高さ | 50.00 |
| 速度 | 0.50 |
| 揺れ抑制 | OFF |
| ほか | 初期値 |

1 px ごとに揺れがずれるので、輪郭がなめらかに曲がります。オブジェクトの縦に半波ぶんの曲がりが入り、2 秒で 1 往復します。

### 例: 根元を固定して先だけ揺らす

初期値のまま（**揺れ抑制** ON、**抑制位置** 100）にすると、オブジェクトの下端が動かず、上へ行くほど大きく揺れます。
草・炎・吊り下げたものの揺れに向きます。上端を固定したいときは **抑制位置** を 0 にします。

## パラメータ

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 細かさ | 1 ~ 120 | 5 | 帯 1 本の太さ（px）。小さいほどなめらか、大きいほど段々に見える |
| 振幅 | 0 ~ 4096 | 50 | 揺れの大きさ（px）。この分だけオブジェクトの領域が左右（縦⇔横 ON では上下）に広がる |
| 高さ | 0 ~ 4096 | 100 | オブジェクトの端から端までに入る波の量（%）。100 で 1 波、200 で 2 波。0 だと全体が同じ位相で揺れる（揺れ抑制 OFF なら平行移動になる） |
| 速度 | 0 ~ 100 | 1 | 1 秒あたりに揺れる回数（往復）。0 で止まる |
| 縦⇔横 | ON / OFF | OFF | OFF は横縞に切って左右に揺らす。ON は縦縞に切って上下に揺らす |
| 揺れ抑制 | ON / OFF | ON | ON は「抑制位置」で揺れが 0 になり、そこから離れるほど大きく揺れる。OFF は全体が同じ振幅で揺れる |
| 抑制位置[0-100] | 数値入力 | 100 | 揺れが 0 になる位置。0 が上端（縦⇔横 ON では左端）、100 が下端（同 右端）。揺れ抑制が ON のときだけ効く |
| ｽﾞﾚ指定[Angle] | 数値入力 | 0.00 | 揺れの位相をずらす角度（度）。個別オブジェクトのテキストでは、1 文字ごとにこの角度ずつずれる |
| 動き向き | ON / OFF | OFF | ON で揺れの左右（縦⇔横 ON では上下）が反転する。波が流れる向きは変わらない |
| 透過 | ON / OFF | OFF | ON で帯ごとに透明度を変え、端から端へ透明から不透明へ変化させる |
| 透過向き | ON / OFF | OFF | OFF は上端（縦⇔横 ON では左端）が透明で下端が不透明。ON はその逆 |
| 透過補正[%] | 数値入力 | 0.00 | 透過の度合いに足す値。プラスで全体が不透明寄り、マイナスで透明寄りになる。透過が ON のときだけ効く |

「数値入力」の 3 項目はトラックバーではないので、時間で動かせません。

### 揺れ方の決まり方

帯ごとの揺れの大きさは、次の角度の sin に振幅を掛けたものです。

```
角度 = 360 × 高さ/100 × (帯の位置) + 360 × 速度 × 経過秒 + ズレ指定
```

「帯の位置」は上端（縦⇔横 ON では左端）が 0、反対の端が 1 です。時間が進むと、波は下から上へ（縦⇔横 ON では右から左へ）流れます。

**揺れ抑制** が ON のときは、振幅に「帯の位置 − 抑制位置/100」を掛けます。抑制位置 50 なら中央が止まり、
上下の端でも振幅の半分しか揺れず、上半分と下半分は逆向きに揺れます。

## 注意

- **振幅の分だけ、オブジェクトの領域が常に広がります**（揺れ抑制や速度 0 でも同じ）。後に掛ける効果や、
  オブジェクトの大きさを基準にする効果は、広がった後の大きさで動きます
- 広げた領域の外へはみ出した部分は切れます。抑制位置を 0 ~ 100 の外にすると振幅を超えて揺れ、端が切れます
- **細かさがオブジェクトの高さ（縦⇔横 ON では幅）より大きいと揺れません**（領域だけが広がります）
- 領域を広げるので、フィルタオブジェクトには使えません
- 透過は帯ごとの段階で変わります。細かさが大きいと透明度も段々に見えます
