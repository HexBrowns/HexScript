掛けたオブジェクトの範囲の中に、図形や画像の粒を**次々に出しては消す**フィルタ効果です。
アス（AVILITY）さんの `装飾パーティクル.anm2` を元にしています。
元の配布ページは https://avilityyy.blogspot.com/2025/11/decoParticle.html です。

元と同じ粒を同じ順番で描き、中の計算をまとめて**呼び出しを減らしました**。
元の「装飾パーティクル」と同じオブジェクトに並べても干渉しません。

粒 100 個で測った範囲では、速さは元とほぼ同じでした。
見た目は元と同じです。

## インストール

1. `Script\装飾パーティクル_H.anm2` を置く。
2. AviUtl2を起動する。
3. フィルタ効果の **HexScript → 装飾パーティクル_H** から追加する。

## 使い方

1. 粒を出したい範囲の大きさで図形などを置き、フィルタ効果「装飾パーティクル_H」を追加する。
2. **個数** の粒が範囲の中に出て、**表示時間[f]** の間表示され、**登退場[f]** のフレーム数で出入りする。
3. 粒の形は **図形／画像** と **図形** / **画像** で選び、**色** で色を決める。
4. 出入りの動きは **登場の動き** と **退場の動き** で付ける（8 つの数をカンマで区切って入力する）。

範囲を広げる・中を空けるときは **外領域** / **内領域除** を使います（4 つの数をカンマで区切って入力する）。
**領域可視化** をオンにすると範囲が見えます。

## パラメータ

### 粒

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 個数 | 1 ~ 100 | 16 | 同時に出す粒の数 |
| 表示時間[f] | 1 ~ 2000 フレーム | 60 | 1 つの粒が出ているフレーム数 |
| 登退場[f] | 1 ~ 2000 | 20 | 出入りにかけるフレーム数 |
| 表時ばらつき[%] | 0 ~ 100 | 100 | 表示時間のばらつき |
| サイズ | 1 ~ 2000 | 100 | 粒の大きさ |
| サイズばらつき[%] | 0 ~ 100 | 30 | 大きさのばらつき |
| 登退場カーブ | 0 ~ 1 | 0 | 出入りの速さの変わり方。この項目を 0 → 1 に移動させ、その移動方法の曲線を出入りに使う |
| 合成モード | 通常 / 加算 / 減算 / … | 通常 | 粒の合成モード |
| 色 | 色 | 黄 | 図形の色 |
| 図形／画像 | オン / オフ | オン | オンで図形、オフで画像ファイル。選ばなかった側の項目は隠れる |
| 図形 | 図形 | 円 | 粒の形（図形／画像がオンのときに表示） |
| 画像 | ファイル | なし | 粒に使う画像（図形／画像がオフのときに表示） |
| 透明度[%] | 0 ~ 100 | 0 | 粒の透明度。時間で動かせる |
| 回転の範囲[min/max] | ±360 ° | 0,0 | 粒の向きの範囲。「最小,最大」の順に 2 つの数を入力する |
| 縦横比の範囲[min/max] | ±100 | 0,0 | 粒の縦横比の範囲。「最小,最大」の順に 2 つの数を入力する |
| Z軸幅 | 0 ~ 1000 | 0 | 奥行きの散らばり |
| 徐々に増減 | オン / オフ | オン | オンで先頭から粒が順に出てくる。オフなら先頭のフレームから出そろっている |

### 出入りの動き

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 登場の動き[X/Y/Z/rX/rY/rZ/拡大%/不透明%] | 下の表 | 0,0,0,0,0,0,100,100 | 出てくるときの動き。8 つの数をこの順にカンマで区切って入力する |
| 退場の動き[X/Y/Z/rX/rY/rZ/拡大%/不透明%] | 同上 | 同上 | 消えるときの同じ設定 |

登場の動き・退場の動きの 8 つの数（左から順に）:

| 位置 | 名前 | 範囲 | 初期値 | 説明 |
|---|---|---|---|---|
| 1〜3 | X / Y / Z | ±1000 px | 0 | 出てくる（消える）ときに、ここからずれた位置から来る（へ行く） |
| 4〜6 | rX / rY / rZ | ±3600 ° | 0 | 出てくる（消える）ときの回転 |
| 7 | 拡大% | 0 ~ 1000 | 100 | 出てくる（消える）ときの大きさ |
| 8 | 不透明% | 0 ~ 100 | 100 | 出てくる（消える）ときの不透明度 |

数が足りないときは、足りない所を初期値で補います。数でない文字や範囲の外の値は、初期値または範囲の端にそろえて読みます。

### 範囲

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 領域可視化 | オン / オフ | オフ | 粒の出る範囲を表示する |
| 外領域[上/下/右/左] | ±1000 px | 0,0,0,0 | オブジェクトの外へ範囲を広げる。マイナスで狭める。「上,下,右,左」の順に 4 つの数を入力する |
| 内領域除[上/下/右/左] | 0 ~ 1000 px | 0,0,0,0 | 範囲の内側を空ける。「上,下,右,左」の順に 4 つの数を入力する |
| シード | 0 ~ 1000 | 0 | 粒の並びを変える種。小数は切り捨てる。コマ単位の切り替えや移動方法も使える |

## 注意

- 元の「装飾パーティクル」と同じ値を入れれば同じ絵になります。元の項目（登場X、外領域上 など）は、このスクリプトでは
  数をカンマで区切る欄（登場の動き、外領域 など）にまとめてあるので、順に入れ替えてください
- v1.10 で、動かさない値の項目を上のようにまとめました。v1.00 で作ったプロジェクトを v1.10 で開くと、まとめた項目は
  初期値に戻ります（透明度[%]・シードとそのほかの項目はそのまま）。必要な値を入れ直してください
- 粒の並びは乱数で決まり、同じ **シード** でもオブジェクトごとに変わります
