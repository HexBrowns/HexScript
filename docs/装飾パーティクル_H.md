# 装飾パーティクル_H

掛けたオブジェクトの範囲の中に、図形や画像の粒を**次々に出しては消す**フィルタ効果です。アス（AVILITY）さんの `装飾パーティクル.anm2`（https://avilityyy.blogspot.com/2025/11/decoParticle.html）を元にしています。

元と同じ粒を同じ順番で描き、中の計算をまとめて**呼び出しを減らしました**（設定の読み出しを減らし、同じ透明度が続く粒はまとめて描く）。元の「装飾パーティクル」と同じオブジェクトに並べても干渉しません。

実機で測った範囲（粒 100 個）では、速さは元とほぼ同じでした。見た目は元と同じです。

## インストール

1. `Script\装飾パーティクル_H.anm2` を置く
2. AviUtl2 を再起動する（新しく置いたスクリプトは、再起動するまで一覧に出ません）
3. フィルタ効果の **HexScript → 装飾パーティクル_H** から追加する

## 使い方

1. 粒を出したい範囲の大きさで図形などを置き、フィルタ効果「装飾パーティクル_H」を追加する
2. **個数** の粒が範囲の中に出て、**表示時間[f]** の間表示され、**登退場[f]** のフレーム数で出入りする
3. 粒の形は **図形／画像**（オンで図形、オフで画像）と **図形** / **画像** で選び、**色** で色を決める
4. 出入りの動きは **登場X / 登場Y …** と **退場X / 退場Y …** で付ける

範囲を広げる・中を空けるときは **外領域** / **内領域除** を使います。**領域可視化** をオンにすると範囲が見えます。

## パラメータ

### 粒

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 個数 | 1 ~ 100 | 16 | 同時に出す粒の数 |
| 表示時間[f] | 1 ~ 2000 | 60 | 1 つの粒が出ている長さ（フレーム） |
| 登退場[f] | 1 ~ 2000 | 20 | 出入りにかけるフレーム数 |
| 表時ばらつき[%] | 0 ~ 100 | 100 | 表示時間のばらつき |
| サイズ | 1 ~ 2000 | 100 | 粒の大きさ |
| サイズばらつき[%] | 0 ~ 100 | 30 | 大きさのばらつき |
| 登退場カーブ | 0 ~ 1 | 0 | 出入りの速さの変わり方。この項目を 0 → 1 に移動させ、その移動方法（イージング）の曲線を出入りに使う |
| 合成モード | 通常 / 加算 / 減算 / … | 通常 | 粒の合成モード |
| 色 | 色 | 黄 | 図形の色 |
| 図形／画像 | オン / オフ | オン | オンで図形、オフで画像ファイル |
| 図形 | 図形 | 円 | 粒の形 |
| 画像 | ファイル | なし | 粒に使う画像 |
| 透明度[%] | 0 ~ 100 | 0 | 粒の透明度 |
| 回転min / 回転max | ±360 ° | 0 / 0 | 粒の向きの範囲 |
| 縦横比min / 縦横比max | ±100 | 0 / 0 | 粒の縦横比の範囲 |
| Z軸幅 | 0 ~ 1000 | 0 | 奥行きの散らばり |
| 徐々に増減 | オン / オフ | オン | オンで先頭から粒が順に出てくる。オフなら先頭のフレームから出そろっている |

### 出入りの動き

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 登場X / Y / Z | ±1000 | 0 | 出てくるときに、ここからずれた位置から来る |
| 登場rX / rY / rZ | ±3600 ° | 0 | 出てくるときの回転 |
| 登場zoom[%] / 登場alpha[%] | 0 ~ 1000 / 0 ~ 100 | 100 | 出てくるときの大きさ・不透明度 |
| 退場X / Y / Z、退場rX / rY / rZ、退場zoom[%] / 退場alpha[%] | 同上 | 同上 | 消えるときの同じ設定 |

### 範囲

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 領域可視化 | オン / オフ | オフ | 粒の出る範囲を表示する |
| 外領域上 / 下 / 右 / 左 | ±1000 px | 0 | オブジェクトの外へ範囲を広げる（マイナスで狭める） |
| 内領域除上 / 下 / 右 / 左 | 0 ~ 1000 px | 0 | 範囲の内側を空ける |
| シード | 0 ~ 1000 | 0 | 粒の並びを変える種 |

## 注意

- 元の「装飾パーティクル」から乗り換えると、項目名が同じなので、同じ値を入れれば同じ絵になります
- 粒の並びは乱数で決まり、同じ **シード** でもオブジェクトごとに変わります
