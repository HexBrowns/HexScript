# 偽被写界深度_H

カメラからの距離に応じてオブジェクトをぼかす、被写界深度もどきのアニメーション効果です。
ピントの合う距離と範囲を決めると、そこから離れたオブジェクトほど強くぼけます。
離れ具合に応じて色を付けたり、透明にしたりもできます。

v1.00。第三者作の `偽被写界深度2.anm2` をフォークし、**カメラ制御を読むように直したもの**です。
`偽被写界深度2.anm2` とは名称が違うため競合の心配は不要で、両方が一覧に出ます。

## インストール

1. `Script\偽被写界深度_H.anm2` を配置する。
2. AviUtl2を起動する。
3. オブジェクトのフィルタ効果に、HexScriptの中の「偽被写界深度_H」を追加する。

フィルタオブジェクトにも追加できます。

## 使い方

1. Zをずらして並べたオブジェクトの **1 つ 1 つに直接**「偽被写界深度_H」を追加する。
2. **焦点距離** でピントの合う位置を前後させる。0 で、等倍で描かれる面に合う。
3. **焦点範囲** でピントの合う範囲の広さを決める。範囲の内側はぼけない。
4. **Blur** でぼけ方の強さを決める。

### ピントの合う位置

- **カメラ制御の無いシーン**: オブジェクトのZがそのまま距離になります。焦点距離 0 ならZ=0 のオブジェクトにピントが合います。
  Zが焦点距離から離れるほどぼけます
- **カメラ制御の対象のオブジェクト**: カメラの視線の方向に測った奥行きで決まります。
  焦点距離 0 は、カメラの設定の「カメラからスクリーンまでの距離」です。カメラを前後に動かすと、それに合わせてボケ方が変わります
- **焦点を目標に固定** をONにすると、焦点距離 0 がカメラの目標点の距離になります。目標点を被写体に置けば、カメラが動いてもピントが追いかけます

### ぼけの量

焦点範囲の外へ出た距離に比例してぼけます。
**範囲の外へ 1024px 出た所でぼかしの範囲がBlurの値**になり、最大でその 3 倍で止まります。
範囲の内側はぼかしを掛けません。

### 例: カメラの無いシーンで、奥の文字をぼかす

原作の実制作では、焦点距離 0 / 512 / 1024、焦点範囲 100 〜 400、Blur 20 / 50 / 80 のあたりが使われていました。
項目名は原作と同じなので、同じ値がそのまま使えます。
カメラ制御の無いシーンでは原作と同じ絵になります。

## パラメータ

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 焦点距離 | -5000 ~ 5000 | 0 | ピントの合う位置。0 でスクリーン、焦点を目標に固定なら目標点。正で奥、負で手前へ動く |
| 焦点範囲 | 0 ~ 5000 px | 100 | ピントの合う範囲。焦点距離から前後それぞれこの距離まではぼかさない |
| Blur | 0 ~ 100 | 10 | ぼけ方の強さ。焦点範囲の外 1024px でぼかしの範囲がこの値になり、最大でこの 3 倍 |
| 色強度 | 0 ~ 100 % | 0 | 離れ具合に応じて色を付ける強さ。0 なら色を付けない |
| 焦点を目標に固定 | ON / OFF | OFF | ONで、焦点距離 0 の基準をスクリーンではなくカメラの目標点の距離にする |
| ﾚﾝｽﾞﾌﾞﾗｰ | ON / OFF | OFF | ONで、標準の「ぼかし」ではなく「レンズブラー」でぼかす |
| ﾌｪｰﾄﾞ | ON / OFF | OFF | ONで、ピントから離れるほど透明にする。完全に透明になったらぼかしも掛けない |
| ﾌｪｰﾄﾞ% | 数値入力 | 100 | 透明になりきる距離。100 で、ぼかしの範囲がBlurと同じになる範囲の外 1024px の所。300 でぼかしが最大になる所。色の付き方にも効く |
| 色(近) | - | ffffff | ピントより手前にあるときに付ける色 |
| 色(近)無効 | ON / OFF | OFF | ONで、手前にあるときは色を付けない |
| 色(遠) | - | ffffff | ピントより奥にあるときに付ける色 |
| 色(遠)無効 | ON / OFF | OFF | ONで、奥にあるときは色を付けない |
| 中心点を含む | ON / OFF | OFF | ONで、中心点のずれをオブジェクトの回転に合わせて回してから距離を測る。スクリプトの説明でも「恐らく正確ではない」としている |
| 球判定 | ON / OFF | OFF | ONで、奥行きではなくカメラの位置からの直線距離で測る。画面の端にあるものほど遠い扱いになる |

「数値入力」の ﾌｪｰﾄﾞ% はトラックバーではないので、時間で動かせません。

### 色の付き方

色強度を 0 より大きくすると、ピントから離れるほど色(近) / 色(遠) が強く乗ります。
ピントの範囲の内側では色は付かず、ﾌｪｰﾄﾞ% で決まる距離で色強度の値に達します。
色の初期値は白なので、色を変えずに色強度を上げると、離れたものほど白くなります。

## フィルタオブジェクトに掛けるとき

フィルタオブジェクトに掛けると、フィルタオブジェクト自身の位置で距離を測り、画面全体を同じ量でぼかします。
このときは画面の大きさを変えないぼかし方になり、**ﾌｪｰﾄﾞ は効きません**。

## 注意

- **グループ制御に追加すると、配下のオブジェクトのZは見えません。** 配下は全部、グループ制御自身のZと同じ深さとして扱われます。
  配下のオブジェクトをZ=512 に置いても、グループ制御のZが 0 ならピントが合ったままになります
  - オブジェクトごとに奥行きでぼかしたいときは、**1 つずつ直接**掛けます
  - グループ制御でまとめて掛けたいときは、**Zをグループ制御の側に持たせます**
- **色(近) / 色(遠) に黒の 000000 を選ぶと、「無効」と同じ扱いになって色が付きません。** 000001 のような黒に近い色で代わりにします
- 距離は、標準描画の座標に前の効果が動かした分を足した、オブジェクトの位置で測ります。1 つのオブジェクトの中では同じ量でぼけます。オブジェクトの中で奥行きが変わっても、部分ごとにぼけ方は変わりません
- 原作由来のスクリプト内の説明では、カメラのZバッファ / シャドウマップを無効にするか、オブジェクトの合成モードを通常以外にすることを勧めています。また、大きな画像にはあまり効かないとしています
- 原作に作者・ライセンスの表記がありません。原作の部分の権利は原作者にあります。HexScriptでは、原作者から求めがあれば取り下げる前提で公開しています

## 原作との違い

原作は `Script/偽被写界深度2.anm2`（作者・ライセンス表記なし）です。項目名・範囲・初期値は原作と同じです。
ただし効果の名称が違うため、原作を使っているプロジェクトは原作のまま動きます。

- **カメラ制御を読みます。** 原作はカメラ制御があっても読めておらず、常に固定の位置のカメラで距離を測っていました。
  そのため、カメラを動かしてもボケ方が変わりませんでした。カメラ制御の無いシーンでは原作と同じ結果です
- **スクリーンの距離をカメラの設定から取ります。** 原作は 1024 に固定でした
- **焦点範囲の内側ではぼかしを掛けません。** 原作は範囲の内側で負のぼかし量を渡していました
- **フィルタオブジェクトで画面の大きさを変えません。** ぼかしを大きさ固定にし、ﾌｪｰﾄﾞ で透明度を書き換えないようにしました
- 中心Zにも、中心X / 中心Yと同じく拡大率を掛けます
