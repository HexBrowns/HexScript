# レベル補正_H

入力の黒点・白点・中間調と、出力の範囲を指定して、明るさとコントラストを整えるアニメーション効果です。
R・G・B・Aのどれに掛けるかをチャンネルごとに選べます。
フィルタオブジェクトにも対応しているので、画面全体にも掛けられます。

- `Script/レベル補正_H.anm2`（v1.00）

しけもち氏の `レベル補正.anm2` と、こんにゃくねこ氏の `Level.anm2` を 1 本にまとめ、不具合を直したフォークです。
原作2本とは名称が違うため競合の心配は不要です。

### 原作との違い

- **チャンネルのチェックが効きます。** 原作の `レベル補正` はチェックに関係なくR・G・B・Aの全部に掛かっていました
- **半透明の部分を正しく扱います。** 透明度を外した本来の色で補正してから掛け戻すので、縁が黒ずんだり明るく浮いたりしません。AがOFFなら透明度は変わりません
- シャドウ = ハイライトや、中間調を最小にしたときに壊れません
- 項目名は `レベル補正` と同じです。原作の「_」の項目だけ削りました。
  項目名が設定の保存キーなので、`.aup2` の `effect.name=レベル補正` を `レベル補正_H` に書き換えると設定値がそのまま読まれます。
  ただし原作はAにも掛かっていたので、出力レベル最大を下げていた所などは見た目が変わります
- `Level` のMin・Maxは、**シャドウ = Min × 255、ハイライト = Max × 255、ほかは初期値**で同じ結果になります。
  シャドウ・ハイライトは 1 刻みなので、Min × 255 が整数にならない値はわずかに丸まります

## インストール

1. `Script\レベル補正_H.anm2` を配置する。
2. AviUtl2を起動する。
3. オブジェクトに、ラベル **HexScript** の中にある「レベル補正_H」を追加する。画面全体に掛けるときはフィルタオブジェクトとして追加する。

## 使い方

1. 補正したいオブジェクト・グループ制御・フィルタオブジェクトに「レベル補正_H」を追加する。
2. **シャドウ** を上げると暗い部分が黒に、**ハイライト** を下げると明るい部分が白に寄り、コントラストが上がる。
3. **出力レベル最大** を下げると全体が暗く、**出力レベル最小** を上げると黒が浮いて眠い絵になる。
4. **中間調** を 1 より大きくすると中間の明るさが暗く、小さくすると明るくなる。
5. 一部の色だけに掛けたいときは、掛けないチャンネルのチェックを外す。

### 例: グループをまとめて少しだけ暗くする

グループ制御に追加して、実制作で使った設定です。

| 項目 | 値 |
|---|---|
| 出力レベル最大 | 242 |
| ほか | 初期値（Aチャンネル はOFF） |

明るさが全体で約 95% になります。AがOFFなので、グループ内の文字や図形は透けません。

## パラメータ

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| シャドウ | 0 ~ 255 | 0 | 入力の黒点。これ以下の明るさは出力レベル最小になる |
| 中間調 | 0.01 ~ 2 | 1 | 中間の明るさの曲がり具合。1 で直線。大きいほど暗く、小さいほど明るい |
| ハイライト | 0 ~ 255 | 255 | 入力の白点。これ以上の明るさは出力レベル最大になる |
| 出力レベル最小 | 0 ~ 255 | 0 | 出力の最も暗い値 |
| 出力レベル最大 | 0 ~ 255 | 255 | 出力の最も明るい値 |
| Rチャンネル | ON / OFF | ON | 赤に掛けるか |
| Gチャンネル | ON / OFF | ON | 緑に掛けるか |
| Bチャンネル | ON / OFF | ON | 青に掛けるか |
| Aチャンネル | ON / OFF | OFF | 透明度に掛けるか。ONにすると透明度にも同じ補正が掛かる |

### 補正の式

チャンネルごとに、0〜255 の値 x を次のように変えます。

```
n    = (x − シャドウ) / (ハイライト − シャドウ)    … 0〜1 に収める
出力 = 出力レベル最小 + (出力レベル最大 − 出力レベル最小) × n ^ 中間調
```

- **中間調の向きは、Photoshopなどのガンマとは逆です**。値を大きくすると暗くなります。原作に合わせてあります
- ハイライトをシャドウより小さくすると、明暗が反転します。出力レベル最小を最大より大きくしても反転します

## 注意

- **Aチャンネル をONにすると、完全に透明な部分にも同じ式が掛かります。** 出力レベル最小を 0 より大きくすると、
  オブジェクトの四角い範囲全体に薄い灰色の膜が出ます
- 初期値から動かしているときは、**チェックを外したチャンネルも含めて、255 を超える明るさは 255 に切り詰められます**
- R・G・B・Aのチェックをすべて外したとき、またはすべて初期値のときは何もしません
