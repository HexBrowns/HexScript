# KD_DepthMap_H

別に用意した深度画像（奥行きを明暗で表したグレースケールの画像）を使って、オブジェクトを奥行きで切り抜くアニメーション効果です。
深度画像の明るい部分に当たる画素だけを残し、暗い部分を透明にします。

v1.2。kurodonut さんの Toolbox_kurodonut v1.1 の「深度マスク」を、AviUtl2 で動くように直したフォークです（下の「原作との違い」）。
入っている効果は「深度マスク」の 1 つです。

- `Script/@KD_DepthMap_H.anm2`（v1.2）

## インストール

1. `Script\@KD_DepthMap_H.anm2` を配置する（ファイル名の先頭の `@` を消さない）
2. AviUtl2 を再起動する
3. オブジェクトのフィルタ効果に「深度マスク」を追加する（HexScript の中）

フィルタオブジェクトのメニューには出ません。

## 使い方

1. 切り抜きたい画像と**同じ大きさ**の深度画像を用意する（明るいほど残る。グレースケールの不透明な画像）
2. 画像オブジェクトに「深度マスク」を追加する
3. **深度ファイル** で深度画像を選ぶ
4. **閾値** を上げていくと、暗い（閾値に届かない）部分から順に透明になる

深度ファイルを選んでいない間は何もしません。読み込めなかったときも、元の画像のまま残します。

### 閾値の効く範囲

深度画像の赤（R）の明るさを 0〜1 で読み、**それを 3 で割った値が閾値より大きい画素だけ**を残します（原作の判定のまま）。
そのため、閾値の効く範囲は実質 **0 〜 0.333** です。

| 閾値 | 残る部分（深度画像の明るさ） |
|---|---|
| 0 | 真っ黒以外のすべて |
| 0.15 | 明るさ 45% より明るい部分 |
| 0.334 以上 | 何も残らない（真っ白でも 1 ÷ 3 = 0.333… にしかならない） |

横に黒から白へ変わる深度画像で閾値 0.15 にすると、左の 45% が透明になることを実機で確かめてあります。

## パラメータ

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 閾値 | 0 ~ 1 | 0 | 残す明るさの下限。深度画像の R ÷ 3 がこれより大きい画素だけ残る（上の「閾値の効く範囲」） |
| 深度ファイル | ファイル選択 | （なし） | 深度画像のファイル |

## 注意

- **深度画像と元の画像は同じ大きさにします。** 画素の位置どうしで突き合わせるので、大きさが違うと位置がずれます。
  出力の大きさも深度画像の大きさになります
- 深度画像は**赤（R）だけ**を見ます。グレースケールならどの色でも同じです。深度画像が半透明だと、その分だけ暗い扱いになります
- 残した部分は、元の画像の色と透明度をそのまま使います（半透明の部分は半透明のまま）

## 原作との違い

原作は `Toolbox_kurodonut` の `@KD_DepthMap.anm2` です（`oldScript/@KD_DepthMap_kurodonut_v1.1.anm2` へ退避済み）。

- **AviUtl2 で動くようにしました。** 原作はシェーダーのコンパイルが通らず、`invalid shader output parameter` で動きませんでした
- **深度ファイルが未指定・読み込み失敗のときに、エラーにならず元の画像を残します。** 原作は `invalid buffer type. name=object` になっていました
- **残した部分の透明度を元の画像のまま通します。** 原作は透明度を 1（不透明）に固定していたので、半透明の部分が暗くなっていました。不透明な画像なら原作と同じ絵です
- 閾値の判定（R ÷ 3 と比べる）は原作のままです
