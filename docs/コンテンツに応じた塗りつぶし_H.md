# コンテンツに応じた塗りつぶし_H

画像の中の消したい物を、周りの絵で埋めて消す効果です。
After Effectsの「コンテンツに応じた塗りつぶし」に当たります。
周りの色をなめらかに流し込む方法と、周りに似た模様を画像の別の場所から探して貼る方法を選べます。

## インストール

1. `Script\コンテンツに応じた塗りつぶし_H.anm2` を配置する。
2. AviUtl2を起動する。

## 使い方

1. 画像・動画のオブジェクトに、フィルタ効果の追加メニューのラベル **HexScript** の中にある「コンテンツに応じた塗りつぶし_H」を掛ける。
   画面全体に掛けるならフィルタオブジェクトとして置く。
2. **範囲** で消す所を決める。最初は中央の矩形 200x200。**範囲を表示** をONにすると、消す所が赤く重なって見える。
3. 位置と大きさを合わせたら **範囲を表示** をOFFに戻す。

形の決まらない物を消すときは、消したい所を白く塗った画像を別のレイヤーに置きます。
**範囲** を「レイヤー」にして、そのレイヤーの番号を入れます。
そのレイヤーは画面の外に置いても読み込めます。

## パラメータ

### 消す範囲

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 範囲 | 透明な所 / レイヤー / 矩形 / 楕円 | 矩形 | 透明な所: アルファが半分より小さい所を埋める。レイヤー: 別のレイヤーの画像で決める |
| 範囲のレイヤー | 1 ~ 1000 | 1 | 範囲＝レイヤーのとき、範囲を決める画像のレイヤー番号。オブジェクトの大きさに引き伸ばして使う |
| 範囲の決め方 | アルファ / 輝度 | アルファ | 範囲＝レイヤーのとき、不透明な所か明るい所を消す |
| 範囲を反転 | ON / OFF | OFF | 範囲＝レイヤーのとき、消す所と残す所を入れ替える |
| 中心X / 中心Y | px | 0 | オブジェクトの中心から見た矩形・楕円の中心 |
| 幅 / 高さ | px | 200 | 矩形・楕円の大きさ |
| 範囲を広げる | 0 ~ 64 px | 2 | 範囲を四方に膨らませる。消した物の縁のにじみが残るときに増やす |

### 塗り方

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 方法 | なめらか / パッチ | パッチ | なめらか: 周りの色をぼかして流し込む。速く、ちらつかないが、模様は消える。パッチ: 周りに似た模様を探して貼る。模様や線が続く |
| パッチの大きさ | 5 / 7 / 9 px | 7 | 似た所を探すときに比べる範囲。大きいほど大きな模様をつなげやすいが重い |
| 探す細かさ | 等倍 / 1/2 | 1/2 | 等倍は細かい模様まで合うが重く、FHDでは一時的な画像の置き場をほぼ使い切る |
| 繰り返し | 1 ~ 10 | 4 | 探し直す回数。多いほど合うが重い |
| シード | 0 ~ 10000 | 0 | 探し方のランダムを変える。うまく埋まらないときに変えてみる |
| 範囲を表示 | ON / OFF | OFF | 消す所を赤く重ねて表示する |

## 使い方の例

- **背景の電線・ゴミを消す**: 範囲 矩形か楕円・方法 パッチ・範囲を広げる 3〜5
- **透過PNGの抜けを埋める**: 範囲 透明な所・方法 なめらか
- **動かないロゴや字幕を消す**: 範囲 矩形・方法 なめらか。動画でもちらつかない

## 注意事項

- **1 フレームずつ別々に塗ります。** パッチは選ぶ場所がフレームごとに変わることがあり、動画ではちらつく場合があります。
  動画でちらつくときは方法を なめらか にしてください。After Effectsのように前後のフレームを使って揃えることはしません
- 塗った所は不透明になります。範囲の外は 1 画素も変えません
- 消す範囲の周りに、似た模様が無い・少ない絵では、パッチでもうまく埋まりません
- 重さの目安: FHD・パッチ・探す細かさ 1/2・矩形 300x300 で、1 フレーム約 23ms。大きさを変えた直後の 1 フレームは確保し直す分だけ重くなります
- 初めて表示するときは、シェーダーの準備で 0.3 秒ほど止まります
