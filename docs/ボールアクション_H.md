オブジェクトを格子状に並んだボールに置き換える効果です。
各ボールはその位置の色を拾い、光の当たった立体に見えます。
After Effectsの「CC Ball Action」に当たり、ボールを散らす・ねじる・回す・揺らすことで、ばらける／集まるアニメーションが作れます。

## インストール

1. `Script\ボールアクション_H.anm2` を配置する。
2. AviUtl2を起動する。

## 使い方

1. 画像・テキストなどのオブジェクトに、フィルタ効果の追加メニューのラベル **HexScript** の中にある「ボールアクション_H」を掛ける。
2. そのままで、間隔 10px の格子にボールが並ぶ。
3. **散らばり** や **ねじれの角度** に移動方法を付けて動かす。0 から増やすとばらけ、0 へ戻すと集まる。

**この効果はオブジェクトの効果の一番下に置いてください。** ボールを自分で描くので、これより後に付けたフィルタ効果は掛かりません。

## パラメータ

### ボール

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 間隔 | 2 ~ 200 px | 10 | 格子の間隔。格子はオブジェクトの中心に合わせて並ぶ |
| 大きさ | 0 ~ 400 % | 100 | ボールの直径。間隔に対する %。100 で隣と接する。0 で何も描かない |
| 色の取り方 | 中心 / 平均 | 中心 | 中心: 格子点の色。平均: その周りのマスの平均の色。細かい模様でちらつきにくい |

### 散らばりと揺れ

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 散らばり | 0 ~ 4000 px | 0 | ボールを平面上で、この半径の円の中にばらばらにずらす |
| 奥行きの散らばり | 0 ~ 4000 px | 0 | 手前・奥へばらばらにずらす。遠近で大きさが変わる |
| 揺れ | 0 ~ 1000 px | 0 | ボールごとに時間で揺らす |
| 揺れの速さ | 0 ~ 20 | 1 | 1 秒あたりの揺れの回数 |
| シード | 0 ~ 10000 | 0 | 散らばり・揺れ・ランダムの並びを変える |

### ねじれと回転

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| ねじれの軸 | X軸 / Y軸 / Z軸 | Y軸 | ねじる回転の軸。オブジェクトの中心を通る |
| ねじれの基準 | 横位置 / 縦位置 / 中心からの距離 / ランダム | 横位置 | ボールごとの回す量を決めるもの。横位置なら、右端が ＋角度、左端が −角度、中央は回らない |
| ねじれの角度 | 度 | 0 | ねじる量 |
| X軸回転 / Y軸回転 / Z軸回転 | 度 | 0 | ボールの並び全体を回す。ボール自体はいつも正面を向く |

### 光

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 光の向き | 度 | 135 | 光の来る向き。0 で右、90 で上、135 で左上 |
| 光の高さ | 0 ~ 90 度 | 45 | 90 で正面から |
| 環境光 | 0 ~ 100 | 25 | 影の側の明るさ。100 で陰影なし |
| ハイライト | 0 ~ 100 | 60 | つやの強さ |

## 使い方の例

- **画像がボールになってばらける**: 散らばり 0 → 300、奥行きの散らばり 0 → 500
- **ボールの渦**: ねじれの軸Z軸・ねじれの基準 中心からの距離・ねじれの角度 0 → 360
- **陰影なしのドットアート風**: 環境光 100・ハイライト 0・大きさ 90
- **くるっと回って集まる**: ねじれの軸Y軸・ねじれの角度 180 → 0

## 注意事項

- **これより後に付けたフィルタ効果は掛かりません**。一番下に置いてください
- ボールが 15 万個を超えるときは、間隔を自動で広げて 15 万個に収めます。FHDなら間隔 4 まではそのままです
- ボールはいつも正面を向いた円で描きます。カメラ制御で横から見ると、板のように見えます
- 重さの目安: 1920x1080・間隔 8 の約 3 万個で、奥行きとねじれを付けても 1 フレーム約 22ms
