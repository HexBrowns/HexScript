# グリッド_H

線の網目や、円・四角・ひし形・十字などを等間隔に並べた模様を、1 つのオブジェクトで出すカスタムオブジェクトです。
種類・全体の大きさ・図形の大きさ・太さ・間隔を変えられ、主線や破線、流す・順に出す・端を薄くするまでこれ 1 本で済みます。

## インストール

1. `Script\グリッド_H.obj2` を配置する
2. AviUtl2 を再起動する

## 使い方

1. オブジェクトの追加メニューで、ラベル **HexScript** の中にある「グリッド_H」（カスタムオブジェクト）を置く
2. そのままで、画面いっぱいの方眼（間隔 100・太さ 2・白）が出る
3. **種類** で形を選び、**間隔X / 間隔Y**・**線の太さ**（図形なら **大きさX / 大きさY**）を合わせる

背景は既定で透明です。色を敷きたいときは **背景色** を指定してください。
種類によって使わない項目は自動で隠れます。

## 種類

| 種類 | 形 |
|------|----|
| 方眼 | 縦線（間隔X ごと）と横線（間隔Y ごと）。**行ずらし 50** でレンガ積みになる |
| 横線 / 縦線 | 横線だけ（間隔Y ごと）/ 縦線だけ（間隔X ごと） |
| 斜め格子 | 水平から ±**角度** の 2 方向の線でできたひし形の網目。線の間隔は間隔X |
| 三角格子 | 3 方向の線。**間隔X = 間隔Y のとき正三角形**（1 辺 = 間隔X）。間隔Y を変えると縦に伸び縮みする |
| 六角格子 | ハニカム。**間隔X = 間隔Y のとき正六角形**（隣の六角形の中心まで = 間隔X）。間隔Y で縦に伸び縮み |
| 円 | 楕円（大きさX × 大きさY）。小さくすれば点（ドット）になる |
| 四角 | 長方形（大きさX × 大きさY） |
| ひし形 | 対角線が 大きさX・大きさY のひし形 |
| 多角形 | 正 **角数** 角形を、大きさX × 大きさY の枠に合わせて伸ばしたもの |
| 星 | **角数** の星形。**へこみ** で谷の深さを決める |
| 十字 / バツ | 長さ 大きさX・大きさY、太さ = 線の太さ の十字 / それを 45 度回したもの |

図形は線の交点（格子点）に並びます。方眼と十字を重ねると、交点と十字の中心が一致します。
六方最密の水玉にしたいときは、**円・行ずらし 50・間隔Y = 間隔X × 0.866** にします。

## パラメータ

### 形の設定

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 種類 | 上の表 | 方眼 | 形の種類 |
| 幅 / 高さ | 0 ~ 8000 px | 0（画面） | 全体の大きさ。0 なら画面サイズ |
| 間隔X / 間隔Y | 2 ~ 2000 px | 100 | 格子の間隔。三角・六角・斜め格子では間隔Y は縦の伸び（間隔X と同じで正則） |
| 大きさX / 大きさY | 0 ~ 4000 px | 40 | 図形 1 個の大きさ（外接矩形）。図形のときだけ |

### 線と図形の設定

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 線の太さ | 0.1 ~ 500 px | 2 | 線の格子・十字・バツの太さ |
| 枠の太さ | 0 ~ 500 px | 0（塗りつぶし） | 円〜星を枠だけにする。枠は輪郭の内側に付くので、見た目の大きさは変わらない |
| 角の丸み | 0 ~ 500 px | 0 | 四角・ひし形・多角形・星の角を丸める。丸めても外形の大きさは変わらない |
| 角数 | 3 ~ 32 | 5 | 多角形・星の角の数 |
| へこみ | 0 ~ 100 % | 50 | 星の谷の深さ |
| 角度 | 5 ~ 85 度 | 45 | 斜め格子の線の傾き |
| 図形の回転 | 度 | 0 | 図形 1 個ずつを回す |
| 格子の回転 | 度 | 0 | 模様全体を回す（全体の枠は回らない） |
| 行ずらし | 0 ~ 100 % | 0 | 1 段ごとに横へずらす。50 で千鳥 / レンガ。方眼と図形だけ |
| 色 | | 白 | 線・図形の色 |
| 背景色 | | 透明 | 模様の下に敷く色 |

### 主線と線種の設定（線の格子のみ）

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 主線を入れる | ON / OFF | OFF | 中心の線から数えて N 本ごとの線を太く・別の色にする（六角格子は対象外） |
| 主線の間隔 | 2 ~ 100 本 | 5 | 何本ごとに主線にするか |
| 主線の太さ / 主線の色 | | 4 / 白 | 主線の見た目 |
| 線種 | 実線 / 破線 / 点線 | 実線 | 主線以外の線（補助線）の線種。**主線は常に実線** |
| 1辺の個数 | 1 ~ 200 | 5 | 交点から次の交点までに並べる破線・点の数 |
| 実部の割合 | 1 ~ 99 % | 60 | 破線の線の部分の長さの割合 |

破線と点線は「1 辺に何個並べるか」で決まるので、交点で必ず線がつながり、途中で模様が詰まりません。
間隔を変えると破線の長さも一緒に伸び縮みします。点線の点の直径は線の太さと同じです。
方眼紙のような「太い実線＋細い点線」は、**主線を入れる ON・線種 点線** で作れます。

### 位置とスクロールの設定

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 位置X / 位置Y | px | 0 | 模様をずらす |
| 速度X / 速度Y | px / 秒 | 0 | 模様を流し続ける。格子を回しているときは回した向きに沿って流れる |

### 出現の設定

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 出現の順 | なし / 左から / 右から / 上から / 下から / 中心から / 外側から / ランダム | なし | マスが現れる順 |
| 線の出方 | マスごと / 伸びる | マスごと | 線の格子のとき。マスごと: マスの範囲ごとに現れる。伸びる: 交点の間の 1 辺ずつ、線が端から伸びる |
| 出現にかける時間 | 0 ~ 60 秒 | 1 | 最初のマスが現れ始めてから、最後のマスが現れ始めるまで |
| 1マスの時間 | 0.01 ~ 10 秒 | 0.3 | 1 マス（1 辺）が現れきるまで。図形は中心から大きくなりながら現れる |
| 出現の緩急 | | 100 | **移動方法を付けて使う**項目（下記） |
| 終わりに消える | ON / OFF | OFF | オブジェクトの最後に、出現を逆再生して消える |
| 乱数シード | | 0 | ランダムの並びを変える |

**出現の緩急** は値そのものには意味がありません。この項目に移動方法（Basic_S のイージングや カーブエディタ2 など）を付けると、
その曲線の形が 1 マスの現れ方の緩急になります。始点と終点の値は何でもかまいません（0 → 100 など）。
移動方法を付けなければ一定の速さで現れます。

### 端のフェードの設定

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 端のフェード | なし / 四角 / 楕円 | なし | 全体の外周に向かって模様を薄くする。背景色は薄くならない |
| フェード幅 | 0 ~ 100 % | 20 | 薄くする幅。短辺の半分に対する割合 |

## 注意事項

- **初めて表示するときに一瞬（1 秒弱）止まります。** 模様を描くシェーダーを準備する時間で、2 回目以降は止まりません
- 間隔が 3px より細かいと、線が画素より細かくなって干渉縞（モアレ）が出ます
- 図形が大きすぎて隣と重なりすぎると、大きさが自動で頭打ちになります（間隔 100 の方眼の並びなら、外接矩形の対角線が約 300px まで）
- 出現の緩急で 1 を超える曲線（行き過ぎて戻るもの）を使うと、図形が一瞬大きくなり、隣のマスの境で欠けることがあります
- 標準描画で拡大すると、線も一緒に太く見えます。太さを保ちたいときは 幅・高さ・間隔 で大きさを変えてください
- 重さの目安（4K）: 星 32 角を大きく並べたときが最も重く、1 フレーム約 30ms。線の格子は 10ms 前後です
