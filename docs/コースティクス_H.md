# コースティクス_H

水面越しに見た画像を作る効果です。揺れる水面で画像が曲がって見え、水の底に揺らめく光の筋（コースティクス）が走ります。
After Effects の「ウェーブワールド」（水面の波を作る）と「コースティクス」（水面越しの見え方を描く）を 1 つにまとめたものです。
水面の高さだけを灰色で出す（高さマップ）、光の筋だけを出す、もできます。

## インストール

1. `Script\コースティクス_H.anm2` を配置する
2. AviUtl2 を再起動する

## 使い方

1. 水の底に見せたい画像に、フィルタ効果の追加メニューのラベル **HexScript** の中にある「コースティクス_H」を掛ける
   （画面全体に掛けるならフィルタオブジェクトとして置く）
2. そのままで、波が流れ、画像が揺れて光の筋が出る
3. **波の大きさ**（波長）・**高さ**・**速さ** で水面を、**屈折**・**コースティクス**・**集光の距離** で見え方を合わせる

水面は毎フレーム数式で決まるので、どのフレームから再生しても同じ絵になります。

## パラメータ

### 波

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 波の大きさ | 10 ~ 2000 px | 120 | 波の波長のおおよその大きさ |
| 高さ | 0 ~ 200 px | 4 | 波の高さ。0 で波なし（波紋だけにするとき） |
| 速さ | 0 ~ 2000 px/秒 | 60 | 波が進む速さ（長い波ほど速い）。0 で止まる |
| 向き | 度 | 0 | 波が進む向き（0 で右） |
| ばらつき | 0 ~ 360 度 | 90 | 波の向きのばらつき。小さいと筋状、大きいと入り組んだ水面 |
| 複雑さ | 1 ~ 4 | 2 | 半分の大きさの波を重ねる段数。多いほど細かいさざ波が乗る |
| シード | 0 ~ 10000 | 0 | 波の並びを変える |

### 波紋

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 波紋を出す | ON / OFF | OFF | 一点から広がる同心円の波を足す。オブジェクトの最初から広がり始める |
| 波紋の中心X / Y | px | 0 | 波紋の中心（オブジェクトの中心から） |
| 波紋の高さ | 0 ~ 200 px | 6 | |
| 波紋の波長 | 4 ~ 2000 px | 60 | |
| 波紋の速さ | 0 ~ 4000 px/秒 | 200 | 波紋の先頭が広がる速さ。まだ届いていない所は平ら |
| 波紋の減衰 | 10 ~ 10000 px | 600 | 中心から離れるほど低くなる距離 |

### 光と水

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 屈折 | 0 ~ 1000 | 40 | 画像の曲がり方（水の深さに当たる）。0 で曲がらない |
| コースティクス | 0 ~ 200 | 60 | 光の筋の強さ。0 でなし |
| 集光の距離 | 0 ~ 5000 | 150 | 光が集まる距離。大きいほど筋が細く鋭く、暗い所も増える |
| 光の色 | | 白 | 光の筋とハイライトの色 |
| ハイライト | 0 ~ 100 | 20 | 水面のつや |
| 光の向き | 度 | 135 | ハイライトを出す光の向き |
| 水の色 / 水の濃さ | | 1a6e8c / 0 | 画像に水の色を混ぜる |
| 表示 | 合成 / コースティクスだけ / 高さマップ | 合成 | コースティクスだけ: 光の筋だけを透明な地に出す（別の素材に加算で重ねる用）。高さマップ: 水面の高さを灰色で（0.5 が高さ 0） |

## 使い方の例

- **プールの底**: 波の大きさ 150・高さ 4・コースティクス 80・集光の距離 200・水の色 薄い水色・水の濃さ 15
- **水たまりに落ちる一滴**: 高さ 0・波紋を出す ON・波紋の高さ 8・波紋の速さ 150
- **水中の光の揺らめきを別の素材に重ねる**: 表示 コースティクスだけ にして、そのオブジェクトの合成モードを加算にする
- **揺らぎだけ欲しい**: コースティクス 0・ハイライト 0・屈折 20

## 注意事項

- 光の筋は点ごとの近似で計算しています。集光を強くするほど、全体がやや明るくなります
- 画像の端の外は端の色が続いているものとして読みます
- 重さの目安（FHD）: 画面全体にフィルタオブジェクトで、複雑さ 4・波紋ありで 1 フレーム約 20ms。初めて表示するときだけシェーダーの準備で 0.2 秒ほど止まります
