画像の輪郭の向きに沿って、画像を引き延ばす効果です。
After Effectsの「ベクトルブラー」に近い効果で、筆でなぞったような絵画調・流体のような質感になります。
向きを決めるベクトルマップには、自分自身か別のレイヤーを使えます。

## インストール

1. `Script\ベクトルブラー_H.anm2` を配置する。
2. AviUtl2を起動する。

## 使い方

1. 画像・動画などのオブジェクトに、フィルタ効果の追加メニューのラベル **HexScript** の中にある「ベクトルブラー_H」を掛ける。
2. そのままで、輪郭に沿って長さ 20px ずつ引き延ばされる。輪郭そのものはくずれにくい。
3. **長さ** で流れの強さ、**角度** で流れの向きを決める。

フィルタオブジェクトにも対応しています。

### 向きの決まり方

ベクトルマップの、**プロパティ** で選んだ値が変わる向きを求めます。
**角度 0** では、それに直交する向き＝**輪郭に沿う向き**に引き延ばします。
まっすぐな線や円の縁はくずれず、模様が輪郭に沿って流れます。
**角度 90** では輪郭を横切る向きになり、普通のぼかしに近い見た目になります。
その間の角度では渦を巻くように流れます。

## パラメータ

### ぼかし

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 長さ | 0 ~ 500 px | 20 | 引き延ばす長さ。両側の合計で数える。0 で何もしない |
| 角度 | -360 ~ 360 度 | 0 | 流れの向き。0 で輪郭に沿う、90 で輪郭を横切る |
| 種類 | 平均 / 最大値 / 最小値 | 平均 | 平均: 流れに沿って混ぜる。最大値: 流れの中で最も明るい色を広げる。最小値: 最も暗い色を広げる |
| 長さの決め方 | 一定 / 勾配に比例 | 一定 | 一定: どこでも同じ長さ。勾配に比例: マップの明るさの変化が緩い所ほど短くし、平らな所は引き延ばさない |
| 重み | 一様 / 三角 / ガウス / 片側に減衰 | 一様 | 流れに沿って読んだ色の混ぜ方。下の「重み」を参照 |
| 尾の向き | 前 / 後 | 前 | 重み＝片側に減衰のときだけ出る。尾を伸ばす側 |

#### 重み

v1.10 で足した項目です。初期値の一様は v1.01 までと同じ見た目で、保存済みのプロジェクトはそのまま開けます。

| 選択肢 | 見た目 |
|---|---|
| 一様 | 流れの中の色を同じ強さで混ぜる。筋の濃さが端まで一定 |
| 三角 | 近い色ほど強く混ぜ、遠い色ほど弱める。筋の中央が濃く、端へ向かって薄れる柔らかい筋になる |
| ガウス | 三角と同じく中央が濃いが、端の薄れ方がさらに滑らか |
| 片側に減衰 | 片側だけを長さいっぱいまで読み、遠いほど薄くする。尾が一方向にだけ伸びる（彗星の尾・スピード線） |

- 種類 最大値・最小値でも効きます。三角・ガウス・片側に減衰では、広がった明るい色（暗い色）が先細りになります
- **尾の向き** は、角度 90 のとき、前でマップの明るい側へ、後で暗い側へ尾が伸びます。一様な色の所（向きが決まらない所）では、角度 0 で前が右です
- 違いがはっきり出るのは、長さを大きくしたときと、線や輪郭がはっきりした素材です

### ベクトルマップ

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| マップ | 自分 / レイヤー | 自分 | 向きを決める画像 |
| マップのレイヤー | 1 ~ 1000 | 1 | マップ＝レイヤーのとき、使うレイヤーの番号。そのレイヤーの効果を掛けた後の画像を、このオブジェクトの大きさに引き伸ばして使う |
| プロパティ | 輝度 / 赤 / 緑 / 青 / アルファ | 輝度 | マップのどの値の変化を見るか |
| マップのぼかし | 0 ~ 100 px | 2 | マップを先にぼかす量。大きいほど細かい模様を無視して、大きな流れだけを拾う |
| リッジの滑らかさ | 0 ~ 100 px | 4 | 向きをならす量。大きいほど流れがなめらかにつながる。小さいと細かい筋が立つ |

## 使い方の例

- **絵画調・筆のタッチ**: マップ 自分・長さ 15〜30・リッジの滑らかさ 4〜8
- **流体・マーブル模様**: 角度 30〜60 で渦を巻く流れにする。リッジの滑らかさを大きめに
- **別の画像の形に沿って流す**: 流したい向きの画像を別のレイヤーに置き、マップ＝レイヤーでその番号を指定する。
  マップのレイヤーは画面の外に置いても読み込めます
- **明るい部分を筋状に伸ばす**: 種類 最大値・角度 90
- **一方向へ流れるスピード線**: 重み 片側に減衰にして、長さを大きめにする。逆へ流したいときは尾の向きを 後 にする

## 注意事項

- 向きは明るさの変化から決まるので、**一様な色の所では向きが決まりません。** 角度 0 のとき、そこでは横向きに引き延ばします。
  平らな所を動かしたくないときは **長さの決め方 勾配に比例** にしてください
- マップ＝レイヤーで、自分のいるレイヤーを指定した場合は自分の画像を使います
- オブジェクトの大きさは変わりません。端の外側は端の色が続いているものとして読みます
- 重さの目安: 1920x1080 全体に長さ 200 で 1 フレーム約 17ms
- ベクトルブラー_H は長さ 500 で 1 フレーム約 41ms と重い（FHD・本体 2.1.13 で効果ぶんを実測、2026-10-13）
- 初めて表示するときだけ、シェーダーの準備で 0.3 秒ほど止まります
