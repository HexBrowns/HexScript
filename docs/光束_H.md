# 光束_H

掛けたオブジェクトの形から、**光の筋を伸ばす**フィルタ効果です。光の柱、窓から差す日差し、形から放たれる光、光源へ吸い込まれる光を作れます。光の筋は、進むほど広げたり、先細りにしたりもできます。

形は作りません。図形・テキスト・画像などに掛けて、その形から光を伸ばします。芯の白いビームの質感は `ビーム化_H` が受け持ちます。

## インストール

1. `Script\光束_H.anm2` を置く
2. AviUtl2 を再起動する（新しく置いたスクリプトは、再起動するまで一覧に出ません）
3. フィルタ効果の **HexScript → 光束_H** から追加する

## 使い方

### 光の柱（平行）

1. 図形を置き、**図形の種類** を「円」、**サイズ** を 160 にする
2. フィルタ効果「光束_H」を追加する。円の上へ光が伸びる
3. **光の色** で光の色を決める（透明のままなら図形の色で光る）
4. 向きは **方向** で変える（0 = 右、90 = 下、-90 = 上）
5. 光を扇のように広げるなら **拡散角度** を動かす（マイナスで先細り）

光は元の形の**上に**描かれます。強い光ほど形を覆い、形そのものは光に溶け込みます。

### 形から放たれる光（放射）

1. テキストや図形に「光束_H」を追加する
2. **光の出方** を「放射」にする。形の縁から外へ向かって光が伸びる
3. **光源X / 光源Y** で光源を動かす。プレビューに出るアンカーをドラッグしてもよい。光は光源の反対側へ伸びる

光源に向かって縮みながら伸びる光（吸い込まれる光）は、光の出方を「収束」にします。

### 形を光の前に出す（後光）

文字やロゴをくっきり見せたまま、その後ろから光を出したいときは、オブジェクトを 2 つ使います。

1. 形のオブジェクトを複製し、2 つのレイヤーに同じ位置で重ねる
2. **下のレイヤー**の方に「光束_H」を追加し、**光だけ** をオンにする
3. 上のレイヤーの形はそのまま（効果なし）にしておく。光の上に形が乗る

光を明るく重ねたいときは、下のレイヤーの合成モードを「加算」にします。

## パラメータ

### 形

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 光の出方 | 平行 / 放射 / 収束 | 平行 | 平行 = 同じ向きへ伸びる。放射 = 光源から広がる。収束 = 光源へ向かって縮む |
| 光の中身 | 体積光 / ベタ | 体積光 | 光の描き方（下の「体積光とベタ」） |
| 方向 | -360 ~ 360 ° | -90 | 平行のとき。光の伸びる向き。0 = 右、90 = 下、-90 = 上 |
| 画面基準 | オン / オフ | オン | 平行のとき。オンなら、オブジェクトを回しても光は画面上の同じ向きに伸びる。オフなら、オブジェクトと一緒に回る |
| 拡散角度 | -170 ~ 170 ° | 0 | 平行のとき。光の筋が進むほど広がる角度。マイナスにすると先細りになる |
| 光源X / 光源Y | ±100000 px | 0 / 0 | 放射・収束のとき。光源の位置。オブジェクトの画像の中心から数える |
| 長さ | 0 ~ 4000 px | 300 | 光の長さ。0 で光が消える |
| 減衰 | 0 ~ 100 % | 50 | 光が先へ行くほど消えていく度合い。0 は長さいっぱい同じ明るさで、先端でぷつりと切れる |

- 各モードで使わない項目は隠れます（平行のときは光源、放射・収束のときは方向・画面基準・拡散角度）
- **減衰の働き**: 長さの (100 − 減衰) % までは同じ明るさのまま進み、そこから消えていきます。長さの所で約 5 % まで暗くなり、減衰していく尾は長さの (1 + 2 × 減衰) 倍まで届きます（減衰 50 なら長さの 2 倍）。画像もその分だけ大きくなります
- **画面基準** が打ち消すのは Z軸回転だけです。X軸・Y軸回転は打ち消しません
- 光源はオブジェクトの座標で決まるので、オブジェクトを回すと光源も一緒に回ります

#### 拡散角度

形の両端から出る光の筋が、この角度で開きます（60 なら外側へ 30° ずつ）。スポットライトの円錐や、レーザーショーの扇になります。

**マイナスにすると先細りになり、筋が 1 点で交わる所（頂点）で止まります。** 頂点までの距離は、形の幅と角度で決まります（直径 160 の円に -60 なら、円の中心から 139 px 先）。

- 幅は**形そのもの**（透明でない部分）を光の向きに垂直に測ります。画像の四角い枠ではないので、円い形なら**方向を変えても光の長さや広がり方は変わりません**
- 扇の中心は形の中心に合います。画像の中で形が片側に寄っていても、光は形からまっすぐ伸びます

### 体積光とベタ

| | 体積光 | ベタ |
|---|---|---|
| 見た目 | 光の筋を足し合わせた、やわらかい光。厚い所ほど濃くなり、形の隙間は光の筋の抜けになる | 形をそのまま押し出した、中が平らな光。光の筋を横切っても明るさが変わらない |
| 色（光の色が透明のとき） | 光る部分の色が混ざる | 光の筋が最初に当たった所の色 |
| 向く表現 | 霧の中の光線、窓から差す日差し、後光 | 光の柱、押し出し文字、くっきりした光の帯 |

- 体積光の明るさは、形の厚みを基準に揃えています（平行は光の向きに測った形の幅、放射・収束は画像の対角線の半分）。**形がしっかり詰まっていれば、強さ 100 % で形のすぐ外がほぼ最大の明るさ**になります
- **細い線や文字のように隙間の多い形は暗く見えます。** 強さを上げるか、ベタにしてください

### 光

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 光の色 | 色 / 透明 | 透明 | 光の色。**透明にすると元の色で光る**（緑の形なら光も緑） |
| 強さ | 0 ~ 1000 % | 100 | 光の明るさ。0 で消える |
| しきい値 | 0 ~ 100 % | 0 | この明るさ以下の所は光らない。明るさは R・G・B のいちばん大きい値で見る |
| 光だけ | オン / オフ | オフ | オンにすると元の画像を描かず、光だけを残す |

- **光は元の画像の上に描かれます。** 強い光は形を覆い、弱い光なら下の形が透けます。形をはっきり見せたいときは、強さを下げるか「形を光の前に出す（後光）」の手順で重ねてください
- 光が重なって 1 を超えた分は頭打ちになり、白っぽく飛びます。色の付いた光で強さを上げすぎると、光の色が白に寄ります
- **しきい値** は、写真や動画の明るい所だけから光を出したいときに使います。しきい値を超えた分だけが光ります（60 なら、白は光り、50 % の灰色は光らない）
- **光だけ** をオンにすると、光を別のレイヤーとして重ねたり、合成モードを変えたりできます

### 霧

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 霧 | 0 ~ 100 % | 0 | 光をまだらに暗くする強さ。元の画像には掛からない |
| 霧の大きさ | 1 ~ 2000 px | 150 | まだら模様の大きさ |
| 風向き | -360 ~ 360 ° | 0 | 模様が流れる向き。0 = 右、90 = 下 |
| 風の速さ | -5000 ~ 5000 px/秒 | 60 | 模様が流れる速さ。0 で止まる |
| シード | -1000 ~ 1000 | 0 | 模様の乱数 |

- 霧が 0 のときは、風の速さを変えても見た目は変わりません
- 模様はシードだけで決まり、オブジェクトの画像に貼り付いています。オブジェクトを動かすと、模様も一緒に動きます
- **ベタに霧を掛けると、光の柱の中を霧が流れて見えます**（ベタは中が平らなので、まだらがはっきり出る）

### 品質

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 解像度 | 等倍 / 1/2 / 1/4 | 1/2 | 光を計算する解像度。元の画像は常に等倍で描かれる |

光はやわらかいので、たいていは 1/2 で足ります。光の筋の細かい模様（窓の桟など）をくっきり出したいときは等倍にします。1/4 は最も速く、光は少しぼやけますが、明るさはほとんど変わりません。

**光が大きく広がる設定では、解像度が自動で粗くなります**（1/2、さらに 1/4 まで）。大きな形に長い光や大きな拡散角度を掛けると、光を計算する画像が大きくなりすぎて描画が崩れるためです。等倍にしていても、光の筋が少しやわらかくなることがあります。

v1.13 から、AviUtl2 が一時的に持てる画像の量（合わせて約 1600 万画素）に収まるかも見て粗くします。1920x1080 の画像に斜めや放射の長い光を掛けると、1/2 の設定でも 1/4 で計算されます（v1.12 までは、ここで画面が黒くなっていました）。

## 用途例

値は目安です。形の大きさに合わせて調整してください。

| 表現 | 形 | 設定の例 |
|---|---|---|
| 魔法陣から立つ光の柱 | 円や魔法陣の画像 | 平行・方向 -90・ベタ・長さ 600・減衰 60・光の色 水色 |
| 窓から差す日差し | 窓の格子の形（四角形を並べたもの） | 平行・方向 45・体積光・長さ 800・減衰 70・霧 40 |
| スポットライトの円錐 | 小さな円 | 平行・方向 90・拡散角度 40・減衰 80 |
| 文字の後ろから差す光 | テキスト（2 つ重ねる） | 下の文字に 放射・光源は文字の中心（0, 0）・長さ 200・強さ 200・光だけ オン。上の文字はそのまま |
| 吸い込まれる光 | 任意の形 | 収束・光源を形の外に置く・長さ 150 |

## 注意事項

- **フィルタオブジェクトには使えません。** 光の分だけ画像を広げるためです（メニューにも出ません）
- 画像を広げられる上限（1 辺 16384 px、約 839 万画素）を超えると、光が途中で切れます。長さか減衰を小さくしてください
- 作成時の環境（1920x1080 のプロジェクト）での実測では、400 px の枠に放射・長さ 600・解像度 1/2 で 1 フレーム 12 ms 以下、直径 300 の円に平行・長さ 2000・等倍で 11 ms 以下、直径 512 の円に拡散 100・長さ 800・等倍・ベタで 14 ms 以下でした
- 標準描画の **中心X / 中心Y** を動かしたときに、アンカーの位置が光源と合うかは確かめていません
- 設定項目の名前は保存データのキーなので、今後も変えません。保存したプロジェクトの値はそのまま読み込めます

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| 光が出ない | 長さ・強さが 0 でないか、しきい値が高すぎないか確かめる |
| 光が暗い | 強さを上げる。文字や細い線は体積光だと暗くなりやすいので、ベタも試す |
| 形が光に覆われて見えない | 強さを下げる。形をくっきり残したいなら「形を光の前に出す（後光）」の手順で 2 つ重ねる |
| 光が白っぽく色が出ない | 強さを下げる。光の色が透明なら、形の色が白になっていないか確かめる |
| オブジェクトを回すと光の向きも回る | 画面基準をオンにする（平行のとき） |
| 光が途中で切れる | 画像の上限に達している。長さか減衰を小さくする |
| 光の筋の模様がぼやける | 解像度を等倍にする。等倍でもぼやけるなら、光が大きく広がって自動で粗くなっている。長さか拡散角度を小さくする |
| 画面が黒くなり、ログに `invalid buffer type. name=cache:lb/src` が出る | v1.12 以前の症状。v1.13 に更新する |
| 霧が流れない | 霧を 0 より大きくし、風の速さを 0 以外にする |
| 明るい背景の上で、光が背景を覆い隠す | 光だけをオンにした別のオブジェクトを重ね、合成モードを「加算」にする |

## 更新履歴

| 版 | 内容 |
|---|---|
| 1.13 | **大きく広がる設定で画面が黒くなる問題を直した。** 1920x1080 の画像に斜め・放射の長い光（長さ 800 など）を掛けると、光も形も消えて黒くなり、ログに `invalid buffer type` が出ていた。AviUtl2 が一時的に持てる画像の量を超えないよう、光を計算する解像度を自動で 1/4 まで下げる。枠に収まっていた設定の見た目は変わらない |
| 1.12 | 項目のグループ名を変えた（設定値はそのまま読み込める） |
| 1.11 | **光を元の画像の上に描くようにした**（それまでは元の画像が前）。保存済みのプロジェクトも見た目が変わり、形の上に光が乗る。形を前に出したいときは「形を光の前に出す（後光）」の手順を使う |
| 1.10 | **「弧の角度」をなくした。** 弧の角度を設定していたプロジェクトは、光が曲がらずまっすぐ伸びる（ほかの項目の値はそのまま読み込めることを実際のプロジェクトで確かめた）。拡散角度の幅を形そのもので測るようにし、方向を変えても光が伸び縮みしなくなった。大きく広がる設定で描画が崩れる（ログに `invalid buffer type`）問題を直した |
| 1.00 | 初版 |
