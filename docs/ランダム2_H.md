# ランダム2_H

位置・回転・拡大率・透明度を、オブジェクトごとにばらばらの量だけずらすアニメーション効果です。
文字毎に個別オブジェクトにしたテキストや、並べた図形を散らすのに使います。ずれの量は時間では変わらず（ちらつかない）、
設定値を動かすと、ばらばらの向きへ同時に動いていきます。

v1.01（`Script/ランダム2_H.anm2`）。作者不明の `ランダム2.anm2` のフォークです（下の「原作との違い」）。私的に使うためのもので、配布しません。
原作の `ランダム2.anm2` もそのまま残してあるので、両方が一覧に出ます。

## インストール

1. `Script\ランダム2_H.anm2` を配置する
2. AviUtl2 を再起動する（設定項目の変更は「キャッシュを破棄」では反映されません）
3. オブジェクトに「ランダム2_H」を追加する（HexScript の中）

## 使い方

1. 散らしたいオブジェクトに「ランダム2_H」を追加する
2. **X** / **Y** などに、ずらす量の最大値を入れる。オブジェクトごとに、0 からその値までのどこかだけずれる
3. **正負ランダム** が ON（初期値）なら、プラスとマイナスの両方へ散る。OFF なら、入れた値の符号の側にだけずれる
4. 散り方を変えたいときは **Seed** を変える
5. レイヤーを入れ替えても散り方を変えたくないときは、**乱数の基準** を「レイヤーに依存しない」にする

### 例: 1 点から散らばる

原作を実制作で使っていた設定です（同じ図形をレイヤーを 1 つずつずらして 50 個置き、それぞれに掛けた）。

| 項目 | 値 |
|---|---|
| X | 0 → 960（イージングで移動） |
| Y | 0 → 540（同上） |
| 正負ランダム | ON |
| Seed | 0 |
| ほか | 初期値 |

最初は全部が同じ位置にあり、時間とともにそれぞれ別の向きへ散らばっていきます。
原作ではここに Zoom -200 → 0 も入れていました。原作の Zoom は縮小側にしか振れませんが、ランダム2_H では拡大側にも振れるので、同じ値でも見え方が変わります。

### 例: ばらばらの回転から揃う

これも原作を実制作で使っていた設定です。

| 項目 | 値 |
|---|---|
| RX / RY / RZ | -90 → 0（イージングで移動） |
| 正負ランダム | ON |

オブジェクトごとに違う向きに傾いた状態から、正面に揃って登場します。
実制作では、同じ考え方で X / Y を 200 → 0（移動方法 減衰振動）にして、ばらけた位置から定位置へ収める使い方もしていました。

## パラメータ

| 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| X | -10000 ~ 10000 | 0 | 横にずらす量の最大値（px） |
| Y | -10000 ~ 10000 | 0 | 縦にずらす量の最大値（px） |
| Z | -10000 ~ 10000 | 0 | 奥行き方向にずらす量の最大値（px） |
| RX | -1800 ~ 1800 | 0 | X 軸回転に足す角度の最大値（度） |
| RY | -1800 ~ 1800 | 0 | Y 軸回転に足す角度の最大値（度） |
| RZ | -1800 ~ 1800 | 0 | Z 軸回転に足す角度の最大値（度） |
| Zoom | -1000 ~ 10000 | 0 | 拡大率に足す量の最大値（%）。100 なら最大で 100% ぶん足す |
| Alpha | -1000 ~ 1000 | 0 | 不透明度に足す量の最大値（%）。マイナスで透明寄りにする |
| ランダム角度 | -360 ~ 360 | 0 | Z 軸回転に足す角度の最大値（度）。RZ とは別の乱数で、RZ と合わせて足される |
| Seed | -16384 ~ 16384 | 0 | 乱数の種。変えると散り方が変わる。個別オブジェクトとレイヤーに依存しないでは、範囲の外の値（スクリプトや数値入力で入れたもの）は範囲の端として扱う |
| 正負ランダム | ON / OFF | ON | ON なら項目ごとにプラス・マイナスの向きもランダムにする。OFF なら入れた値の符号の側にだけずれる |
| 乱数の基準 | レイヤー（互換） / 個別オブジェクト / レイヤーに依存しない | レイヤー（互換） | 乱数の種の作り方。下の「乱数の基準」 |

項目ごとに別々の乱数を使うので、X と Y のずれは連動しません（下の注意の例外を除く）。

### 乱数の基準

| 選択肢 | 種の作り方 | レイヤーを動かすと |
|---|---|---|
| レイヤー（互換） | レイヤー番号 ＋ Seed。原作と同じ | 散り方が変わる |
| 個別オブジェクト | レイヤー番号 ＋ Seed に、個別オブジェクトの番号（何文字目か）を加える | 散り方が変わる |
| レイヤーに依存しない | Seed と個別オブジェクトの番号だけ。レイヤー番号を使わない | **変わらない** |

- レイヤー（互換）でも、文字毎に個別オブジェクトにしたテキストの文字は、1 文字ずつ別々にずれます（確かめてあります）
- レイヤーに依存しないでは、**Seed が同じオブジェクトどうしは同じだけずれます**（同じテキストの文字どうしは番号が違うので別々）。
  別々のオブジェクトを散らすときは、オブジェクトごとに Seed を変えます
- 個別オブジェクトの番号は 1024 ごとに一巡します（1024 文字を超えるテキストでは、同じずれの文字が出ます）

## 原作との違い

- **乱数の基準** を足した（初期値の「レイヤー（互換）」は原作と同じ種）
- **Zoom** が専用の乱数を使い、正負ランダムも効くようにした。原作の Zoom は「ランダム角度」の乱数を流用していて、
  正負ランダムを ON にしても片側（Zoom がマイナスなら縮小側）にしか振れなかった。この修正はどの基準でも効く
- 旧形式の項目定義を新形式に書き換えた。項目名・範囲・初期値は原作と同じ（原作で初期値の無かった Alpha は 0 にした）

**保存値の互換**: 項目名は原作と同じです。乱数の基準を「レイヤー（互換）」にしておけば、Zoom 以外は原作と同じだけずれます
（ホスト上で確かめてあります）。Zoom を 0 以外にしていた設定は見え方が変わるので、そのまま再現したいときは原作を使います。

## 注意

- 同じオブジェクトに 2 つ重ねて掛け、Seed も同じだと、2 つは同じずれになります（確かめてあります）。重ねるときは Seed を変えます
- レイヤー（互換）で Seed を −(レイヤー番号) より小さくすると、乱数の種がマイナスになり、種が同じになるオブジェクトはすべて同じだけずれます（原作どおり）
- レイヤー（互換）で正負ランダムが ON のとき、Y の向き（プラスかマイナスか）は RX のずれの大きさと連動します（原作どおり）。他の 2 つの基準では起きません
