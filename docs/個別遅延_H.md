# 個別遅延_H

テキストの文字のような**個別オブジェクトを、1 つずつ遅らせて**動かすアニメーション効果です。
文字毎に個別オブジェクトにしたテキストを中間点で動かすと、文字が順にずるっと遅れて追いかけます。
**最後の中間点で非表示** を ON にすると、中間点で止まった文字から順に消えます。

v1.00。ファイルは `Script/個別遅延_H.anm2` です。
`@DelayMove.anm2` の「Delay個別」（AviUtl2 移植版。作者・ライセンスの表記なし）のフォークです（下の「原作との違い」）。
原作の `@DelayMove.anm2` とは名称が違うため、並べて置けます。

## インストール

1. `Script\個別遅延_H.anm2` を配置する。
2. AviUtl2を起動する。
3. オブジェクトに、HexScriptの中にある「個別遅延_H」を追加する。

## 使い方

1. テキストを「文字毎に個別オブジェクト」にし、標準描画の座標などに中間点を打って動かす
2. 同じオブジェクトに「個別遅延_H」を追加する
3. **遅延** で遅れを決める。初期値 100 で、最初の文字と最後の文字のずれが 1 秒（文字の数によらない）
4. 止まった文字から消したいときは **最後の中間点で非表示** を ON にする

### 止まったら消す（最後の中間点で非表示）

遅れた時刻が**最後の中間点**に届いた文字から順に消えます。
例: 0〜6 フレームで Y −300→300、6 フレームに中間点、その後は 300 のまま。遅延 30（4 文字なら 1 文字 0.1 秒）なら、
1 文字目は 6 フレーム、2 文字目は 9 フレーム、3 文字目は 12 フレームで消えます。

- 中間点が無ければ何もしません
- **親レイヤー** を指定したときは、親レイヤーのオブジェクトの中間点で判定します
- 逆順のときは最後の文字から消えます

## パラメータ

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 遅延 | −1000〜1000 | 100 | 遅れの長さ。遅延の時間補正 ON なら 100 で最初と最後のずれが 1 秒、OFF なら 1 個あたりのずれ（ミリ秒） |
| ランダム | 0〜200 | 0 | 動き出すタイミングをばらつかせる |
| 時間ブレ | 0〜1000 | 0 | ランダムに似ているが、時間とともにふらふらと過去や未来を行き来する |
| 順番 | 番号順 / 右から / 上から / 中央から左右へ / 中央から上下へ / 中央から外へ | 番号順 | どの文字から先に動くか（下の「順番」） |
| 逆順 | | OFF | 動く順を逆にする |
| 最後の中間点で非表示 | | OFF | 上の「止まったら消す」 |

### 詳細設定（初期状態では閉じている）

| 項目 | 初期値 | 説明 |
|---|---|---|
| 遅延の時間補正 | ON | ON: 遅延 100 で最初と最後のずれが 1 秒（数によらない）。OFF: 遅延が 1 個あたりのずれ（ミリ秒） |
| シード | 0 | ランダム・時間ブレの乱数の種 |
| 倍率[移動/回転] | {100,100} | 動きの大きさに掛ける倍率（％）。移動と回転を別に |
| 終了補正(秒)[in/out] | {0,0} | オブジェクトの始まり・終わりで、遅れを縮めて追いつかせる時間。0 なら補正しない |
| 時間ブレ周期 | 100 | 時間ブレの揺れの周期 |
| グループ回転 | OFF | 回転をグループ制御のように、オブジェクトの中心のまわりの回転にする（カメラ制御かグループ制御が無いと、Z の移動が拡大縮小に見えることがある） |
| 親レイヤー | 0 | 別のレイヤーのオブジェクトの動きを追う。0 なら自分の動き |
| 番号を無視 | OFF | 順番が番号順のとき、番号を無視してランダム・時間ブレだけでずらす |
| 順番のずらし | 0 | 遅れの段に足す数 |
| 座標を出力 | しない | XYZ / XY にすると、各文字の座標を `DM.layer<レイヤー番号>` に入れる（格子線などの座標に入れて使う） |
| 順番の表示 | OFF | 遅れ具合を色で表示する（赤いほど遅れ、青は先回り） |

### 順番

横書き・中央揃えのテキストのときの並びです。逆順を ON にすると向きが逆になります。

| 順番 | 動く順 | 逆順 ON |
|---|---|---|
| 番号順 | 1 文字目から | 最後の文字から |
| 右から | 右端の列から | 左端の列から |
| 上から | 上の行から | 下の行から |
| 中央から左右へ | 中央の縦の線に近い文字から | 左右の端から |
| 中央から上下へ | 中央の横の線に近い文字から | 上下の端から |
| 中央から外へ | 中央に近い文字から同心円状に | 外側から |

「上から」「中央から上下へ」は 1 行だけのテキストでは使えません（原作と同じ）。

## 原作との違い

- **最後の中間点で非表示** を足しました
- 設定項目を日本語の名前にし、ダイアログ欄の項目を「詳細設定」に分けました。値の意味・範囲・初期値は原作と同じです

| 原作 | 個別遅延_H |
|---|---|
| Delay / random / 時間ブレ / Order / 逆順 | 遅延 / ランダム / 時間ブレ / 順番 / 逆順 |
| Delay時間補正 / Seed | 遅延の時間補正 / シード |
| 倍率[移動/回転] / 終了補正(秒)[in/out] / 時間ブレ周期 / グループ回転 | 同じ名前 |
| 親レイヤーを指定 / indexを無視 | 親レイヤー / 番号を無視 |
| (Orderscirpt) / 座標を出力[0/2] / infoview | 順番のずらし / 座標を出力 / 順番の表示 |

- **順番のずらし（原作の Orderscirpt）には数値しか入りません。** 原作のダイアログ欄のように `obj.ox/30` のような式は書けません
- 原作から入れ替えると、項目名が変わるので保存済みの設定は引き継がれません。作り直してください

## 注意

- 原作と同じく、拡大率と透明度を遅らせるときは、標準描画の拡大率を 0.01 以上、透明度を 99.9 以下にしてください（親レイヤーを指定しているときは不要）
- 逆順のときは、最後の文字にも 1 段分の遅れが付きます（原作と同じ）
