# 微粒子_H

小さな丸い粒（ほこり・水中の浮遊物・雪の細かい粒など）を画面いっぱいに散らし、一定の速さで流すカスタムオブジェクトです。
背景は透明で、粒だけが描かれます。粒は流れ続けても途切れず、継ぎ目も出ません。

- `Script/微粒子_H.obj2`（v1.10）

## インストール

1. `Script\微粒子_H.obj2` を配置する
2. AviUtl2 を再起動する（新しく置いたスクリプトは、再起動するまで一覧に出ません）
3. オブジェクトの追加の **カスタムオブジェクト** から **HexScript → 微粒子_H** を選ぶ

## 使い方

1. 微粒子_H を置く。初期値では画面いっぱいに白っぽい粒が格子からずれた位置に並ぶ（止まったまま）
2. 粒の数は **密度**（横に並ぶ区画の数）と **間引き** で、大きさは **サイズ**（半径）で決める
3. 大小 2 種類の粒を混ぜるなら、**サイズ2** に別の半径を入れ、**サイズ2の比率** で混ぜる割合を決める
4. 流すなら **速度X** / **速度Y** に 1 秒あたりの移動量（px）を入れる
5. 目立たせたくないときは **不透明度** を下げる
6. 画面の一部にだけ出す、または画面より大きく作るなら **画面サイズ** を OFF にして **幅** / **高さ** を決める

### 例: 背景にうっすら漂う粒

実制作で使った設定です（約 53 秒のオブジェクト。標準描画で少し左へずらして置いた）。

| 項目 | 値 |
|---|---|
| 画面サイズ | OFF |
| 幅 / 高さ | 3360 / 1890（画面より大きく作った） |
| 密度 | 45 |
| 散らばり | 90.0 |
| 間引き | 40.0 |
| サイズ / サイズ2 | 1.0 / 1.5 |
| サイズ2の比率 | 25.0 |
| 不透明度 | 35.0 |
| 速度X | 2.50 → -2.50（移動方法「ランダム移動」） |
| 速度Y | 1.00 → -1.00（移動方法「ランダム移動」） |
| ほか | 初期値 |

区画は 3360 ÷ 45 で約 75 px 四方になり、その 4 割を空けているので、粒はまばらです。
半径 1 ~ 1.5 px の小さな粒を不透明度 35% で置き、主張させずに漂わせています。
速度をランダム移動で ±2.5 / ±1.0 px/秒 の間に揺らしているので、粒は向きを変えながらゆっくり漂います。

## パラメータ

### 配置

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 幅 | 0 ~ 4000 | 1920 | 描く範囲の幅（px）。画面サイズが ON のときは使わない |
| 高さ | 0 ~ 4000 | 1080 | 描く範囲の高さ（px）。画面サイズが ON のときは使わない |
| 画面サイズ | ON / OFF | ON | ON なら画面（シーン）の大きさで描く。OFF なら幅・高さで描く |
| 密度 | 4 ~ 400 | 80 | 横に並ぶ区画の数。区画は正方形で、1 辺は「描く範囲の幅 ÷ 密度」px。区画ごとに粒が最大 1 つ |
| 散らばり | 0 ~ 100 | 80 | 区画の中で粒の位置をずらす量（%）。横と縦は別々の乱数でずれる。0 なら区画の中心に格子状に並ぶ |
| 間引き | 0 ~ 100 | 0 | 粒を置かない区画の割合（%） |
| シード | 0 ~ 9999 | 0 | 粒の並び方を変える種 |

画面サイズを ON にしても幅・高さの項目は消えません（値が使われないだけです）。

### 粒

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 色 | - | f2fafc | 粒の色（初期値はほぼ白の淡い水色） |
| サイズ | 0.1 ~ 20 | 2 | 粒の**半径**（px）。縁は幅 1.4 px ほどでなめらかに消える（半径によらず同じ） |
| サイズ2 | 0.1 ~ 20 | 2 | もう 1 種類の粒の半径（px） |
| サイズ2の比率 | 0 ~ 100 | 0 | サイズ2 で描く粒の割合（%）。0 なら全部サイズ、100 なら全部サイズ2 |
| 不透明度 | 0 ~ 100 | 100 | 粒の不透明度（%） |

### 動き

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 速度X | -200 ~ 200 | 0 | 1 秒あたりの横の移動量（px）。プラスで右へ流れる。時間で動かしてよい（下の「注意」） |
| 速度Y | -200 ~ 200 | 0 | 1 秒あたりの縦の移動量（px）。プラスで下へ流れる |

## 注意

- **速度は時間で動かしてかまいません。** 粒はオブジェクトの先頭からの速度を積み上げた距離だけ流れるので、
  速度を変えるとその時点から流れる速さが変わるだけで、粒が跳んだりはしません
  （v1.00 は「その時点の速度 × 経過秒」で決めていたので、後半ほど速度の小さな変化で粒が大きく動いていました）
- 約 256 フレーム（30fps で 8.5 秒）より長いオブジェクトでは、速度を積み上げる刻みが粗くなります。
  速度が急に折れる・跳ぶ所では流れた量がわずかにずれます（粒の位置が跳ぶことはありません）
- **v1.10 で乱数の作り方を変えたので、同じシードでも粒の並びは v1.00 と違います。** v1.00 は横と縦のずれが連動していて、
  粒が斜めの向きにしか散らばっていませんでした
- サイズ（半径）が区画の 1 辺（描く範囲の幅 ÷ 密度）より大きいと、粒の端が切れることがあります。
  大きな粒を使うときは密度を下げます
- 粒は描く範囲（幅 × 高さ）の中にだけ描かれます。範囲の外へ流れ出た粒は反対側から入ってくるのではなく、
  範囲の外にある区画の粒が新しく流れ込んできます（途切れも継ぎ目もありません）
