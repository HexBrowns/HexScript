# 微粒子_H

小さな丸い粒を画面いっぱいに散らし、一定の速さで流すカスタムオブジェクトです。
背景は透明で、粒だけが描かれます。
粒は流れ続けても途切れず、継ぎ目も出ません。

- `Script/微粒子_H.obj2`（v1.10）

## インストール

1. `Script\微粒子_H.obj2` を配置する。
2. AviUtl2を起動する。新しく置いたスクリプトは、再起動するまで一覧に出ない。
3. オブジェクトの追加の **カスタムオブジェクト** から **HexScript → 微粒子_H** を選ぶ。

## 使い方

1. 微粒子_Hを置く。初期値では画面いっぱいに白っぽい粒が格子からずれた位置に並び、止まったまま動かない。
2. 粒の数は **密度** と **間引き** で決める。粒の半径は **サイズ** で決める。
3. 大小 2 種類の粒を混ぜるなら、**サイズ2** に別の半径を入れ、**サイズ2の比率** で混ぜる割合を決める。
4. 流すなら **速度X** / **速度Y** に 1 秒あたりの移動量を入れる。
5. 目立たせたくないときは **不透明度** を下げる。
6. 画面の一部にだけ出す、または画面より大きく作るなら **画面サイズ** をOFFにして **幅** / **高さ** を決める。

### 例: 背景にうっすら漂う粒

実制作で使った設定です。
約 53 秒のオブジェクトを、標準描画で少し左へずらして置きました。

| 項目 | 値 |
|---|---|
| 画面サイズ | OFF |
| 幅 / 高さ | 3360 / 1890（画面より大きく作った） |
| 密度 | 45 |
| 散らばり | 90.0 |
| 間引き | 40.0 |
| サイズ / サイズ2 | 1.0 / 1.5 |
| サイズ2の比率 | 25.0 |
| 不透明度 | 35.0 |
| 速度X | 2.50 → -2.50（移動方法「ランダム移動」） |
| 速度Y | 1.00 → -1.00（移動方法「ランダム移動」） |
| ほか | 初期値 |

区画は 3360 ÷ 45 で約 75 px 四方になり、その 4 割を空けているので、粒はまばらです。
半径 1 ~ 1.5 px の小さな粒を不透明度 35% で置き、主張させずに漂わせています。
速度をランダム移動で ±2.5 / ±1.0 px/秒 の間に揺らしているので、粒は向きを変えながらゆっくり漂います。

## パラメータ

### 配置

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 幅 | 0 ~ 4000 px | 1920 | 描く範囲の幅。画面サイズがONのときは使わない |
| 高さ | 0 ~ 4000 px | 1080 | 描く範囲の高さ。画面サイズがONのときは使わない |
| 画面サイズ | ON / OFF | ON | ONなら画面の大きさで描く。OFFなら幅・高さで描く |
| 密度 | 4 ~ 400 | 80 | 横に並ぶ区画の数。区画は正方形で、1 辺は「描く範囲の幅 ÷ 密度」px。区画ごとに粒が最大 1 つ |
| 散らばり | 0 ~ 100 % | 80 | 区画の中で粒の位置をずらす量。横と縦は別々の乱数でずれる。0 なら区画の中心に格子状に並ぶ |
| 間引き | 0 ~ 100 % | 0 | 粒を置かない区画の割合 |
| シード | 0 ~ 9999 | 0 | 粒の並び方を変える種 |

画面サイズをONにしても幅・高さの項目は消えません。

### 粒

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 色 | - | f2fafc | 粒の色 |
| サイズ | 0.1 ~ 20 px | 2 | 粒の**半径**。縁は半径によらず幅 1.4 px ほどでなめらかに消える |
| サイズ2 | 0.1 ~ 20 px | 2 | もう 1 種類の粒の半径 |
| サイズ2の比率 | 0 ~ 100 % | 0 | サイズ2 で描く粒の割合。0 なら全部サイズ、100 なら全部サイズ2 |
| 不透明度 | 0 ~ 100 % | 100 | 粒の不透明度 |

### 動き

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 速度X | -200 ~ 200 px | 0 | 1 秒あたりの横の移動量。プラスで右へ流れる。時間で動かしてよい |
| 速度Y | -200 ~ 200 px | 0 | 1 秒あたりの縦の移動量。プラスで下へ流れる |

## 注意

- **速度は時間で動かしてかまいません。** 粒はオブジェクトの先頭からの速度を積み上げた距離だけ流れるので、
  速度を変えるとその時点から流れる速さが変わるだけで、粒が跳んだりはしません
- 約 256 フレームより長いオブジェクトでは、速度を積み上げる刻みが粗くなります。
  速度が急に折れる・跳ぶ所では流れた量がわずかにずれます。粒の位置が跳ぶことはありません
- **v1.10 で乱数の作り方を変えたので、同じシードでも粒の並びは v1.00 と違います。** v1.00 は横と縦のずれが連動していて、
  粒が斜めの向きにしか散らばっていませんでした
- サイズが区画の 1 辺より大きいと、粒の端が切れることがあります。
  大きな粒を使うときは密度を下げます
- 粒は描く範囲の中にだけ描かれます。範囲の外へ流れ出た粒は反対側から入ってくるのではなく、
  範囲の外にある区画の粒が新しく流れ込んできます
