# SceneTransitions

シーンチェンジ 3 種を 1 ファイルにまとめたシーンチェンジスクリプトです。

- `Script/@SceneTransitions.scn2`（各セクション v1.10）

| セクション | 一覧での名前 | 内容 |
|---|---|---|
| スマッシュカット | `スマッシュカット@SceneTransitions` | 途中で白くフラッシュさせて、そのピークで次のシーンへ切り替える |
| ズームトランジション | `ズームトランジション@SceneTransitions` | 拡大か縮小をし続けながら次のシーンへクロスフェードする |
| パララックス | `パララックス@SceneTransitions` | 前のシーンが抜けていき、次のシーンが遅れて入ってくる間をクロスフェードする。奥行きの差で速さが違う |

## 動作の状況

**v1.10 は実機でシーンチェンジとして動くことを確かめました**。

v1.00 は本体の説明書に無い書き方で書かれていて、シーンチェンジとして動かなかったとみられます。
v1.10 で説明書の「シーンチェンジスクリプトの例」の書き方に直しました。
あわせて下の「v1.10 で変えたこと」の式も直しています。

## インストール

1. `Script\@SceneTransitions.scn2` を配置する。ファイル名先頭の `@` は外さない。
2. AviUtl2を起動する。
3. シーンチェンジの種類の一覧で、HexScriptの中から選ぶ。

ヘッダーで本体のバージョン `2010800` 以上を要求しています。

## 使い方

1. 本体のシーンチェンジと同じように、シーンの切り替わるフレームに開始フレームを合わせて置く。
2. 種類から 3 つのうちどれかを選ぶ。
3. 下の表の項目を調整する。

## パラメータ

### スマッシュカット

<!-- サンプル動画 -->
<img src="samples/SceneTransitions/%E3%82%B9%E3%83%9E%E3%83%83%E3%82%B7%E3%83%A5%E3%82%AB%E3%83%83%E3%83%88.webp" width="480" alt="スマッシュカット@SceneTransitions のサンプル">

| 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| フラッシュ時間 | 0 ~ 100 | 30 | フラッシュの長さ。シーンチェンジ全体の長さに対する %。0 でフラッシュなしの切り替え |
| フラッシュ明度 | 0 ~ 100 % | 80 | フラッシュのいちばん明るいときの白さ |
| スタイル | 標準 / ハード / ソフト | 標準 | 標準: ピークで切り替え、なめらかに消える。ハード: ピークで切り替え、一定の速さで消える。ソフト: フラッシュの間に前から後へクロスフェードし、なめらかに消える |

- フラッシュは全体の 45% の位置から始まります。フラッシュ時間が 55 より長いときは、シーンチェンジの終わりで消えきるよう前に寄せます
- フラッシュの最初の 2 割で白くなり、残りの 8 割で消えます。フラッシュが始まるまでは切り替え前、消えた後は切り替え後の画像そのものです
- 「効果音付き」は v1.10 で外しました。保存済みの値を消さないよう項目は残し、設定画面には出しません

### ズームトランジション

<!-- サンプル動画 -->
<img src="samples/SceneTransitions/%E3%82%BA%E3%83%BC%E3%83%A0%E3%83%88%E3%83%A9%E3%83%B3%E3%82%B8%E3%82%B7%E3%83%A7%E3%83%B3.webp" width="480" alt="ズームトランジション@SceneTransitions のサンプル">

| 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| ズーム量 | 0 ~ 200 % | 100 | 足す倍率。倍率は 1 + ズーム量/100。100 で 2 倍、0 で等倍になり、ただのクロスフェードになる |
| 中心X | -100 ~ 100 px | 0 | ズームの中心を、画面の中央から横にずらす量。プラスで右 |
| 中心Y | -100 ~ 100 px | 0 | ズームの中心を、画面の中央から縦にずらす量。プラスで下 |
| 方向 | イン / アウト | イン | イン: 切り替え前が等倍から拡大していき、切り替え後は縮んだ状態から拡大して等倍に止まる。アウト: その逆で、縮小し続ける |

- 始まりは切り替え前の画像がそのまま、終わりは切り替え後の画像がそのままです
- 縮んだ画像の外側は、もう一方の画像だけで埋めます

### パララックス

<!-- サンプル動画 -->
<img src="samples/SceneTransitions/%E3%83%91%E3%83%A9%E3%83%A9%E3%83%83%E3%82%AF%E3%82%B9.webp" width="480" alt="パララックス@SceneTransitions のサンプル">

| 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 視差深度 | 0 ~ 100 | 50 | 切り替え前の画像が動く量。画面の幅に対する %。上下なら高さに対する % |
| 方向 | 右 / 左 / 上 / 下 | 右 | 画像が動く向き |

- 切り替え前の画像は元の位置から「方向」へ抜けていき、切り替え後の画像はその半分の量だけ反対側から入ってきて元の位置に止まります。その間をクロスフェードします
- 画像が抜けた部分は、もう一方の画像だけで埋めます

## v1.10 で変えたこと

- 説明書どおりの読み書きに直した（上の「動作の状況」）
- スマッシュカット: 「ソフト」がハードと同じ消え方になっていたのを、クロスフェードする形にした。フラッシュ時間が 55 より長いと
  終わりまでに消えきらなかったのを直した。フラッシュ中に下地が黒くなっていた（切り替え前も後も見えなかった）のを、
  切り替え前・後の画像を白へ寄せる形にした。消え始めが明度の 7 割へ跳んでいたのをなくした
- ズームトランジション: 初期値（ズーム量 100）でズームしなかった・ズーム量 0 で倍率 0 になった・切り替え後の画像が
  終わりまで拡大されたままで最後に等倍へ跳んだ・「イン」で始まりから拡大されていた、を直した
- パララックス: ずれが最大でも 1 ピクセルほどしかなかったのを、画面に対する % にした。始まりで切り替え前の画像が
  ずれた位置から始まっていたのを直した。「右」で画像が左へ動いていたのを、名前どおりの向きにした

## 注意

- ズーム量・視差深度・スタイルのソフトは、v1.00 から意味が変わっています。v1.00 で保存した値はそのまま読まれますが、見た目は変わります
- 項目の表示名と選択肢は v1.00 と同じです。項目を変えたので、入れ替えた後はAviUtl2の再起動が必要です
