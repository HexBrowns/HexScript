# 押し出し_H

オブジェクトの形を奥行き方向に押し出して、厚みのある立体にする効果です。
縁には面取りか丸みのベベルを付けられます。
After Effectsの 3D テキストの「押し出し」と「ベベル」に当たります。
文字・図形・透過画像など、形のあるものに掛けます。

## インストール

1. `Script\押し出し_H.anm2` を配置する。
2. AviUtl2を起動する。

## 使い方

1. テキストや図形のオブジェクトに、フィルタ効果の追加メニューのラベル **HexScript** の中にある「押し出し_H」を掛ける。
2. 標準描画の **X軸回転 / Y軸回転** で傾けると、側面とベベルが見える。正面からは、ベベルの陰影だけが見える。
3. **奥行き** で厚みを、**ベベルの形・幅・深さ** で縁の形を決める。
4. **光の向き・光の高さ** で、どちらの面を明るくするかを決める。

カメラ制御の下に置くと、本当の 3D として見えます。

## パラメータ

### 押し出し

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 奥行き | 0 ~ 2000 px | 40 | 押し出す厚み。0 で何もしない |
| 側面の間隔 | 1 ~ 8 px | 2 | 側面とベベルを描く板の間隔。小さいほど縁がなめらかになるが重い。斜めから見て輪郭が階段状に見えるときは小さくする |
| 側面の色の決め方 | 色 / 元の色 | 色 | 色: 側面の色で塗る。元の色: 表面と同じ色を奥へ伸ばす |
| 側面の色 | 色 | 808080 | 側面の色の決め方＝色のとき、側面と裏面の色 |
| 裏面を描く | ON / OFF | ON | 裏面を描く。裏から見ない場合はOFFにすると少し軽い |

### ベベル

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| ベベルの形 | なし / 面取り / 丸み | 面取り | 表面の縁の形。面取りはまっすぐ斜めに、丸みは丸く削る |
| ベベルの幅 | 0 ~ 200 px | 6 | 縁から内側へ削る幅 |
| ベベルの深さ | 0 ~ 200 px | 6 | 奥行き方向に削る深さ。奥行きより深くはならない |
| ベベルの色の決め方 | 表面と同じ / 側面と同じ | 表面と同じ | ベベルの面の色を、表面の色にするか側面の色にするか |

### 光

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 光の向き | -360 ~ 360 度 | 135 | 光の来る向き。0 が右、90 が上、135 が左上、315 が右下 |
| 光の高さ | 0 ~ 90 度 | 45 | 0 で真横から、90 で真正面から照らす |
| 環境光 | 0 ~ 100 | 35 | 光の当たらない面の明るさ。100 で陰影なし |
| 表面にも陰影 | ON / OFF | OFF | ONで表面にも光の当たり方の明暗を付ける。OFFでは表面は元の色のまま |

## 使い方の例

- **ロゴ文字を立体に**: 奥行き 40〜100・ベベルの形 丸み・幅 / 深さ 4〜10。Y軸回転 20〜30 で側面を見せる
- **側面だけ別の色に**: 側面の色の決め方 色・側面の色を暗い色に・ベベルの色の決め方 表面と同じ
- **平らな板**: ベベルの形 なし・奥行き 4〜10・側面の色の決め方 元の色

## 注意事項

- **この効果より下に掛けたフィルタ効果は掛かりません**。縁取りや色調補正は、この効果より上に置いてください
- 内側は詰まった立体ではなく、薄い板を重ねて描いています。真横から見ると板の段が見えることがあります。気になるときは **側面の間隔** を小さくしてください
- カメラ制御の外では、オブジェクトの中心から見た遠近で描かれます。
  回転が 90 度を超えて裏返ったときは描く順番を入れ替えて、裏面が手前に来るようにしています
- 板 1 枚ごとにオブジェクトの大きさ全部を塗るので、**大きいオブジェクト・深い奥行きほど重くなります**。重いときは側面の間隔を広げてください
- 重さの目安: FHDの中の 1200x300 のオブジェクト・奥行き 100・丸み 20・側面の間隔 2 で、1 フレーム約 18ms
- 初めて表示するときは、シェーダーの準備で 0.2 秒ほど止まります
