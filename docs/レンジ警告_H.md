# レンジ警告_H

白飛び・黒潰れ・色域外（0 未満 / 1 超）の画素を、色付きの縞（ゼブラ）で示す検査用のフィルタ効果です。
露出計のように素材の明るさを確かめるためのもので、縞は画面に固定され、オブジェクトを動かしても流れません。

v1.10。

## インストール

1. `Script\レンジ警告_H.anm2` を配置する
2. AviUtl2 を再起動する（設定項目の変更は「キャッシュを破棄」では反映されません）
3. オブジェクトに「レンジ警告_H」を追加する（HexScript の中）

フィルタオブジェクトとしても使えます。そのときは、それまでに描かれた画面全体を検査します。

## 使い方

1. 検査したい素材（画像・動画）に「レンジ警告_H」を追加する。画面全体を見たいときはフィルタオブジェクトとして置く
2. 白飛びしている所に赤、黒潰れしている所に青の縞が出る
3. 範囲を詰めたいときは **白飛びしきい値** / **黒潰れしきい値** を動かす
4. 警告の場所を見つけやすくしたいときは **警告部分だけ表示** を ON にする（警告の出ていない所が灰色になる）
5. 確認が済んだら効果を外すか無効にする（検査用の表示なので、出力に残さない）

### 例: ほぼ全面に縞が出るとき

初期値の判定方式「チャンネル極値」は、R・G・B のどれか 1 つでもしきい値に届けば警告します。
鮮やかな色は R・G・B のどれかが 1 や 0 に張り付くので、淡い色や単色に寄った素材ではほぼ全面に縞が出ることがあります
（素材の情報が失われているかを見るには、これが正しい判定です）。どこが明るすぎるかを見たいときは、次のどちらかにします。

| 項目 | 値 |
|---|---|
| 判定方式 | 輝度 |

または、**白飛びしきい値** を引き上げます（初期値 99）。

## パラメータ

### 表示

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 白飛びを表示 | ON / OFF | ON | 白飛びの警告を出す |
| 黒潰れを表示 | ON / OFF | ON | 黒潰れの警告を出す |
| 色域外を表示 | ON / OFF | OFF | 0 未満か 1 を超える値を持つ画素の警告を出す |

3 つとも OFF にすると何もしません。

### しきい値

| 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 判定方式 | チャンネル極値 / 輝度 | チャンネル極値 | チャンネル極値は、白飛びを R・G・B の最大値、黒潰れを最小値で判定する（1 チャンネルでも飽和すれば警告）。輝度は、白飛び・黒潰れとも同じ輝度（Rec.709 の係数）で判定する |
| 白飛びしきい値 | 0 ~ 100 | 99 | この値（%）以上を白飛びとする。白飛びを表示が OFF のときは隠れる |
| 黒潰れしきい値 | 0 ~ 100 | 1 | この値（%）以下を黒潰れとする。黒潰れを表示が OFF のときは隠れる |

色域外は、判定方式によらず常に R・G・B のどれかが 0 未満か 1 を超えるかで判定します。

### 見た目

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 白飛びの色 | - | FF0000 | 白飛びの縞の色。白飛びを表示が OFF のときは隠れる |
| 黒潰れの色 | - | 0000FF | 黒潰れの縞の色。黒潰れを表示が OFF のときは隠れる |
| 色域外の色 | - | FFFF00 | 色域外の縞の色。色域外を表示が OFF のときは隠れる |
| 縞の幅 | 1 ~ 64 | 8 | 縞 1 周期（色の帯と素通しの帯の 1 組）の幅（画面上の px）。色の帯はその半分 |
| 縞の角度 | -180 ~ 180 | 45 | 縞の向き（度）。0 で縦縞、90 で横縞 |
| 警告の濃さ | 0 ~ 100 | 80 | 縞の色を元の色に重ねる濃さ（%）。100 で縞の部分が警告の色そのものになる |
| 警告部分だけ表示 | ON / OFF | OFF | ON なら、警告に当たらない画素を灰色（明るさだけ）にして、警告を目立たせる |

1 つの画素が複数の条件に当たるときは、色域外 ＞ 白飛び ＞ 黒潰れ の順に 1 つだけ表示します。
判定は透明度を除いた色で行い、完全に透明な画素は判定しません。

## 縞が画面に固定される範囲

縞の位置は、標準描画の X / Y / 拡大率 / 中心 / Z 軸回転と、この効果より前の効果が動かした分から、画面の座標で決めています。
オブジェクトを動かしても、Z 軸回転しても、縮小しても、縞は画面に対して同じ位置・同じ向きのままです。

次の場合は、縞が画面に固定されません。

- **拡大率が 100% を超えるとき。** 縞がオブジェクトの画素より細かくなって見えなくならないよう、画面上の縞の幅を拡大率の分だけ太くします。拡大率を動かすと縞の幅も変わります
- この効果より**後ろ**に置いた効果でオブジェクトを動かしたとき（画面に揃えたいなら、動かす効果より後ろにレンジ警告_H を置く）
- X 軸・Y 軸回転、カメラ制御の下のオブジェクト、グループ制御に追加したとき

フィルタオブジェクトとして置いたときは、常に画面に固定されます。

## 注意

- **警告部分だけ表示** は色の鮮やかさを落として見せるものなので、灰色の素材では見た目が変わりません
- 色域外は、検証で発光系の効果により 1.0 を超えるはずの素材に掛けても、警告が出ませんでした（効果に渡る前に 0〜1 に収まっていたとみられます）。どの場面で出るかは確かめていません
- 縞や灰色を描いた画素は 0〜1 に収めて出力します。警告に当たらず、警告部分だけ表示も OFF の画素は、元の値のまま通します
