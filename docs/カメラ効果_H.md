# カメラ効果_H

カメラ制御に掛けて、カメラを回す・動かす・目標をずらす・傾ける・寄るためのカメラ効果です。5 つのセクションに分かれています。

- `Script/@カメラ効果_H.cam2`（v1.00）
- 「@Camera」（`Script/@Camera.cam2`、作者・版の記載なし）をフォークしたものです（下の「原作との違い」）

| セクション | すること |
|---|---|
| 回転@カメラ効果_H | カメラの向きを回す。その場で首を振る（パン・ティルト）か、目標のまわりを回り込む |
| 座標@カメラ効果_H | カメラの位置を動かす（ドリー・トラック） |
| 目標座標@カメラ効果_H | カメラの目標（見ている点）を動かす |
| 傾き@カメラ効果_H | カメラを視線のまわりに傾ける |
| ズーム@カメラ効果_H | 寄る・引く（スクリーンまでの距離の倍率） |

## インストール

1. `Script\@カメラ効果_H.cam2` を配置する
2. AviUtl2 を再起動する（設定項目の変更は「キャッシュを破棄」では反映されません）
3. カメラ制御に「回転@カメラ効果_H」などを追加する（HexScript の中）

## 使い方

座標系は AviUtl2 と同じで、X が右、Y が下、Z が奥です。既定のカメラは (0, 0, -1024) から原点を見ています。
どのセクションも、カメラ制御の値（と、それより上に置いたカメラ効果の結果）に足す形で効きます。

### 例: 奥へ寄っていく・引いていく（実制作での使い方）

原作の「座標@Camera」を実制作で使った設定です。座標@カメラ効果_H は項目も挙動も原作と同じなので、同じ値で同じ絵になります。

| 項目 | 値 |
|---|---|
| X / Y | 0 |
| Z | -128 → -256 のように 128 ずつ、カーブエディタ2 で移動 |
| 平行移動 | OFF |
| カメラ基準 | OFF |

カメラ制御（レイヤー 2）の下のレイヤーに、座標@Camera だけを持つ短いオブジェクトを並べ、区間ごとに Z を 128 ずつ動かしていました。
Z をマイナスにするとカメラが手前へ下がって小さく、プラスにすると奥へ進んで大きく写ります（Z 300 で Z=0 の物が約 1.41 倍）。

### 例: 画面を横へ流す（実制作での使い方）

同じく原作で、カメラ制御に直接追加した設定です。**平行移動** を ON にし、**X** を 0 → 480 へ移動させていました。
カメラと目標が一緒に動くので、向きを変えずに画面が横へ流れます。Y で縦に流すこともしていました（0 → -480）。

### その場で首を振る（パン・ティルト）

1. 回転@カメラ効果_H を追加する
2. **回転の中心** を「カメラ位置」、**カメラ基準** を ON にする
3. **Y軸回転** をプラスにすると視線が右へ、**X軸回転** をプラスにすると視線が上へ振れる

カメラ基準 ON なら、角度 0 のときは今の向きのままです。そこから何度振るかを入れます。

### 被写体のまわりを回り込む

1. 回転@カメラ効果_H を追加する
2. **回転の中心** を「目標座標」にする
3. **Y軸回転** を 0 → 360 へ移動させると、目標のまわりを水平に 1 周する

目標とカメラの距離は保たれます。目標は目標座標@カメラ効果_H やカメラ制御の目標で決めます。

### 寄る・引く

ズーム@カメラ効果_H の **ズーム率** を 100 より大きくすると寄り、小さくすると引きます（110% で約 1.1 倍に写る）。
カメラの位置は変わらないので、座標の Z で寄るのと違ってパース（遠近感）は変わりません。

## パラメータ

### 回転@カメラ効果_H

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| X軸回転 | -3600 ~ 3600 | 0 | 縦に振る角度（度）。プラスで視線が上へ |
| Y軸回転 | -3600 ~ 3600 | 0 | 横に振る角度（度）。プラスで視線が右へ |
| Z軸回転 | -3600 ~ 3600 | 0 | 傾きに足す角度（度）。傾き@カメラ効果_H と同じ |
| 回転の中心 | カメラ位置 / 目標座標 | カメラ位置 | カメラ位置は、カメラが動かず目標が動く（首振り）。目標座標は、目標が動かずカメラが回り込む |
| カメラ基準 | ON / OFF | OFF | OFF は角度 0 で正面（+Z、奥）を向く。ON は角度 0 で今の向きのまま、そこから回す |

- **カメラ基準 OFF では、角度 0 でも正面を向き直ります。** カメラ制御の目標を横にずらしていても、X・Y 0 なら正面（+Z）を見ます
  （回転の中心が目標座標なら、目標の真正面の手前へ回り込む）。今の向きから振りたいときはカメラ基準を ON にします
- X軸回転 で真上・真下を越えて回すと、画面が裏返らないように傾きへ 180 度を足します
- カメラ位置と目標が同じ点にあると、向きが決まらないので X軸回転・Y軸回転は何もしません（Z軸回転だけ効きます）

### 座標@カメラ効果_H

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| X | -10000 ~ 10000 | 0 | カメラを動かす量（横） |
| Y | -10000 ~ 10000 | 0 | カメラを動かす量（縦。プラスで下） |
| Z | -10000 ~ 10000 | 0 | カメラを動かす量（奥行き。プラスで奥） |
| 平行移動 | ON / OFF | OFF | ON なら目標も同じだけ動かす（向きが変わらない）。OFF ならカメラだけ動き、目標を見たまま |
| カメラ基準 | ON / OFF | OFF | OFF は画面の X・Y・Z の向きに動かす。ON はカメラの右・下・視線の向きに動かす |

### 目標座標@カメラ効果_H

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| X | -10000 ~ 10000 | 0 | 目標に足す量（横） |
| Y | -10000 ~ 10000 | 0 | 目標に足す量（縦。プラスで下） |
| Z | -10000 ~ 10000 | 0 | 目標に足す量（奥行き） |

### 傾き@カメラ効果_H

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 傾き | -10000 ~ 10000 | 0 | カメラ制御の傾きに足す角度（度） |

### ズーム@カメラ効果_H

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| ズーム率 | 1 ~ 1000 | 100 | スクリーンまでの距離に掛ける倍率（%）。100 で変化なし、大きいほど寄る |

ズーム率は角度（画角）ではありません。何度の画角になるかの換算は分かっていないので、見た目で合わせます。

## 原作との違い

原作「@Camera」（`Script/@Camera.cam2`）はそのまま残してあります。

- **回転**: 原作は「カメラ基準」を ON にすると回転しませんでした（中身が空）。4 通り（首振り / 回り込み × 絶対 / カメラ基準）すべて動きます
- **回転**: 原作の首振り（目標中心回転 OFF）は、目標が原点以外にあると視線が飛んでいました（新しい目標に元の目標座標を二重に足していた）。直しました
- **回転**: 首振りと回り込みで、同じ角度なら同じ向きを向くように揃えました（原作の首振りとは X・Y の回る向きが逆です）
- **回転**: 項目名を変えました（原作は X / Y / Z / 目標中心回転 / カメラ基準）。原作の回転の設定は引き継げません
- **視野角 → ズーム**: 原作の視野角は、初期値 0 のまま置いただけでスクリーンまでの距離に 120 を足し、画面が拡大されていました。
  倍率（ズーム率、初期値 100% で変化なし）に置き換えました
- **座標・目標座標・傾き**: 項目名も挙動も原作と同じです。原作が使っていた `Vec3.lua` は要りません

効果の名前が違うので、原作を使っているプロジェクトは原作のまま動きます（自動では置き換わりません）。
座標は `effect.name=座標@Camera` を `座標@カメラ効果_H` に書き換えれば、設定を引き継いで同じ絵になります。

## 注意

- **座標のカメラ基準 ON には原作の癖が残っています**（原作と同じ絵にするため）。カメラが上下を向くほど X・Y の動く量が縮みます（Z は縮みません）。
  カメラ位置と目標が同じ点にあるときにカメラ基準を ON にすると、カメラの座標が計算できなくなり正しく写りません（原作も同じ）
- 上下を向いたカメラを、回転のカメラ基準 ON で回すと、画面の傾きは揃いません。真上・真下の近くで画面が 180 度反転することがあります。
  水平なカメラ（既定のカメラなど）ではこれは起きません
- カメラの上方向を書き換える効果（オートターゲット系）の後ろに置いたときの見え方は確かめていません
- 原作の作者・ライセンスは分かりません。原作の部分の権利は原作者にあります。HexScript では、原作者から求めがあれば取り下げる前提で公開しています
