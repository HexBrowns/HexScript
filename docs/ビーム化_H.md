# ビーム化_H

掛けたオブジェクトの形を、**白く光る芯と色の付いた光**でできたビーム・レーザーに描き替えるフィルタ効果です。長さ方向のフェード、流れる揺らぎ、ちらつきも付けられます。

形は作りません。図形・テキスト・LongShadowN などで作った形に掛けて、見た目だけを変えます。折れ線や曲線の形に掛けると、フェードと揺らぎが曲がりに沿います（v1.10 の **長さの測り方 = 形に沿う**）。

## インストール

1. `Script\ビーム化_H.anm2` を置く
2. AviUtl2 を再起動する（新しく置いたスクリプトは再起動するまで一覧に出ません）
3. フィルタ効果の **HexScript → ビーム化_H** から追加する

## 使い方

いちばん手早いのは、図形の四角形を細長くして掛ける方法です。

1. 図形を置き、**図形の種類** を「四角形」、**サイズ** を 600、**縦横比** を -90 にする（600x60 の横長の帯）
2. **色** をビームの色にする（例: 青）
3. フィルタ効果「ビーム化_H」を追加する。帯の中が白く光り、周りが図形の色で光る
4. 向きは標準描画の **Z軸回転** で変える。**方向** は 0 のままでよい
5. 明るい背景の上に重ねるときは、標準描画の **合成モード** を「加算」にする

図形の色を白のままにして、**光の色** でビームの色を決めてもかまいません。

### 曲がったビーム

反射して折れるレーザーや、曲がりながら飛ぶホーミングレーザーは、折れ線・曲線の形に掛けます。

1. 形を作る。反射するレーザーなら `光線経路_H`（鏡で自動的に反射する）、手で折れ線を描くなら `パス図形σ@Path_S`（線タイプ 折れ線）、曲線なら同じくベジェ曲線
2. フィルタ効果「ビーム化_H」を追加し、**長さの測り方** を「形に沿う」にする
3. **先端のフェード** や **揺らぎ** を入れる。曲がった先まで、線に沿って消え・流れる

## パラメータ

### 光

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 光の色 | 色 / 透明 | 透明 | 周りの光の色。**透明にすると元の色で光る**（虹色の形なら光も虹色） |
| 内側の広がり | 0 ~ 1000 px | 10 | 形に近い、強い光の広がり |
| 内側の強さ | 0 ~ 1000 % | 100 | 内側の光の明るさ。0 で消える |
| 外側の広がり | 0 ~ 1000 px | 60 | 遠くまで届く、弱い光の広がり |
| 外側の強さ | 0 ~ 1000 % | 60 | 外側の光の明るさ。0 で消える |

- 光は **広がりのおよそ 2 倍の距離** まで届きます。その分だけオブジェクトの画像が大きくなります
- **細い形ほど光は弱く見えます**（光る面積が小さいため）。細いレーザーでは強さを 200〜500% に上げてください
- 光は足し算で重なり、明るくなりすぎた所は白く飛びます。芯の周りが白っぽくなるのはこのためです

### 芯

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 芯の明るさ | 0 ~ 1000 % | 100 | 芯の明るさ。0 で芯が消え、光だけになる |
| 芯の色 | 色 | ffffff | 芯の色 |
| 芯の太さ | -50 ~ 50 px | 0 | 形の輪郭から、芯をマイナスで細く・プラスで太くする |
| 芯のぼかし | 0 ~ 20 px | 0 | 芯の縁の幅。0 でくっきり |

**芯の太さ** を 0 にすると、形そのものが芯になります。**マイナスにすると、色の付いた帯の中に細い白い芯が通った見た目**になります（例: 高さ 60 の帯に -15 で、芯の高さが 30）。線がどの向きでも同じだけ細くなります。

### 長さ方向

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 長さの測り方 | 方向 / 形に沿う | 方向 | フェードと揺らぎの流れを、何に沿って測るか（下の説明） |
| 方向 | -360 ~ 360 ° | 0 | ビームの長さの向き。0 = 右、90 = 下。根元から先端へ向かう向き |
| 根元のフェード | 0 ~ 100 % | 0 | 根元から長さの何 % までをフェードインさせるか |
| 先端のフェード | 0 ~ 100 % | 0 | 先端から長さの何 % までをフェードアウトさせるか |

**方向** は画像の中での向きです。標準描画の回転はこの効果の後に掛かるので、横長の図形を回して使うなら 0 のままでかまいません。縦長の形に掛けるときは 90、LongShadowN の影に掛けるときは影の角度に合わせます。方向 0 では、左端が根元・右端が先端になります。

フェードは芯と光の両方に掛かります。

#### 長さの測り方

- **方向**: 画面の決まった 1 方向（方向）で長さを測ります。まっすぐなビーム向け。折れ線に掛けると、フェードは曲がりに沿わずまっすぐ横切り、揺らぎも 1 方向へ流れます
- **形に沿う**: 形の中の道のり（根元からの距離）で長さを測ります。折れ線・曲線のどこまで行っても、フェードと揺らぎが線に沿います

形に沿う の根元はこう決まります。

- **光線経路_H に掛けたとき**: 光線の始点が根元です。フェードは光線経路_H の **表示の始まり / 終わり** の範囲に合わせて掛かります。光線が自分と交差しても道のりは正しく数えられます（光線経路_H が道のりを渡すため）
- **それ以外の形**: 形の両端（道のりでいちばん離れた 2 点）のうち、**方向 の後ろ側の端**が根元です。方向 0 なら左寄りの端、90 なら上寄りの端。根元を逆にしたいときは方向を 180 回します

形に沿う で気を付けること。

- **自分と交差する形では、交差点で近道されます**（形からは線の順番が分からないため）。交差する経路は光線経路_H で作ってください
- **つながっていない形（破線など）** は、それぞれの部分の根元を 方向 に沿った位置で継いで数えます。まっすぐ並んだ破線なら全体で 1 本として数えられますが、曲がった破線では近似になります
- 形から道のりを求めるのは CPU の計算です。1920x1080 のプロジェクトで、1600x900 の範囲に折れた線に掛けた場合、1 フレームは 19 ms 以下でした（作成時の環境での実測）
- フェードも揺らぎも 0 のときは、長さ方向の計算そのものをしません

### 揺らぎ

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 揺らぎ | 0 ~ 100 % | 0 | まだら模様で暗くする強さ。100 % で最も暗い所が元の 2 割ほどになる |
| 揺らぎの大きさ | 1 ~ 1000 px | 60 | 模様の大きさ（長さ方向） |
| 揺らぎの伸び | 1 ~ 20 | 4 | 模様を長さ方向に引き伸ばす倍率。大きいほど筋っぽくなる |
| 流れの速さ | -5000 ~ 5000 px/秒 | 400 | 模様が流れる速さ。プラスで根元→先端、0 で止まる |
| ちらつき | 0 ~ 100 % | 0 | フレームごとにランダムで暗くする強さ |
| シード | -1000 ~ 1000 | 0 | 模様とちらつきの乱数 |

- **乱数はシードだけで決まります。** レイヤーを動かしても模様は変わりません。そのかわり、同じシードのオブジェクトは同じ模様・同じちらつきになるので、複数のビームを並べるときはシードを変えてください
- 揺らぎが 0 のときは、流れの速さを変えても見た目は変わりません
- 長さの測り方 が 形に沿う のときは、模様も道のりに沿って伸び、流れます

## 用途例

値は目安です。形の大きさに合わせて調整してください。

| 表現 | 形 | 設定の例 |
|---|---|---|
| 細いレーザー | 図形の四角形 サイズ 1200・縦横比 -99.5（1200x6） | 光の色 赤・内側の強さ 300・外側の広がり 40・外側の強さ 200 |
| 極太ビーム | 図形の四角形 サイズ 1200・縦横比 -90（1200x120） | 芯の太さ -30・芯のぼかし 6・外側の広がり 200・揺らぎ 40・揺らぎの伸び 10 |
| 光の刃 | 図形の四角形（長さ一定）を回転させる | 芯の太さ -3・内側の広がり 6。振ったときの残像は `色付き残像` などを後に足す |
| エネルギーが流れる光線 | 任意の帯 | 揺らぎ 80・揺らぎの伸び 8・流れの速さ 800 |
| 反射するレーザー | 光線経路_H（鏡で反射） | 長さの測り方 形に沿う・先端のフェード 30・揺らぎ 50。光線経路_H の 表示の終わり を 0 → 100 に動かすと撃ち出す |
| プリズムで分かれる光 | 光線経路_H（分光） | 光の色 透明（光も虹色になる）・芯の明るさ 50 |
| ホーミングレーザー | パス図形σ の 3 次ベジェ曲線（開始位置・終了位置を動かす） | 長さの測り方 形に沿う・方向 は曲線の始まり側が後ろになる向きに・先端のフェード 60 |
| 霧の中の光線 | LongShadowN の光束（同じオブジェクトの前段。この組み合わせは実機では未確認） | 方向を影の角度に・揺らぎ 60・揺らぎの伸び 12・流れの速さ 60・先端のフェード 60 |

発射・消滅の太さの変化（ビームが太ってまた細る動き）は、この効果の後に「拡大率」を動かすか、`ビームインアウト` を組み合わせます。

## 注意事項

- **フィルタオブジェクトには使えません。** 光の分だけ画像を広げるためです（メニューにも出ません）
- 画像を広げられる上限（16384 px）に達すると、そこで光が切れます
- 外側の広がりを大きくすると画像が大きくなります。1920x1080 のプロジェクトで、1600x40 の帯に外側の広がり 400 を掛けた場合、1 フレームは 16 ms 以下でした（作成時の環境での実測）
- 画像を作るカスタムオブジェクト（光線経路_H・パス図形σ など）には効きます。`連結ライン.obj2` のように、画像を作らずに自分で描くスクリプトには効かない見込みです（未確認）
- 光線経路_H との間に、画像の大きさを変える効果（縁取り・領域拡張など）を挟むと、道のりの受け渡しが外れて「それ以外の形」の扱いになります
- 設定項目の名前は保存データのキーなので、今後も変えません。保存したプロジェクトの値はそのまま読み込めます（v1.10 で足した 長さの測り方 は v1.00 で保存したプロジェクトに無いので、既定の「方向」で読まれ、見た目は変わらない見込みです。未確認）

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| 光が見えない | 内側・外側の強さを上げる。細い形ほど光は弱い |
| 全体が白っぽく色が出ない | 形の色か光の色が白になっていないか確かめる（光の色の既定は透明＝元の色） |
| 明るい背景の上で光が濁る | 標準描画の合成モードを「加算」にする |
| フェードや揺らぎの向きが合わない | 方向をビームの長さの向きに合わせる（縦長の形なら 90） |
| 折れ線でフェードが曲がりに沿わない | 長さの測り方 を「形に沿う」にする |
| 形に沿う で根元と先端が逆 | 方向 を 180 回す（光線経路_H に掛けたときは、光線の始点が常に根元） |
| 交差した先のフェードがおかしい | 形を光線経路_H で作る（形から求めると交差点で近道される） |
| 並べたビームの模様が同じ | シードを変える |
| 模様が流れない | 揺らぎを 0 より大きくする |
| 画面が黒くなる・真っ白になり、ログに `invalid buffer type. name=cache:beamh/src` が出る | v1.11 以前の症状。v1.12 に更新する |
