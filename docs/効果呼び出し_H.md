# 効果呼び出し_H

**ほかの効果を名前で指定して掛ける**アニメーション効果です。2 つの使い方があります。

- **ランダム**: 候補に並べた効果から 1 つを選んで掛けます。時間ごと・文字（個別オブジェクト）ごと・レイヤーごとに選び直します
- **登場退場**: どの効果でも、項目の値を「登場の値 → 通常の値 → 退場の値」と動かして、登場・退場の演出にします

YMM4のプラグイン「エフェクトランダム切り替え」「登場退場（汎用）」に当たるものです。
説明だけを元に作り、コードは使っていません。

`Script/@効果呼び出し_H.anm2`、v0.1.0。

## インストール

1. `Script\@効果呼び出し_H.anm2` を配置する。
2. AviUtl2を起動する。
3. オブジェクトに、HexScriptの中にある「ランダム」か「登場退場」を追加する（一覧では `ランダム@効果呼び出し_H` / `登場退場@効果呼び出し_H`）。

## 効果の書き方（両方に共通）

1 行に 1 つ、**「効果名,項目,値,項目,値,…」** の形で書きます。

```
単色化,色,ff0000,強さ,100,輝度を保持する,0
色調補正,明るさ,150,色相,180
```

- **効果名と項目名は設定画面の表示のとおりに書きます**（例: `単色化` の `強さ`）。スクリプトの効果は `セクション名@スクリプト名` で書きます（例: `グレイン@Filters_H`）
- 値は数字ならそのまま、色は 6 桁の 16 進（`ff0000`）、チェックボックスは `0` / `1` で書きます
- **書かなかった項目は、その効果の初期値になります。** たとえば `単色化` は「輝度を保持する」が初期値でオンなので、
  色を指定の色そのものにしたいときは `輝度を保持する,0` も書きます
- 区切りは半角の `,` のほか、全角の `，` `、` も使えます。前後の空白は無視します
- 値の中にカンマは書けません
- 効果名を間違えると、何も掛からず、ログに `invalid filter effect. effect=<書いた名前>` が出ます
- この効果自身（`@効果呼び出し_H`）は書けません

## ランダム

### 使い方

1. オブジェクトに「ランダム」を追加する
2. **候補** に、選ばせたい効果を 1 行に 1 つずつ書く。何も掛けない回を混ぜたいときは `なし` だけの行を書く
3. **切り替えの単位** と **切り替え間隔(f)** で、いつ・何ごとに選び直すかを決める

### パラメータ

| 項目 | 範囲・選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 候補 | 複数行の文字列 | `ぼかし,範囲,20` と `モザイク,サイズ,24` の 2 行 | 上の「効果の書き方」。空行は無視する |
| 頻度 | 文字列 | 空 | 候補ごとの出やすさの比。`2,5,7` のように候補の順に整数で書く（空白区切りでもよい）。空なら同じ。0 の候補は選ばれない。数が候補と合わないときは同じにして、ログに警告を出す |
| 切り替えの単位 | 時間 / 個別オブジェクト / 時間と個別オブジェクト / レイヤー | 時間 | 時間: 切り替え間隔ごとに選び直す。個別オブジェクト: 文字ごと（テキストの「文字毎に個別オブジェクト」）に選び、時間では変えない。時間と個別オブジェクト: 両方。レイヤー: レイヤーごとに選ぶ（グループ制御に追加して配下ごとに変えるとき） |
| 選び方 | ランダム / 順番 / 続けて同じにしない | ランダム | 順番: 候補を上から順に（文字ごとなら 1 文字目から順に）使う。続けて同じにしない: 前の区間と同じ候補を選ばない |
| 切り替え間隔(f) | 1〜3600 | 10 | 何フレームごとに選び直すか。単位が「個別オブジェクト」「レイヤー」のときは出ない |
| シード | −10000〜10000 | 0 | 乱数の種。下の「シードの符号」 |

### シードの符号

AviUtl2 の乱数（`obj.rand`）と同じく、符号で意味が変わります。

- **マイナス**: 種が同じなら、どのオブジェクトでも同じ並びになる
- **プラス（0 を含む）**: 種が同じでも、オブジェクトごとに違う並びになる

文字ごと・レイヤーごとの単位では、どちらの符号でも文字・レイヤーごとに違う候補が選ばれます。
同じフレームでは何度描き直しても同じ候補になります（ちらつきません）。

### 例

- 10 フレームごとに 3 色のどれかへ: 候補に `単色化,色,ff0000,強さ,100,輝度を保持する,0` などを 3 行、単位 時間
- 文字ごとに違う色: テキストの「文字毎に個別オブジェクト」をオンにして、単位 個別オブジェクト・選び方 順番
- ときどきだけ乱れる: 候補を `なし` と効果の 2 行にし、頻度を `9,1` にする

## 登場退場

### 使い方

1. オブジェクトに「登場退場」を追加する
2. **効果と値** に、1 行に 1 つ **「効果名,項目,登場の値,通常の値,退場の値」** を書く（5 つの組。それ以外の形の行はログに警告を出して無視する）
3. **登場(秒)** と **退場(秒)** で、動く時間を決める

```
ぼかし,範囲,50,0,50
単色化,色,ff0000,ff0000,ff0000
単色化,強さ,100,0,100
単色化,輝度を保持する,0,0,0
```

同じ効果名の行が続いていれば、1 つの効果としてまとめて掛けます（上の例の `単色化` の 3 行は 1 回の単色化になります）。
離れたところに同じ効果名を書くと、その回数だけ掛かります。

### 時間の流れ

```
始まり ─ 登場前の遅延 ─ 登場（登場の値 → 通常の値）─ 通常 ─ 退場（通常の値 → 退場の値）─ 退場後の遅延 ─ 最後のフレーム
```

- オブジェクトの最初のフレームで登場の値、最後のフレームで退場の値になります
- 数字でない値（色など）は動かず、登場・退場の時間の半分で切り替わります
- 登場と退場が重なるほど短いオブジェクトでは、前半は登場、後半は退場として動きます

### パラメータ

| 項目 | 範囲・選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 効果と値 | 複数行の文字列 | `ぼかし,範囲,50,0,50` | 上の書き方 |
| 登場(秒) | 0〜10 | 0.5 | 0 なら登場しない（最初から通常の値） |
| 退場(秒) | 0〜10 | 0.5 | 0 なら退場しない（最後まで通常の値） |
| 登場前の遅延(秒) | 0〜10 | 0 | この間は登場の値のまま止まる |
| 退場後の遅延(秒) | 0〜10 | 0 | この間は退場の値のまま止まる |
| 個別オブジェクトの時間差(秒) | −5〜5 | 0 | 文字ごとにずらす。登場は 1 文字ごとにこの秒数だけ遅れ、退場も同じ順に進み、最後の文字が最後のフレームで退場し終わる。マイナスなら後ろの文字から |
| 登場のイージング | 直線 / 加速 / 減速 / 加減速 / バック / バウンス | 減速 | 登場の動き方 |
| 退場のイージング | 同上 | 加速 | 退場の動き方 |

バックとバウンスは、登場では「着いた先で行き過ぎて／弾んで収まる」、退場では「いったん戻ってから／弾みながら離れる」動きになります。

## 注意

- **呼んだ効果は、この効果を置いた位置で掛かります。** この効果より下にある効果は、その後に掛かります
- グループ制御に追加しても配下に効きます（配下ごとに変えるなら ランダム の単位を レイヤー にする）
- フィルタオブジェクトとしては使えません（オブジェクトの効果として追加してください）
- 候補に重い効果を並べると、その効果が選ばれたフレームだけ重くなります
- リスト選択や文字列の項目に値を渡す書き方は、まだ確かめていません。数字・色・チェックボックスの項目は確かめてあります
