# 円形配置プラス

オブジェクトを円（楕円）の周に並べるアニメーション効果です。
通常のオブジェクトなら指定した数だけ複製して周に並べ、テキストの個別オブジェクトなら文字を周に沿って並べます。

`Script/MAD/円形配置改.anm2` と同じ配置の計算に、**PI**（別の値で項目を上書きする欄）を足したものです。
項目名は円形配置改と同じですが、効果の名前が違うので、円形配置改で保存した設定はこちらへは引き継がれません。
円形配置改と違い、フィルタオブジェクト用の宣言は持っていません。

- `Script/円形配置プラス.anm2`（v1.01）

## インストール

1. `Script\円形配置プラス.anm2` を配置する
2. AviUtl2 を再起動する
3. オブジェクトのフィルタ効果に「円形配置プラス」を追加する（HexScript の中）

## 使い方

1. 並べたいオブジェクト（図形・画像など）に「円形配置プラス」を追加する
2. **数** で並べる個数、**X半径**・**Y半径** で円の大きさを決める（同じ値で真円）
3. **円周** 100 で周をちょうど一周し、等間隔に並ぶ。50 なら半周の範囲に並ぶ
4. **回転** で並び全体を回す

並びの中心は円の真上で、そこから左右に振り分けて時計回りに並びます。
各オブジェクトは自分の位置に合わせて回り、上側が外を向きます（**回転無し** を ON にすると回りません）。

### 例: 図形を輪にして広げる

実制作で使った設定です（きらめき形の図形 `カーブ@twinkle_sl` に掛けた）。

| 項目 | 値 |
|---|---|
| 円周 | 100.00 |
| X半径・Y半径 | 40 → 320（2 つを同じ値で動かす。移動方法は 区間ごとに時間制御@Basic_S） |
| 回転 | 0 から 移動量指定 で回す |
| 数 | 8 |
| ほか | 初期値 |

8 個の図形が等間隔の輪のまま、中心から外へ広がりながら回ります。
同じ作品では、数 4・半径 60 → 480 の輪を重ね、続くオブジェクトで半径を 320 → 100 のように縮めて戻しています。

## パラメータ

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 円周 | 0 ~ 800 | 100 | 並べる範囲の広さ。100 で一周（360 度）、200 で二周。0 だとすべて同じ位置に重なる |
| X半径 | -2400 ~ 2400 | 200 | 円の横の半径（px）。マイナスで並びの左右が反転する（各オブジェクトの回転はそのまま） |
| Y半径 | -2400 ~ 2400 | 200 | 円の縦の半径（px）。水平配置(カメラ制御) が ON のときは奥行き方向の半径 |
| 回転 | -3600 ~ 3600 | 0 | 並び全体を回す角度（度）。プラスで時計回り |
| 水平配置(カメラ制御) | ON / OFF | OFF | ON なら縦（Y）の代わりに奥行き（Z）方向へ並べ、床に置いた輪にする。各オブジェクトは Y 軸回転で向きを変える。カメラ制御の下で使う |
| 数 | 数値入力 | 8 | 並べる個数（通常のオブジェクトのとき）。テキストの個別オブジェクトでは使わない |
| 向き反転 | ON / OFF | OFF | ON なら並びの中心が円の真下になり、反時計回りに並ぶ。各オブジェクトの上側が円の中心を向く |
| 回転無し | ON / OFF | OFF | ON なら各オブジェクトを回さず、元の向きのまま並べる |
| PI | 数値入力 | `{}`（空） | 項目を別の値で上書きする欄（下記） |

### PI（上書き）

**PI** の欄にテーブルを書くと、書いた項目だけがトラックバーや設定より優先されます。書かなかった項目は通常どおりです。

| キー | 上書きする項目 | 書き方 |
|---|---|---|
| `track0` | 円周 | 数値 |
| `track1` | X半径 | 数値 |
| `track2` | Y半径 | 数値 |
| `track3` | 回転 | 数値 |
| `check0` | 水平配置(カメラ制御) | `true` / `false` か `1` / `0` |
| `num` | 数 | 数値 |
| `dir` | 向き反転 | `1` / `0` か `true` / `false` |
| `rot` | 回転無し | `1` / `0` か `true` / `false` |

例: `{track0=50, num=12}`

ON / OFF の 3 つ（`check0` `dir` `rot`）は、`true` / `false` でも `1` / `0` でも同じに読みます（`0` と `false` が OFF）。

### テキストの個別オブジェクトのとき

テキストの「文字毎に個別オブジェクト」が ON のときは、複製せずに文字そのものを周に並べます。**数** は使いません。

- 文字の横の位置に比例した角度で並びます。FHD では「文字の送り幅（px）× 円周 = 9600」のとき、ちょうど一周して等間隔になります（送り幅 96px なら円周 100、48px なら 200）
- 複数行のテキストは、下の行ほど内側（半径から行の位置を引いた位置）に並びます。向き反転 が ON のときは逆に下の行ほど外側です。水平配置(カメラ制御) が ON のときは行の位置を使いません

## 注意

- 通常のオブジェクトでは、この効果より後に並べたフィルタ効果を先に掛けてから複製します
- オブジェクトの枠（選択したときの枠）は大きさ固定になります
