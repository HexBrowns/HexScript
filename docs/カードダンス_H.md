# カードダンス_H

オブジェクトをトランプのようなカードに分けて、1 枚ずつ時間差で裏返したり、飛ばしたり、縮めたりする効果です。
After Effects の「カードダンス」と「カードワイプ」に当たります。裏面には色・同じ画像・別のレイヤーを出せます。

## インストール

1. `Script\カードダンス_H.anm2` を配置する
2. AviUtl2 を再起動する

## 使い方

1. 画像・テキストなどのオブジェクトに、フィルタ効果の追加メニューのラベル **HexScript** の中にある「カードダンス_H」を掛ける
2. **進行度** を 0 → 100 に動かす（移動方法を付ける）。既定では左の列から順にカードが裏返り、裏面の暗い灰色が出る
3. 裏返った後に別の画像を見せたいときは、**裏面** を「レイヤー」にして、見せたい画像を置いたレイヤーの番号を **裏面のレイヤー** に入れる
   （カードワイプ。見せたい画像は画面の外に置いても読み込めます）

**この効果はオブジェクトの効果の一番下に置いてください。** カードを自分で描くので、これより後に付けたフィルタ効果は掛かりません。

### 進み方

カードごとに **勾配** の値（0〜1）を決め、値の小さいカードから順に動き始めます。
**進行度** 0 で全部が始めの状態、100 で全部が終わった状態です。
**1枚の時間** は 1 枚が動き終えるまでの長さ（進行度に対する割合）で、小さいほど 1 枚ずつ順に、大きいほど一斉に動きます。

**変化** の項目は、カードが動き終えたときの値です。途中はイージングに沿って 0 からその値まで変わります。

## パラメータ

### 分割

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 列数 / 行数 | 1 ~ 100 | 10 / 6 | カードの分け方 |
| 隙間 | 0 ~ 200 px | 0 | カードの間をあける。進行度 0 でも効く |

### 進行

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 進行度 | 0 ~ 100 | 0 | 全体の進み具合。移動方法を付けて動かす |
| 1枚の時間 | 1 ~ 100 | 30 | 1 枚が動き終えるまでの長さ（進行度に対する %） |
| イージング | 直線 / 加速 / 減速 / 加減速 | 加減速 | 1 枚の動きの緩急 |
| 勾配 | 横 / 縦 / 斜め / 放射 / ランダム / レイヤー | 横 | 動き出す順。横: 左から。縦: 上から。斜め: 左上から。放射: 中央から。ランダム: ばらばら。レイヤー: 別のレイヤーの暗い所から |
| 勾配のレイヤー | 1 ~ 1000 | 1 | 勾配＝レイヤーのとき、順番を決める画像のレイヤー番号。カードの中心に当たる位置の明るさを使う（オブジェクトの大きさに引き伸ばして読む） |
| 勾配を反転 | ON / OFF | OFF | 順番を逆にする（右から・下から・外側から など） |
| ばらつき | 0 ~ 100 | 0 | 順番にランダムな乱れを混ぜる |
| シード | 0 ~ 10000 | 0 | ランダム・ばらつきの並びを変える |

### 変化（動き終えたときの値）

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| X軸回転 / Y軸回転 / Z軸回転 | 度 | 0 / 180 / 0 | カードの中心を軸に回す。Y軸回転 180 で左右に裏返る |
| X / Y / Z | px | 0 | カードを動かす |
| 浮き上がり | px | 0 | 動いている途中だけ手前に浮かせる（始めと終わりは 0） |
| 拡大率 | 0 ~ 1000 % | 100 | カードの大きさ |
| 透明度 | 0 ~ 100 | 0 | 100 で動き終えたカードが消える |

### 裏面の設定

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 裏面 | 色 / 同じ画像 / レイヤー / なし | 色 | 裏返ったときに見える面。なしは裏が透明 |
| 裏面の色 | | 暗い灰色（202020） | 裏面＝色のとき |
| 裏面のレイヤー | 1 ~ 1000 | 1 | 裏面＝レイヤーのとき、裏に出す画像のレイヤー番号。オブジェクトの大きさに引き伸ばして使う |

## 使い方の例

- **カードワイプ（画面の切り替え）**: 裏面 レイヤー・Y軸回転 180・1枚の時間 20〜40。進行度を 0 → 100
- **カードが散らばって消える**: Y軸回転 0・Z軸回転 360・Y 600・透明度 100・勾配 ランダム
- **めくれながら手前に浮く**: Y軸回転 180・浮き上がり 200・1枚の時間 30
- **タイル状に縮んで消える**: Y軸回転 0・拡大率 0・勾配 放射

## 注意事項

- **これより後に付けたフィルタ効果は掛かりません**（一番下に置く）。ただし、進行度 0・隙間 0 のときは何もしないので、後の効果も掛かります
- 裏面は **Y軸回転で裏返したときに正しい向き** になります。X軸回転で裏返すと上下が逆さまに見えます
- 裏面＝レイヤーのとき、カードが重なる所では奥と手前の順が崩れることがあります（表を全部描いてから裏を全部描くため）
- 勾配＝レイヤー・裏面＝レイヤーに自分のいるレイヤーを指定した場合は、読み込みません（勾配は横、裏面は出ません）
- 重さの目安（FHD）: 1920x1080 を 50 x 50 枚に分けて浮き上がらせても 1 フレーム約 20ms
