# 電波_H

中心から同じ形の波が一定の間隔で生まれて広がり、寿命が来ると消えるカスタムオブジェクトです。
After Effects の「電波」に当たります。円・多角形・星の波を、線の太さの変化・プロファイル・フェード付きで出せます。

## インストール

1. `Script\電波_H.obj2` を配置する
2. AviUtl2 を再起動する

## 使い方

1. オブジェクトの追加メニューで、ラベル **HexScript** の中にある「電波_H」（カスタムオブジェクト）を置く
2. そのままで、中心から白い円の波が 1 秒に 2 本、毎秒 200px の速さで広がる
3. **周波数**（本数）・**拡張速度**（広がる速さ）・**寿命**（消えるまでの秒数）で波の間隔と届く範囲を決める

波はオブジェクトの位置（標準描画の X / Y）から出ます。オブジェクトの最初は波が 1 本も無い状態から始まるので、
最初から波が並んでいてほしいときは **先行時間** に秒数を入れてください（その秒数だけ進んだ状態から始まります）。

隣り合う波の間隔は **拡張速度 ÷ 周波数** px です（既定で 100px）。届く半径は **拡張速度 × 寿命** px です（既定で 600px）。

## パラメータ

### 波

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 周波数 | 0.01 ~ 30 | 2 | 1 秒あたりに生まれる波の数 |
| 拡張速度 | 0 ~ 4000 px/秒 | 200 | 波が広がる速さ。波の大きさは外接円の半径で測る |
| 寿命 | 0.01 ~ 60 秒 | 3 | 生まれてから消えるまで |
| 発生時間 | 0 ~ 600 秒 | 0（無制限） | この秒数より後は新しい波を出さない。出た波は寿命まで広がる |
| 先行時間 | 0 ~ 60 秒 | 0 | オブジェクトの最初を、この秒数だけ進んだ状態にする |

### 波の形

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 形状 | 円 / 多角形 / 星 | 円 | 波の形 |
| 角数 | 3 ~ 32 | 6 | 多角形・星の角の数。頂点の 1 つが真上に来る |
| へこみ | 0 ~ 100 % | 50 | 星の谷の深さ |
| 回転 | 度 | 0 | 形を回す（時計回り） |

### 線

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 色 | | 白 | 波の色 |
| プロファイル | 四角 / サイン / ノコギリ（内）/ ノコギリ（外） | 四角 | 線の太さ方向の濃さ。四角: 一様。サイン: 中央が濃く両端へなめらかに薄くなる。ノコギリ（内）: 内側の縁が濃く外側へ薄くなる。ノコギリ（外）: その逆 |
| 開始時の幅 | 0 ~ 500 px | 4 | 生まれたときの線の太さ |
| 終了時の幅 | 0 ~ 500 px | 4 | 寿命が来たときの線の太さ。途中は年齢に比例して変わる |
| フェードイン | 0 ~ 60 秒 | 0 | 生まれてから濃くなりきるまで |
| フェードアウト | 0 ~ 60 秒 | 0.5 | 寿命の何秒前から薄くし始めるか |

### 描画範囲（既定で閉じている）

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 幅 / 高さ | 0 ~ 16384 px | 0（自動） | オブジェクトの大きさ。自動なら今いちばん外の波が収まる大きさ（ただし片側は画面の幅・高さまで）。指定すると、その外の波は切れる |

## 使い方の例

- **衝撃波・ソナー**: 周波数 1〜2、終了時の幅を開始時の幅より大きく、フェードアウトを寿命の半分くらい
- **ぼんやりした輪**: プロファイル サイン、開始時の幅・終了時の幅 20〜40
- **にじむ光の輪**: プロファイル ノコギリ（外）にして、上からグローを掛ける
- **星形の電波マーク**: 形状 星・角数 5・へこみ 50
- 線の内側を塗りつぶすことはできません。帯状の太い線にしたいときは幅を広げてください

## 注意事項

- **波は発生点と一緒に動きます。** オブジェクトを動かすと、出た後の波もそのまま付いてきます（After Effects のように、波が出た場所に残る動きにはなりません）
- 周波数を上げて波の間隔（拡張速度 ÷ 周波数）が線の太さより狭くなると、波どうしが重なって塗りつぶしのようになります
- 自動の描画範囲は画面の 2 倍（片側が画面の幅・高さ）までです。カメラ制御で引いたり、標準描画で縮小したりして、それより外が見える使い方では、幅・高さを指定してください
- 標準描画で拡大すると線も太く見えます。線の太さを保ちたいときは、拡張速度と幅で大きさを決めてください
- 重さの目安（FHD）: 描画範囲が 3840x2160 まで広がり、波が全面で重なる設定でも、1 フレーム 13ms 程度です
