# 電波_H

<!-- サンプル動画 -->
<img src="samples/%E9%9B%BB%E6%B3%A2_H/%E9%9B%BB%E6%B3%A2_H.webp" width="480" alt="電波_H のサンプル">

中心から同じ形の波が一定の間隔で生まれて広がり、寿命が来ると消えるカスタムオブジェクトです。
After Effectsの「電波」に当たります。
円・多角形・星の波を、線の太さの変化・プロファイル・フェード付きで出せます。

## インストール

1. `Script\電波_H.obj2` を配置する。
2. AviUtl2を起動する。

## 使い方

1. オブジェクトの追加メニューで、ラベル **HexScript** の中にある「電波_H」を置く。
2. そのままで、中心から白い円の波が 1 秒に 2 本、毎秒 200px の速さで広がる。
3. **波の間隔の指定** と、その欄（**周波数** / **間隔（f）** / **BPM**）・**拡張速度**・**寿命** で波の間隔と届く範囲を決める。

音楽に合わせるときは **BPM** と **拍子**（1 小節に 1 本。4/4 なら 4 拍に 1 本、3/4 なら 3 拍に 1 本、6/8 なら 8 分音符 6 個＝4 分音符 3 個に 1 本。1 拍ごとに出したいときは 1/4）、映像のフレームに揃えるときは **フレーム** を選びます。
どちらも波の生まれる時刻が拍・フレームにちょうど揃うので、長く続けてもずれません。
周波数に BPM ÷ 60 を小数で入れる方法は、小数の桁が足りない分だけ時間とともにずれます（BPM 128 を周波数 2.13 で近似すると、60 秒後に約 0.09 秒ずれます）。

波はオブジェクトの位置から出ます。
オブジェクトの最初は波が 1 本も無い状態から始まります。
最初から波が並んでいてほしいときは **先行時間** に秒数を入れてください。

隣り合う波の間隔は **拡張速度 ÷ 周波数** px です（フレーム・BPM の指定では、周波数にそれぞれ フレームレート ÷ 間隔、BPM ÷ 60 ÷（1 小節の 4 分音符の数）を当てはめます）。
届く半径は **拡張速度 × 寿命** px です。

## パラメータ

### 波

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 波の間隔の指定 | 秒数 / フレーム / BPM | 秒数 | 波の間隔を何で決めるか。選んだ指定の欄だけが表示される |
| 周波数（秒数） | 0.01 ~ 30 | 2.000 | 1 秒あたりに生まれる波の数 |
| 間隔（フレーム） | 1 ~ 3600 f | 15 | 何フレームごとに波を生むか。1 秒あたりの本数は プロジェクトのフレームレート ÷ 間隔 |
| BPM | 1 ~ 1800 | 120.0 | 4 分音符が 1 分間に何個か。波は拍子の 1 小節に 1 本生まれる |
| 拍子の拍数 | 1 ~ 32 | 4 | 拍子の分子。BPM の指定のときだけ表示される |
| 拍子の音符 | 2 / 4 / 8 / 16 分音符 | 4 分音符 | 拍子の分母。BPM の指定のときだけ表示される |
| 拡張速度 | 0 ~ 4000 px/秒 | 200 | 波が広がる速さ。波の大きさは外接円の半径で測る |
| 寿命 | 0.01 ~ 60 秒 | 3 | 生まれてから消えるまで |
| 発生時間 | 0 ~ 600 秒 | 0（無制限） | この秒数より後は新しい波を出さない。出た波は寿命まで広がる |
| 先行時間 | 0 ~ 60 秒 | 0 | オブジェクトの最初を、この秒数だけ進んだ状態にする |

### 波の形

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 形状 | 円 / 多角形 / 星 | 円 | 波の形 |
| 角数 | 3 ~ 32 | 6 | 多角形・星の角の数。頂点の 1 つが真上に来る |
| へこみ | 0 ~ 100 % | 50 | 星の谷の深さ |
| 回転 | 度 | 0 | 形を時計回りに回す |

### 線

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 色 | | 白 | 波の色 |
| プロファイル | 四角 / サイン / ノコギリ（内）/ ノコギリ（外） | 四角 | 線の太さ方向の濃さ。四角: 一様。サイン: 中央が濃く両端へなめらかに薄くなる。ノコギリ（内）: 内側の縁が濃く外側へ薄くなる。ノコギリ（外）: その逆 |
| 開始時の幅 | 0 ~ 500 px | 4 | 生まれたときの線の太さ |
| 終了時の幅 | 0 ~ 500 px | 4 | 寿命が来たときの線の太さ。途中は年齢に比例して変わる |
| フェードイン | 0 ~ 60 秒 | 0 | 生まれてから濃くなりきるまで |
| フェードアウト | 0 ~ 60 秒 | 0.5 | 寿命の何秒前から薄くし始めるか |

### 描画範囲（既定で閉じている）

| パラメータ | 範囲 | 初期値 | 説明 |
|-----------|------|--------|------|
| 幅 / 高さ | 0 ~ 16384 px | 0（自動） | オブジェクトの大きさ。自動なら今いちばん外の波が収まる大きさ。片側は画面の幅・高さまで。指定すると、その外の波は切れる |

## 使い方の例

- **衝撃波・ソナー**: 周波数 1〜2、終了時の幅を開始時の幅より大きく、フェードアウトを寿命の半分くらい
- **ぼんやりした輪**: プロファイル サイン、開始時の幅・終了時の幅 20〜40
- **にじむ光の輪**: プロファイル ノコギリ（外）にして、上からグローを掛ける
- **星形の電波マーク**: 形状 星・角数 5・へこみ 50
- 線の内側を塗りつぶすことはできません。帯状の太い線にしたいときは幅を広げてください

## 注意事項

- **波は発生点と一緒に動きます。** オブジェクトを動かすと、出た後の波もそのまま付いてきます。After Effectsのように、波が出た場所に残る動きにはなりません
- 周波数を上げて波の間隔が線の太さより狭くなると、波同士が重なって塗りつぶしのようになります
- 自動の描画範囲は、片側が画面の幅・高さまでです。カメラ制御で引いたり、標準描画で縮小したりして、それより外が見える使い方では、幅・高さを指定してください
- 標準描画で拡大すると線も太く見えます。線の太さを保ちたいときは、拡張速度と幅で大きさを決めてください
- FHDでの重さの目安: 描画範囲が 3840x2160 まで広がり、波が全面で重なる設定でも、1 フレーム 13ms 程度です
