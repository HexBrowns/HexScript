# 泡_H

**泡がゆらゆら揺れながら上っていく**背景を描くカスタムオブジェクトです。泡は輪（線）で描き、内側を薄く塗ることもできます。奥行きを 3 段まで重ねられ、奥の段ほど小さく遅くなります。

泡の大きさを変えても線の太さは変わりません。1 枚のシェーダーで描くので、数が多くても軽く動きます。

## インストール

1. `Script\泡_H.obj2` を置く
2. AviUtl2 を再起動する（新しく置いたスクリプトは、再起動するまで一覧に出ません）
3. オブジェクトの追加の **カスタムオブジェクト** から **HexScript → 泡_H** を選ぶ

## 使い方

1. 泡_H を置く。画面いっぱいに泡が出て、上へ流れる
2. 泡の数は **密度**（横に並ぶ区画の数）と **間引き** で、大きさは **半径** で決める
3. 上る速さは **上昇速度**、左右の揺れは **揺れ幅** と **揺れ周期** で決める
4. 画面の一部にだけ出すなら **画面サイズ** をオフにして **幅 / 高さ** を決める

上端で泡を消したいときは **上端フェード** に消えるまでの距離（px）を入れます。

## パラメータ

### 配置

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 幅 / 高さ | 0 ~ 4000 px | 1920 / 1080 | 描く範囲。画面サイズがオンのときは画面の大きさ |
| 画面サイズ | オン / オフ | オン | オンで画面いっぱいに描く |
| 密度 | 1 ~ 100 | 12 | 横に並ぶ区画の数。区画ごとに泡が最大 1 つ |
| 散らばり | 0 ~ 100 % | 80 | 区画の中で泡の位置をずらす量。0 で格子状に並ぶ |
| 間引き | 0 ~ 100 % | 50 | 泡を置かない区画の割合 |
| 奥行きの段数 | 1 ~ 3 | 2 | 重ねる段の数。奥の段ほど小さく遅い |
| シード | 0 ~ 9999 | 0 | 泡の並びを変える種 |

### 泡

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 色 | 色 | 淡い水色 | 泡の色 |
| 半径 | 1 ~ 200 px | 18 | 手前の段の泡の半径 |
| 半径のばらつき | 0 ~ 100 % | 50 | 半径を泡ごとに最大この割合だけ小さくする |
| ライン幅 | 0.5 ~ 50 px | 2 | 輪の太さ（半径によらず一定） |
| 塗り | 0 ~ 100 % | 0 | 輪の内側を塗る濃さ |
| 不透明度 | 0 ~ 100 % | 100 | 全体の不透明度。0 で何も描かない |

### 動き

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 上昇速度 | -1000 ~ 1000 px/秒 | 120 | 手前の段の上る速さ。マイナスで下る |
| 速度のばらつき | 0 ~ 100 % | 40 | 速さを泡ごとに最大この割合だけ遅くする |
| 揺れ幅 | 0 ~ 200 px | 6 | 左右に揺れる幅 |
| 揺れ周期 | 0.1 ~ 20 秒 | 3 | 1 往復にかかる時間 |
| 上端フェード | 0 ~ 4000 px | 0 | 上端からこの距離の間で泡を薄くする。0 で薄くしない |

## 注意

- 泡は途切れずに流れ続けます（どれだけ流しても継ぎ目は出ません）
