# 円形変位_H

オブジェクトを、今の位置を中心とした円の上へ動かすアニメーション効果です。**半径** と **角度** で位置を決め、
向き（外側・内側・進行方向）も合わせられます。角度を動かせば円を描いて回ります。

- `Script/円形変位_H.anm2`（v1.00）
- 「円形変位」（`Script/円形変位.anm2`、作者・版の記載なし）をフォークしたものです（下の「原作との違い」）

## インストール

1. `Script\円形変位_H.anm2` を配置する
2. AviUtl2 を再起動する（設定項目の変更は「キャッシュを破棄」では反映されません）
3. オブジェクトに「円形変位_H」を追加する（HexScript の中）

## 使い方

1. 動かしたいオブジェクトに「円形変位_H」を追加する。円の中心は、この効果を掛ける前のオブジェクトの位置
2. **半径** で中心からの距離（px）を決める
3. **角度** で円の上のどこに置くかを決める。0 で中心の右、90 で真下、180 で左、270 で真上（画面の時計回り）
4. **向き** で、オブジェクトをどちらへ向けるかを選ぶ

**角度** を 0 → 360 へ移動させると、中心のまわりを時計回りに 1 周します。

### 例: 向きを変えずに円を描いて動かす

**向き** を「回転しない」にすると、位置だけが円の上を動き、オブジェクトは傾きません。テロップを円に沿って動かすときに使います。

### 例: 進行方向を向いて回る

**向き** を「接線」にすると、角度が増える向き（時計回り）へ進む向きにオブジェクトの右側が向きます。
角度を減らして反時計回りに動かすときは、**向き調整** を 180 にします。

### 例: 原作での使い方

原作「円形変位」を実制作で使った設定です（図形の三角形の後に、フィルタ効果としてレイヤーに置いていた）。
円形変位_H でも、向きを「外側を向くに従う」のままにすれば同じ見た目になります。

| 項目 | 値 |
|---|---|
| 半径 | -240（0 → -240 の移動もあり） |
| 角度 | 90 / 135 |
| 向き調整 | 90 |
| 外側を向く | OFF |

## パラメータ

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 半径 | -9999 ~ 9999 | 0 | 中心からの距離（px）。マイナスにすると、角度の反対側（角度 + 180 度）に出る |
| 角度 | -9999 ~ 9999 | 0 | 円の上の位置（度）。0 が右、90 が下（時計回り） |
| 向き調整 | -360 ~ 360 | 0 | 向きに足す角度（度）。向きが「回転しない」のときは表示されない |
| 外側を向く | ON / OFF | OFF | ON で外側、OFF で内側を向く。向きが「外側を向くに従う」のときだけ表示される |
| 向き | 外側を向くに従う / 回転しない / 外側 / 内側 / 接線 | 外側を向くに従う | オブジェクトの向け方（下の表） |
| 負の半径で向きを反転 | ON / OFF | OFF | ON なら、半径がマイナスのとき向きを 180 度反転し、出た位置に合った向きにする。向きが「回転しない」のときは表示されない |

**向き** の選択肢:

| 選択肢 | 向き |
|---|---|
| 外側を向くに従う | 原作と同じ。**外側を向く** の ON / OFF で外側か内側 |
| 回転しない | 位置だけ動かし、回転には触らない（向き調整も効かない） |
| 外側 | オブジェクトの右側（回転 0 のときの右）が、中心から離れる向き |
| 内側 | オブジェクトの右側が、中心へ向かう向き |
| 接線 | オブジェクトの右側が、角度が増える向き（時計回り）の進行方向 |

向きは、前に置いた効果の回転と標準描画の Z軸回転 に足されます。

## 原作との違い

原作「円形変位」（`Script/円形変位.anm2`）はそのまま残してあります。

- **前に置いた効果の回転を消しません。** 原作は回転を上書きしていたので、先に「ランダム」やスクリプト制御などで回転させていると、その回転が消えていました。
  標準描画の Z軸回転 は原作でも残ります
- **向き** の選択肢を足しました。原作は必ず外側か内側を向き、「回転しない」を選べませんでした
- **負の半径で向きを反転** を足しました（初期値 OFF）。原作は半径がマイナスでも向きの計算が変わらないので、位置は反対側に出るのに向きは元の側のままです。
  初期値を OFF にしてあるので、負の半径と向き調整で向きを合わせている使い方はそのまま使えます
- 原作はフィルタオブジェクトのメニューにも出ましたが、円形変位_H は出ません（位置と回転を変える効果はフィルタオブジェクトには使えないため）

半径・角度・向き調整・外側を向くは、原作と同じ項目名・範囲・初期値です。**向き** と **負の半径で向きを反転** が初期値のままなら、原作と同じ見た目になります
（違いが出るのは、前に回転させる効果を置いたオブジェクトだけです）。
ただし効果の名前が違うので、原作を使っているプロジェクトは原作のまま動きます（自動では置き換わりません）。
`effect.name=円形変位` を `円形変位_H` に書き換えれば、設定を引き継げます。

## 注意

- 半径をプラスからマイナスへまたいで動かすと、位置は中心を通って反対側へ移りますが、**負の半径で向きを反転** が OFF なら向きは変わりません。
  途中で外向きと内向きが入れ替わって見えます
- 円形変位_H を「フィルタ効果を追加」でレイヤーに単独で置く使い方（原作の実制作の置き方）は、円形変位_H では確かめていません
