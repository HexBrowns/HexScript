# 円形変位_H

オブジェクトを、今の位置を中心とした円の上へ動かすアニメーション効果です。
**半径** と **角度** で位置を決め、向きも合わせられます。
角度を動かせば円を描いて回ります。

- `Script/円形変位_H.anm2`（v1.00）
- 「円形変位」をフォークしたものです。原作のファイルは `Script/円形変位.anm2` で、作者・版の記載はありません

## インストール

1. `Script\円形変位_H.anm2` を配置する。
2. AviUtl2を起動する。
3. オブジェクトに、HexScriptの中にある「円形変位_H」を追加する。

## 使い方

1. 動かしたいオブジェクトに「円形変位_H」を追加する。円の中心は、この効果を掛ける前のオブジェクトの位置。
2. **半径** で中心からの距離を決める。
3. **角度** で円の上のどこに置くかを決める。0 で中心の右、90 で真下、180 で左、270 で真上。
4. **向き** で、オブジェクトをどちらへ向けるかを選ぶ。

**角度** を 0 → 360 へ移動させると、中心のまわりを時計回りに 1 周します。

### 例: 向きを変えずに円を描いて動かす

**向き** を「回転しない」にすると、位置だけが円の上を動き、オブジェクトは傾きません。テロップを円に沿って動かすときに使います。

### 例: 進行方向を向いて回る

**向き** を「接線」にすると、時計回りに進む向きへオブジェクトの右側が向きます。
角度を減らして反時計回りに動かすときは、**向き調整** を 180 にします。

### 例: 原作での使い方

原作「円形変位」を実制作で使った設定です。
図形の三角形の後に、フィルタ効果としてレイヤーに置いていました。
円形変位_Hでも、向きを「外側を向くに従う」のままにすれば同じ見た目になります。

| 項目 | 値 |
|---|---|
| 半径 | -240（0 → -240 の移動もあり） |
| 角度 | 90 / 135 |
| 向き調整 | 90 |
| 外側を向く | OFF |

## パラメータ

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 半径 | -9999 ~ 9999 px | 0 | 中心からの距離。マイナスにすると、角度 + 180 度の反対側に出る |
| 角度 | -9999 ~ 9999 度 | 0 | 円の上の位置。0 が右、90 が下 |
| 向き調整 | -360 ~ 360 度 | 0 | 向きに足す角度。向きが「回転しない」のときは表示されない |
| 外側を向く | ON / OFF | OFF | ONで外側、OFFで内側を向く。向きが「外側を向くに従う」のときだけ表示される |
| 向き | 外側を向くに従う / 回転しない / 外側 / 内側 / 接線 | 外側を向くに従う | オブジェクトの向け方 |
| 負の半径で向きを反転 | ON / OFF | OFF | ONなら、半径がマイナスのとき向きを 180 度反転し、出た位置に合った向きにする。向きが「回転しない」のときは表示されない |

**向き** の選択肢:

| 選択肢 | 向き |
|---|---|
| 外側を向くに従う | 原作と同じ。**外側を向く** のON / OFFで外側か内側 |
| 回転しない | 位置だけ動かし、回転には触らない。向き調整も効かない |
| 外側 | オブジェクトの右側が、中心から離れる向き |
| 内側 | オブジェクトの右側が、中心へ向かう向き |
| 接線 | オブジェクトの右側が、時計回りの進行方向 |

向きは、前に置いた効果の回転と標準描画のZ軸回転 に足されます。

## 原作との違い

原作の `円形変位.anm2` とは名称が違うため競合の心配は不要です。

- **前に置いた効果の回転を消しません。** 原作は回転を上書きしていたので、先に「ランダム」やスクリプト制御などで回転させていると、その回転が消えていました。
  標準描画のZ軸回転 は原作でも残ります
- **向き** の選択肢を足しました。原作は必ず外側か内側を向き、「回転しない」を選べませんでした
- **負の半径で向きを反転** を足しました。原作は半径がマイナスでも向きの計算が変わらないので、位置は反対側に出るのに向きは元の側のままです。
  初期値をOFFにしてあるので、負の半径と向き調整で向きを合わせている使い方はそのまま使えます
- 原作はフィルタオブジェクトのメニューにも出ましたが、円形変位_Hは出ません

半径・角度・向き調整・外側を向くは、原作と同じ項目名・範囲・初期値です。
**向き** と **負の半径で向きを反転** が初期値のままなら、原作と同じ見た目になります。
違いが出るのは、前に回転させる効果を置いたオブジェクトだけです。
ただし効果の名称が違うので、原作を使っているプロジェクトは原作のまま動きます。
`effect.name=円形変位` を `円形変位_H` に書き換えれば、設定を引き継げます。

## 注意

- 半径をプラスからマイナスへまたいで動かすと、位置は中心を通って反対側へ移りますが、**負の半径で向きを反転** がOFFなら向きは変わりません。
  途中で外向きと内向きが入れ替わって見えます
- 円形変位_Hを「フィルタ効果を追加」でレイヤーに単独で置く使い方は、円形変位_Hでは確かめていません
