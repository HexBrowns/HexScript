# 光学系ボケ

カメラのレンズで撮ったようなボケを付けるアニメーション効果です。1 つのファイルに 5 つの効果が入っています。

| 効果 | 何をするか |
|---|---|
| 玉ボケ | 明るい部分だけを取り出して、円・六角形・八角形の「玉」に広げて重ねる |
| レンズぼかし | 画像全体を、円・六角形・八角形の形でぼかす |
| チルトシフト | 帯状の範囲だけピントを合わせ、その外をぼかす。ミニチュア風の絵になる |
| 球面収差ボケ | 縁が明るいリング状のボケに、赤と青の色ずれを付ける |
| マップぼかし | 深度マップなどの明るさに応じて、場所ごとにぼかしの量を変える |

- `Script/@光学系ボケ.anm2`（玉ボケ・レンズぼかし・チルトシフト・球面収差ボケ v1.02 / マップぼかし v1.00）

## インストール

1. `Script\@光学系ボケ.anm2` を配置する。ファイル名の先頭の `@` は消さない。消すと 5 つに分かれず動かなくなる。
2. AviUtl2を起動する。
3. オブジェクトのフィルタ効果に、HexScriptの中にある「玉ボケ」「レンズぼかし」「チルトシフト」「球面収差ボケ」「マップぼかし」のどれかを追加する。

5 つとも、フィルタオブジェクトにも追加できます。
画面全体をぼかすときはフィルタオブジェクトに付けます。
通常のオブジェクトに付けると、ぼけがオブジェクトの外枠の外まで広がります。

## 使い方

1. ぼかしたいオブジェクトか、フィルタオブジェクトに効果を追加する。
2. **ボケ半径** でボケの大きさを決める。
3. **強さ** で効き具合を決める。
4. 効果ごとの項目を合わせる。

### 例: 画面全体に六角形の玉ボケを足す

実制作で使った設定です。フィルタオブジェクトに「玉ボケ」を追加します。

| 項目 | 値 |
|---|---|
| ボケ半径 | 25.0 |
| 輝度閾値 | 16.00 |
| エッジ強度 | 100.00 |
| 強さ | 50 |
| 形状 | 六角形 |
| 加算合成 | ON |

輝度閾値を低めにしているので、明るい部分の多くが六角形の玉になって加算されます。エッジ強度 100 で玉の縁が明るくなります。

`Default\玉ボケ@光学系ボケ.effect` に、輝度閾値 0・エッジ強度 50・強さ 50・形状 円・加算合成ONの設定を保存してあります。

### 例: 画面の上下をぼかすミニチュア風

実制作で使った設定です。フィルタオブジェクトに「チルトシフト」を追加します。

| 項目 | 値 |
|---|---|
| ボケ半径 | 25.0 |
| 焦点位置 | 50.0 |
| 焦点幅 | 240 |
| グラデ幅 | 480 |
| 強さ | 100.00 |
| 方向 | 縦 |

画面の縦の中央を中心に、高さ 240px の帯がくっきり残ります。帯の上下 480px をかけてだんだんぼけ、その外は完全にぼけます。

## パラメータ

### 玉ボケ

| 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| ボケ半径 | 0 ~ 200 px | 30 | 玉の半径。0 なら何もしない |
| 輝度閾値 | 0 ~ 100 % | 70 | 玉にする明るさの下限。これより暗い部分は玉にならない。境目は 5% の幅でなめらかに切り替わる。100 なら何もしない |
| エッジ強度 | 0 ~ 100 | 50 | 玉の縁の明るさ。半径の外側 3 割の縁ほど明るくなり、100 で縁が中心の 2 倍になる |
| 強さ | 0 ~ 1000 | 100 | 玉の明るさ。100 が基準。0 なら何もしない |
| 形状 | 円 / 六角形 / 八角形 | 円 | 玉の形 |
| 加算合成 | ON / OFF | ON | ONは元の画像に玉を足して明るくする。OFFは玉を元の画像の上に重ねる。どちらも、玉が重なって濃くなっても不透明度は 100% で止まる |

取り出した明るい部分を玉に広げて重ねるので、明るい部分が広い素材ほど足される光も増えます。

### レンズぼかし

| 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| ボケ半径 | 0 ~ 200 px | 30 | ぼかしの半径。0 なら何もしない |
| 強さ | 0 ~ 100 % | 100 | 元の画像とぼかした画像の混ぜ具合。100 でぼかした画像だけ。0 なら何もしない |
| 形状 | 円 / 六角形 / 八角形 | 円 | ぼかしの形。明るい点がこの形に広がる |

### チルトシフト

| 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| ボケ半径 | 0 ~ 200 px | 30 | 帯の外のぼかしの半径。形は円。0 なら何もしない |
| 焦点位置 | 0 ~ 100 % | 50 | くっきり残す帯の中心の位置。方向が縦なら 0 が上端・100 が下端、横なら 0 が左端・100 が右端 |
| 焦点幅 | 0 ~ 2000 px | 200 | くっきり残す帯の幅。焦点位置を中心に、この幅の半分ずつ両側に広がる |
| グラデ幅 | 0 ~ 1000 px | 150 | 帯の外で、くっきりから完全なぼけへ移る距離。0 は 1 として扱う |
| 強さ | 0 ~ 100 % | 100 | 一番ぼけた所での、ぼかした画像の混ぜ具合。0 なら何もしない |
| 方向 | 縦 / 横 | 縦 | 縦は焦点位置を上下で決め、横長の帯を残す。横は焦点位置を左右で決め、縦長の帯を残す |

### 球面収差ボケ

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| ボケ半径 | 0 ~ 200 px | 20 | ぼかしの半径。緑の半径になる。形は円。0 なら何もしない |
| リング強度 | 0 ~ 100 | 60 | ボケの縁の強さ。半径の外側 3 割の縁の重みを上げ、100 で縁が中心の 2 倍になる |
| 色収差 | 0 ~ 100 % | 20 | 色ずれの量。赤は半径 × (1 + 色収差)、青は半径 × (1 − 色収差 ÷ 2) でぼける。0 なら色ずれなし |
| 強さ | 0 ~ 100 % | 80 | 元の画像とぼかした画像の混ぜ具合。0 なら何もしない |

### マップぼかし

制御用の画像（マップ）の明るさに応じて、場所ごとにぼかしの量を変えます。**マップの白い所ほど強く、黒い所ほど弱く**ぼけます。
深度マップ（`@KD_DepthMap_H` などで作ったもの）と組み合わせた疑似の被写界深度や、手で描いたマップでの部分ぼかしに使います。
After Effectsの「ブラー（合成）」に当たるものです。

| 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 最大ボケ半径 | 0 ~ 200 px | 30 | マップが白い所のボケの半径。0 なら何もしない |
| 形状 | ガウス / 円 / 六角形 / 八角形 | ガウス | ガウスは裾の広い柔らかいぼけ。円・六角形・八角形は、明るい点がその形の縁のはっきりした玉に広がる |
| マップ | 自分の明るさ / 自分のアルファ / レイヤー | 自分の明るさ | ぼかしの量を決める画像。自分の明るさ・自分のアルファはこのオブジェクトの画像を使う。レイヤーは別のレイヤーの画像の明るさを使う |
| マップのレイヤー | 1 ~ 1000 | 1 | マップにするレイヤーの番号。マップ=レイヤーのときだけ表示 |
| マップの効果を適用 | ON / OFF | ON | ONならマップのレイヤーのオブジェクトに付けた効果を掛けた後の画像を使う。マップ=レイヤーのときだけ表示 |
| マップの合わせ方 | 伸ばす / 中央に置く | 伸ばす | 伸ばす: マップの画像全体をこのオブジェクトの大きさへ引き伸ばす。中央に置く: 等倍で中央に重ね、外は黒として扱う。マップ=レイヤーのときだけ表示 |
| 黒の点 | 0 ~ 100 % | 0 | マップの明るさがこれ以下の所はぼかさない |
| 白の点 | 0 ~ 100 % | 100 | マップの明るさがこれ以上の所は最大ボケ半径でぼかす。黒の点との間は直線でつなぐ |
| マップを反転 | ON / OFF | OFF | 白い所ほど弱く、黒い所ほど強くぼかす |
| 品質 | 標準 / 高 | 標準 | 高は、ぼかしを細かく作り、円・六角形・八角形では読む点を増やす。重くなる |

- マップの明るさは、黒の上に置いたときの明るさで見ます。透明な所は黒として扱います
- 黒の点と白の点を同じ値にすると、その値で、ぼかさない所と最大ボケ半径の所に分かれます。黒の点を白の点より大きくすると、向きが逆になります
- マップのレイヤーを読めないときは、ぼかさずにそのまま表示します。マップのレイヤーに自分のレイヤーを指定したときは、自分の明るさを使います
- マップのレイヤーも、通常どおり画面に描かれます。見せたくないときは画面の外へ置きます

#### 例: 深度マップで奥だけをぼかす

1. 深度マップの画像（奥ほど白い）を別のレイヤーに置き、画面の外へ出す。
2. ぼかしたい写真か、フィルタオブジェクトに「マップぼかし」を追加する。
3. マップ=レイヤー、マップのレイヤー=深度マップのレイヤー番号、最大ボケ半径=20〜40。
4. ピントを合わせる奥行きをずらしたいときは、黒の点を上げる（黒の点より手前はくっきり残る）。手前をぼかしたいときはマップを反転をONにする。

## 注意

- **ボケ半径を大きくするほど重くなります。** 1 画素ごとに半径の 2 乗に比例する数の画素を読むため、
  FHDの画面全体に大きな半径を掛けると再生が大きく遅れます。球面収差ボケは最大でボケ半径の 2 倍になる赤の半径で読むので、さらに重くなります
- **通常のオブジェクトでは、ぼけが外枠の外まで広がります。** 画像の上下左右をボケ半径の分だけ広げてからぼかすので、
  文字や図形に掛けても四角の縁で切れません。球面収差ボケは赤の半径の分だけ広げます。
  広げた分だけオブジェクトの大きさが変わり、元の画像の中心の位置は変わりません
- **フィルタオブジェクトでは広げません。** 画面の大きさは変えられないので、ぼけは画面の中に収まります
- **大きな画像では広げる量が減ります。** 広げた画像が画像サイズの上限や一時バッファの枠に収まるように
  広げる量を縮めるので、そのときはぼけが広げた所の縁で切れます。ボケの大きさそのものは変わりません
- 形状を選べるのは玉ボケ・レンズぼかし・マップぼかしです。チルトシフトと球面収差ボケは円です
- **マップぼかしのガウスは、最大ボケ半径によらず重さがほぼ同じです。** FHD・本体 2.1.13 のフィルタオブジェクトで、1 フレーム 9〜11ms（半径 30 でも 200 でも）、円・半径 30・標準で 11ms
- **マップぼかしで、円・六角形・八角形の最大ボケ半径を大きく（目安 150 以上）して品質を高にすると、FHD の画面全体では 1 フレームの枠（30fps で 33ms）を超えることがあります**（実測 42〜55ms）。プレビューは標準で作り、書き出しのときだけ高にしてください
- マップぼかしは、一時バッファの枠に収まらない大きな画像（目安は FHD の約 1.8 倍の面積、2500x1500 前後より上）には掛かりません。ぼかさずにそのまま表示し、ログに警告を 1 回出します
