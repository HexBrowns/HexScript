# 光学系ボケ

カメラのレンズで撮ったようなボケを付けるアニメーション効果です。1 つのファイルに 4 つの効果が入っています。

| 効果 | 何をするか |
|---|---|
| 玉ボケ | 明るい部分だけを取り出して、円・六角形・八角形の「玉」に広げて重ねる |
| レンズぼかし | 画像全体を、円・六角形・八角形の形でぼかす |
| チルトシフト | 帯状の範囲だけピントを合わせ、その外をぼかす（ミニチュア風） |
| 球面収差ボケ | 縁が明るいリング状のボケに、赤と青の色ずれ（色のにじみ）を付ける |

- `Script/@光学系ボケ.anm2`（v1.02）

## インストール

1. `Script\@光学系ボケ.anm2` を配置する（ファイル名の先頭の `@` を消さない。消すと 4 つに分かれず動かなくなります）
2. AviUtl2 を再起動する
3. オブジェクトのフィルタ効果に「玉ボケ」「レンズぼかし」「チルトシフト」「球面収差ボケ」のどれかを追加する（HexScript の中）

4 つとも、フィルタオブジェクトにも追加できます。画面全体をぼかすときはフィルタオブジェクトに付けます。

通常のオブジェクトに付けると、ぼけがオブジェクトの外枠の外まで広がります（下の「注意」）。

## 使い方

1. ぼかしたいオブジェクトか、フィルタオブジェクトに効果を追加する
2. **ボケ半径** でボケの大きさ（px）を決める
3. **強さ** で効き具合を決める
4. 効果ごとの項目（下の「パラメータ」）を合わせる

### 例: 画面全体に六角形の玉ボケを足す

実制作で使った設定です（フィルタオブジェクトに「玉ボケ」を追加）。

| 項目 | 値 |
|---|---|
| ボケ半径 | 25.0 |
| 輝度閾値 | 16.00 |
| エッジ強度 | 100.00 |
| 強さ | 50 |
| 形状 | 六角形 |
| 加算合成 | ON |

輝度閾値を低めにしているので、明るい部分の多くが六角形の玉になって加算されます。エッジ強度 100 で玉の縁が明るくなります。

`Default\玉ボケ@光学系ボケ.effect` に、輝度閾値 0・エッジ強度 50・強さ 50・形状 円・加算合成 ON の設定を保存してあります。

### 例: 画面の上下をぼかすミニチュア風

実制作で使った設定です（フィルタオブジェクトに「チルトシフト」を追加）。

| 項目 | 値 |
|---|---|
| ボケ半径 | 25.0 |
| 焦点位置 | 50.0 |
| 焦点幅 | 240 |
| グラデ幅 | 480 |
| 強さ | 100.00 |
| 方向 | 縦 |

画面の縦の中央を中心に、高さ 240px の帯がくっきり残ります。帯の上下 480px をかけてだんだんぼけ、その外は完全にぼけます。

## パラメータ

### 玉ボケ

| 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| ボケ半径 | 0 ~ 200 | 30 | 玉の半径（px）。0 なら何もしない |
| 輝度閾値 | 0 ~ 100 | 70 | 玉にする明るさの下限（%）。これより暗い部分は玉にならない。境目は 5% の幅でなめらかに切り替わる。100 なら何もしない |
| エッジ強度 | 0 ~ 100 | 50 | 玉の縁の明るさ。縁（半径の外側 3 割）ほど明るくなり、100 で縁が中心の 2 倍になる |
| 強さ | 0 ~ 1000 | 100 | 玉の明るさ。100 が基準。0 なら何もしない |
| 形状 | 円 / 六角形 / 八角形 | 円 | 玉の形 |
| 加算合成 | ON / OFF | ON | ON は元の画像に玉を足す（明るくなる）。OFF は玉を元の画像の上に重ねる。どちらも、玉が重なって濃くなっても不透明度は 100% で止まる |

取り出した明るい部分を玉に広げて重ねるので、明るい部分が広い素材ほど足される光も増えます。

### レンズぼかし

| 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| ボケ半径 | 0 ~ 200 | 30 | ぼかしの半径（px）。0 なら何もしない |
| 強さ | 0 ~ 100 | 100 | 元の画像とぼかした画像の混ぜ具合（%）。100 でぼかした画像だけ。0 なら何もしない |
| 形状 | 円 / 六角形 / 八角形 | 円 | ぼかしの形。明るい点がこの形に広がる |

### チルトシフト

| 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| ボケ半径 | 0 ~ 200 | 30 | 帯の外のぼかしの半径（px）。形は円。0 なら何もしない |
| 焦点位置 | 0 ~ 100 | 50 | くっきり残す帯の中心の位置（%）。方向が縦なら 0 が上端・100 が下端、横なら 0 が左端・100 が右端 |
| 焦点幅 | 0 ~ 2000 | 200 | くっきり残す帯の幅（px）。焦点位置を中心に、この幅の半分ずつ両側に広がる |
| グラデ幅 | 0 ~ 1000 | 150 | 帯の外で、くっきりから完全なぼけへ移る距離（px）。0 は 1 として扱う |
| 強さ | 0 ~ 100 | 100 | 一番ぼけた所での、ぼかした画像の混ぜ具合（%）。0 なら何もしない |
| 方向 | 縦 / 横 | 縦 | 縦は焦点位置を上下で決め、横長の帯を残す。横は焦点位置を左右で決め、縦長の帯を残す |

### 球面収差ボケ

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| ボケ半径 | 0 ~ 200 | 20 | ぼかしの半径（px。緑の半径）。形は円。0 なら何もしない |
| リング強度 | 0 ~ 100 | 60 | ボケの縁の強さ。縁（半径の外側 3 割）の重みを上げ、100 で縁が中心の 2 倍になる |
| 色収差 | 0 ~ 100 | 20 | 色ずれの量（%）。赤は半径 × (1 + 色収差)、青は半径 × (1 − 色収差 ÷ 2) でぼける。0 なら色ずれなし |
| 強さ | 0 ~ 100 | 80 | 元の画像とぼかした画像の混ぜ具合（%）。0 なら何もしない |

## 注意

- **ボケ半径を大きくするほど重くなります。** 1 画素ごとに半径の 2 乗に比例する数の画素を読むため、
  FHD の画面全体に大きな半径を掛けると再生が大きく遅れます。球面収差ボケは赤の半径（最大でボケ半径の 2 倍）で読むので、さらに重くなります
- **通常のオブジェクトでは、ぼけが外枠の外まで広がります。** 画像の上下左右をボケ半径の分だけ広げてからぼかすので、
  文字や図形に掛けても四角の縁で切れません（球面収差ボケは赤の半径の分だけ広げます）。広げた分だけオブジェクトの大きさが変わり、
  元の画像の位置（中心）は変わりません
- **フィルタオブジェクトでは広げません。** 画面の大きさは変えられないので、ぼけは画面の中に収まります
- **大きな画像では広げる量が減ります。** 広げた画像が画像サイズの上限や一時バッファの枠（合わせて 1600 万ドット）に収まるように
  広げる量を縮めるので、そのときはぼけが広げた所の縁で切れます（ボケの大きさそのものは変わりません）
- 形状を選べるのは玉ボケとレンズぼかしだけです。チルトシフトと球面収差ボケは円です
