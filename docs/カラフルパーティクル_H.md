# カラフルパーティクル_H

図形の粒を一定の間隔で出し、放射状に飛ばす**カスタムオブジェクト**です。
第三者作の `@FIGURE.obj2` の「カラフルパーティクル」を元にしています。

元と同じ粒を描き、**描く前の読み込みを減らして軽くしました**。
見えない粒は描かず、粒が 1 つも見えないフレームは何もしません。
元に無い機能として、**カラフルをオフにして 1 色で描けます**。
v1.10 から、カラフルの色の出し方を色空間で選べます。
v1.20 から、粒の散らし方（一様乱数 / ジッター格子 / Halton列）を選べます。

## インストール

1. `Script\カラフルパーティクル_H.obj2` を置く。
2. 色空間を Oklch にするときは、`EffectUtils_ColorSpace.lua` も `Script` フォルダの直下に置く。
3. AviUtl2を起動する。
4. オブジェクトの追加の **カスタムオブジェクト** から **HexScript → カラフルパーティクル_H** を選ぶ。

## 使い方

1. カラフルパーティクル_Hを置く。オブジェクトの位置から粒が出て、飛んでいく。
2. **頻度** で 1 秒に出す粒の数、**距離** と **速度** で飛ぶ距離と速さを決める。
3. **方向** で飛ぶ向き、**ランダム方向** で向きのばらつきを決める。360 で全方向に散る。
4. 1 色にしたいときは **カラフル** をオフにして **色** を選ぶ。

粒の形は **種類**・**サイズ**・**ライン幅** で決めます。

## パラメータ

### 発生

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 頻度 | 0.1 ~ 500 | 10 | 1 秒に出す粒の数 |
| 距離 | 1 ~ 10000 px | 500 | 粒が消えるまでに飛ぶ距離 |
| 速度 | 1 ~ 2000 px/秒 | 400 | 粒の速さ。距離 ÷ 速度 が粒の寿命になる |
| 方向 | -360 ~ 360 ° | 0 | 粒が飛ぶ向き |
| ランダム方向 | 0 ~ 360 ° | 30 | 向きのばらつきの幅 |
| ランダム速度[-%] | 0 ~ 100 | 0 | 速さを粒ごとに最大この割合だけ遅くする |
| X軸ランダム / Y軸ランダム | 0 ~ 10000 px | 0 | 出る位置のばらつきの幅 |
| 散らし方 | 一様乱数 / ジッター格子 / Halton列 | 一様乱数 | 粒ごとの向き・速さ・出る位置のばらつきの決め方。下の「散らし方」を参照 |

### 散らし方

v1.20 で足した項目です。初期値の一様乱数は v1.10 までと同じ粒の出方で、保存済みのプロジェクトの見た目は変わりません。
ランダム方向・ランダム速度[-%]・X軸ランダム・Y軸ランダム のばらつきを、どう割り振るかを選びます。

| 選択肢 | 散らばり方 |
|---|---|
| 一様乱数 | 粒ごとに乱数で決める。同じ向きに固まる所と、粒の出ない向きができる |
| ジッター格子 | 同時に飛んでいる粒の数で、向きの幅・速さの幅・出る位置の範囲を等分し、それぞれの区切りに 1 粒ずつ入れる。偏りなく散らばる |
| Halton列 | 決まった数の並びで、続いて出る粒ほど離れた向き・位置に出す。偏りなく散らばる |

- 違いがはっきり出るのは、頻度が低く同時に飛ぶ粒が少ないときです。一様乱数では向きに偏りが出ますが、ほかの 2 つは幅全体に行き渡ります
- ジッター格子は、頻度・距離・速度・X軸ランダム・Y軸ランダムを変えると区切り方が変わり、全部の粒の向きと位置が変わります。これらをアニメーションさせるときは Halton列 が向いています
- 粒の回転・大きさ・色は、散らし方を変えても同じです

### 図形

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 種類 | 図形 | 円 | 粒の形 |
| サイズ | 1 ~ 2000 | 100 | 粒の大きさ |
| ライン幅 | 1 ~ 4000 | 4000 | 図形の線の太さ。4000 で塗りつぶし |
| カラフル | オン / オフ | オン | オンで粒ごとに色を変える。オフで **色** の 1 色 |
| 色 | 色 | 白 | カラフルがオフのときの色。オンのときは隠れる |
| 色空間 | 今まで / HSV / Oklch | 今まで | カラフルの色の出し方。下の「色空間」を参照。カラフルがオンのときだけ出る |
| 明度(L) | 0 ~ 100 | 75 | Oklch の明るさ。色空間が Oklch のときだけ出る |
| 彩度(C) | 0 ~ 0.4 | 0.15 | Oklch の鮮やかさ。色空間が Oklch のときだけ出る |

### 色空間

| 選択肢 | 出る色 |
|---|---|
| 今まで | 元のスクリプトと同じ式。青〜緑〜赤だけで、紫・マゼンタは出ない |
| HSV | 色相を一周から選ぶ。彩度・明度は 100% で、紫・マゼンタも出る |
| Oklch | 色相を一周から選び、明るさと鮮やかさを 明度(L)・彩度(C) にそろえる |

- 初期値の「今まで」は v1.00 と同じ色です。保存済みのプロジェクトの見た目は変わりません
- HSV は黄・シアンが明るく、青が暗く見えます。粒の明るさをそろえたいときは Oklch にします
- Oklch で sRGB に無い色になるときは、明るさと色相を保ったまま鮮やかさを下げます。彩度(C) を上げても、色相によっては頭打ちになります
- 粒の位置・向き・大きさは、色空間を変えても同じです

### 変化

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 透過速度[%] | 0 ~ 100 | 100 | 飛ぶにつれて薄くなる度合い。100 で消える所で透明 |
| 拡大速度[%] | -100 ~ 1000 | 0 | 飛ぶにつれて大きさを変える割合 |
| ランダム拡大[-%] | 0 ~ 100 | 0 | 大きさを粒ごとに最大この割合だけ小さくする |
| ランダムZ角度 | 0 ~ 360 ° | 0 | 粒の向きのばらつき |
| ランダムZ回転 | 0 ~ 3600 | 0 | 粒が回る速さのばらつき |

## 注意

- 元の「カラフルパーティクル」から乗り換えると、項目名が同じなので、同じ値を入れれば同じ絵になります。カラフル・色は元に無い項目です
- 粒の並びは乱数で決まり、オブジェクトごとに変わります
- v1.10・v1.20 で設定項目を足しました。ファイルを入れ替えたときは、AviUtl2の再起動が必要です
- Oklch で `EffectUtils_ColorSpace.lua` が読めないときは、ログに注意が出て「今まで」の色で描きます
