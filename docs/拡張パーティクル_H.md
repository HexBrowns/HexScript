# 拡張パーティクル_H

付けたオブジェクトの画像を**粒子として放出する**アニメーション効果です。AviUtl1 の「拡張パーティクル(R)」（rikky）を AviUtl2 へ移し、作り直したものです。
「本体」の上に拡張（出力位置・回転・風・力場・パス・形へ集まる・跳ね返り・子粒子・素材・軌跡・立体物・影・光源・粒子どうし・焼き付け・見た目の調整 など 32 種類）を積んで、動きと見た目を組み合わせます。
粒子を別のオブジェクトへ渡して、そこで描いたり、そこから粒子を出したりもできます（「受け取って描く」・出力位置「渡された粒子」）。
すぐに使える組み合わせを、プリセット（エイリアス）として 22 本付けています。

`Script/@拡張パーティクル_H.anm2`（計算は `Script/Particle_H.lua`）、v0.17.0。

## インストール

1. [HexScript の Releases](https://github.com/HexBrowns/HexScript/releases) の zip を展開し、`Script\@拡張パーティクル_H.anm2` と `Script\Particle_H.lua` の 2 つを、AviUtl2 のデータフォルダ（既定は `C:\ProgramData\aviutl2`）の `Script` フォルダへ置く
2. プリセットを使うなら、zip の `Alias\拡張パーティクル_H\` のフォルダ（`.object` が 22 個）も、データフォルダの `Alias` フォルダへ置く
3. AviUtl2 を再起動する
4. 画像・図形・テキストなどのオブジェクトに「本体@拡張パーティクル_H」を追加する（HexScript の中）

## 使い方

1. 粒子にしたいオブジェクト（例: 図形の円 20px）を置く
2. 「本体@拡張パーティクル_H」を追加する。これだけで、オブジェクトの中心から粒子が出る
3. 必要な拡張を追加し、**本体より上**へ動かす。本体は、自分より上にある有効な拡張だけを使う

```text
オブジェクト（図形・画像・テキスト…）
  出力位置@拡張パーティクル_H        ← 拡張は本体より上
  回転@拡張パーティクル_H
  本体@拡張パーティクル_H            ← 粒子を描く
  （平面描写のときだけ、ここに置いた標準の効果が粒子全体に掛かる）
```

本体より下に置いた拡張は使われません（効果を並べ替えれば効きます）。このときはログに `注意: 本体より下の「…」は使われない` の行が出ます。

「編集中だけ」は、AviUtl2 の編集画面で見ているときだけ描き、動画の出力には出しません。

### 向きと単位

- **出力方向は 0 が下**、90 が右、180 が上、-90（270）が左です
- **出力頻度は 1 秒あたりの個数**です（10 なら 1 秒に 10 個）。0 なら何も出ません（時間の付け替えの「一斉に出す」の分だけは出ます）
- **出力速度は 1 秒あたりの距離**（px）、加速度・重力は 1 秒あたりの速度の変化（px/秒²）です
- **透過率は 0 が不透明**、100 が透明です（AviUtl2 の標準の「パーティクル出力」と同じ向き。原作とは逆です）
- 時間はすべて**秒**です

### トラックバーを動かす

トラックバーには移動方法（直線移動・カーブエディタ2 など）を付けられます。
「放出時の値を使う」がオン（初期値）なら、**粒子は生まれた時刻の値で飛び**、その後に値が変わっても影響を受けません。
たとえば出力方向を 0→180 に動かすと、粒子が扇形に広がります。オフにすると、すべての粒子が今の値で動きます。

出力頻度を動かすと、その時刻ごとの頻度で数が増減します（途中で頻度を上げ下げしても、粒子が飛んだり消えたりしません）。

エイリアスの一覧から置くか、ファイルをタイムラインへドラッグ＆ドロップします。置いた後は普通のオブジェクトと同じで、値を自由に変えられます。

## 使い方の例

拡張を組み合わせて作れるもの。専用の項目は足していません。

- **縁取りの付いた粒子**: フィルター@拡張パーティクル_H の効果名を「縁取り」、変化させる項目を「サイズ」にし、始の値と終の値を同じ値（例 4）にする。
  縁の色は 固定の項目 に `縁色=0xffffff` のように書く（標準の縁取りの項目は サイズ・ぼかし・縁色）
- **光の筋でつなぐ**: メッシュ（結び方 = 近い粒子）＋本体の合成モード「加算」。光らせるなら本体の平面描写をオンにして、本体より下に標準の「発光」を置く
  （プリセットの「ネットワーク」が元になる）
- **巻き戻し・停止の区間**: 時間の付け替えの「進行時間を使う」をオンにし、進行時間のトラックバーを動かす。値が下がる区間は巻き戻し、同じ値の区間は止まる
- **スローモーションの区間**: 同じく進行時間に、カーブエディタ2 の移動方法を付ける。カーブの傾きが緩い所が遅く進む
- **画像を砕いて戻す**: 画像のオブジェクトに、出力位置「自分の画像を並べる」＋素材「切り抜き」（切り抜く所 = 出た所）＋形へ集まる（行き先 = 出た所）。
  本体の出力速度で散らし、形へ集まるの集まり始める時刻で戻す（プリセット「画像が飛び散って戻る」）。戻った絵は元の画像と同じになります
- **文字が組み上がる**: 素材をテキストにして、形へ集まる（行き先 = 文字の並び）。ずらす幅とずらす順で、1 文字ずつ順に着かせる（プリセット「文字が集まる」）
- **ずっと繰り返す背景**: 時間の付け替えの「ループ」をオンにし、周期をオブジェクトの長さの約数にする（周期ごとに同じ絵に戻り、継ぎ目が見えない）
- **絵を割る**: 出力位置「自分の画像を並べる」の並べ方を「破片」にし、素材を切り抜き（切り抜く所 = 出た所）にする（プリセット「ガラスが割れる」）。
  割れる時刻は時間の付け替えの活動時間で決める
- **写真をローポリにする**: 写真を別のレイヤーに置いて透明度 100 で見えなくし、粒子を写真の範囲に散らして、メッシュ（結び方 = 三角形で塗る、面の色 = 他レイヤーの画像の色）。
  粒子は本体の透過率 100 で見えなくしてよい（三角形は粒子の透過率を掛けない設定で塗る）
- **雪を画面の手前に固定する**: カメラ制御の下の雪に、本体の「画面に貼り付ける」。カメラが動いても雪は画面に対して同じ所を降る
- **粒子を他のオブジェクトの間に挟む・粒子だけに効果を掛ける**: 本体に渡す名前を付けて「渡すだけ」をオン。別のレイヤーの図形に「受け取って描く」を付け、その図形に効果を掛ける
- **曲に合わせて出す**: 音で「拍で出す」を選ぶ。曲のファイル（WAV・mp3・m4a など）があれば音声ファイルの拍（キックだけなら 拍を見る音 = 低い音）、無ければ編集画面のグリッド（BPM）を曲に合わせて BPMのグリッド
- **粒を器に溜める・ぶつかって重ならない**: 粒子どうしの「粒子の大きさ」を粒の大きさにし、跳ね返りで器（左右の壁と床）を作る（プリセット「器に溜まる粒」）
- **群れで動かす**: 粒子どうしの「向きをそろえる」「群れの中心へ寄る」「離れる」と、最低・最高の速さ。素材の向きは本体の「進行方向を向く」（プリセット「魚の群れ」）
- **立体に陰影を付ける**: 立体物（六面体など）に光源を足す。平らな粒子でも、回ると明るさが変わる
- **花火の各粒から火の粉を出す**: 花火の本体に渡す名前を付け、その下のレイヤーの別のオブジェクトで出力位置「渡された粒子」（動きの速さを足す 30 くらい）
- **形の色のまま崩す**: 出力位置「他レイヤーの形」＋色の変化（色の決め方 = 出た所の色）で、絵の色の粒子が絵の形から出る
- **ロゴの形に集まる**: ロゴの画像を別のレイヤーに置いて（透明度 100 で見えなくしてよい）、形へ集まる（行き先 = 他レイヤーの形、選び方 = 均等に）

### 出力位置@拡張パーティクル_H

粒子の出る位置を変えます。座標はオブジェクトの中心から測ります。画面上のアンカーで動かせます。
他のレイヤーのオブジェクトの位置や形から出すことも、関数ファイルで位置を決めることもできます。

**自分の画像を並べる**は、オブジェクトの画像（素材の元）をマスに分けて、マスの数だけ一斉に出します（本体の出力頻度・同時発生数は使いません）。素材の切り抜きで「切り抜く所 = 出た所」にすると、粒子はそれぞれ自分のマスの絵になり、並べ直すと元の画像に戻ります。画像は毎フレーム読みます。マスは 10,000 個まで（FHD の画像を間隔 20 で 5,184 個）。
破片も、並べ直すと元の画像に戻ります（破片の間に隙間は出ません）。破片の形はシードと画像の大きさで決まり、同じなら毎フレーム同じ形です。

**文字の並び**は、素材のテキストを、テキストオブジェクトのように並べた位置から 1 文字ずつ出します（出力頻度が 1 秒に出す文字の数。並べ方は素材のテキストの設定の 文字揃え・文字の間隔・行の間隔）。素材をテキストにしたときだけ使えます。

**渡された粒子**は、別のオブジェクトの本体が「渡す名前」で渡した粒子の、自分の粒子が生まれた時刻の位置から出します（花火の各粒から火の粉を出す、など）。
渡す側はフレームごとの粒子の位置を残していて（1 フレームに 500 個まで。多ければ間引く）、生まれたフレームの位置を引きます。
**渡す側を、受け取る側より上のレイヤーに置いてください**（下にあると 1 フレーム遅れます）。
編集中に途中のフレームへ飛ぶと、まだ描いていないフレームの位置が無いので、近いフレームの位置から出ます（頭から再生・出力すると正しくなります）。

他レイヤーの位置・Z軸回転・拡大率は、粒子が生まれた時刻の値を使います（本体の位置を引いた、本体から見た座標）。対象のオブジェクトは本体と同じフレームで始めてください。形（アルファ）は今のフレームの形を使います。

関数ファイルの例（1 秒で半径 300 の円を描く位置から出す）。`t` はオブジェクトの時刻（秒）で、本体の開始時間の分はマイナスになります。

```lua
function xyz(t)
  return 300 * math.sin(2 * math.pi * t), 300 * math.cos(2 * math.pi * t), 0
end
```

| もう一つの周波数帯 | 0〜10 | なし | 選ぶと、2 つの帯の大きい方を使う |
| 感度 | 0〜10000 | 100 | 音の大きさに掛ける %。小さい音でも動かしたいときは上げる |
| 拡大率 | -1000〜1000 | 100 | 音がいちばん大きいとき、粒子の大きさをこの % だけ変える |
| 透過率 | -100〜100 | 0 | 音がいちばん大きいとき、透過率をこの % だけ上げる |
| 広がり | -1000〜1000 | 0 | 音がいちばん大きいとき、粒子が出た所からの距離をこの % だけ広げる |
| 拍で出す | 出さない / 音声ファイルの拍 / BPMのグリッド | 出さない | 拍の時刻に、拍ごとの数の粒子を一斉に出す（下の説明） |
| 拍ごとの数 | 1〜10000 | 30 | 1 つの拍で出す数 |
| 拍の感度 | 0〜100 | 50 | 音声ファイルの拍: 大きいほど小さな立ち上がりも拍として拾う |
| 拍を見る音 | 全体 / 低い音 / 高い音 | 全体 | 音声ファイルの拍: 低い音（150Hz より下。キックなど）・高い音（2kHz より上。ハイハットなど）だけで拍を探す |
| グリッドの細かさ | 1〜16 | 1 | BPMのグリッド: 1 拍を分ける数（2 で 8 分、4 で 16 分） |
| 強い拍ほど多く | オン / オフ | オン | 音声ファイルの拍: 立ち上がりの大きさに比例して数を変える（一番強い拍が 拍ごとの数）。BPMのグリッド: 小節の頭 1 / 拍 0.7 / 拍の間 0.4 を掛ける |
| 音の大きさで出す数 | 0〜1000 | 変えない | 音声ファイルの音の大きさ（ファイルの一番大きい所が 1）に合わせて、出力頻度に 1 ＋ この % × 音の大きさ を掛ける（300 なら一番大きい所で 4 倍）。編集中の音では使えない |
| 音の大きさを見る音 | 全体 / 低い音 / 高い音 | 全体 | 音の大きさで出す数: 低い音（150Hz より下）・高い音（2kHz より上）だけの大きさを見る |

振幅 0.8 の 100Hz の音で、いちばん大きい（拡大率 100 なら 2 倍）になります。

**拍で出す**は、音の大きさの変化（上の表の拡大率・透過率・広がり）とは別に、拍の時刻に粒子を出します（本体の出力頻度の分と合わせて出ます。拍だけで出すなら出力頻度を 0 にします）。
拍だけを使って大きさは変えないなら、拡大率を 0 にします。シークしても同じ絵になります。

- **音声ファイルの拍**: 音を「音声ファイル」にしてファイルを選びます。WAV（16 / 24 / 32 bit・float）のほか、**mp3・m4a など Windows（Media Foundation）が読める形式**も使えます。ファイルを読んで、音が急に大きくなった所を拍にします（拍と拍は 0.1 秒以上離します）。
  ファイルの先頭がオブジェクトの始まりです。mp3・m4a は、エンコーダーが先頭に足した無音を取り除いてから読みます（WAV と同じ時刻になります）。ただし、先頭に情報フレームの無い mp3 は 13ms ほど遅れることがあります。
  読み込むのはファイルか設定を変えたときだけです（WAV は 60 秒のステレオで約 20ms、mp3・m4a は数秒の曲で 20〜40ms ほど。長い曲ほどかかります）
- **音の大きさで出す数**: 拍とは別に、音声ファイルの音の大きさで出る数を増やします（盛り上がる所ほど多く出る）。拍で出すと一緒に使えます。シークしても同じ絵になります
- **BPMのグリッド**: 編集画面のグリッド（BPM）の拍を使います。テンポが途中で変わる区間にも合わせます。ファイルを読まないので、どの音声でも使えます

### カスタム描画@拡張パーティクル_H

関数ファイル（.lua）の `particle_obj` で描いた絵を、粒子の素材にします（素材の代わり）。

| 項目 | 範囲・選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 関数ファイル | ファイル | なし | `particle_obj` を書いた .lua（UTF-8） |
| 種類の数 | 1〜64 | 4 | 絵の種類。粒子ごとにでたらめに選ぶ |
| 時間の段数 | 1〜64 | 8 | 寿命に沿って絵を変える段の数。種類の数 × 時間の段数は 64 まで（超える分は段数を減らす） |
| 値1 / 値2 / 値3 | -9999〜9999 | 0 | 関数へ渡す値 |
| 設定値 | 配列 | なし | 関数へ渡す値（8 つまで） |
| 色1 / 色2 / 図形1 / 図形2 / チェック1 / チェック2 | | 白 / 黒 / 円 / 四角形 / オフ / オフ | 関数へ渡す値 |

関数は次の形で書きます。種類 × 時間の段ごとに 1 回だけ呼ばれます（粒子ごとには呼ばれません）。

```lua
function particle_obj(t, t0, life, pi, pj, seed, v1, v2, v3, s1, s2, s3, s4, s5, s6, s7, s8, col1, col2, fig1, fig2, chk1, chk2)
  -- t: 段の時刻（0〜生存時間）/ pi: 種類（0 から）/ seed: 種類ごとの乱数 / v1〜v3: 値1〜3 / s1〜s8: 設定値
  obj.setoption("drawtarget", "tempbuffer", 60, 60)
  obj.load("figure", "四角形", col1, 40)
  obj.draw()
  obj.load("tempbuffer")   -- 最後に仮想バッファを読み込んで終える
end
```

### 受け取って描く@拡張パーティクル_H

本体の「渡す名前」で渡された粒子の位置に、**このオブジェクトの画像**を描きます。本体とは別のオブジェクト（図形・画像・テキストなど）に付けます。
粒子をそのレイヤーで描くので、他のオブジェクトの間に粒子を挟んだり、粒子だけに別の効果（このオブジェクトの効果）を掛けたりできます。

| 項目 | 範囲・選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 受け取る名前 | 文字列 | なし | 本体の「渡す名前」と同じ名前 |
| 拡大率 | 0〜5000 | 100 | 粒子の拡大率に掛ける %（大きさはこのオブジェクトの画像 × 粒子の拡大率 × この値） |
| 粒子の透過率を使う | オン / オフ | オン | オフなら不透明で描く |
| 粒子の回転を使う | オン / オフ | オン | オフなら回さずに描く |
| 診断ログ | オン / オフ | オフ | 受け取った粒子の数と、何フレーム前の粒子かをログへ出す |

- **渡す側（本体）を、受け取る側より上のレイヤーに置きます。** AviUtl2 は上のレイヤーから順に計算するので、下に置くと 1 フレーム前の粒子になります（描きますが、ログに注意が出ます）
- 位置は、渡した側の本体の位置を含めた画面の座標です（受け取る側のオブジェクトの位置は関係しません）
- 自分の画像はそのままでは描かず、粒子の位置にだけ描きます

### 影@拡張パーティクル_H

粒子の影を、粒子と同じ素材で、粒子より先に（後ろに）描きます。影は影の色に塗りつぶし、ぼかします。

| 項目 | 範囲・選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 落とし方 | ずらす / 床に写す | ずらす | ずらす: 画面の上でずらす（ドロップシャドウ）。床に写す: 光で床の面へ写し、床に寝かせて描く |
| ずらすX / ずらすY | -10000〜10000 | 20 / 20 | ずらすとき（px） |
| 床の高さ | -100000〜100000 | 400 | 床に写すとき。床の Y（本体から見た座標）。床より下にいる粒子の影は描かない |
| 光の向きX / 光の向きZ | -10〜10 | 0.5 / 0 | 床に写すとき。下へ 1 進むごとに X・Z へ進む量（0 なら真下に落ちる） |
| 影の濃さ | 0〜100 | 60 | 粒子の不透明度に掛ける % |
| 影のぼかし | 0〜200 | 6 | px |
| 影の色 | 色 | 黒 | |
| 高さで薄く | 0〜100000 | 薄くしない | 床に写すとき。床からこの距離（px）で影が消える |

床に寝かせた影は、カメラ制御で斜めから見ると床の上に見えます（カメラ制御が無いと、真横から見た細い線になります）。

### 光源@拡張パーティクル_H

粒子の面の向きと光から明るさを決め、粒子を暗く（ハイライトは明るく）描きます。立体物では、面ごとに明るさが変わります。

| 項目 | 範囲・選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 光の種類 | 平行光 / 点光源 | 平行光 | 平行光: どこでも同じ向きの光。点光源: 光の位置から広がる光 |
| 光の向きX / Y / Z | -10〜10 | 0.5 / 1 / 1 | 平行光: 光が進む向き（初期値は左上の手前から右下の奥へ） |
| 光の位置 | アンカー | -400, -400, -300 | 点光源: 光の位置（本体から見た座標） |
| 環境光 | 0〜100 | 30 | 光が当たらない面の明るさ（%） |
| 光の強さ | 0〜200 | 100 | 光に正面から向いた面に足す明るさ（%） |
| ハイライト | 0〜100 | 0 | 光に正面から向いた所を、光の色へ明るくする強さ |
| 段数 | 2〜32 | 8 | 明るさを分ける段の数。多いほど滑らかで重い |
| 裏も照らす | オン / オフ | オン | 平らな粒子の裏を向いた面も、裏から当たる光で照らす。**閉じた立体（六面体・球・錐体・双錐体）では使わない**（光に背を向けた面は環境光だけ） |
| 光の色 | 色 | 白 | ハイライトの色 |

明るさ = 環境光 + 光の強さ × 面が光の方を向いている度合い で、1（100 %）を超えた分は使いません（ハイライトだけが白く明るくします）。
明るさを段数の段に分け、段ごとに標準の「単色化」（黒・強さ = 暗くする割合）を掛けた素材で描きます。
段数 × 素材の種類 × 色の段 の数だけ素材を読み直すので、段数を上げると重くなります。影と円環には掛かりません。

### 粒子どうし@拡張パーティクル_H

粒子どうしを押し合わせ・引き合わせ、群れにします。全部の粒子を同じ時刻の刻みで一緒に進めます（一緒に進める数まで）。

| 項目 | 範囲・選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 届く距離 | 1〜2000 | 40 | 粒子どうしの力が届く距離（px）。群れの仲間を探す距離でもある |
| 反発 | 0〜100000 | 500 | 届く距離の中で、近いほど強く押し合う（px/秒²） |
| 粒子の大きさ | 0〜2000 | 重なってよい | 粒子どうしがこれより近づかない（px）。位置を押し戻して、近づく速さを消す。器に入れると段になって溜まる |
| 引き合い | -100000〜100000 | 0 | 届く距離の中で寄る（遠いほど強い）。負なら離れる |
| 粒子どうしの摩擦 | 0〜100 | 0 | 触れている粒子どうしがずれる速さを弱め、押し合う量 × 摩擦 までのずれを止める（%）。粒子の大きさと一緒に使うと、1 点から落とした粒子が山に積もる（100 で底の幅 250px・高さ 200px ほど。240 粒・大きさ 12） |
| 離れる | 0〜100 | 0 | 群れ: 近い仲間から離れる強さ |
| 向きをそろえる | 0〜100 | 0 | 群れ: 仲間の平均の速さへ寄せる強さ |
| 群れの中心へ寄る | 0〜100 | 0 | 群れ: 仲間の中心へ寄る強さ |
| 見える角度 | 0〜180 | 135 | 群れ: 進む向きから ± この角度（度）の中の粒子だけを仲間にする（180 で全方位） |
| 最低の速さ / 最高の速さ | 0〜10000 | 0 / 制限しない | 速さをこの範囲に収める（px/秒） |
| 奥行きも使う | オン / オフ | オフ | オフなら XY の距離だけで考える（軽い） |
| 当たる相手（受け取る名前） | 文字列 | なし | 別のオブジェクトの本体が「渡す名前」で渡した粒子に当たって押される（相手は押し返さない） |
| 相手の大きさ | 0〜2000 | 20 | 当たる相手の粒子と、中心どうしがこれより近づかない（px） |
| 相手から押される強さ | 0〜100000 | 500 | 相手の大きさの 1.5 倍の中で、近いほど強く押される（px/秒²） |
| 一緒に進める数 | 100〜10000 | 3000 | これを超えた粒子は力を受けず、今までどおり粒子ごとに進む（ログに注意が出る）。10,000 粒で 1 フレーム約 120ms（実機。届く距離 40・大きさ 10） |

- 風・力場・跳ね返り・止まったら残すなどの拡張と一緒に効きます。円運動・パスとは一緒に使えません（ログに注意が出ます）
- **どのフレームから描いても同じ絵になります**（頭から再生しても、途中へ飛んでも同じ）。そのため、最初のフレームと後ろへ飛んだときは、
  シミュレーションの始まりから計算し直すので重くなります（途中の状態を取っておき、次からはそこから進め直します）
- **当たる相手は、相手のオブジェクトを上のレイヤーに置きます**（下にあると 1 フレーム遅れます）。相手の位置は「渡す」の履歴（1 フレームに 渡す数 まで、多ければ間引く）から、刻みの時刻をはさむ 2 つのフレームの同じ粒子の位置を直線で補って使います（速く動く相手もすり抜けにくい）。
  描くフレームの端数の刻み（1 刻みより短い分）は相手を見ないので、速い粒子は数 px はみ出すことがあります。途中のフレームへ飛ぶと、相手の履歴が無い所は近いフレームの相手で計算します（頭から再生・出力すると正しくなります）
- 集結点は、毎刻み粒子の速さを中心へ向け直すので、粒子の大きさより強く押し込みます（重なることがあります）。寄せるなら引き合いを使います
- 平らな床に落とすと、粒子どうしの摩擦 0 では低く広がります。粒子どうしの摩擦を上げると山に積もります（v0.15.0）。器に溜めるなら、跳ね返りで左右の壁を作ります

### 焼き付け@拡張パーティクル_H

計算した粒子をフレームごとにファイルへ書き、後で読み込んで計算を飛ばします。重い粒子どうし・群れを一度だけ計算して、後は軽く見るのに使います。

| 項目 | 範囲・選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 焼き付け | 使わない / 書き出す / 読み込む | 使わない | 書き出す: 描いたフレームを書く。読み込む: 書いたフレームを計算せずに描く |
| 置くフォルダ | フォルダ | なし | ファイル（名前.prh）を置くフォルダ。日本語のフォルダも使える |
| 名前 | 文字列 | particles | ファイルの名前（拡張子 .prh は付けない） |
| 無いフレームは計算する | オン / オフ | オン | 読み込むとき、記録の無いフレームを計算する（オフなら描かない） |
| CSV も書く | オン / オフ | オフ | 書き出すとき、置くフォルダの 名前_csv に、フレームごとの CSV（00012.csv = 12 フレーム目）も書く。1 行 1 粒で `k,x,y,z,rx,ry,rz,zoom,alpha,age,life`（番号・本体から見た座標 px・回転の度・拡大率 %・不透明度 0〜1・年齢と寿命の秒）。Blender などで読むときはフォルダごと読む |

使い方:

1. 焼き付けを「書き出す」にして、AviUtl2 で動画を出力する（頭から全部のフレームを描くと、全部のフレームが書かれる。プレビューで描いたフレームも書かれる）
2. 「読み込む」に切り替える。以後は計算せずに描く（3,000 粒で 1 フレーム約 2ms）

- **本体・拡張の動きの設定を変えると、その焼き付けは使いません**（ログに注意が出ます。もう一度書き出してください）。本体の位置（X・Y・Z）を変えるのは構いません
- **見た目だけの変更なら、焼き付けを使い続けます**（v0.16.0）: 本体の始・終拡大率と透過率、拡大率と透過率・見た目の調整・色の変化・フィルター・素材など。位置と回転は焼き付けのまま、拡大率・透過率は今の設定で計算し直します。
  ただし、形へ集まるの「向きをそろえる」を使っているときは、拡大率・透過率を変えても書き出し直しが要ります
- ファイルの大きさは、3,000 粒で 1 フレーム約 175KB、30fps の 1 分で約 315MB です
- 書き出すと、計算に加えて書く分（3,000 粒で約 5ms）重くなります
- 書いたファイルを、同じフレームで下のレイヤーの別のオブジェクトが読み込むこともできます（同じ設定で、置くフォルダ・名前が同じなら）

## 注意事項・制限

- **拡張は本体より上に置く。** 下に置いた拡張は使われません
- **平面描写でないとき、本体より下の効果は掛かりません**（粒子を描くと、その後ろの効果は実行されないため）。粒子全体に効果を掛けたいときは平面描写をオンにします
- **平面描写でも、下に置いたスクリプトの効果（第三者のスクリプトを含む）は掛からないことがあります。** 標準の効果は掛かります。掛からないときは、別のレイヤーのフィルタオブジェクトで掛けてください
- 生きている粒子は **10,000 個まで**です。超える分は古い粒子から描かれません（診断ログの `overflow` に出ます）。1 フレームの目安は、10,000 個で約 18ms（FHD）
- 生きている粒子が多く、拡張で粒子ごとの透明度がばらつくと、描く順（新しい粒子が手前）が少し崩れることがあります
- 拡張のトラックバーは、今のフレームの値をすべての粒子に使います（「放出時の値を使う」は本体のトラックバーに効きます）。
  風力とノイズ場の強さだけは、トラックバーを動かすとその時刻の値で計算します
- **風・ノイズ場・集結点・跳ね返り・分散と停止・挙動不審を使うときの目安は 3,000 粒**です（1 フレーム約 17ms、FHD）。
  10,000 粒では 1 フレーム 40ms 以上かかります。最初のフレームと、後ろへシークしたときは、粒子が生まれた時刻から計算し直すので重くなります
- 円運動を付けている間は、本体の出力速度・加速度・重力と、風・力場などの動きの拡張は効きません（ログに `注意: 円運動を付けているので…` の行が出ます）
- **力場は風などと同じ重さ**です。力場 3 つ＋3,000 粒で、計算は約 7ms 増えます
- 注意の行（本体より下の拡張、円運動と動きの拡張、カメラ制御の下のガラス化、立体物と切り抜きの形、関数ファイルのエラー）は、内容が変わったときだけログに 1 回出ます。状態の表示にも出ます
- **素材・色・フィルターの組み合わせごとに素材を読み直して効果を掛けます。** 組み合わせ（図形の種類 × 色の段 × フィルターの段）が多いほど重くなります。目安は 3,000 粒・軌跡 8・色 16 段・ぼかし 8 段で 1 フレーム約 33ms（FHD）です
- 素材の切り替えが 1 フレームに 64 回を超えると、読み直しを減らすため同じ見た目の粒子をまとめて描きます。このとき粒子の前後の重なりが描く順（新しい粒子が手前）どおりにならないことがあります
- **動画の素材は、最初の読み込みだけ重い**です。動画の段数 16（初期値）で、最初のフレームが 0.5〜0.7 秒、続くフレームは約 8ms でした（FHD）。最初が気になるなら、動画の段数を下げるか、「全部の粒子をそろえる」をオン（再生位置をランダムはオフ）にすると、読む絵が 1 枚で済みます
- フィルターに使えるのは標準の効果だけです。第三者のスクリプトの効果は掛かりません
- **他レイヤーの形（出力位置・跳ね返り・格子のマスク）は、そのオブジェクトの画像を毎フレーム読みます。** 3,000 粒を形から出して形で跳ね返らせると、1 フレーム約 31ms（FHD）です
- **立体物は粒子が多いと重くなります。** 球（分割数 8）300 粒で 1 フレーム約 12ms（FHD）です
- ガラス化はカメラ制御の下では効きません（粒子をそのまま描きます）
- 関数ファイル（出力位置・挙動・カスタム描画）にエラーがあると、ログに `[拡張パーティクル_H] 自作関数:` の行が 1 回出ます。止まりはしません。ファイルを書き換えたら、プレビューを動かすと読み直します
- **補間のカーブエディタ2 は、CurveEditor2（`Script/CurveEditor2/@カーブエディタ2.tra2` と Live スロット）を入れているときだけ使えます。** 読めないときは直線になり、ログに `[拡張パーティクル_H] 自作関数: ce2:` の行が 1 回出ます
- **「文字の並び」はテキストオブジェクトより 1 文字あたり約 1.2px 詰まります**（MS UI Gothic・大きさ 60 で 8 文字の幅が 385 と 395。テキストオブジェクトの字送りが、スクリプトで読み込む文字の幅より少し広いため）。重ねたいときは素材の文字の間隔を 1.2 くらいにすると重なります（フォントと大きさで変わります）
- 形へ集まるの「時間の基準 = オブジェクト」は、オブジェクトの終わりで時刻が止まります（時間の付け替えの進行時間で時刻を進めても、オブジェクトの長さより先には行きません）
- 自分の画像を並べると、画像を毎フレーム読みます（`obj.getpixeldata`）。間隔 20 で FHD の画像を並べると、Lua の計算だけで 1 フレーム約 10ms です
- **止まったら残すは、風・ノイズ場・跳ね返りなどで計算するとき（積分）だけ効きます。** 寿命の後に残った粒子は、寿命の終わりの拡大率・透過率で描きます（終透過率を 100 にすると見えません）
- 子粒子・止まったら残すは、寿命を過ぎた粒子も計算するので重くなります。止まったら残す 1,000 粒と 3,000 粒で、Lua の計算が 1 フレーム約 12ms です
- **三角形で塗るは、毎フレーム三角形を作り直します。** 1,000 粒で Lua の計算が約 5ms です。頂点に使う粒子は新しいものから 2,000 個まで
- 破片は形を一度作ると取っておきます（シード・画像の大きさ・破片の数・不ぞろいが変わったときだけ作り直します）
- 影は粒子を 2 回描くので、描く重さが約 2 倍になります
- 活動時間などオブジェクトの時刻で決まるものは、オブジェクトの長さより先には進みません。破片のように全部が 0 秒に生まれるなら、時間の付け替えの「相対時間」で数えるとオブジェクトの長さに依りません
- **画面に貼り付けるは、平面描写と一緒には効きません**（ログに注意が出ます）。カメラ制御の外では何もしません
- 画面に貼り付けるでは、粒子の Z は画面からの奥行きです（0 で拡大率 100 %）。カメラの傾き・視野角を変えても同じ見た目になります
- **カメラ制御の下で、同じ奥行きに描いたものは色が混ざります**（受け取って描くの絵と本体の粒子を同じ位置に描くと、半分ずつ混ざって見える）。重ねるときは片方を「渡すだけ」にします
- 渡す名前が別のオブジェクトと重なると、後から計算した方が使われます（ログに注意が出ます）。名前はシーンごとに別です
- **粒子どうしの目安は 3,000 粒**です。広い範囲から出すとき、続けて描くフレームは計算が 13〜16ms（粒子どうしなしは約 10ms）。
  最初のフレームは、シミュレーションの始まりからの秒数に比例して重くなります（6 秒分で約 1 秒）。1 点から大量に出して粒子の大きさを付けると、粒子が押し合い続けるので約 40ms かかります
- 3,000 個を超えた粒子は、粒子どうしの力を受けません（ログに注意が出ます）
- 光源は 3,000 粒で計算が約 1ms 増えます。重くなるのは素材の読み直し（段数）の方です
- 光源はガラス化には効きません（ログに注意が出ます）
- 設定項目を増やした版に入れ替えたときは、AviUtl2 の再起動が要ります
