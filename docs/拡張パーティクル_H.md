# 拡張パーティクル_H

付けたオブジェクトの画像を**粒子として放出する**アニメーション効果です。
rikkyさんがAviUtl1向けに作った「拡張パーティクル(R)」を、AviUtl2へ移して作り直したものです。
「本体」の上に 32 種類の拡張を積んで、動きと見た目を組み合わせます。
「受け取って描く」と出力位置「渡された粒子」で、粒子を別のオブジェクトへ渡して描いたり、そこから粒子を出したりもできます。
すぐに使える組み合わせを、エイリアスのプリセットとして 22 本付けています。

ファイルは `Script/@拡張パーティクル_H.anm2` と `Script/Particle_H.lua` の 2 つで、バージョンは v0.19.1 です。

## インストール

1. [HexScriptのReleases](https://github.com/HexBrowns/HexScript/releases) のzipを展開し、`Script\@拡張パーティクル_H.anm2` と `Script\Particle_H.lua` の 2 つを、AviUtl2の `Script` フォルダへコピーする。
2. 色の変化・軌跡の色空間や色差を初期値から変えるときは、`Script\EffectUtils_ColorSpace.lua` も `Script` フォルダの直下へコピーする。
3. プリセットが必要であれば、zipの `Alias\拡張パーティクル_H\` のフォルダも、AviUtl2の `Alias` フォルダへコピーする。
4. AviUtl2を起動する。
5. 画像・図形・テキストなどのオブジェクトに、HexScriptの中の「本体@拡張パーティクル_H」を追加する。

## 使い方

1. 粒子にしたいオブジェクトを置く。
2. 「本体@拡張パーティクル_H」を追加する。これだけで、オブジェクトの中心から粒子が出る。
3. 必要な拡張を追加し、**本体より上**へ動かす。本体は、自分より上にある有効な拡張だけを使う。

```text
オブジェクト（図形・画像・テキスト…）
  出力位置@拡張パーティクル_H        ← 拡張は本体より上
  回転@拡張パーティクル_H
  本体@拡張パーティクル_H            ← 粒子を描く
  （平面描写のときだけ、ここに置いた標準の効果が粒子全体に掛かる）
```

本体より下に置いた拡張は使われません。このときはログに `注意: 本体より下の「…」は使われない` の行が出ます。

「編集中だけ」は、AviUtl2の編集画面で見ているときだけ描き、動画の出力には出しません。

### 向きと単位

- **出力方向は 0 が下**、90 が右、180 が上、-90 が左です
- **出力頻度は 1 秒あたりの個数**です。0 なら何も出ません。ただし、時間の付け替えの「一斉に出す」の分は出ます
- **出力速度の単位は px/秒**、加速度・重力は px/秒²です
- **透過率は 0 が不透明**、100 が透明です。原作とは逆で、標準の「パーティクル出力」と同じ向きです
- 時間はすべて**秒**です

### トラックバーを動かす

トラックバーには移動方法を付けられます。
「放出時の値を使う」がオンなら、**粒子は生まれた時刻の値で飛び**、その後に値が変わっても影響を受けません。
たとえば出力方向を 0→180 に動かすと、粒子が扇形に広がります。オフにすると、すべての粒子が今の値で動きます。

出力頻度を動かすと、その時刻ごとの頻度で数が増減します。
途中で頻度を上げ下げしても、粒子が飛んだり消えたりしません。

## プリセット

`Alias/拡張パーティクル_H/` に、図形の素材と拡張を組み合わせた長さ 10 秒のオブジェクトを 22 本置いています。
エイリアスの一覧から置くか、ファイルをタイムラインへドラッグ＆ドロップします。置いた後は普通のオブジェクトと同じで、値を自由に変えられます。

## 使い方の例

拡張を組み合わせて作れるもの。専用の項目は足していません。

- **縁取りの付いた粒子**: フィルター@拡張パーティクル_Hの効果名を「縁取り」、変化させる項目を「サイズ」にし、始の値と終の値を同じ値にする。
  縁の色は 固定の項目 に `縁色=0xffffff` のように書く
- **光の筋でつなぐ**: メッシュの結び方を「近い粒子」にし、本体の合成モードを「加算」にする。光らせるなら本体の平面描写をオンにして、本体より下に標準の「発光」を置く。
  プリセットの「ネットワーク」が元になる
- **巻き戻し・停止の区間**: 時間の付け替えの「進行時間を使う」をオンにし、進行時間のトラックバーを動かす。値が下がる区間は巻き戻し、同じ値の区間は止まる
- **スローモーションの区間**: 同じく進行時間に、カーブエディタ_Hの移動方法を付ける。カーブの傾きが緩い所が遅く進む
- **画像を砕いて戻す**: 画像のオブジェクトに、出力位置「自分の画像を並べる」、素材「切り抜き」、形へ集まるを付ける。切り抜く所と行き先は、どちらも「出た所」にする。
  本体の出力速度で散らし、形へ集まるの集まり始める時刻で戻す。プリセット「画像が飛び散って戻る」が元になる。戻った絵は元の画像と同じになります
- **文字が組み上がる**: 素材をテキストにして、形へ集まるの行き先を「文字の並び」にする。ずらす幅とずらす順で、1 文字ずつ順に着かせる。プリセット「文字が集まる」が元になる
- **ずっと繰り返す背景**: 時間の付け替えの「ループ」をオンにし、周期をオブジェクトの長さの約数にする
- **絵を割る**: 出力位置「自分の画像を並べる」の並べ方を「破片」にし、素材を「切り抜き」、切り抜く所を「出た所」にする。プリセット「ガラスが割れる」が元になる。
  割れる時刻は時間の付け替えの活動時間で決める
- **写真をローポリにする**: 写真を別のレイヤーに置いて透明度 100 で見えなくし、粒子を写真の範囲に散らす。メッシュの結び方を「三角形で塗る」、面の色を「他レイヤーの画像の色」にする。
  粒子は本体の透過率を 100 にして見えなくしてよい。そのときはメッシュの「粒子の透過率を掛ける」をオフにする
- **雪を画面の手前に固定する**: カメラ制御の下の雪に、本体の「画面に貼り付ける」。カメラが動いても雪は画面に対して同じ所を降る
- **粒子を他のオブジェクトの間に挟む・粒子だけに効果を掛ける**: 本体に渡す名前を付けて「渡すだけ」をオン。別のレイヤーの図形に「受け取って描く」を付け、その図形に効果を掛ける
- **曲に合わせて出す**: 音で「拍で出す」を選ぶ。曲のファイルがあれば「音声ファイルの拍」を使う。キックだけで出すなら、拍を見る音を「低い音」にする。
  ファイルが無ければ、編集画面のBPMのグリッドを曲に合わせて「BPMのグリッド」を使う
- **粒を器に溜める・ぶつかって重ならない**: 粒子どうしの「粒子の大きさ」を粒の大きさにし、跳ね返りで左右の壁と床の器を作る。プリセット「器に溜まる粒」が元になる
- **群れで動かす**: 粒子どうしの「向きをそろえる」「群れの中心へ寄る」「離れる」と、最低・最高の速さを使う。素材の向きは本体の「進行方向を向く」にする。プリセット「魚の群れ」が元になる
- **立体に陰影を付ける**: 立体物に光源を足す。平らな粒子でも、回ると明るさが変わる
- **花火の各粒から火の粉を出す**: 花火の本体に渡す名前を付け、その下のレイヤーの別のオブジェクトで出力位置「渡された粒子」を使う。動きの速さを足すは 30 くらいにする
- **形の色のまま崩す**: 出力位置「他レイヤーの形」と、色の変化の「出た所の色」を使うと、絵の色の粒子が絵の形から出る
- **ロゴの形に集まる**: ロゴの画像を別のレイヤーに置く。透明度 100 で見えなくしてよい。形へ集まるの行き先を「他レイヤーの形」、行き先の選び方を「均等に」にする

**積分法と刻みの倍率**

風・ノイズ場・力場・跳ね返りなどで動かすときは、時間を短い刻みに分けて粒子を進めます。
1 刻みの長さは「1 フレーム ÷ 描写精度 × 刻みの倍率」です。

| 積分法 | 見た目 |
|---|---|
| 半陰的オイラー | v0.18.0 までと同じ動き |
| 陽的オイラー | 刻みが粗いと軌道が外へずれ、渦が広がる。跳ね返りでは出た所より高く跳ね上がる |
| RK4 | 刻みが粗くても軌道がずれにくく、渦や円を回る道がきれいに閉じる |

- 初期値（半陰的オイラー・刻みの倍率 1）なら、今までと同じ動きです。保存済みのプロジェクトはそのままの動きで開けます
- 違いがはっきり出るのは、刻みが粗いとき（刻みの倍率を上げたとき）と、力場の引力で円を回すとき・跳ね返りです。刻みの倍率 1 では違いは小さめです
- **RK4 は 1 刻みに力を 4 回求めるので、粒子が多いと重くなります。** 刻みの倍率を上げて刻みを粗くし、重さを抑えて使います（RK4 なら刻みの倍率 6 でも円が閉じます）
- 積分法・刻みの倍率・ノイズ場の元のノイズを初期値から変えると動きが変わるので、焼き付けは書き出し直しが要ります

**自分の画像を並べる**は、オブジェクトの画像をマスに分けて、マスの数だけ一斉に出します。
本体の出力頻度・同時発生数は使いません。
素材の切り抜きで「切り抜く所 = 出た所」にすると、粒子はそれぞれ自分のマスの絵になり、並べ直すと元の画像に戻ります。
画像は毎フレーム読みます。マスは 10,000 個までです。
破片も、並べ直すと元の画像に戻ります。破片の形はシードと画像の大きさで決まり、同じなら毎フレーム同じ形です。

**文字の並び**は、素材のテキストを、テキストオブジェクトのように並べた位置から 1 文字ずつ出します。
出力頻度は 1 秒に出す文字の数になります。並べ方は、素材の文字揃え・文字の間隔・行の間隔で決まります。
素材をテキストにしたときだけ使えます。

**渡された粒子**は、別のオブジェクトの本体が「渡す名前」で渡した粒子の、自分の粒子が生まれた時刻の位置から出します。
渡す側はフレームごとの粒子の位置を残していて、生まれたフレームの位置を引きます。
**渡す側を、受け取る側より上のレイヤーに置いてください**。下にあると 1 フレーム遅れます。
編集中に途中のフレームへ飛ぶと、まだ描いていないフレームの位置が無いので、近いフレームの位置から出ます。頭から再生・出力すると正しくなります。

他レイヤーの位置・Z軸回転・拡大率は、粒子が生まれた時刻の値を使います。
対象のオブジェクトは本体と同じフレームで始めてください。形は今のフレームの形を使います。

関数ファイルの例です。1 秒で半径 300 の円を描く位置から出します。
`t` はオブジェクトの時刻の秒数で、本体の開始時間の分はマイナスになります。

```lua
function xyz(t)
  return 300 * math.sin(2 * math.pi * t), 300 * math.cos(2 * math.pi * t), 0
end
```

番号は本体の「状態の表示」と「粒子の番号も表示」で見ます。
変え方の値を変えると、その粒子が別の乱数になります。

**出た所の色**は、出力位置が「他レイヤーの形」か「自分の画像を並べる」のときに使えます。粒子が出た所の画像の色で塗ります。
画像の色から段数の数だけ色を選び、各粒子をいちばん近い色で塗ります。
段数を上げるほど元の色に近づき、重くなります。
ほかの出力位置で選ぶと、ログに注意が出て色は付きません。

**色空間**は、色の段の中間の色を決めます。初期値の sRGB は v0.17.0 までと同じ色です。

| 色空間 | 向いている使い方 |
|---|---|
| sRGB | 今までと同じ混ぜ方 |
| リニア | 光の混ざり方に近い。明るい側が広がる |
| Oklab / Lab | 見た目の明るさが均等に変わる。補色の 2 色の中間がくすみにくい |
| HSV / HSL / HWB / LCh / Oklch | 色相を回して虹色にしたいとき。赤 → 青 を 短経路 にするとマゼンタを、長経路 にすると黄・緑・シアンを通る。Oklch・LCh は色相が回っても明るさがそろう |

例えば 赤 → シアン を段数 3 で変えると、中ほどの段は sRGB では灰色の `808080`、Oklab では色の残った `d2a993` になります。

**色差**は、出た所の色で画像から選んだ色のどれに寄せるかの比べ方です。選ぶ色そのものは今までどおりです。
初期値の RGB は v0.17.0 までと同じです。RGB では見た目に遠い色へ寄ることがあります。見た目の近さで寄せたいときは Oklab か CIEDE2000 にします。
YCbCr は明るさを見ずに色味だけで比べます。

### 立体物@拡張パーティクル_H

<!-- サンプル動画 -->

粒子を立体にします。素材の画像を各面に貼ります。

| 項目 | 範囲・選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 立体の形 | 六面体 / 球 / 錐体 / 双錐体 / 曲面 / 厚み / モデル | 六面体 | 錐体: 上が尖り底が円。双錐体: 上下が尖る。曲面: 画像を曲げる。厚み: 同じ絵を奥行きの向きに重ねる。モデル: 下の説明 |
| 大きさ | 0〜4000 | 素材の大きさ | px。六面体・球・錐体・双錐体のとき。0 は素材の大きさ |
| 分割数 | 3〜64 | 8 | 球・錐体の面の細かさ、曲面の細かさ、厚みの重ねる枚数 |
| 横の曲がり / 縦の曲がり | -100〜100 | 50 / 0 | 曲面のとき。100 で幅か高さを円周とする筒に巻き付く。負なら逆向きに曲がる |
| 奥行き | 0〜4000 px | 20 | 厚みのとき |
| モデルファイル | ファイル | なし | モデルのとき。MikuMikuDanceのpmd |
| モデルの拡大率 | 0〜10000 | 100 | モデルの 1 単位を 10px × この % にする。粒子の拡大率も掛かる |

六面体・球・錐体・双錐体・モデルは、裏を向いた面を描きません。

**モデル**は、pmdの静止した形を粒子ごとに置きます。素材の画像は使いません。

- テクスチャはモデルと同じフォルダから読みます。テクスチャの無い材質は拡散色で塗ります。読めないテクスチャは拡散色になり、ログに注意が出ます
- ボーン・表情・物理は使いません。スフィアマップ・トゥーン・輪郭も使いません
- pmxは読めません。六面体で描き、ログに注意が出ます
- 色の変化・フィルター・光源は、ほかの立体と同じように効きます。材質の間の重なりの前後は、材質の順に描くので正しくないことがあります
- 重い: 三角形 5,000 のモデル × 30 粒で、1 フレーム約 96ms。粒子の数を絞って使います

### 音@拡張パーティクル_H

<!-- サンプル動画 -->
<img src="samples/%E6%8B%A1%E5%BC%B5%E3%83%91%E3%83%BC%E3%83%86%E3%82%A3%E3%82%AF%E3%83%AB_H/%E9%9F%B3.webp" width="480" alt="音@拡張パーティクル_H のサンプル">

今の音の大きさで、今いる粒子の拡大率・透過率・広がりを変えます。
値は、音がいちばん大きいときの変化の % です。

| 項目 | 範囲・選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 音 | 編集中の音 / 音声ファイル | 編集中の音 | 編集中の音: タイムラインで鳴っている音 |
| 音声ファイル | ファイル | なし | 音声ファイルのとき。オブジェクトの時刻の位置を読む |
| 周波数帯 | 1〜10 | 1 | 音を低い方から 10 に分けた番号 |
| もう一つの周波数帯 | 0〜10 | なし | 選ぶと、2 つの帯の大きい方を使う |
| 感度 | 0〜10000 | 100 | 音の大きさに掛ける %。小さい音でも動かしたいときは上げる |
| 拡大率 | -1000〜1000 | 100 | 音がいちばん大きいとき、粒子の大きさをこの % だけ変える |
| 透過率 | -100〜100 | 0 | 音がいちばん大きいとき、透過率をこの % だけ上げる |
| 広がり | -1000〜1000 | 0 | 音がいちばん大きいとき、粒子が出た所からの距離をこの % だけ広げる |
| 拍で出す | 出さない / 音声ファイルの拍 / BPMのグリッド | 出さない | 拍の時刻に、拍ごとの数の粒子を一斉に出す |
| 拍ごとの数 | 1〜10000 | 30 | 1 つの拍で出す数 |
| 拍の感度 | 0〜100 | 50 | 音声ファイルの拍: 大きいほど小さな立ち上がりも拍として拾う |
| 拍を見る音 | 全体 / 低い音 / 高い音 | 全体 | 音声ファイルの拍: 低い音・高い音だけで拍を探す |
| グリッドの細かさ | 1〜16 | 1 | BPMのグリッド: 1 拍を分ける数。2 で 8 分、4 で 16 分 |
| 強い拍ほど多く | オン / オフ | オン | 音声ファイルの拍: 立ち上がりの大きさに比例して数を変える。一番強い拍で拍ごとの数になる。BPMのグリッド: 小節の頭 1 / 拍 0.7 / 拍の間 0.4 を掛ける |
| 音の大きさで出す数 | 0〜1000 | 変えない | 音声ファイルの音の大きさに合わせて、出力頻度に 1 ＋ この % × 音の大きさ を掛ける。300 なら一番大きい所で 4 倍。編集中の音では使えない |
| 音の大きさを見る音 | 全体 / 低い音 / 高い音 | 全体 | 音の大きさで出す数: 低い音・高い音だけの大きさを見る |

振幅 0.8 の 100Hz の音で、いちばん大きくなります。

**拍で出す**は、拡大率・透過率・広がりの変化とは別に、拍の時刻に粒子を出します。
本体の出力頻度の分と合わせて出ます。拍だけで出すなら出力頻度を 0 にします。
拍だけを使って大きさは変えないなら、拡大率を 0 にします。シークしても同じ絵になります。

- **音声ファイルの拍**: 音を「音声ファイル」にしてファイルを選びます。WAVのほか、**mp3・m4aなどWindowsが読める形式**も使えます。ファイルを読んで、音が急に大きくなった所を拍にします。
  ファイルの先頭がオブジェクトの始まりです。mp3・m4aは、エンコーダーが先頭に足した無音を取り除いてから読みます。ただし、先頭に情報フレームの無いmp3は 13ms ほど遅れることがあります。
  読み込むのはファイルか設定を変えたときだけです。長い曲ほどかかります
- **音の大きさで出す数**: 拍とは別に、音声ファイルの音の大きさで出る数を増やします。拍で出すと一緒に使えます。シークしても同じ絵になります
- **BPMのグリッド**: 編集画面のBPMのグリッドの拍を使います。テンポが途中で変わる区間にも合わせます。ファイルを読まないので、どの音声でも使えます

### カスタム描画@拡張パーティクル_H

<!-- サンプル動画 -->
<img src="samples/%E6%8B%A1%E5%BC%B5%E3%83%91%E3%83%BC%E3%83%86%E3%82%A3%E3%82%AF%E3%83%AB_H/%E3%82%AB%E3%82%B9%E3%82%BF%E3%83%A0%E6%8F%8F%E7%94%BB.webp" width="480" alt="カスタム描画@拡張パーティクル_H のサンプル">

関数ファイルの `particle_obj` で描いた絵を、素材の代わりに使います。

| 項目 | 範囲・選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 関数ファイル | ファイル | なし | `particle_obj` を書いた UTF-8 の .lua |
| 種類の数 | 1〜64 | 4 | 絵の種類。粒子ごとにでたらめに選ぶ |
| 時間の段数 | 1〜64 | 8 | 寿命に沿って絵を変える段の数。種類の数 × 時間の段数は 64 まで |
| 値1 / 値2 / 値3 | -9999〜9999 | 0 | 関数へ渡す値 |
| 設定値 | 配列 | なし | 関数へ渡す値。8 つまで |
| 色1 / 色2 / 図形1 / 図形2 / チェック1 / チェック2 | | 白 / 黒 / 円 / 四角形 / オフ / オフ | 関数へ渡す値 |

関数は次の形で書きます。種類 × 時間の段ごとに 1 回だけ呼ばれます。粒子ごとには呼ばれません。

```lua
function particle_obj(t, t0, life, pi, pj, seed, v1, v2, v3, s1, s2, s3, s4, s5, s6, s7, s8, col1, col2, fig1, fig2, chk1, chk2)
  -- t: 段の時刻（0〜生存時間）/ pi: 種類（0 から）/ seed: 種類ごとの乱数 / v1〜v3: 値1〜3 / s1〜s8: 設定値
  obj.setoption("drawtarget", "tempbuffer", 60, 60)
  obj.load("figure", "四角形", col1, 40)
  obj.draw()
  obj.load("tempbuffer")   -- 最後に仮想バッファを読み込んで終える
end
```

### 受け取って描く@拡張パーティクル_H

<!-- サンプル動画 -->
<img src="samples/%E6%8B%A1%E5%BC%B5%E3%83%91%E3%83%BC%E3%83%86%E3%82%A3%E3%82%AF%E3%83%AB_H/%E5%8F%97%E3%81%91%E5%8F%96%E3%81%A3%E3%81%A6%E6%8F%8F%E3%81%8F.webp" width="480" alt="受け取って描く@拡張パーティクル_H のサンプル">

本体の「渡す名前」で渡された粒子の位置に、**このオブジェクトの画像**を描きます。本体とは別のオブジェクトに付けます。
粒子をそのレイヤーで描くので、他のオブジェクトの間に粒子を挟んだり、粒子だけにこのオブジェクトの効果を掛けたりできます。

| 項目 | 範囲・選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 受け取る名前 | 文字列 | なし | 本体の「渡す名前」と同じ名前 |
| 拡大率 | 0〜5000 | 100 | 粒子の拡大率に掛ける % |
| 粒子の透過率を使う | オン / オフ | オン | オフなら不透明で描く |
| 粒子の回転を使う | オン / オフ | オン | オフなら回さずに描く |
| 診断ログ | オン / オフ | オフ | 受け取った粒子の数と、何フレーム前の粒子かをログへ出す |

- **渡す側の本体を、受け取る側より上のレイヤーに置きます。** AviUtl2は上のレイヤーから順に計算するので、下に置くと 1 フレーム前の粒子になります。描きますが、ログに注意が出ます
- 位置は、渡した側の本体の位置を含めた画面の座標です。受け取る側のオブジェクトの位置は関係しません
- 自分の画像はそのままでは描かず、粒子の位置にだけ描きます

粒子の面の向きと光から明るさを決め、粒子を暗く描きます。
立体物では、面ごとに明るさが変わります。

| 項目 | 範囲・選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 光の種類 | 平行光 / 点光源 | 平行光 | 平行光: どこでも同じ向きの光。点光源: 光の位置から広がる光 |
| 光の向きX / Y / Z | -10〜10 | 0.5 / 1 / 1 | 平行光: 光が進む向き |
| 光の位置 | アンカー | -400, -400, -300 | 点光源: 光の位置 |
| 環境光 | 0〜100 % | 30 | 光が当たらない面の明るさ |
| 光の強さ | 0〜200 % | 100 | 光に正面から向いた面に足す明るさ |
| ハイライト | 0〜100 | 0 | 光に正面から向いた所を、光の色へ明るくする強さ |
| 段数 | 2〜32 | 8 | 明るさを分ける段の数。多いほど滑らかで重い |
| 裏も照らす | オン / オフ | オン | 平らな粒子の裏を向いた面も、裏から当たる光で照らす。**六面体・球・錐体・双錐体の閉じた立体では使わない** |
| 光の色 | 色 | 白 | ハイライトの色 |

明るさ = 環境光 + 光の強さ × 面が光の方を向いている度合い で、1 を超えた分は使いません。
明るさを段数の段に分け、段ごとに標準の「単色化」を掛けた素材で描きます。
段数 × 素材の種類 × 色の段 の数だけ素材を読み直すので、段数を上げると重くなります。影と円環には掛かりません。

### 粒子どうし@拡張パーティクル_H

<!-- サンプル動画 -->

粒子同士を押し合わせ・引き合わせ、群れにします。
一緒に進める数までの粒子を、同じ時刻の刻みで一緒に進めます。

| 項目 | 範囲・選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 届く距離 | 1〜2000 px | 40 | 粒子同士の力が届く距離。群れの仲間を探す距離でもある |
| 反発 | 0〜100000 | 500 | 届く距離の中で、近いほど強く押し合う |
| 粒子の大きさ | 0〜2000 px | 重なってよい | 粒子同士がこれより近づかない。位置を押し戻して、近づく速さを消す。器に入れると段になって溜まる |
| 引き合い | -100000〜100000 | 0 | 届く距離の中で寄る。負なら離れる |
| 粒子どうしの摩擦 | 0〜100 % | 0 | 触れている粒子同士がずれる速さを弱め、押し合う量 × 摩擦 までのずれを止める。粒子の大きさと一緒に使うと、1 点から落とした粒子が山に積もる |
| 離れる | 0〜100 | 0 | 群れ: 近い仲間から離れる強さ |
| 向きをそろえる | 0〜100 | 0 | 群れ: 仲間の平均の速さへ寄せる強さ |
| 群れの中心へ寄る | 0〜100 | 0 | 群れ: 仲間の中心へ寄る強さ |
| 見える角度 | 0〜180 度 | 135 | 群れ: 進む向きから ± この角度の中の粒子だけを仲間にする。180 で全方位 |
| 最低の速さ / 最高の速さ | 0〜10000 px/秒 | 0 / 制限しない | 速さをこの範囲に収める |
| 奥行きも使う | オン / オフ | オフ | オフならXYの距離だけで考える |
| 当たる相手（受け取る名前） | 文字列 | なし | 別のオブジェクトの本体が「渡す名前」で渡した粒子に当たって押される。相手は押し返さない |
| 相手の大きさ | 0〜2000 px | 20 | 当たる相手の粒子と、中心同士がこれより近づかない |
| 相手から押される強さ | 0〜100000 | 500 | 相手の大きさの 1.5 倍の中で、近いほど強く押される |
| 一緒に進める数 | 100〜10000 | 3000 | これを超えた粒子は力を受けず、今までどおり粒子ごとに進む。ログに注意が出る。10,000 粒で 1 フレーム約 120ms |

- 風・力場・跳ね返り・止まったら残すなどの拡張と一緒に効きます。円運動・パスとは一緒に使えません。ログに注意が出ます
- **どのフレームから描いても同じ絵になります**。そのため、最初のフレームと後ろへ飛んだときは、
  シミュレーションの始まりから計算し直すので重くなります
- **当たる相手は、相手のオブジェクトを上のレイヤーに置きます**。下にあると 1 フレーム遅れます。
  相手の位置は「渡す」の履歴から、刻みの時刻をはさむ 2 つのフレームの同じ粒子の位置を直線で補って使います。
  描くフレームの端数の刻みは相手を見ないので、速い粒子は数 px はみ出すことがあります。
  途中のフレームへ飛ぶと、相手の履歴が無い所は近いフレームの相手で計算します。頭から再生・出力すると正しくなります
- 集結点は、毎刻み粒子の速さを中心へ向け直すので、粒子の大きさより強く押し込みます。重なることがあります。寄せるなら引き合いを使います
- 平らな床に落とすと、粒子どうしの摩擦 0 では低く広がります。粒子どうしの摩擦を上げると山に積もります。器に溜めるなら、跳ね返りで左右の壁を作ります

### 焼き付け@拡張パーティクル_H

<!-- サンプル動画 -->
<img src="samples/%E6%8B%A1%E5%BC%B5%E3%83%91%E3%83%BC%E3%83%86%E3%82%A3%E3%82%AF%E3%83%AB_H/%E7%84%BC%E3%81%8D%E4%BB%98%E3%81%91.webp" width="480" alt="焼き付け@拡張パーティクル_H のサンプル">

計算した粒子をフレームごとにファイルへ書き、後で読み込んで計算を飛ばします。重い粒子どうし・群れを一度だけ計算して、後は軽く見るのに使います。

| 項目 | 範囲・選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 焼き付け | 使わない / 書き出す / 読み込む | 使わない | 書き出す: 描いたフレームを書く。読み込む: 書いたフレームを計算せずに描く |
| 置くフォルダ | フォルダ | なし | ファイルを置くフォルダ。日本語のフォルダも使える |
| 名前 | 文字列 | particles | ファイルの名前。拡張子 .prh は付けない |
| 無いフレームは計算する | オン / オフ | オン | 読み込むとき、記録の無いフレームを計算する。オフなら描かない |
| CSV も書く | オン / オフ | オフ | 書き出すとき、置くフォルダの 名前_csvに、フレームごとのCSVも書く。00012.csv が 12 フレーム目。1 行 1 粒で `k,x,y,z,rx,ry,rz,zoom,alpha,age,life` の順に、番号・本体から見た座標 px・回転の度・拡大率 %・不透明度 0〜1・年齢と寿命の秒。Blenderなどで読むときはフォルダごと読む |

使い方:

1. 焼き付けを「書き出す」にして、AviUtl2で動画を出力する。プレビューで描いたフレームも書かれる。
2. 「読み込む」に切り替える。以後は計算せずに描く。

- **本体・拡張の動きの設定を変えると、その焼き付けは使いません**。ログに注意が出るので、もう一度書き出してください。本体の位置を変えるのは構いません
- **見た目だけの変更なら、焼き付けを使い続けます**: 本体の始・終拡大率と透過率、拡大率と透過率・見た目の調整・色の変化・フィルター・素材など。位置と回転は焼き付けのまま、拡大率・透過率は今の設定で計算し直します。
  ただし、形へ集まるの「回転と大きさをそろえる」を使っているときは、拡大率・透過率を変えても書き出し直しが必要です
- **v0.18.0 で書き出した焼き付けは、v0.19.0 でもそのまま読み込めます**（積分法・刻みの倍率・元のノイズが初期値のとき）
- ファイルの大きさは、3,000 粒で 1 フレーム約 175KB、30fps の 1 分で約 315MB です
- 書き出すと、計算に加えて書く分だけ重くなります
- 書いたファイルを、同じフレームで下のレイヤーの別のオブジェクトが読み込むこともできます。設定と置くフォルダ・名前を同じにします

## 注意事項・制限

- **拡張は本体より上に置く。** 下に置いた拡張は使われません
- **平面描写でないとき、本体より下の効果は掛かりません**。粒子全体に効果を掛けたいときは平面描写をオンにします
- **平面描写でも、下に置いたスクリプトの効果は掛からないことがあります。** 標準の効果は掛かります。掛からないときは、別のレイヤーのフィルタオブジェクトで掛けてください
- 生きている粒子は **10,000 個まで**です。超える分は古い粒子から描かれず、診断ログの `overflow` に出ます。1 フレームの目安は、10,000 個で約 18ms
- 生きている粒子が多く、拡張で粒子ごとの透明度がばらつくと、描く順が少し崩れることがあります
- 拡張のトラックバーは、今のフレームの値をすべての粒子に使います。「放出時の値を使う」が効くのは本体のトラックバーだけです。
  風力とノイズ場の強さだけは、トラックバーを動かすとその時刻の値で計算します
- **風・ノイズ場・集結点・跳ね返り・分散と停止・挙動不審を使うときの目安は 3,000 粒**です。1 フレーム約 17ms です。
  10,000 粒では 1 フレーム 40ms 以上かかります。最初のフレームと、後ろへシークしたときは、粒子が生まれた時刻から計算し直すので重くなります
- 円運動を付けている間は、本体の出力速度・加速度・重力と、風・力場などの動きの拡張は効きません。ログに `注意: 円運動を付けているので…` の行が出ます
- **力場は風などと同じ重さ**です。力場 3 つ＋3,000 粒で、計算は約 7ms 増えます
- 注意の行は、内容が変わったときだけログに 1 回出ます。状態の表示にも出ます
- **素材・色・フィルターの組み合わせごとに素材を読み直して効果を掛けます。** 図形の種類 × 色の段 × フィルターの段 の組み合わせが多いほど重くなります。目安は 3,000 粒・軌跡 8・色 16 段・ぼかし 8 段で 1 フレーム約 33ms です
- 素材の切り替えが 1 フレームに 64 回を超えると、読み直しを減らすため同じ見た目の粒子をまとめて描きます。このとき粒子の前後の重なりが描く順どおりにならないことがあります
- **動画の素材は、最初の読み込みだけ重い**です。動画の段数 16 で、最初のフレームが 0.5〜0.7 秒、続くフレームは約 8ms でした。
  最初が気になるなら、動画の段数を下げるか、「全部の粒子をそろえる」をオンにして再生位置をランダムをオフにします。読む絵が 1 枚で済みます
- フィルターに使えるのは標準の効果だけです。第三者のスクリプトの効果は掛かりません
- **他レイヤーの形を使う出力位置・跳ね返り・格子のマスクは、そのオブジェクトの画像を毎フレーム読みます。** 3,000 粒を形から出して形で跳ね返らせると、1 フレーム約 31ms です
- **立体物は粒子が多いと重くなります。** 分割数 8 の球 300 粒で 1 フレーム約 12ms です
- ガラス化はカメラ制御の下では効きません
- 出力位置・挙動・カスタム描画の関数ファイルにエラーがあると、ログに `[拡張パーティクル_H] 自作関数:` の行が 1 回出ます。止まりはしません。ファイルを書き換えたら、プレビューを動かすと読み直します
- **補間のカーブエディタ_Hは、CurveEditor_Hを入れているときだけ使えます。** `Script/CurveEditor_H/@カーブエディタ_H.tra2` とLiveスロットが必要です。
  読めないときは直線になり、ログに `[拡張パーティクル_H] 自作関数: ce2:` の行が 1 回出ます
- **「文字の並び」はテキストオブジェクトより 1 文字あたり約 1.2px 詰まります**。重ねたいときは素材の文字の間隔を 1.2 くらいにします。値はフォントと大きさで変わります
- 形へ集まるの「時間の基準 = オブジェクト」は、オブジェクトの終わりで時刻が止まります
- 自分の画像を並べると、画像を毎フレーム読みます。間隔 20 でFHDの画像を並べると、Luaの計算だけで 1 フレーム約 10ms です
- **止まったら残すは、風・ノイズ場・跳ね返りなどで計算するときだけ効きます。** 寿命の後に残った粒子は、寿命の終わりの拡大率・透過率で描きます。終透過率を 100 にすると見えません
- **終了時に消えるでは、生存時間（子粒子を出すなら、それに子の生存時間を足した時間）がオブジェクトの長さより長いと、粒子は 1 つも出ません。** 生存時間を短くするか、オブジェクトを長くします。v0.19.0 までは、終わり際の粒子の寿命を縮めていました（始と終の値が同じだと、終わりで一斉に消えました）
- 子粒子・止まったら残すは、寿命を過ぎた粒子も計算するので重くなります。止まったら残す 1,000 粒と 3,000 粒で、Luaの計算が 1 フレーム約 12ms です
- **三角形で塗るは、毎フレーム三角形を作り直します。** 1,000 粒でLuaの計算が約 5ms です。頂点に使う粒子は新しいものから 2,000 個まで
- 破片は形を一度作ると取っておきます
- 影は粒子を 2 回描くので、描く重さが約 2 倍になります
- 活動時間などオブジェクトの時刻で決まるものは、オブジェクトの長さより先には進みません。破片のように全部が 0 秒に生まれるなら、時間の付け替えの「相対時間」で数えるとオブジェクトの長さに依りません
- **画面に貼り付けるは、平面描写と一緒には効きません**。ログに注意が出ます。カメラ制御の外では何もしません
- 画面に貼り付けるでは、粒子のZは画面からの奥行きです。カメラの傾き・視野角を変えても同じ見た目になります
- **カメラ制御の下で、同じ奥行きに描いたものは色が混ざります**。重ねるときは片方を「渡すだけ」にします
- 渡す名前が別のオブジェクトと重なると、後から計算した方が使われます。ログに注意が出ます。名前はシーンごとに別です
- **粒子どうしの目安は 3,000 粒**です。広い範囲から出すとき、続けて描くフレームは計算が 13〜16ms です。
  最初のフレームは、シミュレーションの始まりからの秒数に比例して重くなります。1 点から大量に出して粒子の大きさを付けると、粒子が押し合い続けるので約 40ms かかります
- 3,000 個を超えた粒子は、粒子同士の力を受けません。ログに注意が出ます
- 光源は 3,000 粒で計算が約 1ms 増えます。重くなるのは素材の読み直しの方です
- 光源はガラス化には効きません。ログに注意が出ます
- **色差の CIEDE2000 は、出た所の画像が毎フレーム変わる動画などでは重くなります。** 止まった画像なら重いのは最初のフレームだけです
- 色空間・色差を初期値から変えたときは `EffectUtils_ColorSpace.lua` を読みます。`Script` フォルダの直下に無いと、スクリプトのエラーになります
- 設定項目を増やした版に入れ替えたときは、AviUtl2の再起動が必要です。v0.18.0 では色の変化と軌跡に色空間・色相経路・色差を、v0.19.0 ではノイズ場に元のノイズを、本体に積分法と刻みの倍率を足しました

## 原作から作らなかったもの

- 「時間」「時間2」: トラックバーの移動と「放出時の値を使う」、拡大率と透過率の補間で代わります
- ガラス化の倍率と頂点の位置、カスタム描画の使用引数と使い方表示。pmdは直接読めるので、原作の .dat への変換は不要です
- 他レイヤーの形の「出る所の色を粒子の色にする」: 色の変化の「出た所の色」で代わります
