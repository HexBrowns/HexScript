# 手持ちカメラ_H

カメラ制御に掛けて、手持ち撮影のような揺れを加えるカメラ効果です。細かい手ぶれ、ゆっくりした重心の流れ、呼吸の上下を
混ぜて作ります。揺れは時間方向になめらかで、同じ設定なら何度再生しても同じ揺れになります。

- `Script/手持ちカメラ_H.cam2`（v1.03）

## インストール

1. `Script\手持ちカメラ_H.cam2` を配置する
2. AviUtl2 を再起動する（設定項目の変更は「キャッシュを破棄」では反映されません）
3. カメラ制御に「手持ちカメラ_H」を追加する（HexScript の中）

## 使い方

1. カメラ制御を置き、揺らしたいオブジェクトを配下に入れる
2. カメラ制御に「手持ちカメラ_H」を追加する。初期値のままで、軽い手持ちの揺れになる
3. **振れ幅** で揺れの大きさ、**速さ** で揺れの速さを決める
4. 傾きの揺れが要らなければ **傾きの振れ幅** を 0 にする。寄り引きの揺れが欲しければ **寄り引きの振れ幅** を上げる
5. 別のカットで別の揺れにしたいときは **シード** を変える

揺れはカメラの右・上の向きに掛かるので、カメラを回していても画面に対して縦横に揺れます。
カメラの位置と目標を同じだけ動かすので、見ている向きは変わらず、画面全体が揺れます。

他のカメラ効果（カメラ効果_H など）と一緒に使うときは、手持ちカメラ_H をいちばん下に置くと、上で決めたカメラに揺れが乗ります。

### 例: 揺れを止めてから入れる

**振れ幅**・**傾きの振れ幅**・**寄り引きの振れ幅** の 3 つが 0 なら、カメラはまったく動きません。
3 つを 0 から上げていけば、静止した画面から手持ちへ移れます。

### 例: ゆっくり漂うカメラ

**ドリフト** を 100 近くにすると細かい手ぶれが消え、ゆっくりした流れだけになります。
**呼吸** を上げると、4 秒周期の規則的な上下が乗ります。

## パラメータ

### 強さ

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 振れ幅 | 0 ~ 100 | 20 | 位置の揺れの大きさ。手ぶれと重心の流れはこの量までで、既定のカメラなら Z=0 の物がおよそこの px まで上下左右に動く（呼吸の分は別に足される） |
| 傾きの振れ幅 | 0 ~ 100 | 15 | 傾き（視線のまわりの回転）の揺れ。100 で最大 ±10 度 |
| 寄り引きの振れ幅 | 0 ~ 100 | 0 | 寄り引き（スクリーンまでの距離）の揺れ。100 で最大 ±10% |

### 速さの設定

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 速さ | 0 ~ 100 | 30 | 揺れの速さ。100 で基本の揺れが 1 秒におよそ 4 回 |
| 細かさ | 1 ~ 8 | 3 | 重ねる揺れの段数。1 段増えるごとに、2 倍速く半分の大きさの揺れが足される。大きいほどガタガタした質感になる。小数も効く |

### 性格

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| ドリフト | 0 ~ 100 | 50 | 細かい手ぶれと、ゆっくりした重心の流れの配分。0 で手ぶれだけ、100 で流れだけ。足し合わせではなく配分なので、上げても揺れの大きさの上限は増えない |
| 呼吸 | 0 ~ 100 | 30 | 4 秒周期の上下の揺れを足す量。100 で振れ幅の 0.6 倍 |

### その他

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| シード | -10000 ~ 10000 | 0 | 揺れ方を選ぶ番号。同じ値なら常に同じ揺れ、違う値なら別の揺れ |
| 前後を固定 | ON / OFF | ON | ON は上下左右だけ揺らす。OFF は視線の向き（前後）にも振れ幅と同じだけ揺らす |

- **シードの正負に意味はありません。** `obj.rand` のような「マイナスなら全オブジェクト共通」の決まりは無く、どの値も「別の揺れの番号」です。
  -5000 と 5000 も別の揺れです
- 呼吸は速さに関係なく 4 秒周期です

## 注意

- **速さ 0 で手ぶれと重心移動が止まり、カメラは揺れの無い位置に戻ります**（v1.03）。速さ 0〜1 の間は、揺れの大きさが速さに比例して
  小さくなります（速さ 1 以上は v1.02 と同じ）。呼吸は別の項目なので、速さ 0 でも呼吸を 0 にしない限り上下に動き続けます。
  v1.02 までは速さ 0 でも揺れの途中の一瞬で止まり、カメラがずれた位置のままでした
- 揺れは、効果を掛けたオブジェクトの先頭からの時間で決まります。オブジェクトを途中で区切ると、区切り目から揺れ方が変わります（続きにはなりません）
- カメラが真上・真下を向いているときは、カメラの向きではなく画面の X・Y の向きに揺らします（破綻はしません）
- 振れ幅を大きくすると画面の端から外が見えます。背景を大きめに置くか、振れ幅を抑えます
