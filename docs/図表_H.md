# 図表_H

テキストを書くだけで、**表・関数のグラフ・ツリー図（階層図）** を描くカスタムオブジェクトです。1 つのファイルに 3 つ入っています。

- **表**: 区切り記号で書いた行と列を、見出し・縞・罫線のある表にする
- **関数グラフ**: `sin(x)` のような式から、軸と目盛りのある関数のグラフを描く
- **ツリー図**: 字下げで親子を書いたテキストから、組織図・系統図のような箱と線の図を描く

どれも 1 枚の画像として出すので、後ろにフィルタ効果（縁取り・影など）を掛けられます。
YMM4のプラグイン「表テーブル」「簡易関数グラフ」「ツリー・階層図プラグイン」に当たるものです。
説明だけを元に作り、コードは使っていません。

`Script/@図表_H.obj2`、v1.00。

## インストール

1. `Script\@図表_H.obj2` を配置する。
2. AviUtl2を起動する。
3. カスタムオブジェクトの、HexScriptの中にある「表」「関数グラフ」「ツリー図」を置く（一覧では `表@図表_H` などと出る）。

## 表

### 使い方

1. 「表」を置く
2. **データ** に、1 行 = 表の 1 行として、セルを区切り記号（初期値はカンマ）で区切って書く
3. 1 行目は見出しになる（**見出し行**。1 列目を見出しにするなら **見出し列**）

```
項目,値,備考
りんご,120,赤い
みかん,80,冬
```

- セルの中で改行するときは `<br>` と書く
- カンマ区切りのときは、セルを `"…"` で囲むとカンマを含められる（`"a,b"`）。囲みの中の `""` は `"` 1 つ
- 表計算ソフトからコピーした表は、区切りを **タブ** にすれば貼れる
- セルの中では本体のテキストの制御文字（`<#ff0000>` `<s40>` など）が使える

### パラメータ

| 項目 | 範囲・選択肢 | 初期値 | 説明 |
|---|---|---|---|
| データ | 複数行の文字列 | 3 行 3 列の例 | 上の書き方 |
| 区切り | カンマ / タブ / 縦棒 | カンマ | |
| 見出し行 / 見出し列 | オン・オフ | オン / オフ | 1 行目・1 列目を見出しにする（見出しの文字色・太字・背景が付く） |
| 幅 / 高さ | 0〜8000 | 0（自動） | 表全体の大きさ。0 なら文字に合わせる。指定すると列・行を伸び縮みさせる（文字は縮めない） |
| 列の幅 | 文字に合わせる / 均等 | 文字に合わせる | 均等: どの列も同じ幅 |
| 余白X / 余白Y | 0〜200 | 16 / 8 | セルの内側の左右・上下 |
| 列の揃え | 文字列 | 空（左） | 1 文字 1 列で `左` `中` `右`（`L` `C` `R` でもよい）。`左右中` なら 1 列目左・2 列目右・3 列目中央。書かない列は左 |
| フォント / サイズ | | Yu Gothic UI / 36 | |
| 文字色 / 見出しの文字色 | 色 | 白 / 白 | |
| 文字装飾 / 影・縁色 | 標準文字〜縁取り文字(角) | 標準文字 / 黒 | |
| 見出しを太字 | オン・オフ | オン | |
| 罫線 | 格子 / 横線のみ / 外枠のみ / なし | 格子 | なし のときは外枠も描かない |
| 罫線の太さ / 罫線の色 | 0〜50 / 色 | 2 / 808080 | |
| 外枠の太さ / 外枠の色 | 0〜50 / 色 | 2 / 808080 | 外枠は表の縁の内側に引く |

### 注意

- 幅を指定して列が文字より狭くなると、文字は隣のセルへはみ出します（切り取りません）
- セルの中に座標の制御文字 `<p>` を書くと、配置が崩れます

## 関数グラフ

### 使い方

1. 「関数グラフ」を置く
2. **式** に `y = f(x)` の右辺を書く（`y =` は省いてよい）。1 行 1 本で、3 本まで
3. 式の中の **a・b・c・d** はトラック（変数a〜変数d）、**t** はオブジェクトの時間（秒）。移動方法で動かせば形が変わる

```
sin(a*x + t)
y <= x^2 - 1
```

### 式の書き方

- 四則 `+ - * /`、べき乗 `^`、剰余 `%`、括弧
- 関数: `sin` `cos` `tan` `asin` `acos` `atan` `atan2` `sinh` `cosh` `tanh` `log`（自然対数）`log10` `exp` `sqrt` `abs` `floor` `ceil` `round` `sign` `pow` `min` `max`
- 定数: `pi`（`π` でもよい）`e` `tau`
- 掛け算の `*` は省ける: `2x`、`3(x+1)`、`(x+1)(x-1)`、`2πx`。文字どうし（`xy`）は 1 つの名前として読むので省けない
- 全角の数字・記号（`３` `（）` `×` `÷` `≦`）も読める
- **不等式**（`y < 式` `y <= 式` `y > 式` `y >= 式`）は範囲を塗る。左辺は `y` だけ
- 上に挙げた名前と記号のほかは書けない（安全のため）。書けないものがあればその式は描かず、ログに `[WARN]` を 1 回出す

### パラメータ

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 式 | 複数行の文字列 | `sin(a*x + t)` | 上の書き方 |
| 線の色1〜3 | 色 | 水色 / 橙 / 緑 | 1〜3 行目の式の色。塗りも同じ色 |
| 変数a〜d | −1000〜1000 | 1 / 0 / 0 / 0 | 式の a〜d |
| X最小 / X最大 / Y最小 / Y最大 | | −10 / 10 / −6 / 6 | 描く範囲 |
| 幅 / 高さ | 16〜8000 | 1200 / 720 | グラフの大きさ（画素） |
| 線の太さ | 0.5〜50 | 4 | |
| 塗りの不透明度 | 0〜100 | 30 | 不等式の塗り（%） |
| 軸 / 軸の太さ / 軸の色 | | オン / 2 / 白 | x = 0 と y = 0 の線 |
| 目盛り線 / 目盛りの間隔X・Y / 目盛り線の色 | | オン / 0（自動）/ 505050 | 自動の間隔は範囲の 1/8 に近い 1・2・5 × 10 の累乗 |
| 目盛りの数字 / フォント / 数字のサイズ / 数字の色 | | オン / Yu Gothic UI / 24 / cccccc | 軸の横に数字を出す |
| 背景色 | 色 | 透明 | |
| 描画の進み | 0〜100 | 100 | % 。X最小から X最大へ線が伸びる |

### 注意

- 細かく振れる式（`sin(100x)`）は、標本（幅の半分の数、式 1 本で最大 2048）より細かい形が失われます
- `tan(x)` のように値が範囲の上下へ飛ぶところは、線をつながずに切ります
- `%` は Lua の剰余（負の数でも結果は割る数と同じ符号）、`log` は自然対数です

## ツリー図

### 使い方

1. 「ツリー図」を置く
2. **項目** に、1 行 1 項目で、字下げで親子を書く

```
社長
  営業部
    第一営業課
    第二営業課
  開発部
    設計<br>チーム
```

- 前の行より深く字下げすれば子、同じなら兄弟、浅ければ戻る（字下げの幅はそろっていなくてよい）
- 字下げには半角空白・タブ（半角 4 つ分）・全角空白（半角 2 つ分）が使える
- 行頭の `- ` `* ` `・` は外して読む（箇条書きをそのまま貼れる）
- 根（字下げなしの行）は 2 つ以上あってもよい。項目の中の改行は `<br>`。制御文字も使える
- 項目は 500 個まで

### パラメータ

| 項目 | 範囲・選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 項目 | 複数行の文字列 | 上の例 | |
| 向き | 上から下 / 下から上 / 左から右 / 右から左 / 字下げ | 上から下 | 字下げ: エクスプローラーのように 1 行 1 項目で並べる |
| 兄弟の間隔 | 0〜2000 | 40 | 字下げでは出ない |
| 階層の間隔 | 0〜2000 | 80 | 字下げでは 1 段の字下げの幅 |
| 行の間隔 | 0〜500 | 12 | 字下げのときだけ |
| 箱 | すべて / 子を持つ項目だけ / 子の無い項目だけ / なし | すべて | なし: 文字だけ（線は文字の縁につなぐ） |
| 箱の幅 / 箱の高さ | 0〜4000 | 0（文字に合わせる） | |
| 余白 | 0〜200 | 14 | 箱の内側 |
| 箱の色 / 根の箱の色 | 色 | 2d5f8a / 8a2d4f | 根（字下げなしの項目）の箱だけ別の色にする。同じにしたいときは同じ色を選ぶ |
| 枠の太さ / 枠の色 | 0〜50 / 色 | 2 / 白 | 0 で枠なし |
| 線 | カギ線 / 直線 / 曲線 / なし | カギ線 | カギ線の横線は兄弟で共有する |
| 線の太さ / 線の色 | 0.5〜50 / 色 | 3 / c0c0c0 | |
| 矢印 / 矢印の大きさ | オン・オフ / 1〜200 | オフ / 16 | 子の側の端に三角 |
| フォント / サイズ / 文字色 / 文字装飾 / 影・縁色 | | Yu Gothic UI / 32 / 白 / 標準文字 / 黒 | |
| 文字揃え | 左 / 中央 | 中央 | 箱の中 |
| 出現 | なし / 階層ごと / 項目ごと | なし | 項目ごと = 書いた順 |
| 出現の進み / 重なり | 0〜100 / 0〜20 | 100 / 1 | 下の「出現」。線は親の側から伸びる |

### 注意

- 全体の外接矩形の中心が画像の中心になるので、項目を足すと図全体の位置がずれます
- 箱の幅を固定すると、長い項目は箱からはみ出します（折り返しません）

## 出現（表・ツリー図に共通）

**出現の進み** を移動方法で 0 → 100 に動かすと、単位（行・列・セル・階層・項目）が順に現れます。

- **重なり** は、1 つの単位が現れきるまでに進む単位の数です。1 なら前の単位が現れきった時に次が現れ始め、
  大きくすると同時にいくつも現れていく、0 なら段で切り替わります
- 表では、全体の背景と外枠は最初から見えています（出現の対象は各セルの背景・文字・罫線）
