# ShapeDistort_H

オブジェクトの画像をゆがませるアニメーション効果 4 種（回転 / 放射 / 方向 / ジグザグ）を 1 ファイルにまとめたものです。
渦巻き、花や星のような放射状の波打ち、一方向の波、縦横のジグザグが作れます。
ラップ OFF のときは、形の外へずれた部分も外枠で切れずに描かれ、内側へずれて空いた所は透明になります（v1.03）。

- `Script/@ShapeDistort_H.anm2`（回転・放射・方向 v1.03 / ジグザグ v1.04）

以前 Gemini に指示して書かせた `ShapeDistort.anm2` と `@ShapeDistort.anm2` の 2 本を 1 本にまとめて作り直したものです。
旧 2 本は退避済みで、一覧には出ません。**項目名は旧版と同じでも絵は一致しない**ので、旧版の設定を移すときは見た目を調整し直してください。

| セクション | 一覧での名前 | 内容 |
|---|---|---|
| 回転 | `回転@ShapeDistort_H` | 中心ほど強くねじる渦巻き。リッジ数を増やすと同心円状に向きが入れ替わる |
| 放射 | `放射@ShapeDistort_H` | 中心から放射状に、方向ごとに画像を押し出したり引き込んだりする（花・星形） |
| 方向 | `方向@ShapeDistort_H` | 縞状に、指定した向きへ画像をずらす波 |
| ジグザグ | `ジグザグ@ShapeDistort_H` | 横方向と縦方向の波を重ねたジグザグ |

## インストール

1. `Script\@ShapeDistort_H.anm2` を配置する（ファイル名先頭の `@` は外さない）
2. AviUtl2 を再起動する
3. オブジェクトのフィルタ効果に、上の 4 つのどれかを追加する（HexScript の中）

4 つともフィルタオブジェクトにも対応しています（画面全体をゆがませられます）。

## 使い方

1. ゆがませたいオブジェクト（画像・テキスト・図形など）に 4 つのどれかを追加する
2. **ねじれ角**（回転）または **量**（ほかの 3 つ）で強さを決める。マイナスにすると向きが逆になる
3. **リッジ数**（放射は **放射リッジ数**）で波の数を決める
4. 画像の端の扱いを **ラップ** で、元の画像を下に残すかを **背景を合成** で決める（下の「表示」）

時間で変化する仕組みは持っていません。動かしたいときは、ねじれ角・量・角度などのトラックバーを移動させます。

### 例: 中心を渦巻かせる

回転を初期値のまま（ねじれ角 90、半径 300）掛けると、オブジェクトの中心から半径 300 ピクセルの範囲が、
中心ほど強く（中心で 90 度）ねじれます。ねじれ角を 0 から動かすと、渦巻いていくアニメーションになります。

### 例: 透過のある素材をゆがませる

**背景を合成** を ON にすると、ゆがませる前の画像が下に残ります。テキストや切り抜いた画像では二重に見え、
図形や写真では元の輪郭がまっすぐ残ります。初期値は OFF（v1.03。v1.02 までは ON）で、ゆがんだ形だけが出ます。

## パラメータ

4 つのセクションに共通する項目は、名前も意味も同じです。

### 回転

| グループ | 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|---|
| 変形 | ねじれ角 | -720 ~ 720 | 90 | 中心でのねじれの角度（度）。半径の外側へ向かって 0 まで弱まる |
| 変形 | 半径 | 1 ~ 2000 | 300 | ねじれが届く範囲（ピクセル）。この外側はゆがまない |
| 変形 | リッジ数 | 0 ~ 50 | 0 | 0 は単純な渦巻き。1 以上にすると、中心から半径までの間にこの数の波が入り、ねじれの向きが同心円状に交互に入れ替わる |
| 変形 | 波形 | 正弦波 / 三角波 | 正弦波 | リッジの波の形。リッジ数が 1 以上のときだけ効く |
| 中心 | 中心X | -4000 ~ 4000 | 0 | 渦の中心を、オブジェクトの中央から横にずらす量（ピクセル）。プラスで右 |
| 中心 | 中心Y | -4000 ~ 4000 | 0 | 同じく縦にずらす量（ピクセル）。プラスで下 |
| ゆらぎ | ランダム割合 | 0 ~ 100 | 0 | リッジごとに強さをばらつかせる割合（%）。100 で各リッジが 0 ~ 2 倍の間でばらつく。リッジ数が 1 以上のときだけ効く |
| ゆらぎ | ランダムシード | 0 ~ 10000 | 0 | ばらつき方を変える番号 |
| 表示 | ラップ | ON / OFF | ON | 下の「表示」を参照 |
| 表示 | 背景を合成 | ON / OFF | OFF | 下の「表示」を参照 |

### 放射

| グループ | 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|---|
| 変形 | 量 | -200 ~ 200 | 20 | 押し出し・引き込みの強さ。中心から離れるほど大きくずれる |
| 変形 | 放射リッジ数 | 1 ~ 50 | 8 | 1 周の中に並ぶ波（花びら）の数 |
| 変形 | 波形 | 正弦波 / 三角波 | 正弦波 | 波の形 |
| 中心 | 中心X | -4000 ~ 4000 | 0 | 放射の中心を、オブジェクトの中央から横にずらす量（ピクセル）。プラスで右 |
| 中心 | 中心Y | -4000 ~ 4000 | 0 | 同じく縦にずらす量（ピクセル）。プラスで下 |
| 中心 | サイズの自動補正 | ON / OFF | ON | ON のとき、量の大きさに応じて、中心を基準に画像を縮めた状態からゆがませ、はみ出しを抑える（量 100 で約 0.83 倍、200 で約 0.71 倍） |
| ゆらぎ | ランダム割合 | 0 ~ 100 | 0 | 波ごとに強さをばらつかせる割合（%）。100 で各波が 0 ~ 2 倍の間でばらつく |
| ゆらぎ | ランダムシード | 0 ~ 10000 | 0 | ばらつき方を変える番号 |
| 表示 | ラップ | ON / OFF | ON | 下の「表示」を参照 |
| 表示 | 背景を合成 | ON / OFF | OFF | 下の「表示」を参照 |

### 方向

| グループ | 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|---|
| 変形 | 量 | -200 ~ 200 | 15 | ずらす強さ |
| 変形 | リッジ数 | 1 ~ 50 | 8 | オブジェクトの端から端までに入る波の数 |
| 変形 | 角度 | 0 ~ 360 | 0 | ずらす向き（度）。0 で左右、90 で上下。縞はこの向きと直角に並ぶ（0 なら横縞が左右にずれる） |
| 変形 | 波形 | 正弦波 / 三角波 | 正弦波 | 波の形 |
| ゆらぎ | ランダム割合 | 0 ~ 100 | 0 | 縞ごとに強さをばらつかせる割合（%）。100 で各縞が 0 ~ 2 倍の間でばらつく |
| ゆらぎ | ランダムシード | 0 ~ 10000 | 0 | ばらつき方を変える番号 |
| 表示 | ラップ | ON / OFF | ON | 下の「表示」を参照 |
| 表示 | 背景を合成 | ON / OFF | OFF | 下の「表示」を参照 |

方向には中心の項目がありません（波はオブジェクトの中央を基準にします）。

### ジグザグ

| グループ | 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|---|
| 変形 | 量 | -200 ~ 200 | 15 | ずらす強さ |
| 変形 | リッジ数 | 1 ~ 50 | 8 | オブジェクトの端から端までに入る波の数（縦・横とも同じ数） |
| 変形 | 波形 | 正弦波 / 三角波 | 正弦波 | 波の形 |
| 変形 | 重ねる順 | 横→縦 / 縦→横 | 横→縦 | 横のずれと縦のずれを重ねる順番。順番で絵が変わる（下の説明） |
| ゆらぎ | ランダム割合 | 0 ~ 100 | 0 | 縞ごとに強さをばらつかせる割合（%）。縦と横で別々にばらつく |
| ゆらぎ | ランダムシード | 0 ~ 10000 | 0 | ばらつき方を変える番号 |
| 表示 | ラップ | ON / OFF | ON | 下の「表示」を参照 |
| 表示 | 背景を合成 | ON / OFF | OFF | 下の「表示」を参照 |

横縞ごとに左右へ、縦縞ごとに上下へずらし、2 つを順に重ねます。1 つ目でずらした後の位置で 2 つ目のずれを決めるので、
量を大きくしても画像は裂けず、帯がつながったまま波打ちます（方向を角度 0 と 90 で 2 回掛けたのと同じ仕組み）。
**横→縦** は先に左右へずらしてから上下へ、**縦→横** は先に上下へずらしてから左右へずらします。

v1.03 までは 2 つのずれを同時に足していて、量を上げると（400 ピクセル四方・リッジ数 8 なら量 10 前後から）画像が折り返し、
四隅がちぎれた破片になっていました。v1.04 で直しました。

### 表示（4 つ共通）

| 項目 | ON | OFF |
|---|---|---|
| ラップ | オブジェクトの端からはみ出した部分が、反対側の端から出てくる（画像を敷き詰めたように続く）。オブジェクトの大きさは変わらない | 外へずれた部分はオブジェクトの外まで描かれ（オブジェクトが大きくなる）、内側へずれて空いた所は透明になる。縦と横に同時に歪む |
| 背景を合成 | ゆがんだ画像を、ゆがませる前の画像の上に重ねる | ゆがんだ画像だけを出す |

「ゆらぎ」と「表示」のグループは、初期状態で閉じています。

## 注意

- **ラップ OFF のとき、外へずれた部分はオブジェクトの外まで描かれます**（v1.02。v1.01 までは外枠で切れていました）。
  その分だけオブジェクトが上下・左右に同じだけ大きくなり、中心の位置は変わりません。ラップ ON では大きさは変わりません
- v1.02 は元の範囲の中だけ端の色で埋めていて、中身が内側へずれて空く所が埋まり、元の輪郭がまっすぐ残っていました（v1.03 で直しました）
- フィルタオブジェクトとして使うときは、大きさを変えられないので外へは描かれません。ラップ OFF では画面の外を読む所が画面の端の色で埋まります
- v1.02 までは、フィルタオブジェクトで画面の端を読む所と、ラップ ON の折り返しの継ぎ目が半透明になっていました（背景を合成 ON では隠れていました）。v1.03 で直しました
- 放射で量を大きくする（ランダム割合 0 で量 150 前後から）と、外へ伸びる分が大きくなりすぎるので、元の大きさの 4 倍の範囲までで打ち切ります。
  それより外へ伸びる部分は切れます。とても大きいオブジェクトでは、広げた後の大きさが 1500 万ドットを超えない所までで打ち切ります
- 横長・縦長のオブジェクトでも、ずれの大きさと回転の範囲はピクセルで測るので、横と縦で同じように効きます
  （回転の範囲は真円）。v1.00 は横長のオブジェクトで横の効き方が大きすぎました（1920 × 1080 で約 3.2 倍）。v1.01 で直しました
- 方向の縞の本数は、オブジェクトの幅・高さに対する割合で決まります。横長のオブジェクトで斜めの角度にすると、
  ずらす向きは角度どおりですが、縞の並びは角度と直角からずれます
- 旧 `ShapeDistort.anm2` / `@ShapeDistort.anm2` とは絵が一致しません（上記）
