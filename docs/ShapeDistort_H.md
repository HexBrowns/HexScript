# ShapeDistort_H

オブジェクトの画像をゆがませるアニメーション効果 6 種を 1 ファイルにまとめたものです。
渦巻き、花や星のような放射状の波打ち、一方向の波、縦横のジグザグ、終わりなく寄り続ける入れ子（無限ズーム）、ピンで曲げる変形（パペット）が作れます。
ラップOFFのときは、形の外へずれた部分も外枠で切れずに描かれ、内側へずれて空いた所は透明になります。

- `Script/@ShapeDistort_H.anm2`（v1.20。回転・放射・方向・ジグザグ・無限ズーム v1.10 / パペット v1.00）

v1.20 で、パペット以外の 5 つに **画像の読み方**（バイリニア / 最近傍 / バイキュービック）を足しました。
初期値のバイリニアは v1.10 までと同じ見た目で、保存済みのプロジェクトはそのまま開けます。

以前Geminiに指示して書かせた `ShapeDistort.anm2` と `@ShapeDistort.anm2` の 2 本を 1 本にまとめて作り直したものです。
**項目名は旧版と同じでも絵は一致しない**ので、旧版の設定を移すときは見た目を調整し直してください。

| セクション | 一覧での名前 | 内容 |
|---|---|---|
| 回転 | `回転@ShapeDistort_H` | 中心ほど強くねじる渦巻き。リッジ数を増やすと同心円状に向きが入れ替わる |
| 放射 | `放射@ShapeDistort_H` | 中心から放射状に、方向ごとに画像を押し出したり引き込んだりする |
| 方向 | `方向@ShapeDistort_H` | 縞状に、指定した向きへ画像をずらす波 |
| ジグザグ | `ジグザグ@ShapeDistort_H` | 横方向と縦方向の波を重ねたジグザグ |
| 無限ズーム | `無限ズーム@ShapeDistort_H` | 画像の中に縮小した自分自身を入れ子に重ね、終わりなく寄り続ける（引き続ける）ように見せる |
| パペット | `パペット@ShapeDistort_H` | 絵に打ったピン（最大 8 本）を動かすと、絵がピンに引かれて自然に曲がる |

## インストール

1. `Script\@ShapeDistort_H.anm2` を配置する。ファイル名の先頭の `@` は外さない。
2. **パペットを使うときは、`Script\Puppet_H\` のフォルダごと `Script` フォルダの中に置く**（中に `puppet.mod2` が入っています）。HexScript の zip に入っています。カタログから入れた場合も一緒に入ります。
3. AviUtl2を再起動する。
4. オブジェクトのフィルタ効果のHexScriptの中から、上の 6 つのどれかを追加する。

パペット以外の 5 つはフィルタオブジェクトにも対応しています。
`Puppet_H` のフォルダが無くても、ほかの 5 つは動きます。パペットだけが、ログに警告を 1 回出して何もしません。

以下の「使い方」「パラメータ」の回転〜ジグザグの説明は、4 つの変形のものです。無限ズームとパペットは、それぞれの節を見てください。

## 使い方

1. ゆがませたいオブジェクトに 4 つのどれかを追加する。
2. 回転は **ねじれ角**、他の 3 つは **量** で強さを決める。マイナスにすると向きが逆になる。
3. **リッジ数** で波の数を決める。放射では **放射リッジ数** を使う。
4. 画像の端の扱いを **ラップ** で、元の画像を下に残すかを **背景を合成** で決める（下の「表示」）。

時間で変化する仕組みは持っていません。
動かしたいときは、ねじれ角・量・角度などのトラックバーを移動させます。

### 例: 中心を渦巻かせる

回転を初期値のまま掛けると、オブジェクトの中心から半径 300 ピクセルの範囲が、中心ほど強くねじれます。
中心でのねじれは 90 度です。
ねじれ角を 0 から動かすと、渦巻いていくアニメーションになります。

### 例: 透過のある素材をゆがませる

**背景を合成** をONにすると、ゆがませる前の画像が下に残ります。
テキストや切り抜いた画像では二重に見え、図形や写真では元の輪郭がまっすぐ残ります。
初期値はOFFで、ゆがんだ形だけが出ます。

### ジグザグ

| グループ | 項目 | 範囲 / 選択肢 | 初期値 | 説明 |

| 変形 | 量 | -200 ~ 200 | 15 | ずらす強さ |
| 変形 | リッジ数 | 1 ~ 50 | 8 | オブジェクトの端から端までに入る波の数。縦・横とも同じ数 |
| 変形 | 波形 | 正弦波 / 三角波 | 正弦波 | 波の形 |
| 変形 | 重ねる順 | 横→縦 / 縦→横 | 横→縦 | 横のずれと縦のずれを重ねる順番。順番で絵が変わる（下の説明） |
| ゆらぎ | ランダム割合 | 0 ~ 100 % | 0 | 縞ごとに強さをばらつかせる割合。縦と横で別々にばらつく |
| ゆらぎ | ランダムシード | 0 ~ 10000 | 0 | ばらつき方を変える番号 |
| 表示 | ラップ | ON / OFF | ON | 下の「表示」を参照 |
| 表示 | 背景を合成 | ON / OFF | OFF | 下の「表示」を参照 |
| 表示 | 画像の読み方 | バイリニア / 最近傍 / バイキュービック | バイリニア | 下の「画像の読み方」を参照 |

横縞ごとに左右へ、縦縞ごとに上下へずらし、2 つを順に重ねます。
1 つ目でずらした後の位置で 2 つ目のずれを決めるので、量を大きくしても画像は裂けず、帯がつながったまま波打ちます。
**横→縦** は先に左右へずらしてから上下へ、**縦→横** は先に上下へずらしてから左右へずらします。

v1.03 までは 2 つのずれを同時に足していて、量を上げると画像が折り返し、四隅がちぎれた破片になっていました。
v1.04 で直しました。

### 表示（4 つ共通）

| 項目 | ON | OFF |
|---|---|---|
| ラップ | オブジェクトの端からはみ出した部分が、反対側の端から出てくる。オブジェクトの大きさは変わらない | 外へずれた部分はオブジェクトの外まで描かれ、オブジェクトが大きくなる。内側へずれて空いた所は透明になる。縦と横に同時に歪む |
| 背景を合成 | ゆがんだ画像を、ゆがませる前の画像の上に重ねる | ゆがんだ画像だけを出す |

「ゆらぎ」と「表示」のグループは、初期状態で閉じています。

### 画像の読み方（無限ズームと合わせて 5 つ共通）

ゆがませた先で、元の画像の色をどう読むかを選びます。

| 選択肢 | 見た目 |
|---|---|
| バイリニア | 周りの 4 画素を混ぜて読む。滑らかにつながる。v1.10 までと同じ |
| 最近傍 | いちばん近い 1 画素をそのまま読む。中間の色ができず、ゆがんだ所がドット絵のように角張る |
| バイキュービック | 周りの 16 画素から読む。強く引き伸ばした所でもぼけにくく、くっきりする。色の境目の手前が少し強調される |

違いがはっきり出るのは、ゆがみの強い所（ねじれ角や量を大きくしたとき、無限ズームで段が大きく映る所）と、ドット絵や細かい模様の素材です。
弱いゆがみでは 3 つともほとんど同じに見えます。
ラップや画面の端の扱いは、どれを選んでも変わりません。

## 無限ズーム

<!-- サンプル動画 -->
<img src="samples/ShapeDistort_H/%E7%84%A1%E9%99%90%E3%82%BA%E3%83%BC%E3%83%A0.webp" width="480" alt="無限ズーム@ShapeDistort_H のサンプル">

画像の中に、縮小（と回転）した自分自身を入れ子に重ねます。
**ズーム** を 1 進めるごとに 1 段内側へ入り、絵はズームの小数部だけで決まるので、どこまで動かしても継ぎ目なくループします。
写真や画面の中へ終わりなく寄り続ける（引き続ける）ループ素材を、1 つの効果で作ります（ドロステ効果）。

### 使い方

1. 画像・動画か、フィルタオブジェクトに「無限ズーム」を追加する。掛けた時点で、中央に半分の大きさの複製が入れ子に並ぶ。
2. **ズーム** を直線移動で 0 → 3 のように動かす。1 動くごとに 1 段入る。
3. 入れ子の大きさは **縮小率**、らせん状にしたいときは **回転**、寄っていく点は **中心X / 中心Y** で決める。

### パラメータ

| グループ | 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|---|
| 変形 | ズーム | -1000 ~ 1000 | 0 | 進み具合。1 で 1 段入る。直線移動で動かす |
| 変形 | 向き | 寄る / 引く | 寄る | 引くは、ズームを動かしたときに外へ引いていく。ズームの符号を逆にするのと同じ |
| 変形 | 縮小率 | 10 ~ 90 % | 50 | 1 段内側の複製の大きさ |
| 変形 | 回転 | -360 ~ 360 度 | 0 | 1 段ごとの回転。内側の段ほど同じ角度ずつ回り、らせんになる |
| 中心 | 中心X / 中心Y | -4000 ~ 4000 px | 0 | 入れ子が集まっていく点。オブジェクトの中央からずらす量 |
| 継ぎ目 | 継ぎ目のなじませ | 0 ~ 500 px | 0 | 各段の複製の外周を、この幅で透明へぼかして外側の段と混ぜる |
| 継ぎ目 | 枠の幅 | 0 ~ 500 px | 0 | 各段の複製の外周の内側に、この幅の枠を塗る |
| 継ぎ目 | 枠の色 | - | ffffff | |
| 品質 | 段の数 | 1 ~ 32 | 8 | 1 画素で重ねる段の数の上限。透明の多い素材で、奥の段まで透かしたいときに上げる |
| 品質 | アンチエイリアス | なし / 2x2 / 4x4 | 2x2 | 1 画素を何点で読んで平均するか。小さい段のちらつきを抑える |
| 品質 | 画像の読み方 | バイリニア / 最近傍 / バイキュービック | バイリニア | 上の「画像の読み方」を参照。最近傍の角張りをそのまま見せたいときは、アンチエイリアスを なし にする |

「継ぎ目」と「品質」のグループは、初期状態で閉じています。
継ぎ目のなじませと枠の幅は元の画像の px で数え、段と一緒に縮みます。どの段も同じ見え方になるので、ループは崩れません。

### 注意

- 内側（小さい）段が上に重なります。テキストなど透明の多い素材では、上の段の透明な所から下の段が透けて見えます
- 中心を画像の外に置くと、複製が覆わない所は透明になります
- ズーム中に小さい段がちらつくときは、アンチエイリアスを 4x4 にします
- 大きさは変えません。フィルタオブジェクトにも置けます
- 重さ: FHD・本体 2.1.13 のフィルタオブジェクトで 1 フレーム 9〜10ms。4x4・段の数 32・回転 30 で 9〜11ms

## パペット

<!-- サンプル動画 -->
<img src="samples/ShapeDistort_H/%E3%83%91%E3%83%9A%E3%83%83%E3%83%88.webp" width="480" alt="パペット@ShapeDistort_H のサンプル">

After Effectsのパペットツールに当たるものです。
絵の透明でない所から三角形の網を作り、絵に打ったピン（最大 8 本）を動かすと、絵がピンに引かれて自然に曲がります。
立ち絵・切り抜いた写真・イラストの手足や頭を、骨を組まずに数本のピンで動かします。
**`Script\Puppet_H\` のフォルダ（`puppet.mod2`）が要ります**（上の「インストール」）。

ピンの所は必ずその位置に来て、ほかの所は形をなるべく保ったまま（伸び縮みせず、回るように）曲がります。
全部のピンを同じだけ動かすと、絵は歪まずにそのまま動きます。

### 使い方

1. 立ち絵などの画像に「パペット」を追加する。
2. **ピンの数** を決め、**元の位置を打つ** をONにする。変形が止まり、ピンの元の位置のアンカーが出るので、動かしたい所（手先・頭・腰など）と、動かさずに止めておきたい所へドラッグする。
3. **元の位置を打つ** をOFFに戻す。ピンごとのアンカーが出るので、ドラッグして絵を曲げる。値は **ピンN** の **ピンNX / ピンNY** に入る。
4. 動かすときは、ピンNX / ピンNY に中間点を打つ。

**ピン 1 本を引くだけでは、絵は曲がらずに回るか平行移動します。** 曲げたいときは、根元側にピンを 2 本以上打って向きを止めてから、先のピンを引きます。

### パラメータ

#### ピン

| 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| ピンの数 | 1 ~ 8 | 3 | 使うピンの数。使わないピンの行は隠れる |
| 元の位置を打つ | ON / OFF | OFF | ONの間は変形せず、ピン・硬さピン・重なりピンの元の位置のアンカーを出す |
| ピンの元の位置 | `{x1, y1, x2, y2, …}` | `{}` | ピンの元の位置。オブジェクトの中心からの px（下が +）。元の位置を打つで入る。足りない分は決まった位置（上・下・左・右・四隅の近く） |

#### ピンのずれ

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| ピン1X / ピン1Y 〜 ピン8X / ピン8Y | -4000 ~ 4000 px | 0 | ピンを元の位置から動かす量。アンカーのドラッグで入る |

#### 付いていく（初期状態で閉じている）

| 項目 | 形 | 初期値 | 説明 |
|---|---|---|---|
| 付いていくレイヤー | `{L1, L2, …, L8}` | `{0,0,0,0,0,0,0,0}` | ピンごとに、付いていくレイヤーの番号。そのレイヤーのオブジェクトが最初の位置から画面の上で動いた分だけ、ピンも画面の上で動く。0・自分のレイヤー・オブジェクトの無いレイヤーは付いていかない |

#### 揺れ（初期状態で閉じている）

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 揺れの強さ | 0 ~ 500 px | 0 | ピンを自動で揺らす大きさ。0 で揺れない |
| 揺れの速さ | 0 ~ 20 回/秒 | 1 | 0 なら形はずれたまま止まる |
| 揺れのシード | 0 ~ 10000 | 0 | 揺れ方 |
| 揺れの効き方 | `{100, …}`（8 個） | すべて 100 | ピンごとの揺れの割合（%）。0 のピンは揺れない |

#### 硬さピン（初期状態で閉じている）

### 使用例

- **腕を振る**: 肩に 2 本、手先に 1 本。手先のピンX / Y に中間点を打つ
- **髪や服を揺らす**: 揺れの強さ=20〜40、揺れの速さ=1〜2。根元のピンの揺れの効き方を 0 にする
- **顔を曲げずに首だけ動かす**: 顔に硬さピンを置き、半径を顔の大きさにする
- **腕を胴の前へ回す**: 腕に重なりピン（前後 +）を置く

### 注意

- **フィルタオブジェクトには対応しません。** 画像を持つオブジェクト（画像・図形・テキスト・動画）に掛けます
- 曲げた絵が収まるように画像を上下・左右に広げます。広げた画像が 800 万ドットを超える所は切れます
- パペットの後ろに足したフィルタ効果は、曲げた後の絵に掛かります
- テキストの個別オブジェクトでは 1 文字ずつ、グループ制御では配下ごとに曲げます
- 付いていく・揺れの分は、アンカーの位置には出ません
- ピンの数を減らしてから元の位置を打つでドラッグすると、ピンの元の位置は今のピンの数に切り詰められます。使わなくなったピンの位置は残りません
- 網は絵の透明でない所から作ります。絵の形（透明な所）が変わる動画などでは、毎フレーム網を作り直すので重くなります
- 重さ: FHD・本体 2.1.13 で、800x1200 の絵・ピン 8 本・細かさ 30（初期値）で 1 フレーム 9〜11ms。細かさ 100 では約 19ms で、網を作る最初の 1 枚は約 100ms
- パペットは細かさ 100 で 1 フレーム約 70ms と重い（強化デバッグの素材で、FHD・本体 2.1.13 で効果ぶんを実測、2026-10-13。上の 800x1200 の絵より大きい素材の値）

## 注意（回転・放射・方向・ジグザグ）

- **ラップOFFのとき、外へずれた部分はオブジェクトの外まで描かれます**。
  その分だけオブジェクトが上下・左右に同じだけ大きくなり、中心の位置は変わりません。ラップONでは大きさは変わりません
- v1.02 は元の範囲の中だけ端の色で埋めていて、中身が内側へずれて空く所が埋まり、元の輪郭がまっすぐ残っていました。v1.03 で直しました
- フィルタオブジェクトとして使うときは、大きさを変えられないので外へは描かれません。ラップOFFでは画面の外を読む所が画面の端の色で埋まります
- v1.02 までは、フィルタオブジェクトで画面の端を読む所と、ラップONの折り返しの継ぎ目が半透明になっていました。v1.03 で直しました
- 放射で量を大きくすると、外へ伸びる分が大きくなりすぎるので、元の大きさの 4 倍の範囲までで打ち切ります。
  ランダム割合 0 なら、量 150 前後からです。それより外へ伸びる部分は切れます。とても大きいオブジェクトでは、広げた後の大きさが 1500 万ドットを超えない所までで打ち切ります
- 横長・縦長のオブジェクトでも、ずれの大きさと回転の範囲はピクセルで測るので、横と縦で同じように効きます。
  回転の範囲は真円です。v1.00 は横長のオブジェクトで横の効き方が大きすぎました。v1.01 で直しました
- 方向の縞の本数は、オブジェクトの幅・高さに対する割合で決まります。横長のオブジェクトで斜めの角度にすると、
  ずらす向きは角度どおりですが、縞の並びは角度と直角からずれます
- 旧 `ShapeDistort.anm2` / `@ShapeDistort.anm2` とは絵が一致しません
