# 2Dライティング_H

平たい素材に、立体の光と陰を足すアニメーション効果です。
2 つ入っています。

- **環境遮蔽**: 明るさかアルファを高さとみなし、くぼみ・溝・接触部に陰を落とす
- **大域照明**: 明るい所を光源にして、不透明な所で遮りながら光を周りへ広げる

YMM4のプラグイン「環境遮蔽」「輻射光」に当たるものです。
説明だけを元に作り、コードは使っていません。

`Script/@2Dライティング_H.anm2`、v1.00。

## インストール

1. `Script\@2Dライティング_H.anm2` を配置する。
2. AviUtl2を起動する。
3. HexScriptの中のフィルタ効果「環境遮蔽」「大域照明」を追加する。一覧では `環境遮蔽@2Dライティング_H` のように出る。

## 環境遮蔽

明るさを高さとみなし、周りより低い所に陰を落とします。
各画素から周りを何方向か見て、どれだけ高い所に遮られているかで陰の濃さを決めます。

### 使い方

1. 陰を付けたいオブジェクトに「環境遮蔽」を追加する。
2. **半径** で陰を探す距離、**高さ** で起伏の強さを決める。
3. 文字や図形の縁に陰を付けるなら **高さの元** を「アルファ」にする（下の「アルファを高さにするとき」）。

### パラメータ

| パラメータ | 範囲 | デフォルト | 説明 |
|-----------|------|---------|------|
| **強さ** | 0～200 | 100 | 陰の濃さ |
| **半径** | 1～500 | 32 | 陰を探す距離 |
| **高さ** | 0～1000 px | 50 | 明るさ 0→1 の起伏の高さ。大きいほど斜面が急になり、陰が濃い |
| **高さの元** | 明るさ / アルファ / 明るさとアルファ | 明るさ | 何を高さにするか。明るさとアルファは積 |
| **高さを反転** | ON / OFF | OFF | 暗い所を高くする。アルファなら透明な所を高くする |
| **方向数** | 2～16 | 8 | 周りを見る方向の数 |
| **サンプル数** | 2～32 | 8 | 1 方向あたりに見る点の数 |
| **模様の抑制** | 0～100 | 30 | 高さを先にぼかして、ベタ塗りの色の境目が段差として陰を作るのを弱める |
| **陰の色** | 色 | 000000 | |
| **合成** | 通常 / 乗算 | 通常 | 通常は陰の色へ寄せる。乗算は陰の色を掛け、明るい陰の色で色味を付けるときに使う |
| **陰だけ** | ON / OFF | OFF | 陰の色と陰の濃さだけを出す。確認用や、別のレイヤーで合成するとき |
| **外へ広げる** | ON / OFF | OFF | 透明な所にも陰を敷く。四方に半径ぶん広げる。フィルタオブジェクトでは表示されない |
| **解像度** | 等倍 / 1/2 | 1/2 | 陰を計算する解像度。1/2 で十分なことが多く、軽い |

### アルファを高さにするとき

アルファを高さにすると、**図形の中が高い台、外の透明な所が低い地面**になります。
陰ができるのは、地面の台に近い所です。

- **図形の足元に接地の陰を付ける**: 高さの元=アルファ、**外へ広げる** をON
- **図形の縁の内側に陰を付ける**: 高さの元=アルファ、**高さを反転** をON
- グループ制御に追加すると、重なり合ったオブジェクトの接する所に陰が出る

### 使用例

- **イラスト・写真に立体感**: 既定のまま、強さ=60〜100
- **文字の足元の接地の陰**: 高さの元=アルファ、半径=16〜24、高さ=40、外へ広げる=ON
- **彫り込んだ文字**: 高さの元=アルファ、高さを反転=ON、半径=12
- **色の付いた陰**: 合成=乗算、陰の色=暖色の明るめの色

### 使用時の注意

- 明るさを高さにするので、**明るい模様は盛り上がり、暗い模様はくぼむ**。文字や線画のように暗い模様の多い絵は、陰が濃く出やすい。逆にするなら高さを反転
- 高さと半径を同じ倍率で変えても、陰の形は変わらない
- 半径は元の画像の画素。拡大したオブジェクトでは、画面上の陰の幅も拡大される
- 細く急な山の頂上には、隣の斜面の陰が少し混ざる
- 重さ: 1080p のフィルタオブジェクトで、既定の設定なら 1 フレーム 13〜16ms。
  等倍・方向 16・サンプル 32 の最も重い設定では 40〜58ms で、30fps のプレビューには間に合わない

## 大域照明

明るい所を光源にして、不透明な所で遮りながら光を周りへ広げます。
光源の周りの透明な所は光そのもので光り、光源に向いた物の縁が照らされます。
ぼかして足すグローと違い、**物の向こうには光が届かず、影ができます**。

### 使い方

1. 光源と遮る物を含むオブジェクトに「大域照明」を追加する。
2. **しきい値** より明るい所が光源になる。光源の明るさは **発光の強さ**、届く距離は **到達距離**。
3. 写真やシーン全体に掛けるなら、フィルタオブジェクトに置き、**遮蔽の元** を「暗さ」、**遮蔽** を 20〜40 にする（下の「写真に掛けるとき」）。

### パラメータ

| パラメータ | 範囲 | デフォルト | 説明 |
|-----------|------|---------|------|
| **しきい値** | 0～100 | 70 | これより明るい所を光源にする。100 で光源がなくなり、環境光だけになる |
| **発光の強さ** | 0～1000 % | 100 | 光源の明るさ |
| **発光色** | 色 / 透明 | 透明 | 光の色。透明なら光源の画素の色のまま |
| **到達距離** | 1～4000 px | 400 | 光が届く距離。長いほど重くなる |
| **遮蔽** | 0～100 | 100 | 遮る物がどれだけ光を止めるか。0 で影ができない |
| **遮蔽の元** | アルファ / 暗さ | アルファ | 何を遮る物にするか。アルファは不透明な所、暗さは暗い所ほど通りにくく、写真向け |
| **面の照らし** | 0～100 | 100 | 光が届いた不透明な所を明るくする強さ |
| **縁の幅** | 0～100 px | 8 | 不透明な物の、光源に向いた縁を照らす幅。0 なら縁を照らさない |
| **空気の発光** | 0～100 | 50 | 光の届いた所に、光そのものを重ねる強さ |
| **環境光** | 0～100 | 0 | どこにでも届く一様な光。面全体を少し明るくする |
| **拡散** | 0～100 | 20 | 光をぼかして柔らかくする。段の継ぎ目の模様も隠す |
| **解像度** | 1/2 / 1/4 | 1/2 | 光を計算する解像度。1/4 で軽くなり、絵はほとんど変わらない |
| **光だけ** | ON / OFF | OFF | 元の絵を描かず、届いた光だけを出す。別のレイヤーで加算・スクリーンするとき |
| **外へ広げる** | ON / OFF | OFF | 元の画像の外にも光を出す。四方に到達距離ぶん、最大 500px 広げる。フィルタオブジェクトでは表示されない |

### 写真に掛けるとき

遮蔽の元が「アルファ」だと、全面が不透明な写真はどこも壁になり、光が広がりません。

- **遮蔽の元** を「暗さ」にする
- **遮蔽** を 20〜40 に下げる。100 のままだと暗い部屋が光を止めて、ほとんど変わらない
- 窓や照明の光を強く広げたいときは、**発光の強さ** を 200〜300 にする

### 使用例

- **ランプ・炎の光と影**: 透明の地に光源と遮る物を描き、既定のまま。影を柔らかくするなら拡散=40
- **光源の周りの光だけを足す**: 光だけ=ONにして、上のレイヤーに加算で重ねる
- **ロゴを光らせて周りへ光を漏らす**: しきい値=50、外へ広げる=ON、到達距離=200
- **写真の窓の光を部屋へ広げる**: フィルタオブジェクトに、遮蔽の元=暗さ、遮蔽=30、発光の強さ=300

### 使用時の注意

- 不透明な物の**内側には光が入らない**。照らされるのは、縁の幅で決まる光源に向いた縁と、空気の発光が重なる所だけ
- 光源になった所は、自分の光では明るくならない
- 光の量は、厳密に光線を追った値より 1〜3 割明るい。広がり方と影の位置は正しい
- 到達距離は元の画像の画素。拡大したオブジェクトでは、画面上の光の届く距離も拡大される
- 重さ: 1080p のフィルタオブジェクトで、1/2・到達距離 400 なら 1 フレーム 24〜26ms、1/4 で 14〜16ms、
  1/2・到達距離 4000 で 19ms 前後。ほかの効果と重ねると 30fps のプレビューに間に合わないことがある。重いときは 1/4 にする
