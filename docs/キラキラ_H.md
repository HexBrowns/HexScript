# キラキラ_H

掛けたオブジェクトを粒にして、**中心から放射状に弾け飛ばす**フィルタ効果です。第三者作の `@ANM1.anm2` の「キラキラ」を元にしています。

元と同じ粒を描き、**粒が全部消えたフレームでは何もしない**ようにして軽くしました。そのとき元の画像も出ません（元と同じ見た目）。設定は新しい形式の項目（トラックバー・チェック）に直してあります。

## インストール

1. `Script\キラキラ_H.anm2` を置く
2. AviUtl2 を再起動する（新しく置いたスクリプトは、再起動するまで一覧に出ません）
3. フィルタ効果の **HexScript → キラキラ_H** から追加する

## 使い方

1. 星や光の粒の図形を置き、フィルタ効果「キラキラ_H」を追加する
2. オブジェクトの先頭で粒が中心に集まり、**距離** まで弾けて飛ぶ
3. 飛ぶ速さは **速度**、止まり方は **減速度**（大きいほど最初に速く、終わりにゆっくり）で決める
4. **終点で消える** がオンなら、粒は飛び切ったところで消える

## パラメータ

### 放射

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 個数 | 1 ~ 500 | 20 | 粒の数 |
| 距離 | 0 ~ 10000 px | 300 | 粒が飛ぶ距離 |
| 速度 | 1 ~ 2000 px/秒 | 100 | 飛ぶ速さ。距離 ÷ 速度 で飛び切る |
| 出現範囲 | 0 ~ 2000 px | 0 | 粒ごとに飛ぶ距離へ足すばらつき |
| ランダム速度[-%] | 0 ~ 100 | 90 | 飛ぶ距離を粒ごとに最大この割合だけ短くする |
| 減速度 | 1 ~ 5 | 3 | 止まり方。1 で一定の速さ、大きいほど急に止まる |

### 変化

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 透過速度[%] | 0 ~ 100 | 100 | 飛ぶにつれて薄くなる度合い |
| 拡大速度[%] | -100 ~ 1000 | 0 | 飛ぶにつれて大きさを変える割合 |
| ランダム拡大[-%] | 0 ~ 100 | 0 | 大きさを粒ごとに最大この割合だけ小さくする |
| ランダム回転 | オン / オフ | オフ | 粒の向きをばらばらにする |
| 回転速度[度] | 0 ~ 3600 | 0 | 粒が回る速さのばらつき |
| 終点で消える | オン / オフ | オン | 飛び切った粒を消す |
| 乱数 | 0 ~ 1000 | 0 | 粒の並びを変える種 |

## 注意

- 元の「キラキラ」の **減速度[1-5]** は、_H では **減速度** という名前です。元から乗り換えるときは値を入れ直してください（ほかの項目は同じ名前）
- 粒の並びは乱数で決まり、同じ **乱数** でもオブジェクトごとに変わります
