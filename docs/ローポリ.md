# ローポリ背景 / ローポリ化

三角形メッシュでローポリ風の絵を作る 2 本のスクリプトです。**ローポリ背景**は乱数からグラデーションの背景を生成し、**ローポリ化**は既存のオブジェクトをローポリ調に変換します。

どちらも `@通常` と `@高速` の 2 方式を持ちます（後述）。

## インストール

1. 次の 3 ファイルを配置します。

   | ファイル | 配置先 |
   |---|---|
   | `@ローポリ背景.obj2` | `Script\` |
   | `@ローポリ化.anm2` | `Script\` |
   | `EffectUtils_Lowpoly.lua` | `Script\` |

   `EffectUtils_Lowpoly.lua` は 2 本の共有モジュールです。**これが無いと両方とも何も表示されません**（エラーは出ずに無反応になります）。

2. AviUtl2 を再起動します。「キャッシュを破棄」では反映されません。

3. メニューに次のように出ます。

   - オブジェクト追加 → **ローポリ背景** → 「通常」または「高速」
   - アニメーション効果 → **ローポリ化** → 「通常」または「高速」

## 「通常」と「高速」の選び方

どちらも同じパラメータで、絵の作り方だけが違います。**基本は「高速」を使ってください。**

| | 通常 | 高速 |
|---|---|---|
| 三角形の作り方 | ドロネー三角形分割（CPU） | 格子を対角で 2 分割（GPU） |
| 描画回数 | 三角形 256 個ごとに 1 回 | 常に 1 回 |
| セルサイズの下限 | **1920x1080 で 32 未満は効かない** | 制限なし |
| 三角形の形 | 不規則。同じ大きさの三角形が並びにくい | 格子由来。やや規則的 |
| 向いている用途 | 細かい制御が要らない静止画 | 細かいメッシュ、アニメ、4K |

「通常」は三角形の点数に上限（2200 点）があり、それを超えるとセルサイズが自動的に大きくなります。そのため 1920x1080 では**セルサイズを 32 より小さくしても絵が変わりません**。細かいメッシュが欲しいときは「高速」を使ってください。

見た目は「通常」のほうが三角形の形が不揃いで手作り感が出ます。好みで選んで構いません。

# ローポリ背景

## 使い方

1. オブジェクト追加 → **ローポリ背景** → 「高速」
2. **色1** と **色2** で全体のグラデーションを決める
3. **セルサイズ** で三角形の大きさを決める（小さいほど細かい）
4. **揺らぎ** で三角形の形の崩し具合を決める
5. **シード** を動かして、気に入る配置が出るまで探す

シードは配置を変えるだけの値です。動かしても重くなりません。

## パラメータ

### サイズ

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 画面サイズに合わせる | ON / OFF | ON | ON のとき画面全体のサイズになる。OFF にすると幅・高さが出てくる |
| 幅 | 1 ~ 8192 px | 1920 | 「画面サイズに合わせる」が OFF のときだけ有効 |
| 高さ | 1 ~ 8192 px | 1080 | 同上 |

### メッシュ

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| セルサイズ | 20 ~ 500 px | 100 | 三角形のおおよその一辺。小さいほど三角形が増える |
| 揺らぎ | 0 ~ 100 % | 40 | 0 で整然とした格子、100 で大きく崩れる |
| シード | -9999 ~ 9999 | 0 | 乱数の種。値を変えると配置が変わる |

### 色設定

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 色1 | - | `2980b9` | グラデーションの始点の色。ランダムでは 1 つ目の色 |
| 色2 | - | `8e44ad` | グラデーションの終点の色。ランダムでは 2 つ目の色 |
| 配色 | グラデーション / ランダム | グラデーション | 色1・色2 の並べ方（v3.03〜） |
| グラデ方向 | 縦 / 横 / 対角 | 縦 | 色1 から色2 へ変化する向き。配色が「グラデーション」のときだけ出る |
| 色2の割合 | 0 ~ 100 % | 50 | 色2 になる三角形の割合。配色が「ランダム」のときだけ出る |
| 中間色 | 0 ~ 100 % | 0 | 0 で色1 と色2 の 2 色だけ。上げるほど 2 色を混ぜた中間の色が増える。配色が「ランダム」のときだけ出る |
| 色相変化(±度) | 0 ~ 180 | 15 | 三角形ごとに色相をばらつかせる。**振れ幅は ±値（度）**。15 なら ±15 度 |
| 明度変化(±%) | 0 ~ 100 % | 20 | 三角形ごとに明るさをばらつかせる。**振れ幅は ±値ポイント**。20 なら ±20 ポイント |

#### 配色「ランダム」

グラデーションのような方向を持たず、**色1 と色2 が三角形ごとにばらばらに入り混じります**。

- **色2の割合**は、画面全体で見たときの 2 色の比率です。30 なら 3 割が色2、7 割が色1 になります。0 で色1 だけ、100 で色2 だけです
- **中間色**を上げると、色1 と色2 の境目の色（2 色を混ぜた色）を持つ三角形が増えます。100 にすると、ほぼすべての三角形が 2 色の間のどこかの色になります。**中間色をいくつにしても、全体の色の平均は「色2の割合」のとおりに保たれます**
- 色相変化・明度変化はグラデーションのときと同じく上乗せされます。2 色のはっきりした対比を見せたいときは、どちらも小さめ（5 前後）にしてください
- どの三角形がどちらの色になるかは**シード**で変わります
- 明転の「明ける順」を**グラデ方向**にすると、ランダム配色では**色1 の三角形から先に明けます**（中間色がある場合は色1 に近い順）
- 「通常」でメッシュアニメを ON にしても、三角形の色はちらつきません。ただし三角形の組み替わり（辺の付け替え）が起きた箇所だけは、その瞬間に色が変わります

### アニメ

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| メッシュ | ON / OFF | OFF | 三角形の頂点が円を描いて動く |
| 色相 | ON / OFF | OFF | 全体の色相が一巡する |
| 明度 | ON / OFF | OFF | 明度のばらつきが明滅する |
| ループ回数 | 1 ~ 64 | 1 | オブジェクトの尺の中で何周するか |

**ループ回数は整数周回なので、先頭と末尾が必ず繋がります。** 尺を変えても速度が自動的に合うので、ループ素材を作るときに端の処理が要りません。

### エッジ

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| エッジ表示 | ON / OFF | OFF | 三角形の輪郭線を描く |
| エッジ幅 | 0.5 ~ 5 px | 1 | 線の太さ。「エッジ表示」が ON のときだけ出る |
| エッジ色 | - | `000000` | 線の色。同上 |

### 明転（v3.02〜 / ローポリ背景のみ）

暗い状態から三角形が順番に明けてくる演出です。**三角形ごとに時間差が付く**ので、画面全体を一律にフェードするのとは違う立ち上がり方になります。**ローポリ化にはこの機能はありません。**

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 明転を使う | ON / OFF | OFF | OFF のときは v3.01 までと同じ絵になる |
| 明ける順 | ランダム / グラデ方向 / 明るい順 / 暗い順 / 中心から | ランダム | どの三角形から明けるか |
| ばらつき | 0 ~ 100 % | 60 | 0 で全部同時に明ける。大きいほど時間差が開く |
| 開始明度 | 0 ~ 100 % | 10 | 明転が始まる時点の明るさ。**100 にすると変化しません** |
| 所要時間 | 1 ~ 100 % | 50 | オブジェクトの尺に対する割合。50 なら前半で明け終わる |

**開始明度は 0 にしないほうが扱いやすいです。** 0 は純黒で、そこから淡い色へ立ち上げると輝度の跳ね上がりが大きく出ます。10 前後にすると「色相と彩度はそのままで暗いだけ」の状態から明けるので、黒を経由せずに繋がります。

**「明ける順」を明るい順にすると、グラデーションの明るい側から光が回ってくるように見えます。** 光源のない背景でも起点を作れるので、ランダムより落ち着いた印象になります。

ばらつきを上げると、全体としての立ち上がりが自然に S 字（最初と最後がゆるやか）になります。透明度フェードにイージングを掛けるのと似た効果が、設定なしで得られます。

エッジ表示と併用したとき、**「通常」ではエッジ色だけが三角形ごとの時間差を持ちません**（線の色は画面全体で 1 つのため）。「高速」では線も三角形ごとに明けます。

# ローポリ化

## 使い方

1. オブジェクトに **ローポリ化** → 「高速」を追加
2. **セルサイズ** で三角形の大きさを決める
3. 必要なら **シルエット維持** を切り替える

色は元の画像から自動的に取られます。三角形の中を 7 点サンプリングして平均した色が入ります。

## パラメータ

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| シルエット維持 | ON / OFF | ON | ON のとき元画像の形を保つ。OFF にすると三角形の境界がそのまま輪郭になる |

メッシュ・アニメ・エッジはローポリ背景と同じです。色調整だけ項目が違います。

### 色調整

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 色相変化(±度) | 0 ~ 60 | 0 | 三角形ごとに色相をばらつかせる。**振れ幅は ±値（度）** |
| 彩度変化(±%) | 0 ~ 100 % | 0 | 三角形ごとに彩度をばらつかせる。**振れ幅は ±値ポイント** |
| 明度変化(±%) | 0 ~ 100 % | 0 | 三角形ごとに明るさをばらつかせる。**振れ幅は ±値ポイント** |

初期値がすべて 0 なので、既定では元画像の色がそのまま出ます。

**シルエット維持について**: ON にすると元画像のアルファをそのまま使うため、輪郭がなめらかなまま中身だけがローポリになります。OFF にすると三角形単位でアルファが決まるので、輪郭がカクカクした「切り絵」風になります。

# 使用例

すべて 1920x1080 を想定した値です。

## 1. 解説動画の背景（落ち着いた・静止）

図やテキストを重ねる前提。色相も明度もほとんど振らないので視線を奪いません。

| 項目 | 値 |
|---|---|
| セルサイズ / 揺らぎ / シード | 150 / 25 / 0 |
| 色1 / 色2 | `2C3E50` / `34495E` |
| グラデ方向 | 縦 |
| 色相変化(±度) / 明度変化(±%) | 5 / 8 |
| アニメ | すべて OFF |
| エッジ表示 | OFF |

色1・色2 は色相が同じで明度だけ違います。三角形は 168 個と少なめです。

## 2. 演出として使う鮮やかな背景（動く）

マゼンタからシアンへ、色相差 153 度。三角形ごとに ±40 度振れます。

| 項目 | 値 |
|---|---|
| セルサイズ / 揺らぎ / シード | 45 / 70 / 7 |
| 色1 / 色2 | `E91E63` / `00BCD4` |
| グラデ方向 | 対角 |
| 色相変化(±度) / 明度変化(±%) | 40 / 12 |
| アニメ | メッシュ・色相・明度 すべて ON |
| ループ回数 | 2 |

三角形が 2016 個になるので**「高速」を使ってください**（「通常」だと描画が 8 回に分かれます）。

## 3. OP・タイトルのワイヤーフレーム調

背景を暗く潰して、エッジの線だけを見せます。ロゴの背面向け。

| 項目 | 値 |
|---|---|
| セルサイズ / 揺らぎ / シード | 90 / 65 / 12 |
| 色1 / 色2 | `0D1B2A` / `1B263B` |
| グラデ方向 | 縦 |
| 色相変化(±度) / 明度変化(±%) | 12 / 8 |
| アニメ | メッシュのみ ON |
| ループ回数 | 1 |
| エッジ表示 / エッジ幅 / エッジ色 | ON / 1.5 / `00E5FF` |

面が暗いのでシアンの線が立ちます。揺らぎ 65 でメッシュが動くと線が波打ちます。

## 4. 夜景・ダーク基調（字幕やロゴの背面）

暗い面と少し明るい面がまだらに出ます。

| 項目 | 値 |
|---|---|
| セルサイズ / 揺らぎ / シード | 80 / 55 / 3 |
| 色1 / 色2 | `252545` / `16213E` |
| グラデ方向 | 対角 |
| 色相変化(±度) / 明度変化(±%) | 10 / 25 |
| アニメ | 明度のみ ON |
| ループ回数 | 1 |

明度変化 25 は暗い側が黒に張り付きます。真っ黒な三角形が混ざるのが狙いですが、潰したくなければ 15 まで下げてください。メッシュを止めて明度だけ動かすので、形は固定のまま面がゆっくり明滅します。

## 5. パステル（商品紹介・明るいトーン）

黒文字を乗せる前提の高明度背景です。

| 項目 | 値 |
|---|---|
| セルサイズ / 揺らぎ / シード | 120 / 35 / 21 |
| 色1 / 色2 | `FCEABB` / `D3E4F7` |
| グラデ方向 | 横 |
| 色相変化(±度) / 明度変化(±%) | 20 / 10 |
| アニメ | すべて OFF |
| エッジ表示 | OFF |

クリームから淡い青へ。色相差は 168 度ありますが彩度が低いので穏やかにまとまります。元の明度が 97〜99% なので、明るい側は 1〜3 ポイントで頭打ちになります。

# 注意事項

## 色相・彩度・明度の変化量はすべて ±値です

3 つとも**入力した値がそのまま片側の振れ幅**になります。

| パラメータ | 値 | 実際の振れ幅 |
|---|---|---|
| 色相変化(±度) | 40 | ±40 度 |
| 彩度変化(±%) | 30 | ±30 ポイント |
| 明度変化(±%) | 8 | ±8 ポイント |

## 明度変化は 0% / 100% をはみ出す分だけ頭打ちになります

明度変化は元の色の明るさに**両方向へ対称に**加算され、0〜100% の外に出た分だけが切り詰められます。上方向を抑える処理は入っていません。

たとえば元の明度 93.7%（`E8ECEF`）に明度変化 8 を指定すると、上側は 93.7 → 100% の **6.3 ポイント分が効き**、はみ出す 1.7 ポイントだけが頭打ちになります。元の色より明るい三角形は普通に出ます。

頭打ちを避けたい場合は「元の明度 + 明度変化 ≦ 100」「元の明度 − 明度変化 ≧ 0」に収まる値を選んでください。明度が 100% に達した三角形は、彩度を保ったまま最も明るいチャンネルが 255 になります（`E8ECEF` なら `F8FCFF`）。彩度は下がりません。

## セルサイズの下限（「通常」のみ）

「通常」は三角形の点数に上限があるため、セルサイズを小さくしても一定より細かくなりません。1920x1080 で 32、3840x2160 で 63 が下限です。「高速」にはこの制限がありません。

## パラメータを増減したら再起動

トラックバーやチェックボックスの構成が変わった場合、「キャッシュを破棄」では反映されません。AviUtl2 の再起動が必要です。スクリプトの中身だけを変えた場合は「キャッシュを破棄」で足ります。

## 動作確認の状況

v3.00 で**「通常」「高速」とも実機で動作確認済み**です。シェーダーのコンパイルエラーは出ていません。v3.01 は項目の表示名だけを変えたもので、処理は同一です。

**v3.01 で項目名を変えたため、v3.00 で作ったプロジェクトでは「色相変化(±度)」「彩度変化(±%)」「明度変化(±%)」の 3 項目が初期値に戻ります。** AviUtl2 は項目名を設定の保存キーに使うためです（プロジェクトファイルで確認済み）。他の項目は影響を受けません。

設定し直す前に元の値を知りたい場合は、`Backup\AutoBackup_*.aup2` をテキストエディタで開いて `色相変化=` を検索してください。1 分間隔の自動バックアップに、更新前の値がそのまま残っています。

v3.02（ローポリ背景のみ）は明転の追加です。**項目を増やしただけなので、v3.01 で作ったプロジェクトの設定は保たれます。** 「明転を使う」が OFF のときは v3.01 とまったく同じ出力になることを数値で確認済みです（内部で恒等式になるよう作られています）。「通常」と「高速」で明転の計算式が一致していることも確認しています。

v3.03（ローポリ背景のみ）は配色「ランダム」の追加です。**項目を増やしただけなので、v3.02 までに作ったプロジェクトの設定は保たれます**（配色はグラデーションのまま開きます）。グラデーションのときの出力が v3.02 と同じであることは数値で確認済みです。ランダムの割合と中間色の計算は数値で確かめてありますが、**実機での見た目の確認はまだです**。

### v3.10（ローポリ背景のみ）: 乱数を作り直しました

「周囲から浮いた三角形が 1 枚だけ出る」という報告の原因が乱数にあったため、作り直しました。**設定項目は 1 つも変わっていないので、これまでに作ったプロジェクトの設定はすべて保たれます。**

ただし**同じ設定でも三角形の形と色が変わります**（シードを 0 にしていても変わります）。書き出し済みの動画と絵柄を揃えたい場合は、v3.03 のファイルを別名で残しておいてください。

直した内容は 2 つです。

- 「通常」の乱数が、実際には**一定の幅で増えていくだけの数列**になっていました。そのため色相のばらつきと明度のばらつきが連動し、**両方が同時に振り切れた三角形が 1 枚だけ周囲から浮いて見えていました**。振れ幅そのものは設定どおり ±値 に収まっていたので、「設定を超える色が出ていた」わけではありません
- 「高速」の乱数が、**シードを大きくすると壊れて**いました。シードが ±2000 を超えたあたりから乱数の種類が急に減り、±9999 付近では格子のゆらぎも色のばらつきもほとんど無くなって、規則正しい格子に戻っていました。シードを 0 付近で使っていた場合は影響が小さいはずです

いずれも数値で確認し、実機でも確かめました（2026-09-23。隣り合う大きいシードで別の絵になり、色の段数も戻りました）。

なお**ローポリ化の「通常」も、同じ共有モジュールを使っているため絵が変わります**。

### v3.10（ローポリ化）: 「高速」の乱数も直しました

ローポリ化の「高速」にも、**シードを大きくすると乱数が潰れて規則的な格子に戻り、三角形ごとの色のばらつきも消える**問題が残っていたので、ローポリ背景と同じ直し方をしました。**同じ設定でも三角形の形と色のばらつきが変わります**（シードを 0 にしていても変わります）。設定項目は変えていないので、保存済みの値はそのまま読まれます。数値で確認し、実機でも確かめました（2026-09-23。シード 9998 と 9999 で別の絵になり、明るさのばらつきも戻りました）。

## 既知の制限

- ローポリ化はフィルタとして動くので、後続のフィルタは通常どおり効きます
- 「通常」と「高速」で乱数の作り方も三角形の作り方も違うため、**同じシードでも見た目は一致しません**。仕様として許容している差なので、セクションを乗り換えたら見た目を調整し直してください
- 三角形の境界にアンチエイリアスはかかりません。輪郭を柔らかくしたい場合は、後段にぼかしを重ねてください
