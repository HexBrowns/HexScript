# ローポリ背景 / ローポリ化

三角形メッシュでローポリ風の絵を作る 2 本のスクリプトです。
**ローポリ背景**は乱数からグラデーションの背景を生成します。
**ローポリ化**は既存のオブジェクトをローポリ調に変換します。

どちらも `@通常` と `@高速` の 2 方式を持ちます。

## インストール

1. 次の 4 ファイルを配置します。

   | ファイル | 配置先 |
   |---|---|
   | `@ローポリ背景.obj2` | `Script\` |
   | `@ローポリ化.anm2` | `Script\` |
   | `EffectUtils_Lowpoly.lua` | `Script\` |
   | `EffectUtils_ColorSpace.lua` | `Script\` |

   `EffectUtils_Lowpoly.lua` は 2 本の共有モジュールです。**これが無いと両方とも何も表示されません。** エラーも出ません。

   `EffectUtils_ColorSpace.lua` は色空間の計算に使います。色空間・ばらつきの色空間を初期値のまま使うなら無くても動きます。
   無いまま初期値から変えると、ログに注意が出て、選んだ色空間が効かずに sRGB と HSV で計算する所があります。

2. AviUtl2を起動する。

3. メニューに次のように出ます。

   - オブジェクト追加 → **ローポリ背景** → 「通常」または「高速」
   - アニメーション効果 → **ローポリ化** → 「通常」または「高速」

## 「通常」と「高速」の選び方

どちらも同じパラメータで、絵の作り方だけが違います。**基本は「高速」を使ってください。**

| | 通常 | 高速 |
|---|---|---|
| 三角形の作り方 | ドロネー三角形分割 | 格子を対角で 2 分割 |
| 描画回数 | 三角形 256 個ごとに 1 回 | 常に 1 回 |
| セルサイズの下限 | **1920x1080 で 32 未満は効かない** | 制限なし |
| 三角形の形 | 不規則。同じ大きさの三角形が並びにくい | 格子由来。やや規則的 |
| 向いている用途 | 細かい制御が必要ない静止画 | 細かいメッシュ、アニメ、4K |

「通常」は三角形の点数に上限があり、それを超えるとセルサイズが自動的に大きくなります。
そのため 1920x1080 では**セルサイズを 32 より小さくしても絵が変わりません**。
細かいメッシュが欲しいときは「高速」を使ってください。

見た目は「通常」のほうが三角形の形が不揃いで手作り感が出ます。好みで選んで構いません。

## 使い方

1. オブジェクト追加 → **ローポリ背景** → 「高速」。
2. **色1** と **色2** で全体のグラデーションを決める。
3. **セルサイズ** で三角形の大きさを決める。
4. **揺らぎ** で三角形の形の崩し具合を決める。
5. **シード** を動かして、気に入る配置が出るまで探す。

シードは配置を変えるだけの値です。動かしても重くなりません。

## パラメータ

### サイズ

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 画面サイズに合わせる | ON / OFF | ON | ONのとき画面全体のサイズになる。OFFにすると幅・高さが出てくる |
| 幅 | 1 ~ 8192 px | 1920 | 「画面サイズに合わせる」がOFFのときだけ有効 |
| 高さ | 1 ~ 8192 px | 1080 | 同上 |

### メッシュ

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| セルサイズ | 20 ~ 500 px | 100 | 三角形のおおよその一辺。小さいほど三角形が増える |
| 揺らぎ | 0 ~ 100 % | 40 | 0 で整然とした格子、100 で大きく崩れる |
| シード | -9999 ~ 9999 | 0 | 乱数の種。値を変えると配置が変わる |
| 塗り方 | フラット / グーロー | フラット | 三角形の中の色の塗り方。下の「塗り方（v3.40〜）」を参照 |

#### 塗り方（v3.40〜）

| 塗り方 | 見た目 |
|---|---|
| フラット | 三角形ごとに 1 色で塗る。面の継ぎ目がはっきり見える、今までどおりのローポリ |
| グーロー | 三角形の頂点ごとに色を決め、三角形の中でなめらかに補間する。三角形の形は残したまま継ぎ目が消え、陰影がなめらかなグラデーションでつながる |

- 初期値のフラットは、塗り方を足す前の版（ローポリ背景 v3.20・ローポリ化 v3.30）と同じ絵です。保存済みのプロジェクトはそのまま開けます
- ローポリ背景のグーローでは、配色・色相変化・明度変化・明転を、三角形ごとではなく頂点ごとに決めます。配色「ランダム」も頂点ごとに色1・色2 を振り、その間をなめらかにつなぎます
- 違いがはっきり出るのは、セルサイズが大きいときと、色相変化・明度変化を大きくしたときです。セルサイズが小さいと三角形が細かくなり、どちらもなめらかに見えます
- エッジ表示は塗り方によらず同じように描きます
- グーローを選べるようにしたため、**最初に表示するフレームだけ、シェーダーの準備に今までより時間がかかります**（最大で 0.8 秒ほど）。フラットのままでも長くなることがあります

### 色設定

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 色1 | - | `2980b9` | グラデーションの始点の色。ランダムでは 1 つ目の色 |
| 色2 | - | `8e44ad` | グラデーションの終点の色。ランダムでは 2 つ目の色 |
| 配色 | グラデーション / ランダム | グラデーション | 色1・色2 の並べ方 |
| グラデ方向 | 縦 / 横 / 対角 | 縦 | 色1 から色2 へ変化する向き。配色が「グラデーション」のときだけ出る |
| 色2の割合 | 0 ~ 100 % | 50 | 色2 になる三角形の割合。配色が「ランダム」のときだけ出る |
| 中間色 | 0 ~ 100 % | 0 | 0 で色1 と色2 の 2 色だけ。上げるほど 2 色を混ぜた中間の色が増える。配色が「ランダム」のときだけ出る |
| 色空間 | sRGB / リニア / Oklab / HSV / HSL / Lab / LCh / Oklch / HWB | sRGB | 色1 と色2 を混ぜる色空間。グラデーションの途中の色と、ランダムの中間色に効く |
| 色相経路 | 短経路 / 長経路 | 短経路 | 色相を回す向き。色空間が HSV / HSL / LCh / Oklch / HWB のとき出る |
| 色相変化(±度) | 0 ~ 180 度 | 15 | 三角形ごとに色相をばらつかせる。**振れ幅は ±値**。15 なら ±15 度 |
| 明度変化(±%) | 0 ~ 100 % | 20 | 三角形ごとに明るさをばらつかせる。**振れ幅は ±値ポイント**。20 なら ±20 ポイント |
| ばらつきの色空間 | HSV / Oklch | HSV | 色相変化・明度変化を掛ける色空間。下の「色空間（v3.20〜）」を参照 |

#### 配色「ランダム」

グラデーションのような方向を持たず、**色1 と色2 が三角形ごとにばらばらに入り混じります**。

- **色2の割合**は、画面全体で見たときの 2 色の比率です。30 なら 3 割が色2、7 割が色1 になります。0 で色1 だけ、100 で色2 だけです
- **中間色**を上げると、色1 と色2 を混ぜた色を持つ三角形が増えます。100 にすると、ほぼすべての三角形が 2 色の間のどこかの色になります。**中間色をいくつにしても、全体の色の平均は「色2の割合」のとおりに保たれます**
- 色相変化・明度変化はグラデーションのときと同じく上乗せされます。2 色のはっきりした対比を見せたいときは、どちらも 5 前後の小さめの値にしてください
- どの三角形がどちらの色になるかは**シード**で変わります
- 明転の「明ける順」を**グラデ方向**にすると、ランダム配色では**色1 の三角形から先に明けます**。中間色がある場合は色1 に近い順です
- 「通常」でメッシュアニメをONにしても、三角形の色はちらつきません。ただし三角形の組み替わりが起きた箇所だけは、その瞬間に色が変わります

#### 色空間（v3.20〜）

**色空間**は、色1 と色2 の間の色を決めます。初期値の sRGB は v3.11 までと同じ色です。

| 色空間 | 向いている使い方 |
|---|---|
| sRGB | 今までと同じ混ぜ方 |
| リニア | 光の混ざり方に近い。明るい側が広がる |
| Oklab / Lab | 見た目の明るさが均等に変わる。補色の 2 色の中間がくすみにくい |
| HSV / HSL / HWB / LCh / Oklch | 色相を回して虹色にしたいとき。赤 → 青 を 短経路 にするとマゼンタを、長経路 にすると黄・緑・シアンを通る。Oklch・LCh は色相が回っても明るさがそろう |

例えば 色1 を赤、色2 をシアンにすると、中ほどは sRGB では灰色の `808080` になります。Oklab では明るく色の残った `d2a993` になります。

**ばらつきの色空間**は、色相変化・明度変化と、アニメの「色相」「明度」を掛ける色空間です。初期値の HSV は v3.11 までと同じです。

| ばらつきの色空間 | 変わり方 |
|---|---|
| HSV | 今までと同じ。色相を回すと、黄やシアンの所が明るく、青の所が暗くなる |
| Oklch | 色相を回しても明るさが変わらない。明度変化は見た目の明るさで揺らす |

色相変化を大きくしても面の明るさをそろえたいときは Oklch にします。色相変化 ±180 度で比べると、Oklch では面ごとの明るさのばらつきが HSV の半分以下になりました。
sRGB に無い色になる面は、明るさと色相を保ったまま鮮やかさを下げます。

### アニメ

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| メッシュ | ON / OFF | OFF | 三角形の頂点が円を描いて動く |
| 色相 | ON / OFF | OFF | 全体の色相が一巡する |
| 明度 | ON / OFF | OFF | 明度のばらつきが明滅する |
| ループ回数 | 1 ~ 64 | 1 | オブジェクトの尺の中で何周するか |

**ループ回数は整数周回なので、先頭と末尾が必ず繋がります。** 尺を変えても速度が自動的に合うので、ループ素材を作るときに端の処理は必要ありません。

### エッジ

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| エッジ表示 | ON / OFF | OFF | 三角形の輪郭線を描く |
| エッジ幅 | 0.5 ~ 5 px | 1 | 線の太さ。「エッジ表示」がONのときだけ出る |
| エッジ色 | - | `000000` | 線の色。同上 |

### 明転（v3.02〜 / ローポリ背景のみ）

暗い状態から三角形が順番に明けてくる演出です。
**三角形ごとに時間差が付く**ので、画面全体を一律にフェードするのとは違う立ち上がり方になります。
**ローポリ化にはこの機能はありません。**

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 明転を使う | ON / OFF | OFF | OFFのときは v3.01 までと同じ絵になる |
| 明ける順 | ランダム / グラデ方向 / 明るい順 / 暗い順 / 中心から | ランダム | どの三角形から明けるか |
| ばらつき | 0 ~ 100 % | 60 | 0 で全部同時に明ける。大きいほど時間差が開く |
| 開始明度 | 0 ~ 100 % | 10 | 明転が始まる時点の明るさ。**100 にすると変化しません** |
| 所要時間 | 1 ~ 100 % | 50 | オブジェクトの尺に対する割合。50 なら前半で明け終わる |

**開始明度は 0 にしないほうが扱いやすいです。**
0 は純黒で、そこから淡い色へ立ち上げると輝度の跳ね上がりが大きく出ます。
10 前後にすると「色相と彩度はそのままで暗いだけ」の状態から明けるので、黒を経由せずに繋がります。

**「明ける順」を明るい順にすると、グラデーションの明るい側から光が回ってくるように見えます。** 光源のない背景でも起点を作れるので、ランダムより落ち着いた印象になります。

ばらつきを上げると、全体としての立ち上がりが自然にS字になり、最初と最後がゆるやかになります。透明度フェードにイージングを掛けるのと似た効果が、設定なしで得られます。

エッジ表示と併用したとき、**「通常」ではエッジ色だけが三角形ごとの時間差を持ちません**。「高速」では線も三角形ごとに明けます。

## 使い方

1. オブジェクトに **ローポリ化** → 「高速」を追加。
2. **セルサイズ** で三角形の大きさを決める。
3. 必要なら **シルエット維持** を切り替える。

色は元の画像から自動的に取られます。三角形の中を 7 点サンプリングして平均した色が入ります。

## パラメータ

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| シルエット維持 | ON / OFF | ON | ONのとき元画像の形を保つ。OFFにすると三角形の境界がそのまま輪郭になる |

メッシュ・アニメ・エッジはローポリ背景と同じです。色調整だけ項目が違います。

メッシュの **塗り方**（v3.40〜）もローポリ背景と同じ項目です。ローポリ化のグーローでは、頂点の位置の元画像の色（頂点のまわりを平均した色）に頂点ごとのばらつきを掛け、三角形の中で補間します。
写真に掛けると、ローポリの形を残したまま元の陰影がなめらかにつながります。

### 色調整

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 色相変化(±度) | 0 ~ 60 度 | 0 | 三角形ごとに色相をばらつかせる。**振れ幅は ±値**。単位は度 |
| 彩度変化(±%) | 0 ~ 100 % | 0 | 三角形ごとに彩度をばらつかせる。**振れ幅は ±値ポイント** |
| 明度変化(±%) | 0 ~ 100 % | 0 | 三角形ごとに明るさをばらつかせる。**振れ幅は ±値ポイント** |
| ばらつきの色空間 | HSV / Oklch | HSV | 色相・彩度・明度の変化を掛ける色空間 |

初期値がすべて 0 なので、既定では元画像の色がそのまま出ます。

ばらつきの色空間はローポリ背景と同じです。Oklch にすると、色相を揺らしても面の明るさが変わりません。
彩度変化は Oklch の鮮やかさ C に掛かります。±100% で C が ±0.32 です。初期値の HSV は v3.11 までと同じです。

**シルエット維持について**: ONにすると元画像のアルファをそのまま使うため、輪郭がなめらかなまま中身だけがローポリになります。OFFにすると三角形単位でアルファが決まるので、輪郭がカクカクした「切り絵」風になります。

# 使用例

すべて 1920x1080 を想定した値です。

## 1. 解説動画の背景（落ち着いた・静止）

図やテキストを重ねる前提。色相も明度もほとんど振らないので視線を奪いません。

| 項目 | 値 |
|---|---|
| セルサイズ / 揺らぎ / シード | 150 / 25 / 0 |
| 色1 / 色2 | `2C3E50` / `34495E` |
| グラデ方向 | 縦 |
| 色相変化(±度) / 明度変化(±%) | 5 / 8 |
| アニメ | すべてOFF |
| エッジ表示 | OFF |

色1・色2 は色相が同じで明度だけ違います。三角形は 168 個と少なめです。

## 2. 演出として使う鮮やかな背景（動く）

マゼンタからシアンへ、色相差 153 度。三角形ごとに ±40 度振れます。

| 項目 | 値 |
|---|---|
| セルサイズ / 揺らぎ / シード | 45 / 70 / 7 |
| 色1 / 色2 | `E91E63` / `00BCD4` |
| グラデ方向 | 対角 |
| 色相変化(±度) / 明度変化(±%) | 40 / 12 |
| アニメ | メッシュ・色相・明度 すべてON |
| ループ回数 | 2 |

三角形が 2016 個になるので**「高速」を使ってください**。「通常」だと描画が 8 回に分かれます。

## 3. OP・タイトルのワイヤーフレーム調

背景を暗く潰して、エッジの線だけを見せます。ロゴの背面向け。

| 項目 | 値 |

| セルサイズ / 揺らぎ / シード | 90 / 65 / 12 |
| 色1 / 色2 | `0D1B2A` / `1B263B` |
| グラデ方向 | 縦 |
| 色相変化(±度) / 明度変化(±%) | 12 / 8 |
| アニメ | メッシュのみON |
| ループ回数 | 1 |
| エッジ表示 / エッジ幅 / エッジ色 | ON / 1.5 / `00E5FF` |

## 4. 夜景・ダーク基調（字幕やロゴの背面）

暗い面と少し明るい面がまだらに出ます。

| 項目 | 値 |
|---|---|
| セルサイズ / 揺らぎ / シード | 80 / 55 / 3 |
| 色1 / 色2 | `252545` / `16213E` |
| グラデ方向 | 対角 |
| 色相変化(±度) / 明度変化(±%) | 10 / 25 |
| アニメ | 明度のみON |
| ループ回数 | 1 |

## 5. パステル（商品紹介・明るいトーン）

黒文字を乗せる前提の高明度背景です。

| 項目 | 値 |
|---|---|
| セルサイズ / 揺らぎ / シード | 120 / 35 / 21 |
| 色1 / 色2 | `FCEABB` / `D3E4F7` |
| グラデ方向 | 横 |
| 色相変化(±度) / 明度変化(±%) | 20 / 10 |

# 注意事項

## 色相・彩度・明度の変化量はすべて ±値です

3 つとも**入力した値がそのまま片側の振れ幅**になります。

| パラメータ | 値 | 実際の振れ幅 |
|---|---|---|
| 色相変化(±度) | 40 | ±40 度 |
| 彩度変化(±%) | 30 | ±30 ポイント |
| 明度変化(±%) | 8 | ±8 ポイント |

## 明度変化は 0% / 100% をはみ出す分だけ頭打ちになります

明度変化は元の色の明るさに**両方向へ対称に**加算され、0〜100% の外に出た分だけが切り詰められます。上方向を抑える処理は入っていません。

たとえば `E8ECEF` は明度 93.7% です。
これに明度変化 8 を指定すると、上側は 93.7 → 100% の **6.3 ポイント分が効き**、はみ出す 1.7 ポイントだけが頭打ちになります。
元の色より明るい三角形は普通に出ます。

頭打ちを避けたい場合は「元の明度 + 明度変化 ≦ 100」「元の明度 − 明度変化 ≧ 0」に収まる値を選んでください。
明度が 100% に達した三角形は、彩度を保ったまま最も明るいチャンネルが 255 になります。`E8ECEF` なら `F8FCFF` です。
彩度は下がりません。

ここまでは、ばらつきの色空間が HSV のときの話です。Oklch のときは、明度変化を Oklab の明るさ L（0〜100%）に足し、外に出た分を切り詰めます。

## セルサイズの下限（「通常」のみ）

「通常」は三角形の点数に上限があるため、セルサイズを小さくしても一定より細かくなりません。1920x1080 で 32、3840x2160 で 63 が下限です。「高速」にはこの制限がありません。

## パラメータを増減したら再起動

トラックバーやチェックボックスの構成が変わった場合、「キャッシュを破棄」では反映されません。AviUtl2の再起動が必要です。スクリプトの中身だけを変えた場合は「キャッシュを破棄」で足ります。

## 既知の制限

- ローポリ化はフィルタとして動くので、後続のフィルタは通常どおり効きます
- 「通常」と「高速」で乱数の作り方も三角形の作り方も違うため、**同じシードでも見た目は一致しません**。仕様として許容している差なので、セクションを乗り換えたら見た目を調整し直してください
- 三角形の境界にアンチエイリアスはかかりません。輪郭を柔らかくしたい場合は、後段にぼかしを重ねてください
- 重さ（FHD・本体 2.1.13 で効果ぶんを実測）: ローポリ化「通常」は v3.30 で速くなった。既定で 1 フレーム約 7.7ms、メッシュのアニメで約 14ms、セルサイズ 10 で約 7.2ms（2026-10-14）。16384x960 の素材は v3.20 で約 560ms と重かった（v3.30 では未計測）。ローポリ背景はセルサイズ 20 で約 210ms と重い（2026-10-13）
