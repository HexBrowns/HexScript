# キーイング_H

背景を抜いた素材の仕上げに使うアニメーション効果の詰め合わせです。
1 つのファイルに 6 つの効果が入っています。

| 効果 | すること |
|---|---|
| マット調整 | 透明度の輪郭を、収縮・膨張 → エッジぼかし → レベル補正 の順で整える |
| スピル除去 | 背景色が被写体の縁や髪に回り込んだ色を取る |
| トラックマット | 別のレイヤーの明るさか透明度で、オブジェクトを型抜きする |
| 動体抽出 | 前のフレームとの差で、動いた所だけを残す |
| 同型塗りつぶし | 指定した点の色の領域と同じ形の領域を、画像の中から全部見つけて塗る |
| 光の回り込み | 抜いた素材の縁の内側に、後ろの背景の光をにじませて合成をなじませる |

- `Script/@キーイング_H.anm2`
- バージョン: マット調整 v1.01 / スピル除去 v1.01 / トラックマット v1.03 / 動体抽出 v1.00 / 同型塗りつぶし v1.00 / 光の回り込み v1.00

## インストール

1. `Script\@キーイング_H.anm2` を配置する。
2. **同型塗りつぶしを使うときは、`Script\SameShapeFill_H\` のフォルダごと `Script` フォルダの中に置く**（中に `same_shape.mod2` が入っています）。HexScript の zip に入っています。カタログから入れた場合も一緒に入ります。
3. AviUtl2を再起動する。
4. オブジェクトに、HexScriptの中の「マット調整」「スピル除去」「トラックマット」「動体抽出」「同型塗りつぶし」「光の回り込み」を追加する。

`SameShapeFill_H` のフォルダが無くても、ほかの 5 つは動きます。同型塗りつぶしだけが、ログに警告を 1 回出して何もしません。

## 使い方の流れ

クロマキーなどで背景を抜いた素材に、**マット調整 → スピル除去 → 光の回り込み** の順で重ねます。
透明度の輪郭を先に整えてから色の被りを取り、最後に新しい背景の光を縁へ回り込ませるためです。トラックマット・動体抽出・同型塗りつぶしは単独で使います。

## マット調整

透明度の輪郭だけを整えます。色そのものはぼかしません。フィルタオブジェクトにも対応しています。

### 使い方

1. 背景を抜いた素材に「マット調整」を追加する。
2. 縁に背景の色が残るなら **収縮／膨張** をマイナスにして輪郭を内側へ削る。抜けすぎて痩せたならプラスにする。
3. 輪郭が硬いときは **エッジぼかし** で柔らかくする。
4. 半透明のもやが残るときは **黒レベル** を上げる。被写体の中に薄い穴があるときは **白レベル** を下げる。

### パラメータ

#### マット形状

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 収縮／膨張 | -16 ~ 16 | 0 | マイナスで不透明な部分を内側へ削り、プラスで外側へ広げる。単位は px。1 px 単位で効き、小数部は効かない |
| エッジぼかし | 0 ~ 32 px | 0 | 輪郭の透明度をぼかす半径。単位は px。不透明な部分の色はぼけない |

#### マットレベル

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 黒レベル | 0 ~ 100 % | 0 | 不透明度がこの値 % 以下の部分を完全に透明にする |
| 白レベル | 0 ~ 100 | 100 | 不透明度がこの値以上の部分を完全に不透明にする。黒レベルとの間は直線で引き伸ばす |
| マットコントラスト | -100 ~ 100 | 0 | 半透明の部分の濃さ。プラスで薄く、マイナスで濃くなる。+100 で不透明度の 2 乗、-100 で平方根 |

- 処理の順番は **収縮／膨張 → エッジぼかし → マットレベル** で固定です
- 膨張で広がった部分には、隣の不透明な画素の色がそのまま入ります。黒い縁は出ません

### 注意

- **透明度に対する操作なので、全面が不透明な画像では何をしても見た目が変わりません。** 背景を抜いた後の、輪郭を持つ素材に使ってください
- **黒レベルが白レベル以上のときは、マットレベルの 3 項目を丸ごと使いません**
- **通常のオブジェクトでは、膨張とエッジぼかしが外枠の外まで広がります。** 膨張の量とぼかしの半径の分だけ画像の上下左右を
  透明で広げてから処理するので、外枠いっぱいまで不透明な素材でも四角の縁で切れません。広げた分だけオブジェクトの大きさが変わり、
  中心の位置は変わりません
- 収縮だけ・マットレベルだけのときは画像を広げません
- **フィルタオブジェクトでは広げません。** 画面の大きさは変えられないので、膨張とぼかしは画面の中に収まります

## スピル除去

背景色の成分が、被写体の縁や髪に回り込んで残った色を中和します。透明度は変えません。フィルタオブジェクトにも対応しています。

### 使い方

1. 背景を抜いた素材に「スピル除去」を追加する。マット調整を使うなら、その後に追加する。
2. **背景色** に抜いた背景の色を指定する。
3. 緑の服など、残したい色まで灰色になるときは **許容** をプラスにする。
4. 取った後に暗く見えるなら **明度を保つ** をONのままにする。

### パラメータ

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 背景色 | - | 00ff00 | 抜いた背景の色。R・G・Bのうち**いちばん強い成分**を、取る対象の色にする |
| 強度 | 0 ~ 100 % | 100 | 効きの強さ。0 で何もしない |
| 許容 | -100 ~ 100 | 0 | 対象の色をどこまで残すか。プラスで多く残し、マイナスで多く取る |
| バランス | 0 ~ 100 | 50 | 対象の色を下げる上限。0 で残り 2 色の小さい方、100 で大きい方、50 でその平均 |
| 明度を保つ | ON / OFF | ON | ONなら、色を取った後の明るさが元と同じになるよう 3 色をまとめて持ち上げる。100% を超える色は 100% で止まる。OFFなら取った分だけ暗くなる |

### 色の取り方

緑背景の場合、画素の緑が、赤と青からバランスで決めた上限に許容を足した値を超えている分を削ります。
上限を超えていない画素は変わらないので、赤や青が十分にある色は残ります。

- 背景色は、**どの成分がいちばん強いか**だけを見ます。正確な色を拾う必要はありません。青背景なら青っぽい色を指定すれば足ります
- R・G・Bが同じ強さの色を指定すると、赤が対象になります
- 半透明の縁でも、縁が白く浮くことはありません

## トラックマット

別のレイヤーのオブジェクトの輝度かアルファを型にして、オブジェクトを型抜きします。
フィルタオブジェクトに追加すると、画面全体をまとめて型抜きできます。

### 使い方

1. 型にしたいオブジェクトを、抜きたいオブジェクトより上のレイヤーに置く。これをマットと呼ぶ。
2. 抜きたいオブジェクトに「トラックマット」を追加する。初期値の **参照レイヤー -1** は、1 つ上のレイヤーを指す。
3. マットの白い所が残り、黒い所が消える。透明度で抜きたいときは **マット元** を「アルファ」にする。
4. マットの位置がずれるときは、下の「位置の合わせ方」のとおり **オフセットX / Y** で合わせる。

### パラメータ

| 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 参照レイヤー | -10 ~ 10 | -1 | マットにするレイヤーを、自分のレイヤー番号からの差で指定する |
| マット元 | 輝度 / アルファ | 輝度 | 輝度: マットの明るい所ほど残し、マットの透明な所は消す。アルファ: マットの不透明な所ほど残す |
| 反転 | ON / OFF | OFF | 残す所と消す所を入れ替える |
| 強度 | 0 ~ 100 % | 100 | 型抜きの効き。0 で何もしない、50 で半分だけ効く |
| エフェクト適用後を使う | ON / OFF | ON | ONならマット側のオブジェクトに付けた効果を掛けた後の画像を型にする。OFFなら効果を掛ける前の画像 |

#### 位置補正

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| オフセットX | -4000 ~ 4000 px | 0 | マットを置いたとみなす位置のX。単位は px で、プラスで右 |
| オフセットY | -4000 ~ 4000 px | 0 | マットを置いたとみなす位置のY。単位は px で、プラスで下 |

### 位置の合わせ方

マットの画像は、**画面の中央にオフセットX / Yだけずらして、等倍で置いてあるもの**とみなして重ねます。
マット側のオブジェクトの位置・拡大率・回転は見ません。

- マット側を画面の中央のX 0・Y 0、拡大率 100 に置けば、オフセットは 0 のままで合う
- マット側を動かしたときは、そのX・YをオフセットX・Yに入れると合う
- 抜く側は、標準描画のX・Yと拡大率に、トラックマットより前に掛けた効果の移動と拡大を足して合わせる。拡大率 100 以外でも合う。前の効果で動かしても、マットは画面に固定されたまま

### フィルタオブジェクトで使う

フィルタオブジェクトに「トラックマット」を追加すると、それより下のレイヤーで描いた画面全体を型抜きします。
オブジェクト追加メニューの「フィルタオブジェクト」の一覧には出ないので、フィルタオブジェクトを置いてから「フィルタ効果を追加」で足してください。

- 画面全体を、画面の中央に等倍で置いたものとして重ねます。マットを画面の中央のX 0・Y 0、拡大率 100 に置けば、オフセットは 0 のままで合う
- 参照レイヤーは、フィルタオブジェクトのレイヤー番号からの差で指定する
- 型抜きした所は透明になります。動画の背景色の上ではなく、透明のまま出力されます
- v1.02 までは、フィルタオブジェクトに追加すると処理が止まって何も起きないおそれがありました

### 注意

- マット側のレイヤーも、通常どおり画面に描かれます。上に不透明なレイヤーを重ねて隠しても、型としての読み込みには影響しません
- **マットの画像からはみ出した部分は消えます。** 反転ONなら残ります
- 抜く側の回転・中心、カメラ制御は位置合わせに入りません。回転させたオブジェクトではずれます
- トラックマットより前に掛けた効果の移動・回転・拡大・不透明度は、そのまま残ります
- マットの外周の半画素は、マットの端の濃さで読みます
- 個別オブジェクトのテキストなど、効果の側で描画するものをマットにするとうまく読めないことがあります
- 参照先を読み込めなかったとき、参照先のレイヤー番号が 1 未満になるときは、型抜きせずにそのまま表示します

## 動体抽出

前のフレームか動画ファイルの別の時刻と比べて、変わった所だけを残します。
動いた物を切り抜く・色で示す・枠で囲む、動いた所のマスクを作って別の効果に渡す、といった使い方をします。
YMM4のプラグイン「動体検知」に当たるものです。説明だけを元に作り、コードは使っていません。

### 使い方

1. **フィルタオブジェクト**を置き、「フィルタ効果を追加」で「動体抽出」を足す。それより下のレイヤーで描いた画面の動きを拾う。
2. 再生すると、動いた所だけが残る。**しきい値** で拾う動きの大きさ、**ぼかし**・**マスクの滑らかさ** で細かいノイズと穴を整える。
3. 残し方は **出力** で選ぶ。枠で囲むだけなら 出力=元のまま、**対象表示（枠）** をON。

オブジェクトに直接掛けると、そのオブジェクトの中身の変化を拾います。**オブジェクト自身の移動は拾いません。** 画面上の動きはフィルタオブジェクトで拾ってください。

### パラメータ

#### 比較

| パラメータ | 範囲 | デフォルト | 説明 |
|-----------|------|---------|------|
| **比較元** | 履歴 / 動画ファイル | 履歴 | 履歴 = 自分が前に描いたフレーム。動画ファイル = 指定した動画の別の時刻 |
| **動画ファイル** | ファイル | | 比較元 動画ファイルのときだけ |
| **比較先** | 前のフレーム / 基準の時刻 | 前のフレーム | 基準の時刻は動画ファイルのときだけ。その時刻の絵との差を取り、背景差分になる |
| **比較フレーム間隔** | 1～30 | 1 | 何フレーム前と比べるか。広げるとゆっくりした動きも拾う |
| **基準の時刻** | 0～36000 | 0 | 動画の時刻。単位は秒 |
| **動画のずれ** | -36000～36000 | 0 | 秒。動画の時刻 = オブジェクトの時刻 + これ |
| **比較元が無いとき** | 何も残さない / すべて残す | 何も残さない | 履歴で、先頭やシークの直後など比べる絵が無いとき |

#### 検出

| パラメータ | 範囲 | デフォルト | 説明 |
|-----------|------|---------|------|
| **しきい値** | 0～100 % | 10 | 明るさの差がこの % 未満の所は動いていないとみなす |
| **境界の幅** | 0～50 % | 5 | しきい値の前後をなめらかにつなぐ幅。単位は % |
| **ぼかし** | 0～50 px | 2 | 差を取る前に何 px ぼかすか。映像の細かいノイズを拾わないようにする |
| **マスクの滑らかさ** | 0～100 px | 4 | マスクを何 px ぼかしてから切り直すか。穴とギザギザを埋める |
| **強度グラデーション** | ON / OFF | OFF | 差の大きさを濃淡で出す。切り直さない |
| **色の差** | ON / OFF | OFF | 明るさだけでなく色の差も見る。明るさの同じ色の入れ替わりも拾う |
| **反転** | ON / OFF | OFF | 動いていない所を残す |

#### 対象

| パラメータ | 範囲 | デフォルト | 説明 |
|-----------|------|---------|------|
| **ノイズ除去** | 0～100000 | 0 | 面積がこの px² より小さい動きを捨てる |
| **ターゲット選択** | すべて / 面積が大きい順 / 最も近い順 | すべて | 動いた塊が複数あるとき、どれを残すか |
| **個数** | 1～32 | 1 | 残す塊の数 |
| **ターゲット座標X / Y** | -4000～4000 | 0 | 最も近い順の基準の位置。オブジェクトの中心からの px |
| **対象表示（枠）** | ON / OFF | OFF | 残した塊に枠を付ける |
| **枠の形状** | 四角 / 輪郭 | 四角 | 四角は塊を囲む矩形の外側、輪郭は塊の縁の内側。四角は 32 個まで |
| **枠の色 / 枠の太さ** | 色 / 1～20 | 30ff60 / 3 | |

#### 表示

| パラメータ | 範囲 | デフォルト | 説明 |
|-----------|------|---------|------|
| **出力** | 切り抜き / マスク / 着色 / 元のまま | 切り抜き | マスク = 不透明な白黒。着色 = 元の上に色を重ねる。元のまま = 絵は変えず、枠やグリッド画像だけ重ねる |
| **着色の色 / 着色の強さ** | 色 / 0～100 | ff3030 / 60 | 出力 着色のとき |
| **グリッド画像** | ON / OFF | OFF | 動いた範囲に画像を並べる |
| **配置する画像** | ファイル | | |
| **グリッド間隔** | 8～1000 px | 64 | 並べるマスの大きさ。単位は px。画像は縦横比を保ってマスに収める |

#### 品質

| パラメータ | 範囲 | デフォルト | 説明 |
|-----------|------|---------|------|
| **解像度** | 等倍 / 1/2 / 1/4 | 1/2 | 差を計算する解像度。出力は等倍 |

### 使用例

- **固定カメラの映像から、動いた人物だけを切り抜く**: フィルタオブジェクトに、比較元=動画ファイル・比較先=基準の時刻。基準の時刻は人のいない時刻にする。背景差分になる
- **動いた所を赤く示す**: 出力=着色
- **動いている物を枠で追う**: 出力=元のまま、対象表示（枠）=ON、ノイズ除去=500〜2000、ターゲット選択=面積が大きい順
- **動きのマスクを別の効果に使う**: 出力=マスク のフィルタオブジェクトを、画像合成（マスク）などの元にする

### 使用時の注意

- 比較元が履歴のときは**描いた順**で決まります。シーク・← キー・途中からの出力の直後のフレームは比べる絵が無く、「比較元が無いとき」に従います。再生や出力で順に進めば正しく比べます。
  シークしても同じ結果が欲しいときは、比較元を動画ファイルにする
- ぼかし・解像度・色の差・比較フレーム間隔を変えた直後のフレームも、比べる絵が無い扱いになる
- ノイズ除去・ターゲット選択・四角の枠で使う塊の判定は、4px 角の格子で行う。4px より近い 2 つの塊は 1 つとみなす
- 前のフレームは 1 つの効果につき 128MB まで持つ。等倍・色の差で比較フレーム間隔を 15 以上にすると超えるので、比べずに警告を出す。そのときは解像度を 1/2 に下げる
- 動画ファイルのときは、前に掛けた効果に関係なく動画の生の絵で比べる。マスクはオブジェクトの大きさに引き伸ばして当てる
- 重さ: 1080p のフィルタオブジェクトで、1/2 なら 1 フレーム 7ms 前後、等倍・色の差で 10〜16ms、動画ファイルで 7ms 前後

## 同型塗りつぶし

指定した点（X・Y）の色の領域と**同じ形**の領域を、画像の中から全部見つけてまとめて塗ります。
回したもの・大きさが違うものも同じ形とみなします。アイコンの並び・柄・文字の中から、同じ形のものだけを色替え・強調するのに使います。
出力をマスクにすれば、別の効果に渡す白黒の型になります。

YMM4のプラグイン「同型塗りつぶし」に当たるものです。説明だけを元に作り、コードは使っていません。
**`Script\SameShapeFill_H\` のフォルダ（`same_shape.mod2`）が要ります**（上の「インストール」）。

### 使い方

1. 図形やアイコンが並んだオブジェクトに「同型塗りつぶし」を追加する。
2. 画面に出るアンカーを、塗りたい形の 1 つの上へドラッグする（**X / Y** に値が入る）。その色の領域が見本の形になる。
3. 同じ形が全部 **塗りの色** で塗られる。拾いすぎるときは **同型許容範囲** を下げ、拾い足りないときは上げる。

### パラメータ

| パラメータ | 範囲 | デフォルト | 説明 |
|-----------|------|---------|------|
| **X / Y** | -4000～4000 | 0 | 見本の形を選ぶ位置。オブジェクトの中心からの px。アンカーで動かせる |
| **色許容範囲** | 0～255 | 15 | X・Y の位置の色とこの差までの色を、同じ領域とみなす。R・G・B・不透明度のうち差の最も大きいもので比べる |
| **同型許容範囲** | 0～100 | 20 | 形がどれだけ違っても同じとみなすか。大きいほど多くの形が一致する |
| **大きさの違い** | On/Off | On | On: 大きさが違っても同じ形なら一致。Off: 面積が近いものだけ一致 |
| **鏡像も一致** | On/Off | Off | 裏返した形も一致とみなす |
| **塗りの色** | 色 | ff4040 | |
| **不透明度** | 0～100 | 100 | 塗りの濃さ。単位は % |
| **境界ぼかし** | 0～10 | 0 | 塗った所の縁をぼかす。単位は px |
| **合成モード** | 通常 / 乗算 / スクリーン / 加算 / オーバーレイ | 通常 | 塗りの色の重ね方 |
| **領域反転** | On/Off | Off | 一致した形以外を塗る。透明な所は塗らない |
| **輝度保持** | On/Off | Off | 塗った後に元の明るさを戻す。陰影を残したまま色だけ変わる |
| **出力** | 合成 / 模様のみ / マスク | 合成 | 合成: 元の絵に塗る。模様のみ: 塗った所だけを出す。マスク: 一致した所が白、ほかが黒の不透明な画像 |
| **解像度** | 等倍 / 1/2 | 等倍 | 形を比べる解像度。1/2 は速いが、小さな形を見分けにくくなる |

### 使用時の注意

- 領域は、色が近くてつながった画素のまとまり（斜めのつながりも含む）。16 画素未満の小さなまとまりは数えない
- X・Y が透明な所や画像の外にあるときは何も塗らない。ログに警告を 1 回出す
- 色の比べ方は 8 ビットの値。アンチエイリアスの縁は外れやすいので、色許容範囲を上げるか境界ぼかしで縁を埋める
- 画像の端で切れた形は、形が変わるので一致しにくい
- 動画に掛けると毎フレーム比べ直す。同じ絵が続く間は前の結果を使い回す
- 大きさは変えない。フィルタオブジェクトにも置ける
- 重さ: FHD・本体 2.1.13・v1.01 で、図形 150 個の画像のとき、同型塗りつぶしの分は 1 フレーム 等倍 7ms 前後・1/2 で 3〜4ms（動く画像で毎フレーム比べ直す場合）。同じ絵が続く間は前の結果を使い回すので、ほとんどかからない

## 光の回り込み

キーで抜いた素材（前景）の**縁の内側に、後ろの背景をぼかした光**を足します。
別の背景に合成した素材は、縁だけが背景の光から浮いて見えます。背景の色と明るさを縁に回り込ませて、なじませます（ライトラップ）。
透明度は変えません。

### 使い方

1. 背景を前景より下のレイヤーに置く。初期値の **背景のレイヤー(相対) -1** は、1 つ下のレイヤーを指す。
2. 前景に「光の回り込み」を追加する。マット調整・スピル除去を使うなら、その後に追加する。
3. **回り込みの幅** で縁から内側へ入る幅を、**強さ** で光の量を決める。**縁だけを表示** をONにすると、足す光だけを黒の上に出して確かめられる。

### パラメータ

#### 背景の取り方

| パラメータ | 範囲 / 選択肢 | デフォルト | 説明 |
|-----------|------|---------|------|
| **背景** | レイヤー / 下の画面 | レイヤー | レイヤー: 指定したレイヤーのオブジェクトを背景にする。下の画面: それより下のレイヤーで描いた画面を背景にする。位置合わせは要らない |
| **背景のレイヤー(相対)** | -10～10 | -1 | 背景にするレイヤーを、自分のレイヤー番号からの差で指定する。背景=レイヤーのときだけ表示 |
| **エフェクト適用後を使う** | On/Off | On | Onなら背景のオブジェクトに付けた効果を掛けた後の画像を使う。背景=レイヤーのときだけ表示 |
| **背景のぼかし** | 0～100 | 20 | 背景をぼかす量。単位は px。大きいほど遠くの色まで混ざった、柔らかい光になる |

#### 回り込み

| パラメータ | 範囲 / 選択肢 | デフォルト | 説明 |
|-----------|------|---------|------|
| **回り込みの幅** | 0～100 | 12 | 縁から内側へ光が入る幅。単位は px。0 で何もしない |
| **強さ** | 0～100 | 50 | 光の量。単位は %。0 で何もしない |
| **しきい値** | 0～100 | 0 | 背景の明るさがこれより暗い所からは回り込まない。単位は % |
| **明るさの重み** | 0～100 | 50 | 0: 背景の明るさによらず同じだけ回り込む。100: 背景の明るい所ほど強く回り込む |
| **合成** | 通常 / スクリーン / 加算 | スクリーン | 通常: 縁の色を背景の色へ寄せる。スクリーン: 明るく重ねる。加算: さらに明るく足す |

| パラメータ | 範囲 | デフォルト | 説明 |
|-----------|------|---------|------|
| **縁だけを表示** | On/Off | Off | 足す光だけを、前景の形の中に黒の上で出す。調整用 |

幅とぼかしの単位は、前景のオブジェクトの画素です。拡大したオブジェクトでは、画面の上の幅も大きくなります。

### 使用例

- **グリーンバックの人物を夕景に合成**: 既定のまま。強さ=60〜80、回り込みの幅=15〜25
- **明るい窓の前の人物**: しきい値=50、明るさの重み=100。明るい所の光だけが縁に回る
- **背景が複数のレイヤーに分かれている**: 背景=下の画面

### 使用時の注意

- **フィルタオブジェクトでは使えません**（前景の縁が無いので、何もしません）
- 背景=レイヤーでは、背景のオブジェクトを、その標準描画の位置・中心・拡大率で画面に置いたものとみなして重ねる。**回転と、背景に掛けた効果による移動は見ない**。前景の回転も見ないので、回したオブジェクトではずれる
- 背景の画像の外は光が無い扱い（レイヤー）、または画面の端の色（下の画面）
- 外枠まで不透明な素材の外枠は縁と数えない。画面の下で切れた人物の下端には光が乗らない
- 背景のレイヤーが自分のレイヤー（相対 0）か、1 未満の番号になるときは何もしない
- グループ制御の配下でも、テキストの個別オブジェクトでも使える。個別オブジェクトでは字ごとに縁へ回り込む
- 重さ: FHD・本体 2.1.13 で、FHD の前景・幅 100・ぼかし 100 で 1 フレーム 9〜10ms
