# 図形グラデーション_H

図形やテキストの**形はそのままに、中身をグラデーションで塗り替える**フィルタ効果です。
中心から見た向きで色が変わる**角度グラデーション**のほか、線形・円形・矩形・ひし形・凸形・角丸矩形と、縞が繰り返すループ 4 種を選べます。

標準の「図形」に掛けるのが基本の使い方です。テキストや画像にも使えます。
色は最大 5 色で、色空間の切り替え、境目をくっきりさせる設定、合成モードもあります。

効果は 2 つあります。

| 効果 | 役割 |
|---|---|
| **描画** | グラデーションで塗る。ふつうはこれだけで足ります |
| **色設定** | パレットに番号を付けて置いておく。複数の図形で同じ色を使いたいときに使う。画像は変えません |

## インストール

1. `Script\@図形グラデーション_H.anm2` を置く。
2. AviUtl2を起動する。
3. オブジェクトの **フィルタ効果の追加** から **HexScript → 描画@図形グラデーション_H** を選ぶ。

`--filter` 対応なので、フィルタオブジェクトの後ろに付ければ画面全体にも効きます。

## 使い方

### 円に角度グラデーションを掛ける

1. 図形オブジェクトを置き、**図形の種類** を「円」にする。
2. フィルタ効果 **描画@図形グラデーション_H** を追加する。初期値で、金色からクリーム色への角度グラデーションになる。
3. **角度** で継ぎ目の位置を決める。0 で継ぎ目が真上に来て、そこから時計回りに 開始色 → 終了色 と変わる。
4. **開始色** と **終了色** を好きな色にする。色を増やすなら **色数** を上げて中間色を足す。

継ぎ目を消したいときは **折り返す** をオンにします。開始色 → 終了色 → 開始色 と一周します。

### 三角形・四角形・星型に掛ける

図形の種類を変えるだけです。
グラデーションの中心は図形の中心で、形は元の図形のまま残ります。
形に合わせたい場合は **種類** を選び直します。

- 四角形には **矩形**
- 円には **円形**
- 斜めに流したいときは **線形** と **角度**

### 流れるグラデーション

**オフセット** を時間で動かすと、グラデーションが流れます。
**繰り返し** を 2 以上にすると縞になり、オフセットを動かすと縞が流れます。
角度グラデーションでオフセットを動かすと、継ぎ目がくるくる回ります。

### 複数の図形で同じ色を使う（パレット）

1. 空いたレイヤーの**上の方**に、フィルタオブジェクトを置く。
2. そこにフィルタ効果 **色設定@図形グラデーション_H** を付け、**パレットID** と色を決める。
3. 図形に付けた **描画** の **パレットID** を同じ番号にする。

**描画** の色の設定は無視され、色設定の色で塗られます。
同じパレットを何個の図形から使ってもかまいません。
色設定を 1 か所直せば、全部の図形の色が変わります。

- 色設定は、描画と**同じ時間に存在**して、**上のレイヤー**にある必要があります。色設定が無い時間や下のレイヤーにある場合は、描画は自分の色で塗ります
- パレットで共有するのは 色数・色・透明度・位置 だけです。色空間や遷移範囲などは、描画ごとの設定が使われます

| 色空間 | 向いている使い方 |
|---|---|
| sRGB | 一般的なグラデーション |

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 遷移範囲 | 0 ~ 100 | 100 | 色と色の間で、実際に色が変わる幅。100 で全体がなめらかに変わり、0 で境目がくっきり分かれる |
| 遷移方法 | ストップに収束 / 中間の位置に収束 / 次のストップに収束 | 中間の位置に収束 | 遷移範囲が 100 未満のとき、どこで色が変わるか（区間の始め / 真ん中 / 終わり） |
| 変化の仕方 | 直線 / なめらか / イーズイン / イーズアウト | 直線 | 色と色の間の変わり方 |
| オフセット | ±1000 % | 0 | グラデーションをずらす。動かすと流れる |
| 開始位置 / 終了位置 | 0 ~ 100 % | 0 / 100 | グラデーションのどこからどこまでを使うか。開始位置 > 終了位置 で向きが逆になる |
| 繰り返し | 1 ~ 100 | 1 | 繰り返す回数（縞になる） |
| 折り返す | オン / オフ | オフ | 繰り返しごとに 開始色 → 終了色 → 開始色 と往復する。角度では継ぎ目が消える。ループ 4 種はオフでもいつも往復する（ループ 4 種のときは隠れる） |
| 反転 | オン / オフ | オフ | グラデーションの向きを逆にする |
| 段数(0で連続) | 0 ~ 256 | 0 | 2 以上で、グラデーションをこの数の段（帯）に区切る。0 と 1 は今までどおりの連続。下の「段数とディザ」を参照 |
| ディザ | なし / Bayer / ノイズ | なし | 段の境目を点の混ぜ方でつなぐ。段数が 2 以上のときだけ効く |

### 色を配列で指定（v2.12.0〜）

**色を配列で指定** をオンにすると、色を 5 色の枠でなく **最大 16 色** の並びで決められます。色の数が多いグラデーションや、同じ色の並びを別の図形・別の作品へ貼って使い回したいときに使います。

| 欄 | 書き方 | 例 |
|---|---|---|
| 色の配列 | 色を `0xRRGGBB` の 16 進で書き、カンマで区切る | `0xff0000,0xffff00,0x00ff00` |
| 透明度の配列 | 色と同じ順に 0（不透明）〜 100（透明）。足りない色は 0 | `0,0,50` |
| 位置の配列(%) | 色と同じ順に 0 〜 100 | `0,30,100` |

- 色は `0x` を付けて書いてください。欄の中身は Lua の式として読まれるので、`ff8040` のように `0x` を付けずに書くと値になりません。文字で書くときは `"ff8040"` のように引用符で囲みます（`"#ff8040"` も読めます）
- 位置の配列が空なら、色を等間隔に並べます。色より位置が少ないときも等間隔になります（ログに 1 回だけ知らせます）。位置が多いぶんは使いません
- 位置が前の色より手前でも、前の色の位置に揃います（並べ替えはしません）。同じ位置を 2 つ書くと、そこで色がくっきり切り替わります。0〜100 の外は端に収めます
- 色が 1 つだけのときは単色です（位置は無視。透明度は効きます）。17 色以上は 16 色で切ります（ログに 1 回だけ知らせます）
- 数字でない書き方の色は黒として扱います（ログに 1 回だけ知らせます）
- **オンのまま配列が空のとき**は、隠れている 色数〜終了色の欄の値で塗ります。欄が隠れているので、色を変えたいときはオフに戻してください
- 色空間・遷移範囲・変化の仕方・繰り返し・段数などは、配列の色にもそのまま効きます
- **色設定** にも同じ 4 つの欄があり、配列で作ったパレットを 描画 が使えます
- 配列を使わない設定（オフ）は、v2.11 までと同じ絵です

### 段数とディザ（v2.10〜）

**段数** を 2 以上にすると、なめらかなグラデーションが段数ぶんのはっきりした帯になります。レトロな帯のグラデーションや、色数を絞ったポスター調にしたいときに使います。

- 最初の段は開始色、最後の段は終了色で、その間の段はグラデーションの途中の色です。色空間・遷移範囲・変化の仕方を変えると、各段の色もそれに合わせて変わります
- 繰り返し・折り返しを使うと、1 回ごとに段数の帯になります

**ディザ** は、隣り合う段の境目を細かい点で混ぜ、段をつないで見せます。

| ディザ | 見た目 |
|---|---|
| なし | 段の境目がくっきり分かれる |
| Bayer | 規則正しい網目の点で混ぜる。古いゲーム機のような 8bit 調 |
| ノイズ | 不規則なざらついた点で混ぜる。網目の模様が出ない |

- ディザの点はオブジェクトに付いていて、オブジェクトと一緒に動きます
- 段数が少ない（数段〜十数段）ほど、帯とディザの点がはっきり見えます。段数を大きくすると連続に近づきます
- 初期値（段数 0・ディザ なし）は v2.02 と同じ絵です。保存済みのプロジェクトはそのまま開けます

## 多色グラデーション_H の設定を写す（v2.13.0〜）

多色グラデーション_H でできることは、描画 で同じ絵にできます。**範囲の基準 を ピクセル にし、範囲(px) に多色の 幅 を入れ**、角度・中心X・中心Y は同じ値にします。

| 多色の 形状 | 描画 の 種類 | 足す設定 |
|---|---|---|
| 線形 | 線形 | **反転** をオン（多色の線形は向きが逆） |
| 円形 | 円形 | |
| 矩形 | **ひし形** | 多色の矩形は角度 0 で菱形の向きです |
| 凸形・角丸矩形・円形ループ・矩形ループ・凸形ループ・角丸矩形ループ | 同じ名前 | 角丸矩形は 角の丸み(%) 50（初期値） |

- 補間経路 は **色相経路**、色空間の Linear sRGB は **リニア**、L\*a\*b は **Lab** です。Lab・LCh は白色点が違う（多色 D50、描画 D65）ので、中間の色が少し違います
- 多色は色と色の間を なめらか に変えます。同じにするなら **変化の仕方** を なめらか にします
- 多色の 合成モード 通常 は、描画 の 合成モード 通常 と同じ絵です。描画 の 塗り替え（形ごと透明にする）は、色が半透明だと図形も抜けます
- 多色の 幅の基準 画像サイズ は、中心から一番遠い角までを 100% とする測り方で、描画 の 画像サイズ とは違います。ピクセル にして長さを入れてください
- 図形は 1 画素を 4 点で平均するので、形の折れ目で 1〜2 階調違うことがあります

## 用途例

値は目安です。

| 表現 | 設定の例 |
|---|---|
| 見本のような円錐の円 | 図形 円 + 種類 角度・角度 -75 |
| 円グラフ風の塗り分け | 種類 角度・色数 4・遷移範囲 0 |
| 虹色のリング | 図形 円（ライン幅を細く）+ 種類 角度・色空間HSV・開始色 = 終了色 = 赤・色相経路 長経路 |
| 回るローディング表示 | 種類 角度・終了色透明度 100・角度 を 0 → 360 で直線移動 |

## 注意事項

- **効果の名称が `図形グラデーション_H` から `描画@図形グラデーション_H` に変わりました。** v1.00 で保存したプロジェクトの設定は読み込めません
- グラデーションの大きさと中心は、効果を掛けた時点のオブジェクトの大きさで決まります。先にぼかし・縁取りなどで画像が広がっていると、広がった大きさで測ります
- 合成モードが 塗り替え 以外のときも、アルファ（形）は元のオブジェクトのままです
- 色設定 は、グループ制御に追加した効果としては使わないでください。パレットが見つからないことがあります
- 色設定 と描画 は同じシーンの中で使ってください
- 36 の設定を連番画像で出力し、数値で全部確かめてあります
- 600px の図形 2 つを並べた 1920x1080 のプレビューで、1 フレーム 5.4 ms 前後、いちばん重い設定でも 15.8 ms です。30fps でも余裕があります
- **AviUtl2を起動してから初めてこの効果を描くときだけ、シェーダーの準備でプレビューが一瞬止まります。** 約 0.25 秒の見込みです。2 回目からは止まりません
- 設定項目の名称は保存データのキーなので、今後も変えません
- v2.12.0 で、パレットID・繰り返し・段数(0で連続) をトラックバーから数値入力の欄（変数項目）に替えました。名前と範囲は同じで、保存した値は引き継がれる見込みです（実機で確認中）。**ファイルを入れ替えたら AviUtl2 の再起動が要ります**
