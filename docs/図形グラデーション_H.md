# 図形グラデーション_H

図形やテキストの**形はそのままに、中身をグラデーションで塗り替える**フィルタ効果です。中心から見た向きで色が変わる**角度（円錐）グラデーション**のほか、線形・円形・矩形・ひし形を選べます。

標準の「図形」（円・四角形・三角形・五角形・六角形・星型）に掛けるのが基本の使い方で、テキストや画像にも使えます。色は最大 5 色で、色空間の切り替え、境目をくっきりさせる設定、合成モードもあります。

効果は 2 つあります。

| 効果 | 役割 |
|---|---|
| **描画** | グラデーションで塗る。ふつうはこれだけで足ります |
| **色設定** | 色の並び（パレット）に番号を付けて置いておく。複数の図形で同じ色を使いたいときに使う（画像は変えません） |

## インストール

1. `Script\@図形グラデーション_H.anm2` を置く
2. AviUtl2 を再起動する（新しく置いたスクリプトは再起動するまで一覧に出ません）
3. オブジェクトの **フィルタ効果の追加** から **HexScript → 描画@図形グラデーション_H** を選ぶ

`--filter` 対応なので、フィルタオブジェクトの後ろに付ければ画面全体にも効きます。

## 使い方

### 円に角度グラデーションを掛ける

1. 図形オブジェクトを置き、**図形の種類** を「円」にする（色は何色でもかまいません）
2. フィルタ効果 **描画@図形グラデーション_H** を追加する。初期値で、金色からクリーム色への角度グラデーションになる
3. **角度** で継ぎ目の位置を決める。0 で継ぎ目が真上に来て、そこから時計回りに 開始色 → 終了色 と変わる（-75 にすると 10 時半の少し上に継ぎ目が来る）
4. **開始色** と **終了色** を好きな色にする。色を増やすなら **色数** を上げて中間色を足す

継ぎ目を消したいときは **折り返す** をオンにします（開始色 → 終了色 → 開始色 と一周します）。

### 三角形・四角形・星型に掛ける

図形の種類を変えるだけです。グラデーションの中心は図形の中心で、形は元の図形のまま残ります。形に合わせたい場合は **種類** を選び直します。

- 四角形には **矩形**（外枠に向かって変わる）
- 円には **円形**（縁に向かって変わる）
- 斜めに流したいときは **線形** と **角度**

### 流れるグラデーション

**オフセット** を時間で動かすと（直線移動など）、グラデーションが流れます。**繰り返し** を 2 以上にすると縞になり、オフセットを動かすと縞が流れます。角度グラデーションでオフセットを動かすと、継ぎ目がくるくる回ります。

### 複数の図形で同じ色を使う（パレット）

1. 空いたレイヤーの**上の方**（レイヤー番号の小さい側）に、フィルタオブジェクトを置く
2. そこにフィルタ効果 **色設定@図形グラデーション_H** を付け、**パレットID**（例: 1）と色を決める
3. 図形に付けた **描画** の **パレットID** を同じ番号にする

**描画** の色の設定は無視され、色設定の色で塗られます。同じパレットを何個の図形から使ってもかまいません。色設定を 1 か所直せば、全部の図形の色が変わります。

- 色設定は、描画と**同じ時間に存在**して、**上のレイヤー**にある必要があります。色設定が無い時間や下のレイヤーにある場合は、描画は自分の色で塗ります
- パレットで共有するのは 色数・色・透明度・位置 だけです。色空間や遷移範囲などは、描画ごとの設定が使われます

## パラメータ（描画）

### 基本

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 種類 | 角度 / 線形 / 円形 / 矩形 / ひし形 | 角度 | グラデーションの形（下の表） |
| 合成モード | 塗り替え / 通常 / 加算 / 減算 / 乗算 / スクリーン / オーバーレイ / 比較(明) / 比較(暗) / 輝度 / 色差 / 陰影 / 明暗 / 差分 | 塗り替え | 塗り替え は中身をグラデーションに置き換える。それ以外は元の色にグラデーションを重ねる |
| 強さ | 0 ~ 100 | 100 | グラデーションの効き具合 |
| 透明な色 | 形ごと透明にする / 元の色を残す | 形ごと透明にする | 色に透明度を付けたときの扱い（塗り替え のときだけ表示）。形ごと透明にする は図形がその部分で抜け、元の色を残す は元の図形の色が透けて見える |

| 種類 | 色の変わり方 | 100% になる所 |
|---|---|---|
| 角度 | 中心から見た向き（時計回り） | 一周 |
| 線形 | 一方向。角度 0 で下 → 上、90 で左 → 右 | オブジェクトの端 |
| 円形 | 中心から外へ | オブジェクトに内接する円（楕円）の縁 |
| 矩形 | 中心から外へ四角く | オブジェクトの外枠 |
| ひし形 | 中心から外へひし形に | 上下左右の端を結ぶひし形 |

### 位置

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 角度 | ±3600 ° | 0 | 角度: 継ぎ目の向き（0 = 真上）。線形: 流れる向き。円形・矩形・ひし形: 時計回りの回転 |
| 中心X / 中心Y | ±5000 | 0 | グラデーションの中心のずれ（px。Y は下が正） |
| 中心を%で指定 | オン / オフ | オフ | 中心X / 中心Y をオブジェクトの幅・高さに対する % にする（0 が中心、50 で右端・下端） |
| 範囲の基準 | 画像サイズ / ピクセル | 画像サイズ | グラデーションの大きさを、オブジェクトの大きさに対する % で決めるか、画素数で決めるか（角度 以外） |
| 範囲 | 1 ~ 1000 % | 100 | 画像サイズのとき。グラデーションの大きさ。50 で半分の距離で終了色になる |
| 範囲(px) | 1 ~ 20000 px | 300 | ピクセルのとき。0% から 100% までの距離。線形は全長（角度を変えても同じ長さ）、円形・矩形・ひし形は中心からの半径（オブジェクトが縦長・横長でも縦横で同じ） |
| 縦横比 | ±100 | 0 | 形を潰す（円形・矩形・ひし形）。+ で横が、- で縦が縮む |
| 縦横比を回転前に掛ける | オン / オフ | オフ | オフは回転した形を潰す、オンは潰してから回す |
| 幅を角度で変えない | オン / オフ | オフ | 線形で、角度によらず 0〜100% の幅をオブジェクトの高さにする（オフだと、斜めのときは対角まで広がる）。範囲の基準がピクセルのときは、いつも角度によらないので隠れる |

### 色

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| パレットID | 0 ~ 100 | 0（使わない） | 1 以上で、同じ番号の 色設定 の色を使う |
| 色数 | 2 ~ 5 色 | 2 色 | 使う色の数。中間色の欄は必要な分だけ出る |
| 位置を等間隔にする | オン / オフ | オン | 中間色を等間隔に並べる。オフで中間色の位置を指定できる |
| 開始色 / 開始色透明度 | 色 / 0 ~ 100 | f1c85a / 0 | 0% の色 |
| 中間色1〜3 / 透明度 / 位置 | 色 / 0 ~ 100 / 0 ~ 100 % | 25 / 50 / 75 % | 途中の色。位置は前の色より手前にしても前の色の位置に揃う |
| 終了色 / 終了色透明度 | 色 / 0 ~ 100 | faf3de / 0 | 100% の色 |
| 色空間 | sRGB / リニア / Oklab / HSV / HSL / Lab / LCh / Oklch / XYZ / HWB | sRGB | 色の混ぜ方。下の表 |
| 色相経路 | 短経路 / 長経路 | 短経路 | 色相を回す向き（HSV / HSL / LCh / Oklch / HWB のとき表示） |

透明度は 0 が不透明です。透明へ向かうグラデーションでも途中の色は黒ずみません。

| 色空間 | 向いている使い方 |
|---|---|
| sRGB | 一般的なグラデーション（CSS などと同じ見え方） |
| リニア / XYZ | 光の混ざり方に近い。明るい側が広がる（XYZ はリニアと同じ結果） |
| Oklab / Lab | 見た目の明るさが均等に変わる。中間がくすみにくい |
| HSV / HSL / HWB / LCh / Oklch | 色相を回して虹色にしたいとき。赤 → 青 を 短経路 にするとマゼンタを、長経路 にすると黄・緑・シアンを通る |

色相を回す色空間で白・黒・灰色へ向かうときは、相手の色の色相のまま明るさ・鮮やかさだけが変わります（白へ向かう途中で色相が一周しません）。

### 変化

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 遷移範囲 | 0 ~ 100 | 100 | 色と色の間で、実際に色が変わる幅。100 で全体がなめらかに変わり、0 で境目がくっきり分かれる（段階的な塗り分け） |
| 遷移方法 | ストップに収束 / 中間の位置に収束 / 次のストップに収束 | 中間の位置に収束 | 遷移範囲が 100 未満のとき、どこで色が変わるか（区間の始め / 真ん中 / 終わり） |
| 変化の仕方 | 直線 / なめらか / イーズイン / イーズアウト | 直線 | 色と色の間の変わり方（それぞれの区間に掛かる） |
| オフセット | ±1000 % | 0 | グラデーションをずらす。動かすと流れる |
| 開始位置 / 終了位置 | 0 ~ 100 % | 0 / 100 | グラデーションのどこからどこまでを使うか。開始位置 > 終了位置 で向きが逆になる |
| 繰り返し | 1 ~ 100 | 1 | 繰り返す回数（縞になる） |
| 折り返す | オン / オフ | オフ | 繰り返しごとに 開始色 → 終了色 → 開始色 と往復する。角度では継ぎ目が消える |
| 反転 | オン / オフ | オフ | グラデーションの向きを逆にする |

## パラメータ（色設定）

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| パレットID | 1 ~ 100 | 1 | パレットの番号。描画 の パレットID と揃える |
| 色数・位置を等間隔にする・開始色〜終了色 | | | 描画 の同名の項目と同じ |

同じ番号の 色設定 が同じ時間に複数あると、下のレイヤーにある方が使われます。

## 用途例

値は目安です。

| 表現 | 設定の例 |
|---|---|
| 見本のような円錐の円 | 図形 円 + 種類 角度・角度 -75（初期値の色） |
| 円グラフ風の塗り分け | 種類 角度・色数 4・遷移範囲 0 |
| 虹色のリング | 図形 円（ライン幅を細く）+ 種類 角度・色空間 HSV・開始色 = 終了色 = 赤・色相経路 長経路 |
| 回るローディング表示 | 種類 角度・終了色透明度 100・角度 を 0 → 360 で直線移動 |
| 光沢のあるボタン | 図形 四角形（角を丸くする）+ 種類 線形・色数 3・変化の仕方 なめらか |
| 流れるストライプ | 種類 線形・角度 45・繰り返し 8・遷移範囲 0・オフセット を時間で動かす |
| テキストのグラデーション | テキストオブジェクト + 種類 線形・角度 0（下 → 上） |
| 長さの違う文字列で同じ幅のグラデーション | 範囲の基準 ピクセル・範囲(px) 400。文字数が変わっても色の変わり方が同じになる |
| 画像の色を染める | 合成モード 乗算・強さ 60 |

## 注意事項

- **v1.00 から効果の名前が変わりました**（`図形グラデーション_H` → `描画@図形グラデーション_H`）。v1.00 で保存したプロジェクトの設定は読み込めません（v1.00 は `oldScript\20260923_図形グラデーション_H_v1\` にあります）
- グラデーションの大きさと中心は、効果を掛けた時点のオブジェクトの大きさで決まります。先にぼかし・縁取りなどで画像が広がっていると、広がった大きさで測ります
- 合成モードが 塗り替え 以外のときも、アルファ（形）は元のオブジェクトのままです
- 色設定 は、グループ制御に追加した効果としては使わないでください（時間の照合がずれて、パレットが見つからないことがあります）
- 色設定 と描画 は同じシーンの中で使ってください（別のシーンのパレットは同じ番号でも区別されません）
- 作成時の環境（1920x1080）で、36 の設定を連番画像で出力し、数値で全部確かめてあります
- 速さの実測（600px の図形 2 つを並べた 1920x1080 のプレビュー）: 1 フレーム 5.4 ms 前後、いちばん重い設定でも 15.8 ms で、30fps でも余裕があります
- **AviUtl2 を起動してから初めてこの効果を描くときだけ、準備（シェーダーのコンパイル）でプレビューが一瞬止まります。** 2026-09-23 の軽量化で約 0.25 秒の見込みです（軽量化の前は実測で約 1 秒。軽量化の後は実機で測っていません）。2 回目からは止まりません
- 設定項目の名前は保存データのキーなので、今後も変えません

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| 一覧に出ない | AviUtl2 を再起動する |
| 最初に効果を付けたときだけプレビューが一瞬止まる | 起動後 1 回だけの準備（シェーダーのコンパイル）で、故障ではありません。2 回目からは止まりません |
| グラデーションの中心がずれる | 前に大きさを変える効果（ぼかし・縁取りなど）があると、広がった画像の中心になる。描画 をそれより前に置くか、中心X / 中心Y で直す |
| 継ぎ目が気になる | 折り返す をオンにする |
| パレットの色にならない | 色設定 が同じ時間・上のレイヤーにあるか、パレットID が同じか確かめる |
| 虹色にならない | 色空間を HSV などの色相のあるものにし、色相経路 を 長経路 にする |
| 透明にした部分で図形が欠ける | 透明な色 を「元の色を残す」にする |
| 境目がくっきりしすぎる / ぼやける | 遷移範囲 を上げる / 下げる |
| 合成モードを使い、テキストを並べたグループ制御に掛けて描き直したとき、まれにグラデーションが崩れ、ログに `invalid buffer type. name=cache:shape_gradient_h/src_…` が出る | v2.01 以前の症状。v2.02 に更新する |
