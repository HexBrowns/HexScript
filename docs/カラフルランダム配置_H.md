# カラフルランダム配置_H

図形の粒を画面の中にばらまいて置く**カスタムオブジェクト**です。第三者作の `@FIGURE.obj2` の「カラフルランダム配置」を元にしています。

元と同じ位置・色に置き、**描く前の読み込みを減らして軽くしました**。元には「個数より 1 つ多く描く」不具合があり、**_H は個数どおりに描きます**（個数 0 なら何も描きません）。元に無い機能として、**カラフルをオフにして 1 色で描けます**。

## インストール

1. `Script\カラフルランダム配置_H.obj2` を置く
2. AviUtl2 を再起動する（新しく置いたスクリプトは、再起動するまで一覧に出ません）
3. オブジェクトの追加の **カスタムオブジェクト** から **HexScript → カラフルランダム配置_H** を選ぶ

## 使い方

1. カラフルランダム配置_H を置く。オブジェクトの位置を中心に粒が散らばる
2. **個数** で粒の数、**X幅[%] / Y幅[%]** で散らばる範囲を決める（100 で画面の幅・高さいっぱい）
3. 1 色にしたいときは **カラフル** をオフにして **色** を選ぶ

## パラメータ

### 配置

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 個数 | 0 ~ 1000 | 5 | 置く粒の数 |
| X幅[%] | 0 ~ 5000 | 100 | 横に散らばる範囲。画面の幅に対する割合 |
| Y幅[%] | 0 ~ 5000 | 100 | 縦に散らばる範囲。画面の高さに対する割合 |
| Z幅[%] | 0 ~ 5000 | 0 | 奥行きに散らばる範囲 |

### 図形

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 種類 | 図形 | 円 | 粒の形 |
| サイズ | 1 ~ 2000 | 100 | 粒の大きさ |
| ライン幅 | 1 ~ 4000 | 4000 | 図形の線の太さ。4000 で塗りつぶし |
| カラフル | オン / オフ | オン | オンで粒ごとに色を変える。オフで **色** の 1 色 |
| 色 | 色 | 白 | カラフルがオフのときの色（オンのときは隠れる） |
| ランダムZ回転 | 0 ~ 3600 | 0 | 粒が回る速さのばらつき |
| ランダム拡大[-%] | 0 ~ 100 | 0 | 大きさを粒ごとに最大この割合だけ小さくする |

## 注意

- 元の「カラフルランダム配置」から乗り換えると、粒が 1 つ減ります（元の不具合で余分に描かれていた 1 粒）。ほかの粒の位置と色は同じです
- 粒の並びは乱数で決まり、オブジェクトごとに変わります
