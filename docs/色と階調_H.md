# 色と階調_H

減色（ディザ）・印刷の網点・露出オーバーの白飛び・彩度の圧縮を、オブジェクトに掛けるフィルタ効果です。
どれも本来は「少ない色で滑らかに見せる」「印刷で濃淡を出す」「明るすぎる光を画面に収める」ための処理で、
その処理が残す癖（ディザの格子模様、網点と版ずれ、色が黄から白へ飛ぶ様子）を、わざと見せて演出に使います。
彩度圧縮だけは補正用で、鮮やかすぎる色だけを自然に抑えます。

- `Script/@色と階調_H.anm2`（ディザ v1.01 / 版ずれ網点 v1.00 / 白飛び v1.00 / 彩度圧縮 v1.00）

1 つのファイルに 4 つの効果が入っています（マルチセクション）。共有モジュール（`EffectUtils_*.lua`）は使いません。

## インストール

1. `Script\@色と階調_H.anm2` を配置する
2. AviUtl2 を再起動する（新しく置いたスクリプトは、再起動するまで一覧に出ません）
3. オブジェクトのフィルタ効果の追加から **HexScript** → **ディザ@色と階調_H** / **版ずれ網点@色と階調_H** / **白飛び@色と階調_H** / **彩度圧縮@色と階調_H** を選ぶ

フィルタオブジェクトとしても置けます（画面全体に掛かります）。

## 使い方

### ディザ

<!-- サンプル動画 -->
<img src="samples/%E8%89%B2%E3%81%A8%E9%9A%8E%E8%AA%BF_H/%E3%83%87%E3%82%A3%E3%82%B6.webp" width="480" alt="ディザ@色と階調_H のサンプル">

1. 画像・動画・テキストに **ディザ@色と階調_H** を掛ける
2. **段数** を減らすほど色数が減り、模様が目立つ（2 なら各チャンネルが 0 と 1 だけ）
3. **方式** で模様の種類を選ぶ（Bayer は規則的な格子、ブルーノイズ風はざらつき、誤差拡散は細かい粒）
4. **点の大きさ** を上げると、模様の 1 点が大きくなってドット絵のようになる
5. 2 色だけの画面（携帯ゲーム機風など）にするなら、**パレット** を「2色指定」にして **暗部の色** と **明部の色** を決める

### 版ずれ網点

<!-- サンプル動画 -->
<img src="samples/%E8%89%B2%E3%81%A8%E9%9A%8E%E8%AA%BF_H/%E7%89%88%E3%81%9A%E3%82%8C%E7%B6%B2%E7%82%B9.webp" width="480" alt="版ずれ網点@色と階調_H のサンプル">

1. **版ずれ網点@色と階調_H** を掛けると、C・M・Y・K の 4 版の網点で刷ったような絵になる
2. **網の間隔** で網点の粗さを決める（値が小さいほど細かい）
3. **ずれ量** を上げると、版がずれて色がにじんだ刷り損じのようになる

### 白飛び

<!-- サンプル動画 -->
<img src="samples/%E8%89%B2%E3%81%A8%E9%9A%8E%E8%AA%BF_H/%E7%99%BD%E9%A3%9B%E3%81%B3.webp" width="480" alt="白飛び@色と階調_H のサンプル">

1. **白飛び@色と階調_H** を掛け、**露出** を上げる
2. **方式** で、明るすぎる部分の飛び方を選ぶ（初期値の「デジカメ風」は、強い光で純色が黄 → 白のように色を失って飛ぶ）

### 彩度圧縮

<!-- サンプル動画 -->
<img src="samples/%E8%89%B2%E3%81%A8%E9%9A%8E%E8%AA%BF_H/%E5%BD%A9%E5%BA%A6%E5%9C%A7%E7%B8%AE.webp" width="480" alt="彩度圧縮@色と階調_H のサンプル">

1. ギラついた素材（ネオン・原色のイラスト・彩度を上げすぎた映像）に **彩度圧縮@色と階調_H** を掛ける
2. 初期値のままで、彩度が最大の半分（**圧縮の開始** 50）を超えた色だけが下がり、いちばん鮮やかな色が最大の 80%（**上限**）に収まる
3. 抑え足りなければ **上限** を下げる。淡い色まで変わってしまうなら **圧縮の開始** を上げる
4. 効いている所を確かめるなら **圧縮される所を表示** を ON にする（下げた割合が明るさで出る。白いほど強く下げた所）

全体の彩度を一律に下げる「彩度」と違い、開始より淡い色（肌・空・背景のくすんだ色）は変わりません。

## パラメータ

### ディザ

#### 減色

| 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 方式 | Bayer2x2 / Bayer4x4 / Bayer8x8 / ブルーノイズ風 / 誤差拡散 | Bayer2x2 | 模様の種類。Bayer は格子状の規則的な模様（数字が大きいほど細かい階調）。ブルーノイズ風は格子の目立たないざらつき。誤差拡散は粒の細かい自然な模様 |
| 段数 | 2 ~ 32 | 4 | チャンネルごとの色の段数。2 なら 0 と 1 だけになる |
| パレット | 白黒 / RGB各段 / 2色指定 | RGB各段 | 白黒は明るさだけで白黒の階調にする。RGB各段は R・G・B をそれぞれ段数に減らす。2色指定は明るさを暗部の色〜明部の色の段数に減らす |
| 暗部の色 | - | 0f380f | 2色指定のときの暗い側の色。パレットが「2色指定」以外のときは隠れる |
| 明部の色 | - | 9bbc0f | 2色指定のときの明るい側の色。パレットが「2色指定」以外のときは隠れる |
| 点の大きさ | 1 ~ 64 | 1 | 模様の 1 点の大きさ（px）。2 以上にすると、その大きさのブロックごとに平均した色で減色する |
| ディザの強さ | 0 ~ 100 | 100 | 模様の強さ（%）。0 にすると模様なしの単純な減色（階調の境目が帯になる） |
| 模様を毎フレーム変える | ON / OFF | OFF | ON にすると、模様がフレームごとに変わってちらつく（同じフレームなら毎回同じ模様） |

#### 透明度ディザ

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 透明度にも掛ける | ON / OFF | OFF | 透明度も同じ模様で「完全に見える / 完全に消える」の 2 つに分ける。半透明の縁が点の集まりになる |
| 消え具合 | 0 ~ 100 | 0 | 透明度を下げてから 2 つに分ける割合（%）。上げていくと点が抜けていき、100 で全部消える。透明度にも掛けるが OFF のときは隠れる |

### 版ずれ網点

#### 網点

| 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 網の間隔 | 2 ~ 200 | 8 | 網点 1 つ分の周期（px）。**値が小さいほど網が細かく、大きいほど粗くなる**（印刷の「線数」とは向きが逆） |
| 網点の形 | 円 / 線 | 円 | 円は丸い網点（濃いところでは白い穴になる）。線は網の向きに沿った線になる |
| 墨版の量 | 0 ~ 100 | 100 | 灰色の成分を K（墨）版に置き換える割合（%）。0 にすると C・M・Y の 3 版だけで刷り、暗部が色の網点の重なりになる |
| 紙の色 | - | f4efe2 | インクの乗っていないところの色（初期値は生成り） |

#### 網角度

角度は画面の右向きから反時計回りです。

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| C版の角度 | -180 ~ 180 | 15 | シアン版の網の角度（度） |
| M版の角度 | -180 ~ 180 | 75 | マゼンタ版の網の角度（度） |
| Y版の角度 | -180 ~ 180 | 0 | イエロー版の網の角度（度） |
| K版の角度 | -180 ~ 180 | 45 | 墨版の網の角度（度） |

版どうしの角度を近づけると、網の重なりにモアレ（うねる縞）が出ます。

#### 版ずれ

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| ずれ量 | 0 ~ 200 | 0 | 版のずれの大きさ（px）。K 版を基準に、C 版は「ずれの向き」へ、M 版は逆向きへこの量だけ、Y 版は直角の向きへ半分だけずれる |
| ずれの向き | -360 ~ 360 | 0 | C 版がずれる向き（度。画面の右向きから反時計回り） |

### 白飛び

| 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 露出 | -8 ~ 8 | 1.5 | 明るさを EV で上げ下げする（+1 で明るさ 2 倍） |
| 方式 | クリップ / Reinhard / ACES / デジカメ風 | デジカメ風 | 明るすぎる部分の収め方。クリップは色相を保ったまま頭打ちにする。Reinhard と ACES は明るい部分をなだらかに圧縮する（ACES は映画調のコントラスト）。デジカメ風はチャンネルごとに頭打ちになり、強い光で純色が黄 → 白のように飛ぶ |
| 白点 | 0.1 ~ 64 | 1 | この明るさでちょうど白になる値。上げると飛びにくくなる |
| 肩の柔らかさ | 0 ~ 100 | 20 | デジカメ風で、頭打ちの手前をどれだけなだらかにするか（%）。0 で硬く切れる。方式が「デジカメ風」以外のときは隠れる |
| 線形で計算 | ON / OFF | ON | 明るさを光の量（線形）に戻してから計算する。OFF にすると画面の値のまま計算し、飛び方が強くなる |

### 彩度圧縮

開始と上限は、彩度の最大に対する割合（%）です。最大は、色空間が sRGB なら R・G・B の最大と最小の差の 1、Oklch なら C（色の強さ）の 0.3225（sRGB でいちばん鮮やかな #ff00ff の値）です。

| 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 強さ | 0 ~ 100 | 100 | 元の色との混ぜ具合（%） |
| 圧縮の開始 | 0 ~ 100 | 50 | ここより淡い色は変えない。ここを超えた分だけを抑える |
| 上限 | 0 ~ 100 | 80 | いちばん鮮やかな色が、ちょうどこの彩度になる。開始以下にすると開始で切り詰める。100 にすると何もしない |
| 曲線の硬さ | 1 ~ 4 | 1.2 | 開始から上限への曲がり方。大きいほど開始の直後は元の色に近いまま、上限の手前で強く抑える |
| 色空間 | sRGB / Oklch | Oklch | Oklch は明るさと色相を保ったまま色の強さだけを下げる（見た目の明るさが変わりにくい）。sRGB は輝度を保ったまま灰色へ寄せる |
| 圧縮される所を表示 | ON / OFF | OFF | 彩度を下げた割合を白黒で出す（黒は変えていない所、白は 100% 下げた所） |

## 使いどころ

- **レトロゲーム風の画面（MAD・モーショングラフィックス）**: ディザを パレット「2色指定」・段数 4・点の大きさ 4〜6 で映像全体（フィルタオブジェクト）に掛けると、
  携帯ゲーム機のような 4 階調の緑の画面になります。方式を Bayer4x4 にすると格子模様がはっきり出ます
- **文字の出現・消滅（キネティックタイポ）**: ディザの「透明度にも掛ける」を ON にして **消え具合** を 100 → 0 と動かすと、
  文字が点の集まりとして湧き出すように現れます。点の大きさを上げると粗いドットで出入りします
- **印刷物・コミック風の質感**: 版ずれ網点を写真やイラストに掛け、網の間隔を 12〜20 と粗めにします。ずれ量を拍に合わせて
  0 → 6 → 0 と動かすと、刷りがぶれるような衝撃の演出になります
- **閃光・露出オーバーの瞬間**: 白飛びの露出を一瞬だけ +5〜+7 まで上げると、明るい色から先に白へ飛ぶ「眩しさ」が出ます。
  デジカメ風は色が黄や水色を通って白くなり、クリップは色を保ったまま明るくなります
- **素材の彩度をそろえる**: 鮮やかさの違う素材（フリー素材のイラストと写真など）を並べるときに彩度圧縮を掛けると、
  派手な素材だけが落ち着き、淡い素材はそのまま残ります。映像全体に掛けるならフィルタオブジェクトで置きます

## 注意

- ディザの模様はオブジェクトの画像に貼り付いています。オブジェクトが動くと模様も一緒に動きます（画面に固定はされません）
- 版ずれ網点のずれ量を上げると、ずれた版がはみ出す分だけオブジェクトの大きさが広がります。
  フィルタオブジェクト（画面全体）では大きさを広げられないので、画面の端でずれた版が切れます
- 版ずれ網点は、元の色を理想的な C・M・Y・K のインクに分けて刷り直したものです。紙の色や網点の重なりで、元の絵より暗く濁って見えます
- 白飛びは 1 フレームずつの明るさの処理で、光のにじみ（グロー）は付きません。にじませたいときは、後ろに発光などの効果を重ねてください
- 彩度圧縮の Oklch では、色相によって最大の鮮やかさが違います（黄は青やマゼンタより C が小さい）。開始と上限は色相によらず同じ C で効くので、
  黄よりもマゼンタや青の方が強く抑えられます。見た目の鮮やかさに合わせた抑え方です
